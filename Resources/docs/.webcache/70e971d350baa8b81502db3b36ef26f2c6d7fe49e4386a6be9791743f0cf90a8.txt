## Network Cards

There are many different network cards. Each one has specific documentation.

### 3C90x

3com 90x, 90xB, 90xC are PCI ethernet adapters which provide full bus-master operation, download/upload packet chains. All of them allow auto-negotiation. 90xB and 90xC have power management capabilities. Many 3com cards share the programming interface with these models, an example is the [3c556](https://wiki.osdev.org/3c556 "3c556") 10/100 LAN + 56k Modem MiniPCI adapter, 3c555 10/100 LAN MiniPCI.

### DP83900/DP83901SNIC/DP83902SNIC/DP83905AT-LANTIC.

The [DP83900](https://wiki.osdev.org/DP8390 "DP8390"), [DP82901/SNIC](https://wiki.osdev.org/DP8390 "DP8390"), [DP82902/SNIC](https://wiki.osdev.org/DP8390 "DP8390"), and [DP82905 AT/LANTIC](https://wiki.osdev.org/DP8390 "DP8390") are network cards that have the same general functionality and only minor differences in there system level operation.

### NE2000

The [Ne2000](https://wiki.osdev.org/Ne2000 "Ne2000") network card chipset was a reference design that was never meant to go into mainstream production, but after Novell used it as cheap hardware to go with their software it became popular. It is a good first network card to program because it follows a simple design (making it helpful for learning), they're probably dirt-cheap, and it is supported by most PC [emulators](https://wiki.osdev.org/Emulators "Emulators"). Both [Bochs](https://wiki.osdev.org/Bochs "Bochs") and [QEMU](https://wiki.osdev.org/QEMU "QEMU") provide ISA and PCI implementations.

[Ne2000](https://wiki.osdev.org/Ne2000 "Ne2000") is not technically a card, it is a standard that several implementers follow. The best available description of the initial standard is located [DP8390D/NS32490D NIC Network Interface Controller](http://www.national.com/pf/DP/DP8390D.html) and was published by National Semiconductor.

### RTL8139

The [RTL8139](https://wiki.osdev.org/RTL8139 "RTL8139") Network Chip is used on many old Ethernet Network Devices. It supports 10 and 100 MBit.

### RTL8169

The [RTL8169](https://wiki.osdev.org/RTL8169 "RTL8169") is Realtek's next generation of high-performance network cards. This particular chipset is designed to operate at 10/100/1000 Mbps speeds.

### Broadcom BCM57xx card family

There are many ethernet cards from Broadcom, but, fortunately, they are very similar. Specifications are available on Broadcom page [BCM57785](https://docs.broadcom.com/doc/1211168564335) [BCM5718](https://docs.broadcom.com/doc/5718-PG108-R)
