                   Abstract Assembly as IR
             • Features:
               – Unlimited number of “registers” (aka “temps”)
               – May ( or may not) restrict how memory is used
               – Simple operations
               – May not restrict how constants are used
               – May specify certain “special registers”
             • Form:
               dest ← src1 operator src2              src can be:
                                                      - constant
               dest ← operator src1                   - temp
                      operator                        - special register
                                                      - memory

                       Abstract Assembly
             program := i1 i2 … in                      seq of instructions

             i        := d ← s             move
                      | d ← s 1 ⊕ s2       binop

             s        := c                 intermediate
                      | t                  temporary
                      | r                  register
             d        := t
                      | r
             ⊕        := + | - | * | / | %

                  SSA for Straight-line code
             • Give each variable a version number.
             • Scan code in program order
             • Whenever we encounter a definition,
               increment the version number
             • Whenever we encounter a use, use the
               most recently assigned version number.
                    x ←5                 x0 ← 5
                    y ←x-4               y ←x-4
                    x ←y+7               x ←y+7
                    z ←x                 z ←x

              From AST to Machine Assembly
             • Implied Approach:
               – AST → Triples using unlimited temporaries
               – Map temporaries to registers/memory
               – Lower Triples to real assembly
             • What about Interaction between registers
               and instructions?
             • Cost model?
             • KISS:
               – Keep things simple, but
               – Prepare for other passes to fix things up.
