     Metastability




▪ Flip-flop input D should not change around the rising edge of the clock to avoid
  metastability
▪ Formally, D should be a stable and valid digital value:
   ▪ For at least tSETUP before the rising edge of the clock
   ▪ For at least tHOLD after the rising edge of the clock
▪ Violating the timing constraints leaves the circuit in a metastability state. A contaminated
  value will be loaded into the register.                                                  28

Two dominant leakage models:
▪ Hamming Weight: Power consumption is proportional to the
  number of 1s in a given value.
▪ Hamming Distance: Power is proportional to the number of “bit
  flips” between two consecutive values.

  For Your Reference: CPA Pseudocode
INPUT: Set of N plaintexts M[1...N], N power traces T[1...N]
OUTPUT: Correct key byte guess K_final

1. [MEASUREMENT] Acquire power traces T while device encrypts M.
2. [PREDICTION] For each key byte hypothesis k (0 to 255):
     For each trace i (1 to N):
       a. Intermediate Value: v[i,k] = SBox(M[i] XOR k)
       b. Leakage Prediction: H[i,k] = HammingWeight(v[i,k])

3. [STATISTICAL COMPARISON] For each key hypothesis k:
     a. R[k] = CorrelationCoefficient(T[1...N], H[1...N, k])

4. [KEYGUESS] Find k that maximizes |R[k]|:
     K_final = argmax_k( |R[k]| )

Countermeasures: Hiding and Masking
Hiding: Break correlation between power consumption and performed
operations/processed values.
•      Examples: Add jitter, randomize clock frequency or execution
    timing, dual-rail pre-charge logic
    • Can sometimes be broken by advanced attack techniques.
Masking: Remove data-dependence on an algorithm level.
    • Split secret x into uniformly random shares 𝑥 = 𝑥1 ⊕ 𝑥2 ⊕ 𝑥3
      and then compute on those shares.
    • Expensive, but gives provable guarantees.

Key Takeaways

▪ Physical attacks can be used to break otherwise secure
  implementations by injecting faults or exploiting leaks
  through various side-channels
▪ Many means to achieve this primitive, with the most
  expensive giving extremely fine-grained control
▪ Protections are possible, but expensive
