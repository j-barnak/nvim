**Limine** is an advanced, portable, multiprotocol bootloader, with support for Linux, the [native Limine boot protocol](https://wiki.osdev.org/Limine_Bare_Bones "Limine Bare Bones"), and [multiboot1 and 2](https://wiki.osdev.org/Multiboot "Multiboot").

## History

Limine was created as the reference implementation for the **stivale** boot protocols. The protocols were conceived as a response to the shortcomings of [Multiboot](https://wiki.osdev.org/Multiboot "Multiboot"). As of Limine 3.x, a new boot protocol, simply called the [Limine boot protocol](https://wiki.osdev.org/Limine_Bare_Bones "Limine Bare Bones") was introduced to supersede stivale 1 and 2. As of Limine 4.x, support for the legacy stivale protocols has been dropped.

It originally only supported x86 [BIOS](https://wiki.osdev.org/BIOS "BIOS") and the stivale1 protocol, but it was later expanded to also support [UEFI](https://wiki.osdev.org/UEFI "UEFI"), the Linux and [multiboot](https://wiki.osdev.org/Multiboot "Multiboot") protocols, and other architectures such as aarch64.

## Supported protocols and filesystems

As mentioned above, Limine supports the [Limine](https://wiki.osdev.org/Limine_Bare_Bones "Limine Bare Bones") boot protocol, alongside Linux's own boot protocol (which means one can boot Linux fully using Limine), multiboot 1 and 2 (allowing it to boot a vast catalogue of hobby OSes and more), and chainloading to allow to indirectly boot unsupported operating systems such as Microsoft Windows.

It supports the [FAT12/16/32](https://wiki.osdev.org/FAT "FAT") and [ISO 9660](https://wiki.osdev.org/ISO_9660 "ISO 9660") (used by optical media and hybrid ISO images) filesystems.

## Supported Architectures

Currently Limine supports 32-bit [X86](https://wiki.osdev.org/X86 "X86") (bootloader only, not protocol), [X86-64](https://wiki.osdev.org/X86-64 "X86-64"), [aarch64](https://wiki.osdev.org/AArch64 "AArch64") (64 bit [ARM](https://wiki.osdev.org/ARM "ARM")), riscv64 (64 bit [RISC-V](https://wiki.osdev.org/RISC-V "RISC-V")), and loongarch64. 32-bit X86 support is targeted for Pentium Pro (i686) class machines as the minimum.

## How to use Limine with your kernel

The [Limine Bare Bones](https://wiki.osdev.org/Limine_Bare_Bones "Limine Bare Bones") article contains a basic tutorial on how to use Limine and its protocol. Furthermore, a Git repository containing a simple example template for a portable 64-bit kernel loaded using the Limine boot protocol can be found in the external links section.
