# Macro concat Copy item path

1.38.0 · [Source](https://doc.rust-lang.org/src/core/macros/mod.rs.html#1151)

``` rust
macro_rules! concat {
    ($($e:expr),* $(,)?) => { ... };
}
```

Expand description

Concatenates literals into a static string slice.

This macro takes any number of comma-separated literals, yielding an expression of type `&'static str` which represents all of the literals concatenated left-to-right.

Integer and floating point literals are [stringified](https://doc.rust-lang.org/std/macro.stringify.html "macro std::stringify") in order to be concatenated.

## Examples

``` rust
let s = concat!("test", 10, 'b', true);
assert_eq!(s, "test10btrue");
```
