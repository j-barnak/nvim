### class `IRCFGSimplifierSSA(IRCFGSimplifierCommon)`

Simplify an IRCFG.
The IRCF is first transformed in SSA, then apply transformations passes
and apply out-of-ssa. Final passes of IRcfgSimplifier are applied

This class apply following pass until reaching a fix point:
- do_propagate_expressions
- do_dead_simp_ssa

- **`__init__(self, lifter, expr_simp=expr_simp)`**
- **`get_forbidden_regs(self)`** - Return a set of immutable register during SSA transformation
- **`init_passes(self)`** - Init the array of simplification passes
- **`ircfg_to_ssa(self, ircfg, head)`** - Apply the SSA transformation to @ircfg using it's @head
- **`ssa_to_unssa(self, ssa, head)`** - Apply the out-of-ssa transformation to @ssa using it's @head
- **`simplify_ssa(self, ssa, _head)`** - Apply self.expr_simp on the @ssa.graph until reaching fix point
- **`do_del_unused_edges(self, ssa, head)`** - Del unused edges of the ssa graph
- **`do_propagate_expressions(self, ssa, head)`** - Expressions propagation through ExprId in the @ssa graph
- **`do_del_dummy_phi(self, ssa, head)`** - Del dummy phi
- **`do_remove_empty_assignblks(self, ssa, head)`** - Remove empty assignblks
- **`do_merge_blocks(self, ssa, head)`** - Merge blocks with one parent/son
- **`do_dead_simp_ssa(self, ssa, head)`** - Apply:
- **`do_simplify(self, ssa, head)`** - Apply passes until reaching a fix point
- **`do_simplify_loop(self, ssa, head)`** - Apply do_simplify until reaching a fix point
- **`simplify(self, ircfg, head)`** - Add access to "abi out regs" in each leaf block
