# [`pwnlib.term`](#module-pwnlib.term "pwnlib.term") — Terminal handling

pwnlib.term.can_init()[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/term.py#L25-L60)  
This function returns True iff stderr is a TTY and we are not inside a REPL. Iff this function returns True, a call to [`init()`](#pwnlib.term.init "pwnlib.term.init") will let `pwnlib` manage the terminal.

&nbsp;

pwnlib.term.init()[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/term.py#L63-L89)  
Calling this function will take over the terminal (iff [`can_init()`](#pwnlib.term.can_init "pwnlib.term.can_init") returns True) until the current python interpreter is closed.

It is on our TODO, to create a function to “give back” the terminal without closing the interpreter.

&nbsp;

pwnlib.term.term_mode* = False*[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/term.py)  
This is True exactly when we have taken over the terminal using [`init()`](#pwnlib.term.init "pwnlib.term.init").
