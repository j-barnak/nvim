### [Specification](#specification)

Here’s what we’ll add to our BASIC implementation in this tutorial:

-

  In the last tutorial, we did some prep work for [the syntax colorer](https://beautifulracket.com/basic-2/the-syntax-colorer.html). But now we’ll write it.

-

  We’ll extend our use of [exceptions](https://beautifulracket.com/appendix/glossary.html#exception) to support [better line errors](https://beautifulracket.com/basic-2/better-line-errors.html).

-

  It seems like all the trendy programming languages have them, so we’ll add [variables and input](https://beautifulracket.com/basic-2/variables-and-input.html).

-

  We’ll move beyond addition to support a wider range of mathematical [expressions](https://beautifulracket.com/basic-2/expressions.html), which will require us to consider some subtle issues about associativity and precedence of operations.

-

  We’ll extend our expressions with [conditionals](https://beautifulracket.com/basic-2/conditionals.html), including the if statement.

-

  And for the grand finale, we’ll add the trickiest BASIC commands, [gosub and for loops](https://beautifulracket.com/basic-2/subroutines-and-loops.html), making short work of them through the magic of [continuations](https://beautifulracket.com/appendix/glossary.html#continuation).

### [Setup](#setup)

We’ll start with the code we made during the first [basic](https://beautifulracket.com/basic/) tutorial. We’ll also assume that we’ve created a basic directory and installed it as a package as described in the previous [specification and setup](https://beautifulracket.com/basic/specification-and-setup.html).

But before we hit the road, let’s reorganize the project to be more modular.

basic/lexer.rkt

\#lang br
(require brag/support)

(define-lex-abbrev digits (:+ (char-set "0123456789")))

(define basic-lexer
  (lexer-srcloc
   \["\n" (token 'NEWLINE lexeme)\]
   \[whitespace (token lexeme \#:skip? \#t)\]
   \[(from/stop-before "rem" "\n") (token 'REM lexeme)\]
   \[(:or "print" "goto" "end"
         "+" ":" ";") (token lexeme lexeme)\]
   \[digits (token 'INTEGER (string-\>number lexeme))\]
   \[(:or (:seq (:? digits) "." digits)
         (:seq digits "."))
    (token 'DECIMAL (string-\>number lexeme))\]
   \[(:or (from/to "\\" "\\") (from/to "'" "'"))
    (token 'STRING
           (substring lexeme
                      1 (sub1 (string-length lexeme))))\]))

(provide basic-lexer)

    (define-lex-abbrev digits (:+ (char-set "0123456789")))

    (define basic-lexer
      (lexer-srcloc
       ["\n" (token 'NEWLINE lexeme)]

       [(:or (:seq (:? digits) "." digits)
             (:seq digits "."))
        (token 'DECIMAL (string->number lexeme))]
       [(:or (from/to "\"" "\"") (from/to "'" "'"))
        (token 'STRING
               (substring lexeme
                          1 (sub1 (string-length lexeme))))]))

    (provide basic-lexer)

We’ll trim down our [expander](https://beautifulracket.com/appendix/glossary.html#expander) module to contain only our \#%module-begin macro. Our supporting structure types will be moved into a new "struct.rkt" module. Our run function will go into "run.rkt". Everything else—i.e., the functions and macros that implement the language constructs—will be moved into a new "elements.rkt" module. We use [all-from-out](http://docs.racket-lang.org/reference/require.html#(form._((lib._racket/private/base..rkt)._all-from-out))) to re-export everything that gets imported from this module:

basic/expander.rkt

\#lang br/quicklang
(require "struct.rkt" "run.rkt" "elements.rkt")
(provide (rename-out \[b-module-begin \#%module-begin\])
         (all-from-out "elements.rkt"))

(define-macro (b-module-begin (b-program LINE ...))
  (with-pattern
      (\[((b-line NUM STMT ...) ...) \#'(LINE ...)\]
       \[(LINE-FUNC ...) (prefix-id "line-" \#'(NUM ...))\])
    #'(#%module-begin
       LINE ...
       (define line-table
         (apply hasheqv (append (list NUM LINE-FUNC) ...)))
       (void (run line-table)))))

The new "run.rkt", which relies on both "struct.rkt" and "line.rkt" (described below):

basic/run.rkt

\#lang br
(require "line.rkt" "struct.rkt")
(provide run)

(define (run line-table)
  (define line-vec
    (list-\>vector (sort (hash-keys line-table) \<)))
  (with-handlers (\[end-program-signal? (λ (exn-val) (void))\])
    (for/fold (\[line-idx 0\])
              (\[i (in-naturals)\]
               #:break (\>= line-idx (vector-length line-vec)))
      (define line-num (vector-ref line-vec line-idx))
      (define line-func (hash-ref line-table line-num))
      (with-handlers
          (\[change-line-signal?
            (λ (cls)
              (define clsv (change-line-signal-val cls))
              (or
               (and (exact-positive-integer? clsv)
                    (vector-member clsv line-vec))
               (error (format "error in line ~a: line ~a not found"
                              line-num clsv))))\])
        (line-func)
        (add1 line-idx)))))

    (define (run line-table)
      (define line-vec
        (list->vector (sort (hash-keys line-table) <)))
      (with-handlers ([end-program-signal? (λ (exn-val) (void))])
        (for/fold ([line-idx 0])
                  ([i (in-naturals)]
                   #:break (>= line-idx (vector-length line-vec)))
          (define line-num (vector-ref line-vec line-idx))
          (define line-func (hash-ref line-table line-num))
          (with-handlers
              ([change-line-signal?
                (λ (cls)
                  (define clsv (change-line-signal-val cls))
                  (or
                   (and (exact-positive-integer? clsv)
                        (vector-member clsv line-vec))
                   (error (format "error in line ~a: line ~a not found"
                                  line-num clsv))))])
            (line-func)
            (add1 line-idx)))))
