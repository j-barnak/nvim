# Function sve_tuple_create3 Copy item path

``` rust
pub unsafe fn sve_tuple_create3<SVec, SVecTup>(
    x0: SVec,
    x1: SVec,
    x2: SVec,
) -> SVecTup
```

🔬This is a nightly-only experimental API. (`core_intrinsics`)

Expand description

Create a tuple of three vectors.

`SVecTup` must be a scalable vector tuple (`#[rustc_scalable_vector]`) and `SVec` must be a scalable vector (`#[rustc_scalable_vector(N)]`). `SVecTup` must be a tuple of vectors of type `SVec`.

Corresponds to Clang’s `__builtin_sve_svcreate3*` builtins.
