# angr.utils.dynamic_dictlist

class angr.utils.dynamic_dictlist.DynamicDictList  
Bases: [`Generic`](https://docs.python.org/3/library/typing.html#typing.Generic "(in Python v3.14)")

A list-like container class that internally uses dicts to store values when the number of values is less than the threshold LIST2DICT_THRESHOLD. Keys must be ints.

The default thresholds are determined according to experiments described at [https://github.com/angr/angr/pull/3471#issuecomment-1236515950](https://github.com/angr/angr/pull/3471#issuecomment-1236515950).
