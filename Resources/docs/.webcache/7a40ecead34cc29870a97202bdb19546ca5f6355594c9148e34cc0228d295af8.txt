# Function max_by_key Copy item path

1.53.0 (const: [unstable](https://github.com/rust-lang/rust/issues/143800 "Tracking issue for const_cmp")) · [Source](https://doc.rust-lang.org/src/core/cmp.rs.html#1742-1746)

``` rust
pub fn max_by_key<T, F, K>(v1: T, v2: T, f: F) -> Twhere
    F: FnMut(&T) -> K,
    K: Ord,
```

Expand description

Returns the element that gives the maximum value from the specified function.

Returns the second argument if the comparison determines them to be equal.

## Examples

``` rust
use std::cmp;

let result = cmp::max_by_key(3, -2, |x: &i32| x.abs());
assert_eq!(result, 3);

let result = cmp::max_by_key(1, -2, |x: &i32| x.abs());
assert_eq!(result, -2);

let result = cmp::max_by_key(1, -1, |x: &i32| x.abs());
assert_eq!(result, -1);
```
