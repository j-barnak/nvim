# Type Alias c_uint Copy item path

pub type c_uint = u32;

Expand description

Equivalent to C’s `unsigned int` type.

This type will almost always be [`u32`](https://doc.rust-lang.org/std/primitive.u32.html "primitive u32"), but may differ on some esoteric systems. The C standard technically only requires that this type be an unsigned integer with the same size as an [`int`](https://doc.rust-lang.org/std/ffi/type.c_int.html "type std::ffi::c_int"); some systems define it as a [`u16`](https://doc.rust-lang.org/std/primitive.u16.html "primitive u16"), for example.
