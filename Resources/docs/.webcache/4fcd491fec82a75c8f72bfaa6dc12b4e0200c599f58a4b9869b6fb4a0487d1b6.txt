One of the main roles of an operating system is to detect hardware that can be used.

## x86

Typically, on newer [x86](https://wiki.osdev.org/X86 "X86") hardware there is [ACPI](https://wiki.osdev.org/ACPI "ACPI"), which lets the operating system to detect hardware. If there is no ACPI, then you can't do more than assume that standard buses like [PCI](https://wiki.osdev.org/PCI "PCI") exist.

After parsing the [ACPI](https://wiki.osdev.org/ACPI "ACPI") structures, you should enumerate whatever is connected to the buses and controllers found in ACPI. Then you should enumerate whatever is connected to whatever found in the first enumeration. This can include [PCI](https://wiki.osdev.org/PCI "PCI"), [PS/2 controllers](https://wiki.osdev.org/%228042%22_PS/2_Controller ""8042" PS/2 Controller"), or whatever.

For example, after scanning the [ACPI](https://wiki.osdev.org/ACPI "ACPI") structures, you will typically find some form of [PCI](https://wiki.osdev.org/PCI "PCI"). Then you find [USB](https://wiki.osdev.org/USB "USB") host controllers connected to PCI. Then you might find external [ATA](https://wiki.osdev.org/ATA "ATA") hard disks, [SCSI](https://wiki.osdev.org/SCSI "SCSI") flash drives, or printers, or mice, or whatever, which are connected to USB host controllers.

A rule of thumb when initialising devices is to start from those that are less likely to be emulated, for example you need to initialise [USB](https://wiki.osdev.org/USB "USB") host controllers before initialising the [PS/2 controller](https://wiki.osdev.org/%228042%22_PS/2_Controller ""8042" PS/2 Controller"), as the latter is more likely to be emulated through USB Legacy Support.
