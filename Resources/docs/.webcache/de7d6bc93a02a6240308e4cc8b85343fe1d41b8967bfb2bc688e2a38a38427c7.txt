# miasm.analysis.ssa

## Classes

### class `SSA(object)`

Generic class for static single assignment (SSA) transformation

Handling of
- variable generation
- variable renaming
- conversion of an IRCFG block into SSA

Variables will be renamed to <variable>.<index>, whereby the
index will be increased in every definition of <variable>.

Memory expressions are stateless. The addresses are in SSA form,
but memory aliasing will occur. For instance, if it holds
that RAX == RBX.0 + (-0x8) and

@64[RBX.0 + (-0x8)] = RDX
RCX.0 = @64[RAX],

then it cannot be tracked that RCX.0 == RDX.

- **`__init__(self, ircfg)`** - Initialises generic class for SSA
- **`get_regs(self, expr)`**
- **`transform(self, *args, **kwargs)`** - Transforms into SSA
- **`get_block(self, loc_key)`** - Returns an IRBlock
- **`reverse_variable(self, ssa_var)`** - Transforms a variable in SSA form into non-SSA form
- **`reset(self)`** - Resets SSA transformation
- **`_gen_var_expr(self, expr, stack)`** - Generates a variable expression in SSA form
- **`_transform_var_rhs(self, ssa_var)`** - Transforms a variable on the right hand side into SSA
- **`_transform_var_lhs(self, expr)`** - Transforms a variable on the left hand side into SSA
- **`_transform_expression_lhs(self, dst)`** - Transforms an expression on the left hand side into SSA
- **`_transform_expression_rhs(self, src)`** - Transforms an expression on the right hand side into SSA
- **`_parallel_instructions(assignblk)`** - Extracts the instruction from a AssignBlock.
- **`_convert_block(irblock, ssa_list)`** - Transforms an IRBlock inplace into SSA
- **`_rename_expressions(self, loc_key)`** - Transforms variables and expressions

### class `SSABlock(SSA)`

SSA transformation on block level

It handles
- transformation of a single IRBlock into SSA
- reassembling an SSA expression into a non-SSA
  expression through iterative resolving of the RHS

- **`transform(self, loc_key)`** - Transforms a block into SSA form
- **`reassemble_expr(self, expr)`** - Reassembles an expression in SSA form into a solely non-SSA expression

### class `SSAPath(SSABlock)`

SSA transformation on path level

It handles
- transformation of a path of IRBlocks into SSA

- **`transform(self, path)`** - Transforms a path into SSA

### class `SSADiGraph(SSA)`

SSA transformation on DiGraph level

It handles
- transformation of a DiGraph into SSA
- generation, insertion and filling of phi nodes

The implemented SSA form is known as minimal SSA.

- **`__init__(self, ircfg)`** - Initialises SSA class for directed graphs
- **`transform(self, head)`** - Transforms into SSA
- **`reset(self)`** - Resets SSA transformation
- **`_init_variable_defs(self, head)`** - Initialises all variable definitions and
- **`_place_phi(self, head)`** - For all blocks, empty phi functions will be placed for every
- **`_gen_empty_phi(self, expr)`** - Generates an empty phi function for a variable
- **`_fill_phi(self, *args)`** - Fills a phi function with variables.
- **`_rename(self, head)`** - Transforms each variable expression in the CFG into SSA
- **`_rename_phi_lhs(self, loc_key)`** - Transforms phi function's expressions of an IRBlock
- **`_rename_phi_rhs(self, successor)`** - Transforms the right hand side of each successor's phi function
- **`_insert_phi(self)`** - Inserts phi functions into the list of SSA expressions
- **`_convert_phi(self)`** - Inserts corresponding phi functions inplace
- **`_fix_no_def_var(self, head)`** - Replace phi source variables which are not ssa vars by ssa vars.

## Functions

### `sanitize_graph_head(ircfg, head)`

In multiple algorithm, the @head of the ircfg may not have predecessors.
The function transform the @ircfg in order to ensure this property
@ircfg: IRCFG instance
@head: the location of the graph's head

### `irblock_has_phi(irblock)`

Return True if @irblock has Phi assignments
@irblock: IRBlock instance

### `get_var_assignment_src(ircfg, node, variables)`

Return the variable of @variables which is written by the irblock at @node
@node: Location
@variables: a set of variable to test

### `get_phi_sources_parent_block(ircfg, loc_key, sources)`

Return a dictionary linking a variable to it's direct parent label
which belong to a path which affects the node.
@loc_key: the starting node
@sources: set of variables to resolve
