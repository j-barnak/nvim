# Overview

MMX is a SIMD technology (single instruction, multiple data) introduced by Intel on January 8, 1997 with their P5 "Pentium" processor line named "Pentium with MMX Technology". It has been superseded by [SSE](https://wiki.osdev.org/SSE "SSE") and now [AVX](https://wiki.osdev.org/AVX "AVX").

## Technical Details

MMX is accessed using 8 CPU registers (MM0 to MM7). Each register is 64 bits wide and can be used to hold 64-bit integers or multiple smaller integers packed. One instruction can be applied to two 32-bit integers, four 16-bit integers, or 8 8-bit integers at once.

## Detection

The bit for MMX can be found on CPUID page 1, in EDX bit 23.

# Current status

MMX has been long made obsolete by the [SSE](https://wiki.osdev.org/SSE "SSE") and [AVX](https://wiki.osdev.org/AVX "AVX") SIMD extensions, however for compatibility modern x86 CPUs still support this instruction set.
