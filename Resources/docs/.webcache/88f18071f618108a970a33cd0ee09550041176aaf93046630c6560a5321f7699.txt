# [`pwnlib.term.readline`](#module-pwnlib.term.readline "pwnlib.term.readline") — Terminal nice readline

pwnlib.term.readline.eval_input(*prompt=''*, *float=True*)[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/term/readline.py#L455-L479)  
Replacement for the built-in python 2 - style `input` using `pwnlib` readline implementation, and pwnlib.util.safeeval.expr instead of `eval` (!).

Parameters:  
- **prompt** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – The prompt to show to the user.

- **float** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – If set to `True`, prompt and input will float to the bottom of the screen when term.term_mode is enabled.

Example

    >>> try:
    ...     saved = sys.stdin, pwnlib.term.term_mode
    ...     pwnlib.term.term_mode = False
    ...     sys.stdin = io.TextIOWrapper(io.BytesIO(b"{'a': 20}"))
    ...     eval_input("Favorite object? ")['a']
    ... finally:
    ...     sys.stdin, pwnlib.term.term_mode = saved
    Favorite object? 20
