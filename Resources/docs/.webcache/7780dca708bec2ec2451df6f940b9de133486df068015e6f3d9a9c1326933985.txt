Smaller C is a simple and small single-pass C compiler, currently supporting most of the C language common between C89/ANSI C and C99 (minus some C89 and plus some C99 features). It generates code for the [x86](https://wiki.osdev.org/X86 "X86") and [MIPS](https://wiki.osdev.org/MIPS "MIPS") architectures.

The compiler self-hosts on DOS, Windows, Linux and Mac OS X meaning it can compile under and for all four OSes and it may additionally be used to write bootloaders and other parts OS running in [Real Mode](https://wiki.osdev.org/Real_Mode "Real Mode"), [Virtual 8086 Mode](https://wiki.osdev.org/Virtual_8086_Mode "Virtual 8086 Mode"), [Unreal Mode](https://wiki.osdev.org/Unreal_Mode "Unreal Mode") and 32-bit [Protected Mode](https://wiki.osdev.org/Protected_Mode "Protected Mode").

With some work it should be possible to run Smaller C on any OS, starting by porting [NASM](https://wiki.osdev.org/NASM "NASM"), [YASM](https://wiki.osdev.org/YASM "YASM") or [FASM](https://wiki.osdev.org/FASM "FASM") (FASM is probably easier) to the OS and then making appropriate changes in the Smaller C standard library to use that OS native system calls instead of those for DOS, Windows, Linux or Mac OS X.

The core compiler comes with a preprocessor, a linker and a compiler driver (the driver invokes the preprocessor, the core compiler, the assembler, and the linker and supports options similar to those of [GCC](https://wiki.osdev.org/GCC "GCC")). The linker ([smlrl](https://wiki.osdev.org/Smlrl "Smlrl")) can produce the following executable formats: [COM](https://wiki.osdev.org/COM "COM"), [MZ](https://wiki.osdev.org/MZ "MZ"), [PE](https://wiki.osdev.org/PE "PE"), [ELF](https://wiki.osdev.org/ELF "ELF"), [Mach-O](https://wiki.osdev.org/Mach-O "Mach-O"), [a.out](https://wiki.osdev.org/A.out "A.out") and flat executables as well. The produced [COM](https://wiki.osdev.org/COM "COM") and [MZ](https://wiki.osdev.org/MZ "MZ") executables may be booted directly with [BootProg](https://wiki.osdev.org/BootProg "BootProg").

The standard C library is work-in-progress and it's close to completion.

Smaller C can run on [RetroBSD](http://retrobsd.org/wiki/doku.php) on a [MIPS](https://wiki.osdev.org/MIPS_Overview "MIPS Overview") microcontroller, fitting into the 96KB of user memory.
