# miasm.arch.mep.jit

## Classes

### class `mep_CGen(CGen)`

Translate a block containing MeP instructions to C

Note: it is used to emulate the *REPEAT instructions

- **`__init__(self, lifter)`**
- **`gen_pre_code(self, attrib)`** - Generate C code inserted before the current block
- **`gen_post_code(self, attrib, pc_value)`** - Generate C code inserted after the current block
