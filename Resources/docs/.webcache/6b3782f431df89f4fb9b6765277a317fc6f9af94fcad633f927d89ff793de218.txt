inline virtual std::optional\<uint64_t\> resolve_symbol(const std::string&)    
This function aims to be overloaded in order to resolve symbols used in the assembly listing.

For instance, given this assembly code:

    0x1000: mov rdi, rbx
    0x1003: call _my_function

The function `_my_function` will remain undefined unless we return its address in [`resolve_symbol()`](#classLIEF_1_1assembly_1_1AssemblerConfig_1a5b3673e544113a58bcbe9c8da588cfc5):

    class MyConfig : public AssemblerConfig {
      public:
      std::optional<uint64_t> resolve_symbol(const std::string& name) {
        if (name == "_my_function") {
          return 0x4000;
        }
        return std::nullopt; // or AssemblerConfig::resolve_symbol(name)
      }
    };
