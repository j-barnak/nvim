# Constant SEPARATORS_STR Copy item path

[Source](https://doc.rust-lang.org/src/std/path.rs.html#284)

``` rust
pub const SEPARATORS_STR: &[&str];
```

🔬This is a nightly-only experimental API. (`const_path_separators` [\#153106](https://github.com/rust-lang/rust/issues/153106))

Expand description

All path separators recognized on the current platform, represented as [`&str`](https://doc.rust-lang.org/std/primitive.str.html "primitive str")s; for example, this is `&["/"][..]` on Unix and `&["\\", "/"][..]` on Windows. The [primary separator](https://doc.rust-lang.org/std/path/constant.MAIN_SEPARATOR_STR.html "constant std::path::MAIN_SEPARATOR_STR") is always element 0 of the slice.
