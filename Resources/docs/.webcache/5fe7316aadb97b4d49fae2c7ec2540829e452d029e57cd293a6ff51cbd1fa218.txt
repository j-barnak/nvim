Expand description

Performs the same functionality as [`from_raw_parts`](https://doc.rust-lang.org/std/ptr/fn.from_raw_parts.html "fn std::ptr::from_raw_parts"), except that a raw `*mut` pointer is returned, as opposed to a raw `*const` pointer.

See the documentation of [`from_raw_parts`](https://doc.rust-lang.org/std/ptr/fn.from_raw_parts.html "fn std::ptr::from_raw_parts") for more details.
