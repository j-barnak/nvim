# Constant SEPARATORS Copy item path

[Source](https://doc.rust-lang.org/src/std/path.rs.html#278)

``` rust
pub const SEPARATORS: &[char];
```

🔬This is a nightly-only experimental API. (`const_path_separators` [\#153106](https://github.com/rust-lang/rust/issues/153106))

Expand description

All path separators recognized on the current platform, represented as [`char`](https://doc.rust-lang.org/std/primitive.char.html "primitive char")s; for example, this is `&['/'][..]` on Unix and `&['\\', '/'][..]` on Windows. The [primary separator](https://doc.rust-lang.org/std/path/constant.MAIN_SEPARATOR.html "constant std::path::MAIN_SEPARATOR") is always element 0 of the slice.
