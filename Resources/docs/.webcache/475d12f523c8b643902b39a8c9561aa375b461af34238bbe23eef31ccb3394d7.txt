# miasm.core.locationdb

## Classes

### class `LocationDB(object)`

LocationDB is a "database" of information associated to location.

An entry in a LocationDB is uniquely identified with a LocKey.
Additional information which can be associated with a LocKey are:
- an offset (uniq per LocationDB)
- several names (each are uniqs per LocationDB)

As a schema:
loc_key  1 <-> 0..1  offset
         1 <-> 0..n  name

>>> loc_db = LocationDB()
# Add a location with no additional information
>>> loc_key1 = loc_db.add_location()
# Add a location with an offset
>>> loc_key2 = loc_db.add_location(offset=0x1234)
# Add a location with several names
>>> loc_key3 = loc_db.add_location(name="first_name")
>>> loc_db.add_location_name(loc_key3, "second_name")
# Associate an offset to an existing location
>>> loc_db.set_location_offset(loc_key3, 0x5678)
# Remove a name from an existing location
>>> loc_db.remove_location_name(loc_key3, "second_name")

# Get back offset
>>> loc_db.get_location_offset(loc_key1)
None
>>> loc_db.get_location_offset(loc_key2)
0x1234
>>> loc_db.get_location_offset("first_name")
0x5678

# Display a location
>>> loc_db.pretty_str(loc_key1)
loc_key_1
>>> loc_db.pretty_str(loc_key2)
loc_1234
>>> loc_db.pretty_str(loc_key3)
first_name

- **`__init__(self)`**
- **`get_location_offset(self, loc_key)`** - Return the offset of @loc_key if any, None otherwise.
- **`get_location_names(self, loc_key)`** - Return the frozenset of names associated to @loc_key
- **`get_name_location(self, name)`** - Return the LocKey of @name if any, None otherwise.
- **`get_or_create_name_location(self, name)`** - Return the LocKey of @name if any, create one otherwise.
- **`get_offset_location(self, offset)`** - Return the LocKey of @offset if any, None otherwise.
- **`get_or_create_offset_location(self, offset)`** - Return the LocKey of @offset if any, create one otherwise.
- **`get_name_offset(self, name)`** - Return the offset of @name if any, None otherwise.
- **`add_location_name(self, loc_key, name)`** - Associate a name @name to a given @loc_key
- **`remove_location_name(self, loc_key, name)`** - Disassociate a name @name from a given @loc_key
- **`set_location_offset(self, loc_key, offset, force=False)`** - Associate the offset @offset to an LocKey @loc_key
- **`unset_location_offset(self, loc_key)`** - Disassociate LocKey @loc_key's offset
- **`consistency_check(self)`** - Ensure internal structures are consistent with each others
- **`find_free_name(self, name)`** - If @name is not known in DB, return it
- **`add_location(self, name=None, offset=None, strict=True)`** - Add a new location in the locationDB. Returns the corresponding LocKey.
- **`remove_location(self, loc_key)`** - Delete the location corresponding to @loc_key
- **`pretty_str(self, loc_key)`** - Return a human readable version of @loc_key, according to information
- **`loc_keys(self)`** - Return all loc_keys
- **`names(self)`** - Return all known names
- **`offsets(self)`** - Return all known offsets
- **`__str__(self)`**
- **`merge(self, location_db)`** - Merge with another LocationDB @location_db
- **`canonize_to_exprloc(self, expr)`** - If expr is ExprInt, return ExprLoc with corresponding loc_key
- **`items(self)`** - Return all loc_keys
