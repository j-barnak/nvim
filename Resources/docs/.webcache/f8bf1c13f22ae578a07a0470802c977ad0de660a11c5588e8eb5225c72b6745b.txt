# NAME

podman-volume - Simple management tool for volumes

# SYNOPSIS

**podman volume** *subcommand*

# DESCRIPTION

podman volume is a set of subcommands that manage volumes.

# SUBCOMMANDS

| Command | Man Page | Description |
|----|----|----|
| create | [podman-volume-create(1)](https://docs.podman.io/en/latest/markdown/podman-volume-create.1.html) | Create a new volume. |
| exists | [podman-volume-exists(1)](https://docs.podman.io/en/latest/markdown/podman-volume-exists.1.html) | Check if the given volume exists. |
| export | [podman-volume-export(1)](https://docs.podman.io/en/latest/markdown/podman-volume-export.1.html) | Export volume to external tar. |
| import | [podman-volume-import(1)](https://docs.podman.io/en/latest/markdown/podman-volume-import.1.html) | Import tarball contents into an existing podman volume. |
| inspect | [podman-volume-inspect(1)](https://docs.podman.io/en/latest/markdown/podman-volume-inspect.1.html) | Get detailed information on one or more volumes. |
| ls | [podman-volume-ls(1)](https://docs.podman.io/en/latest/markdown/podman-volume-ls.1.html) | List all the available volumes (alias list) |
| mount | [podman-volume-mount(1)](https://docs.podman.io/en/latest/markdown/podman-volume-mount.1.html) | Mount a volume filesystem. |
| prune | [podman-volume-prune(1)](https://docs.podman.io/en/latest/markdown/podman-volume-prune.1.html) | Remove unused volumes. |
| reload | [podman-volume-reload(1)](https://docs.podman.io/en/latest/markdown/podman-volume-reload.1.html) | Reload all volumes from volumes plugins. |
| rename | [podman-volume-rename(1)](https://docs.podman.io/en/latest/markdown/podman-volume-rename.1.html) | Rename a volume. |
| rm | [podman-volume-rm(1)](https://docs.podman.io/en/latest/markdown/podman-volume-rm.1.html) | Remove one or more volumes. |
| unmount | [podman-volume-unmount(1)](https://docs.podman.io/en/latest/markdown/podman-volume-unmount.1.html) | Unmount a volume. |
