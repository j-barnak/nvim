# Struct OccupiedEntry Copy item path

Expand description

A view into an occupied entry in a `BTreeMap`. It is part of the [`Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html "enum std::collections::btree_map::Entry") enum.

Gets a reference to the key in the entry.

##### Examples

``` rust
use std::collections::BTreeMap;

let mut map: BTreeMap<&str, usize> = BTreeMap::new();
map.entry("poneyland").or_insert(12);
assert_eq!(map.entry("poneyland").key(), &"poneyland");
```

1.12.0 · [Source](https://doc.rust-lang.org/src/alloc/collections/btree/map/entry.rs.html#525)

Take ownership of the key and value from the map.

##### Examples

``` rust
use std::collections::BTreeMap;
use std::collections::btree_map::Entry;

let mut map: BTreeMap<&str, usize> = BTreeMap::new();
map.entry("poneyland").or_insert(12);

if let Entry::Occupied(o) = map.entry("poneyland") {
    // We delete the entry from the map.
    o.remove_entry();
}

// If now try to get the value, it will panic:
// println!("{}", map["poneyland"]);
```

1.0.0 · [Source](https://doc.rust-lang.org/src/alloc/collections/btree/map/entry.rs.html#577)

Gets a mutable reference to the value in the entry.

If you need a reference to the `OccupiedEntry` that may outlive the destruction of the `Entry` value, see [`into_mut`](https://doc.rust-lang.org/std/collections/btree_map/struct.OccupiedEntry.html#method.into_mut "method std::collections::btree_map::OccupiedEntry::into_mut").

##### Examples

``` rust
use std::collections::BTreeMap;
use std::collections::btree_map::Entry;

let mut map: BTreeMap<&str, usize> = BTreeMap::new();
map.entry("poneyland").or_insert(12);

assert_eq!(map["poneyland"], 12);
if let Entry::Occupied(mut o) = map.entry("poneyland") {
    *o.get_mut() += 10;
    assert_eq!(*o.get(), 22);

    // We can use the same Entry multiple times.
    *o.get_mut() += 2;
}
assert_eq!(map["poneyland"], 24);
```

1.0.0 · [Source](https://doc.rust-lang.org/src/alloc/collections/btree/map/entry.rs.html#604)

Converts the entry into a mutable reference to its value.

If you need multiple references to the `OccupiedEntry`, see [`get_mut`](https://doc.rust-lang.org/std/collections/btree_map/struct.OccupiedEntry.html#method.get_mut "method std::collections::btree_map::OccupiedEntry::get_mut").

##### Examples

``` rust
use std::collections::BTreeMap;
use std::collections::btree_map::Entry;

let mut map: BTreeMap<&str, usize> = BTreeMap::new();
map.entry("poneyland").or_insert(12);

assert_eq!(map["poneyland"], 12);
if let Entry::Occupied(o) = map.entry("poneyland") {
    *o.into_mut() += 10;
}
assert_eq!(map["poneyland"], 22);
```

1.0.0 · [Source](https://doc.rust-lang.org/src/alloc/collections/btree/map/entry.rs.html#627)

Sets the value of the entry with the `OccupiedEntry`’s key, and returns the entry’s old value.

##### Examples

``` rust
use std::collections::BTreeMap;
use std::collections::btree_map::Entry;

let mut map: BTreeMap<&str, usize> = BTreeMap::new();
map.entry("poneyland").or_insert(12);

if let Entry::Occupied(mut o) = map.entry("poneyland") {
    assert_eq!(o.insert(15), 12);
}
assert_eq!(map["poneyland"], 15);
```

1.0.0 · [Source](https://doc.rust-lang.org/src/alloc/collections/btree/map/entry.rs.html#650)

Takes the value of the entry out of the map, and returns it.

##### Examples

``` rust
use std::collections::BTreeMap;
use std::collections::btree_map::Entry;

let mut map: BTreeMap<&str, usize> = BTreeMap::new();
map.entry("poneyland").or_insert(12);

if let Entry::Occupied(o) = map.entry("poneyland") {
    assert_eq!(o.remove(), 12);
}
// If we try to get "poneyland"'s value, it'll panic:
// println!("{}", map["poneyland"]);
```
