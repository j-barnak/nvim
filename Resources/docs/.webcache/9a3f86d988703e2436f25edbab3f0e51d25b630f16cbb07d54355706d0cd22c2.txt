Bases: [`SuccessorsEngine`](https://docs.angr.io/en/latest/api/angr.engines.successors.html#angr.engines.successors.SuccessorsEngine "angr.engines.successors.SuccessorsEngine"), [`ClaripyDataMixin`](https://docs.angr.io/en/latest/api/angr.engines.vex.claripy.datalayer.html#angr.engines.vex.claripy.datalayer.ClaripyDataMixin "angr.engines.vex.claripy.datalayer.ClaripyDataMixin"), [`SimStateStorageMixin`](https://docs.angr.io/en/latest/api/angr.engines.vex.heavy.heavy.html#angr.engines.vex.heavy.heavy.SimStateStorageMixin "angr.engines.vex.heavy.heavy.SimStateStorageMixin"), [`VEXMixin`](https://docs.angr.io/en/latest/api/angr.engines.vex.light.light.html#angr.engines.vex.light.light.VEXMixin "angr.engines.vex.light.light.VEXMixin"), [`VEXLifter`](https://docs.angr.io/en/latest/api/angr.engines.vex.lifter.html#angr.engines.vex.lifter.VEXLifter "angr.engines.vex.lifter.VEXLifter")

Execution engine based on VEX, Valgrind’s IR.

Responds to the following parameters to the step stack:

- irsb: The PyVEX IRSB object to use for execution. If not provided one will be lifted.

- skip_stmts: The number of statements to skip in processing

- last_stmt: Do not execute any statements after this statement

- whitelist: Only execute statements in this set

- thumb: Whether the block should be force to be lifted in ARM’s THUMB mode.

- extra_stop_points:  
  An extra set of points at which to break basic blocks

- opt_level: The VEX optimization level to use.

- insn_bytes: A string of bytes to use for the block instead of the project.

- size: The maximum size of the block, in bytes.

- num_inst: The maximum number of instructions.

- traceflags: traceflags to be passed to VEX. (default: 0)
