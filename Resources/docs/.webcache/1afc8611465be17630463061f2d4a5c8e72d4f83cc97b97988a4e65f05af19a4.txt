Expand description

Options for formatting.

`FormattingOptions` is a [`Formatter`](https://doc.rust-lang.org/std/fmt/struct.Formatter.html "struct std::fmt::Formatter") without an attached [`Write`](https://doc.rust-lang.org/std/fmt/trait.Write.html "trait std::fmt::Write") trait. It is mainly used to construct `Formatter` instances.

Sets or removes the sign (the `+` or the `-` flag).

- `+`: This is intended for numeric types and indicates that the sign should always be printed. By default only the negative sign of signed values is printed, and the sign of positive or unsigned values is omitted. This flag indicates that the correct sign (+ or -) should always be printed.
- `-`: Currently not used

Sets or unsets the `#` flag.

This flag indicates that the “alternate” form of printing should be used. The alternate forms are:

- [`Debug`](https://doc.rust-lang.org/std/fmt/trait.Debug.html "trait std::fmt::Debug") : pretty-print the [`Debug`](https://doc.rust-lang.org/std/fmt/trait.Debug.html "trait std::fmt::Debug") formatting (adds linebreaks and indentation)
- [`LowerHex`](https://doc.rust-lang.org/std/fmt/trait.LowerHex.html "trait std::fmt::LowerHex") as well as [`UpperHex`](https://doc.rust-lang.org/std/fmt/trait.UpperHex.html "trait std::fmt::UpperHex") - precedes the argument with a `0x`
- [`Octal`](https://doc.rust-lang.org/std/fmt/trait.Octal.html "trait std::fmt::Octal") - precedes the argument with a `0o`
- [`Binary`](https://doc.rust-lang.org/std/fmt/trait.Binary.html "trait std::fmt::Binary") - precedes the argument with a `0b`

Sets or removes the width.

This is a parameter for the “minimum width” that the format should take up. If the value’s string does not fill up this many characters, then the padding specified by [`FormattingOptions::fill`](https://doc.rust-lang.org/std/fmt/struct.FormattingOptions.html#method.fill "method std::fmt::FormattingOptions::fill")/[`FormattingOptions::align`](https://doc.rust-lang.org/std/fmt/struct.FormattingOptions.html#method.align "method std::fmt::FormattingOptions::align") will be used to take up the required space.

Sets or removes the precision.

- For non-numeric types, this can be considered a “maximum width”. If the resulting string is longer than this width, then it is truncated down to this many characters and that truncated value is emitted with proper fill, alignment and width if those parameters are set.
- For integral types, this is ignored.
- For floating-point types, this indicates how many digits after the decimal point should be printed.
