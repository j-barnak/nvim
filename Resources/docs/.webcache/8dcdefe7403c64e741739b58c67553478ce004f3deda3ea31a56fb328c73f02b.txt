Below you will find a list of items that we 'need' on the OSDev wiki. They are divided in specific categories. Feel free to add a new item to the list if you would like more information on a specific topic.

If you want to help the wiki out or have some spare time, feel free to log in and add information about any of the requested topics or help maintain the wiki.

## Urgent (High Priority)

- [Memory management](https://wiki.osdev.org/Page_Frame_Allocation "Page Frame Allocation"): Review Solaris slab allocator, overview of the NetBSD UVM.

- Program Loading/Running (e.g. [ELF](https://wiki.osdev.org/ELF "ELF"))

- Link versus load addresses.

- Newer Hardware

- STARTUP IPI driver interface dedicated page

- [Device Driver Interfaces](https://wiki.osdev.org/Device_Driver_Interfaces "Device Driver Interfaces")

- How does one make or implement one?
- Loadable/Unloadable drivers.
- How is DMA, bus, ... access done using a consistent driver interface?
  - Partially implemented in [Uniform Driver Interface](https://wiki.osdev.org/Uniform_Driver_Interface "Uniform Driver Interface")

- The Database of Knowledge

- Scan the forums for (huge) posts from Brendan/(Com)buster/Solar/... and somehow transfer their knowledge to the wiki.

## Less Urgent (Normal Priority)

- [Printing](https://wiki.osdev.org/Printing "Printing")

- [Printer Command Language](https://wiki.osdev.org/Printer_Command_Language "Printer Command Language")

- [File Systems](https://wiki.osdev.org/File_Systems "File Systems")

- Information regarding missing file systems (see the above link: ext3, ext4, UDF, exFAT, ...).
- How to implement a journaling file system.
- [Virtual File Systems](https://wiki.osdev.org/VFS "VFS"): Information about directory caches.

- [AML](https://wiki.osdev.org/AML "AML")

- An AML reference
- More information on AML

- How to parse
- Where found
- How to use

- Hunting for dead external links. Inevitably with the years external links rot, so look them up in the Internet Archive or search for alternative links to the resource (in case the link pointed to a document for example) and update the article with the non-broken link. Of course, don't forget to archive that link too! Use [https://archive.org](https://archive.org) or [http://megalodon.jp](http://megalodon.jp) for that.

## Not Very Urgent (Low Priority)

- [Microkernel](https://wiki.osdev.org/Microkernel "Microkernel")

- How to create a complete microkernel from scratch (IPC, process management, but not necessarily drivers).

- [Virtio](https://wiki.osdev.org/Virtio "Virtio")

- Benefits of using virtio (and let the host take care of the rest)
- Subsystems (nic, block, console, 9P etc.)
- PCI discover (Vendor id: 0x1AF, Device id: 0x103F)
- Device initialization
- Setting up virtio in QEMU/KVM/other

## Other

- [Stubs](https://wiki.osdev.org/Category:Stubs "Category:Stubs"): Pages that exist, but are in need of expansion or merely have placeholder information.
- [In Progress](https://wiki.osdev.org/Category:In_Progress "Category:In Progress"): Pages that might need some help getting finished.
- [Wanted Pages](https://wiki.osdev.org/Special:WantedPages "Special:WantedPages"): Pages that are referenced within other wiki pages but don't exist.
- [Wanted categories](https://wiki.osdev.org/Special:WantedCategories "Special:WantedCategories"): Categories that are referenced within other wiki pages but don't exist.
- [Unused categories](https://wiki.osdev.org/Special:UnusedCategories "Special:UnusedCategories"): Categories that are completely empty.
- [Orphaned pages](https://wiki.osdev.org/Special:LonelyPages "Special:LonelyPages"): Pages that are not yet referenced by any other wiki page (they are on the wiki, but no other page links to them).

If you created a new page you can add it to the relevant expanded [Main page templates](https://wiki.osdev.org/Category:Main_Page_Templates "Category:Main Page Templates"), or even to the categorized main page if it concerns an important or wide range of topics.

- [Uncategorized pages](https://wiki.osdev.org/Special:UncategorizedPages "Special:UncategorizedPages"): Pages that are in need of one or more [categories](https://wiki.osdev.org/Special:Categories "Special:Categories").
- [Uncategorized categories](https://wiki.osdev.org/Special:UncategorizedCategories "Special:UncategorizedCategories"): Categories that aren't placed in any parent category (optimally, the only category without a 'parent' category should be the root category).
- [Broken Redirects](https://wiki.osdev.org/Special:BrokenRedirects "Special:BrokenRedirects"): Pages that redirect to non-existent pages.
- [Dead ends](https://wiki.osdev.org/Special:DeadendPages "Special:DeadendPages"): Pages that lack links to other articles.
