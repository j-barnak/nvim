Expand description

Wrapping (modular) multiplication. Computes `a * b`, wrapping around at the boundary of the type.

Note that, unlike most intrinsics, this is safe to call; it does not require an `unsafe` block. Therefore, implementations must not require the user to uphold any safety invariants.

The stabilized versions of this intrinsic are available on the integer primitives via the `wrapping_mul` method. For example, [`u32::wrapping_mul`](https://doc.rust-lang.org/std/primitive.u32.html#method.wrapping_mul "method u32::wrapping_mul")
