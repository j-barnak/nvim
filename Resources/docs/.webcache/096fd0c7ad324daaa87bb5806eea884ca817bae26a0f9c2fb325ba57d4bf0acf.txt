# Enum Entry Copy item path

[Source](https://doc.rust-lang.org/src/std/collections/hash/set.rs.html#2144-2185)

``` rust
pub enum Entry<'a, T, S, A: Allocator = Global> {
    Occupied(OccupiedEntry<'a, T, S, A>),
    Vacant(VacantEntry<'a, T, S, A>),
}
```

🔬This is a nightly-only experimental API. (`hash_set_entry` [\#60896](https://github.com/rust-lang/rust/issues/60896))

Expand description

A view into a single entry in a set, which may either be vacant or occupied.

This `enum` is constructed from the [`entry`](https://doc.rust-lang.org/std/collections/hash_set/struct.HashSet.html#method.entry) method on [`HashSet`](https://doc.rust-lang.org/std/collections/hash_set/struct.HashSet.html).

## Examples

``` rust
#![feature(hash_set_entry)]

use std::collections::hash_set::HashSet;

let mut set = HashSet::new();
set.extend(["a", "b", "c"]);
assert_eq!(set.len(), 3);

// Existing value (insert)
let entry = set.entry("a");
let _raw_o = entry.insert();
assert_eq!(set.len(), 3);
// Nonexistent value (insert)
set.entry("d").insert();

// Existing value (or_insert)
set.entry("b").or_insert();
// Nonexistent value (or_insert)
set.entry("e").or_insert();

println!("Our HashSet: {:?}", set);

let mut vec: Vec<_> = set.iter().copied().collect();
// The `Iter` iterator produces items in arbitrary order, so the
// items must be sorted to test them against a sorted array.
vec.sort_unstable();
assert_eq!(vec, ["a", "b", "c", "d", "e"]);
```

Ensures a value is in the entry by inserting if it was vacant.

##### Examples

``` rust
#![feature(hash_set_entry)]

use std::collections::HashSet;

let mut set = HashSet::new();

// nonexistent key
set.entry("poneyland").or_insert();
assert!(set.contains("poneyland"));

// existing key
set.entry("poneyland").or_insert();
assert!(set.contains("poneyland"));
assert_eq!(set.len(), 1);
```

Returns a reference to this entry’s value.

##### Examples

``` rust
#![feature(hash_set_entry)]

use std::collections::HashSet;

let mut set = HashSet::new();
set.entry("poneyland").or_insert();

// existing key
assert_eq!(set.entry("poneyland").get(), &"poneyland");
// nonexistent key
assert_eq!(set.entry("horseland").get(), &"horseland");
```
