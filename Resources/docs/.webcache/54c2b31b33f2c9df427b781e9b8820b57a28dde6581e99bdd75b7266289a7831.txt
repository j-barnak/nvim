# NAME

podman-pod - Management tool for groups of containers, called pods

# SYNOPSIS

**podman pod** *subcommand*

# DESCRIPTION

podman pod is a set of subcommands that manage pods, or groups of containers.

# SUBCOMMANDS

| Command | Man Page | Description |
|----|----|----|
| clone | [podman-pod-clone(1)](https://docs.podman.io/en/latest/markdown/podman-pod-clone.1.html) | Create a copy of an existing pod. |
| create | [podman-pod-create(1)](https://docs.podman.io/en/latest/markdown/podman-pod-create.1.html) | Create a new pod. |
| exists | [podman-pod-exists(1)](https://docs.podman.io/en/latest/markdown/podman-pod-exists.1.html) | Check if a pod exists in local storage. |
| inspect | [podman-pod-inspect(1)](https://docs.podman.io/en/latest/markdown/podman-pod-inspect.1.html) | Display information describing a pod. |
| kill | [podman-pod-kill(1)](https://docs.podman.io/en/latest/markdown/podman-pod-kill.1.html) | Kill the main process of each container in one or more pods. |
| logs | [podman-pod-logs(1)](https://docs.podman.io/en/latest/markdown/podman-pod-logs.1.html) | Display logs for pod with one or more containers. |
| pause | [podman-pod-pause(1)](https://docs.podman.io/en/latest/markdown/podman-pod-pause.1.html) | Pause one or more pods. |
| prune | [podman-pod-prune(1)](https://docs.podman.io/en/latest/markdown/podman-pod-prune.1.html) | Remove all stopped pods and their containers. |
| ps | [podman-pod-ps(1)](https://docs.podman.io/en/latest/markdown/podman-pod-ps.1.html) | Print out information about pods. |
| restart | [podman-pod-restart(1)](https://docs.podman.io/en/latest/markdown/podman-pod-restart.1.html) | Restart one or more pods. |
| rm | [podman-pod-rm(1)](https://docs.podman.io/en/latest/markdown/podman-pod-rm.1.html) | Remove one or more stopped pods and containers. |
| start | [podman-pod-start(1)](https://docs.podman.io/en/latest/markdown/podman-pod-start.1.html) | Start one or more pods. |
| stats | [podman-pod-stats(1)](https://docs.podman.io/en/latest/markdown/podman-pod-stats.1.html) | Display a live stream of resource usage stats for containers in one or more pods. |
| stop | [podman-pod-stop(1)](https://docs.podman.io/en/latest/markdown/podman-pod-stop.1.html) | Stop one or more pods. |
| top | [podman-pod-top(1)](https://docs.podman.io/en/latest/markdown/podman-pod-top.1.html) | Display the running processes of containers in a pod. |
| unpause | [podman-pod-unpause(1)](https://docs.podman.io/en/latest/markdown/podman-pod-unpause.1.html) | Unpause one or more pods. |
