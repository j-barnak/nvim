Expand description

State yielded to [`Once::call_once_force()`](https://doc.rust-lang.org/std/sync/struct.Once.html#method.call_once_force "method std::sync::Once::call_once_force")’s closure parameter. The state can be used to query the poison status of the [`Once`](https://doc.rust-lang.org/std/sync/struct.Once.html "struct std::sync::Once").

## Implementations

[Source](https://doc.rust-lang.org/src/std/sync/once.rs.html#348-395)

1.51.0 · [Source](https://doc.rust-lang.org/src/std/sync/once.rs.html#385-387)

Returns `true` if the associated [`Once`](https://doc.rust-lang.org/std/sync/struct.Once.html "struct std::sync::Once") was poisoned prior to the invocation of the closure passed to [`Once::call_once_force()`](https://doc.rust-lang.org/std/sync/struct.Once.html#method.call_once_force "method std::sync::Once::call_once_force").

##### Examples

A poisoned [`Once`](https://doc.rust-lang.org/std/sync/struct.Once.html "struct std::sync::Once"):

``` rust
use std::sync::Once;
use std::thread;

static INIT: Once = Once::new();

// poison the once
let handle = thread::spawn(|| {
    INIT.call_once(|| panic!());
});
assert!(handle.join().is_err());

INIT.call_once_force(|state| {
    assert!(state.is_poisoned());
});
```

An unpoisoned [`Once`](https://doc.rust-lang.org/std/sync/struct.Once.html "struct std::sync::Once"):

``` rust
use std::sync::Once;

static INIT: Once = Once::new();

INIT.call_once_force(|state| {
    assert!(!state.is_poisoned());
});
```
