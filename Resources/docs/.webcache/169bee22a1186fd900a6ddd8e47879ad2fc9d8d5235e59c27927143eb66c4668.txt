# Trait FileTypeExt Copy item path

``` rust
pub trait FileTypeExt {
    // Required methods
    fn is_block_device(&self) -> bool;
    fn is_char_device(&self) -> bool;
    fn is_fifo(&self) -> bool;
    fn is_socket(&self) -> bool;
}
```

Available on **Unix** only.

Expand description

Unix-specific extensions for [`fs::FileType`](https://doc.rust-lang.org/std/fs/struct.FileType.html "struct std::fs::FileType").

Adds support for special Unix file types such as block/character devices, pipes, and sockets.

## Required Methods

1.5.0 · [Source](https://doc.rust-lang.org/src/std/os/unix/fs.rs.html#910)

Returns `true` if this file type is a block device.

##### Examples

``` rust
use std::fs;
use std::os::unix::fs::FileTypeExt;
use std::io;

fn main() -> io::Result<()> {
    let meta = fs::metadata("block_device_file")?;
    let file_type = meta.file_type();
    assert!(file_type.is_block_device());
    Ok(())
}
```
