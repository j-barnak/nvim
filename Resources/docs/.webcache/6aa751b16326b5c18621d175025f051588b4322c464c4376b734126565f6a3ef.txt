## Appendix C Installing the GNU C Library

Before you do anything else, you should read the FAQ at [https://sourceware.org/glibc/wiki/FAQ](https://sourceware.org/glibc/wiki/FAQ). It answers common questions and describes problems you may experience with compilation and installation.

You will need recent versions of several GNU tools: definitely GCC and GNU Make, and possibly others. See [Recommended Tools for Compilation](https://sourceware.org/glibc/manual/latest/html_node/Tools-for-Compilation.html), below.

- [Configuring and compiling the GNU C Library](https://sourceware.org/glibc/manual/latest/html_node/Configuring-and-compiling.html)
- [Installing the C Library](https://sourceware.org/glibc/manual/latest/html_node/Running-make-install.html)
- [Recommended Tools for Compilation](https://sourceware.org/glibc/manual/latest/html_node/Tools-for-Compilation.html)
- [Specific advice for GNU/Linux systems](https://sourceware.org/glibc/manual/latest/html_node/Linux.html)
- [Reporting Bugs](https://sourceware.org/glibc/manual/latest/html_node/Reporting-Bugs.html)
