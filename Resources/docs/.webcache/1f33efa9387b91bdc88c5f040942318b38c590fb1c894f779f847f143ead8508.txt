The **RSDT** (Root System Description Table) is a data structure used in the [ACPI](https://wiki.osdev.org/ACPI "ACPI") programming interface. This table contains pointers to all the other system description tables.

## Detecting

The RSDT is pointed to by the [RSDP](https://wiki.osdev.org/RSDP "RSDP"), in the `RsdtAddress` field. If the ACPI version is at least 2.0, the [XSDT](https://wiki.osdev.org/XSDT "XSDT") should be used^([\[1\]](https://wiki.osdev.org/RSDT#cite_note-1)).

## Structure

Like all other system description tables, the RSDT is separated into a header and data.

``` c
struct SDT_header {
  char Signature[4];
  uint32_t Length;
  uint8_t Revision;
  uint8_t Checksum;
  char OEMID[6];
  char OEMTableID[8];
  uint32_t OEMRevision;
  uint32_t CreatorID;
  uint32_t CreatorRevision;
} __attribute__ ((packed));
```

### Fields

#### Signature

A 4 byte signature used for identification, equal to `RSDT`.

#### Length

The length of the entire table, including the header.

#### Checksum

An 8-bit checksum field for the whole table, inclusive of the header. All bytes of the table, when summed, must be equal to 0 (mod `0x100`).

``` c
bool verify_checksum(struct SDT_header *header)
{
    uint8_t sum = 0;

    for (int i = 0; i < header->Length; i++)
    {
        sum += ((uint8_t *) header)[i];
    }

    return sum == 0;
}
```

#### Entries

The RSDT contains an array of 32-bit physical pointers to other system descriptor tables.

``` c
struct RSDT {
  struct SDT_header header;
  uint32_t entries[(header.Length - sizeof(header)) / 4];
} __attribute__ ((packed));
```

## Usage

Tables can be found by traversing `entries` and looking for one with the correct signature.

As an example, the [FACP](https://wiki.osdev.org/index.php?title=FACP&action=edit&redlink=1 "FACP (page does not exist)") can be found using the following code:

``` c
void *find_FACP(struct RSDT *rsdt)
{
    int entries = (rsdt->h.Length - sizeof(rsdt->h)) / 4;

    for (int i = 0; i < entries; i++)
    {
        struct SDT_header *h = (struct SDT_header *) rsdt->entries[i];
        if (!strncmp(h->Signature, "FACP", 4))
            return (void *)h;
    }

    return NULL;
}
```

The [FADT](https://wiki.osdev.org/FADT "FADT"), [SSDT](https://wiki.osdev.org/SSDT "SSDT"), and [MADT](https://wiki.osdev.org/MADT "MADT") tables are all pointed to by the RSDT, and are quite important for ACPI. For multiprocessor systems, the [SRAT](https://wiki.osdev.org/SRAT "SRAT") and [SLIT](https://wiki.osdev.org/index.php?title=SLIT&action=edit&redlink=1 "SLIT (page does not exist)") tables are essentially required.

## List of Tables

### Defined by ACPI

The ACPI Specification 5.0 has direct definitions for the following System Descriptor tables, identified by their signatures:

- "APIC": Multiple APIC Description Table ([MADT](https://wiki.osdev.org/MADT "MADT"))
- "BERT": Boot Error Record Table ([BERT](https://wiki.osdev.org/index.php?title=BERT&action=edit&redlink=1 "BERT (page does not exist)"))
- "CPEP": Corrected Platform Error Polling Table ([CPEP](https://wiki.osdev.org/index.php?title=CPEP&action=edit&redlink=1 "CPEP (page does not exist)"))
- "DSDT": Differentiated System Description Table ([DSDT](https://wiki.osdev.org/DSDT "DSDT"))
- "ECDT": Embedded Controller Boot Resources Table ([ECDT](https://wiki.osdev.org/index.php?title=ECDT&action=edit&redlink=1 "ECDT (page does not exist)"))
- "EINJ": Error Injection Table ([EINJ](https://wiki.osdev.org/index.php?title=EINJ&action=edit&redlink=1 "EINJ (page does not exist)"))
- "ERST": Error Record Serialization Table ([ERST](https://wiki.osdev.org/index.php?title=ERST&action=edit&redlink=1 "ERST (page does not exist)"))
- "FACP": Fixed ACPI Description Table ([FADT](https://wiki.osdev.org/FADT "FADT"))
- "FACS": Firmware ACPI Control Structure ([FACS](https://wiki.osdev.org/index.php?title=FACS&action=edit&redlink=1 "FACS (page does not exist)"))
- "HEST": Hardware Error Source Table ([HEST](https://wiki.osdev.org/index.php?title=HEST&action=edit&redlink=1 "HEST (page does not exist)"))
- "MSCT": Maximum System Characteristics Table ([MSCT](https://wiki.osdev.org/index.php?title=MSCT&action=edit&redlink=1 "MSCT (page does not exist)"))
- "MPST": Memory Power State Table ([MPST](https://wiki.osdev.org/index.php?title=MPST&action=edit&redlink=1 "MPST (page does not exist)"))
- "OEMx": OEM Specific Information Tables (Any table with a signature beginning with "OEM" falls into this definition)
- "PMTT" Platform Memory Topology Table ([PMTT](https://wiki.osdev.org/index.php?title=PMTT&action=edit&redlink=1 "PMTT (page does not exist)"))
- "PSDT": Persistent System Description Table ([PSDT](https://wiki.osdev.org/index.php?title=PSDT&action=edit&redlink=1 "PSDT (page does not exist)"))
- "RASF": ACPI RAS Feature Table ([RASF](https://wiki.osdev.org/index.php?title=RASF&action=edit&redlink=1 "RASF (page does not exist)"))
- "RSDT": Root System Description Table (This wiki page; included for completeness)
- "SBST": Smart Battery Specification Table ([SBST](https://wiki.osdev.org/index.php?title=SBST&action=edit&redlink=1 "SBST (page does not exist)"))
- "SLIT": System Locality System Information Table ([SLIT](https://wiki.osdev.org/index.php?title=SLIT&action=edit&redlink=1 "SLIT (page does not exist)"))
- "SRAT": System Resource Affinity Table ([SRAT](https://wiki.osdev.org/SRAT "SRAT"))
- "SSDT": Secondary System Description Table ([SSDT](https://wiki.osdev.org/SSDT "SSDT"))
- "XSDT": Extended System Description Table ([XSDT](https://wiki.osdev.org/XSDT "XSDT"); 64-bit version of the RSDT)

### Reserved by ACPI

The ACPI specification maintains reservations for additional third party defined description tables. Each third party submitting a request for a reservation also maintains a specification for these tables, located on individual sites. See the ACPI spec ([\[1\]](http://www.acpi.info/spec50.htm)) for more information.
