# Storage & I/O

The path data takes from an application's read or write down to a physical device — and the layers that make it general and fast.

- [VFS (vfs/)](https://kernel-internals.org/vfs/) — the abstraction that lets one API drive every filesystem
- [Filesystems (filesystems/)](https://kernel-internals.org/filesystems/) — how on-disk formats and the page cache turn bytes into files
- [Block Layer (block/)](https://kernel-internals.org/block/) — the path from a filesystem request to a physical device
- [I/O Patterns (io/)](https://kernel-internals.org/io/) — buffered vs. direct, sync vs. async, and the tradeoffs between them
- [io_uring (io-uring/)](https://kernel-internals.org/io-uring/) — the ring-based interface for high-performance asynchronous I/O
