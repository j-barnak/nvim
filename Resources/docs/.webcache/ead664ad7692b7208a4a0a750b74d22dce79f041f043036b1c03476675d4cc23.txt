🔬This is a nightly-only experimental API. (`linux_pidfd` [\#82971](https://github.com/rust-lang/rust/issues/82971))

Available on **Linux** only.

Expand description

This type represents a file descriptor that refers to a process.

A `PidFd` can be obtained by setting the corresponding option on [`Command`](https://doc.rust-lang.org/std/process/struct.Command.html "struct std::process::Command") with [`create_pidfd`](https://doc.rust-lang.org/std/os/linux/process/trait.CommandExt.html#tymethod.create_pidfd "method std::os::linux::process::CommandExt::create_pidfd"). Subsequently, the created pidfd can be retrieved from the [`Child`](https://doc.rust-lang.org/std/process/struct.Child.html "struct std::process::Child") by calling [`pidfd`](https://doc.rust-lang.org/std/os/linux/process/trait.ChildExt.html#tymethod.pidfd "method std::os::linux::process::ChildExt::pidfd") or [`into_pidfd`](https://doc.rust-lang.org/std/os/linux/process/trait.ChildExt.html#tymethod.into_pidfd "method std::os::linux::process::ChildExt::into_pidfd").

Example:

``` rust
#![feature(linux_pidfd)]
use std::os::linux::process::{CommandExt, ChildExt};
use std::process::Command;

let mut child = Command::new("echo")
    .create_pidfd(true)
    .spawn()
    .expect("Failed to spawn child");

let pidfd = child
    .into_pidfd()
    .expect("Failed to retrieve pidfd");

// The file descriptor will be closed when `pidfd` is dropped.
```

Refer to the man page of [`pidfd_open(2)`](https://man7.org/linux/man-pages/man2/pidfd_open.2.html) for further details.

Forces the child process to exit.

Unlike [`Child::kill`](https://doc.rust-lang.org/std/process/struct.Child.html#method.kill "method std::process::Child::kill") it is possible to attempt to kill reaped children since PidFd does not suffer from pid recycling races. But doing so will return an Error.

[Source](https://doc.rust-lang.org/src/std/os/linux/process.rs.html#75-77)

🔬This is a nightly-only experimental API. (`linux_pidfd` [\#82971](https://github.com/rust-lang/rust/issues/82971))

Waits for the child to exit completely, returning the status that it exited with.

Unlike [`Child::wait`](https://doc.rust-lang.org/std/process/struct.Child.html#method.wait "method std::process::Child::wait") it does not ensure that the stdin handle is closed.

Additionally on kernels prior to 6.15 only the first attempt to reap a child will return an ExitStatus, further attempts will return an Error.

[Source](https://doc.rust-lang.org/src/std/os/linux/process.rs.html#85-87)

🔬This is a nightly-only experimental API. (`linux_pidfd` [\#82971](https://github.com/rust-lang/rust/issues/82971))

Attempts to collect the exit status of the child if it has already exited.

On kernels prior to 6.15, and unlike [`Child::try_wait`](https://doc.rust-lang.org/std/process/struct.Child.html#method.try_wait "method std::process::Child::try_wait"), only the first attempt to reap a child will return an ExitStatus, further attempts will return an Error.
