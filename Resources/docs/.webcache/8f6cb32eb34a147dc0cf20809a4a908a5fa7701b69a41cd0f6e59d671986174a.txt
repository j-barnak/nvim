# Function from_fn Copy item path

1.34.0 · [Source](https://doc.rust-lang.org/src/core/iter/sources/from_fn.rs.html#45-47)

``` rust
pub fn from_fn<T, F>(f: F) -> FromFn<F> ⓘwhere
    F: FnMut() -> Option<T>,
```

Expand description

Creates an iterator with the provided closure `F: FnMut() -> Option<T>` as its [`next`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#tymethod.next "method std::iter::Iterator::next") method.

The iterator will yield the `T`s returned from the closure.

This allows creating a custom iterator with any behavior without using the more verbose syntax of creating a dedicated type and implementing the [`Iterator`](https://doc.rust-lang.org/std/iter/trait.Iterator.html "trait std::iter::Iterator") trait for it.

Note that the `FromFn` iterator doesn’t make assumptions about the behavior of the closure, and therefore conservatively does not implement [`FusedIterator`](https://doc.rust-lang.org/std/iter/trait.FusedIterator.html "trait std::iter::FusedIterator"), or override [`Iterator::size_hint()`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.size_hint "method std::iter::Iterator::size_hint") from its default `(0, None)`.

The closure can use captures and its environment to track state across iterations. Depending on how the iterator is used, this may require specifying the [`move`](https://doc.rust-lang.org/std/keyword.move.html) keyword on the closure.

## Examples

Let’s re-implement the counter iterator from [module-level documentation](https://doc.rust-lang.org/std/iter/index.html "mod std::iter"):

``` rust
let mut count = 0;
let counter = std::iter::from_fn(move || {
    // Increment our count. This is why we started at zero.
    count += 1;

    // Check to see if we've finished counting or not.
    if count < 6 {
        Some(count)
    } else {
        None
    }
});
assert_eq!(counter.collect::<Vec<_>>(), &[1, 2, 3, 4, 5]);
```
