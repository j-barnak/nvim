Calculating Reaching Definitions
A definition of variable v at program point d reaches
program point u if there exists a path of control flow
edges from d to u that does not contain a definition of v.
• Build up RD stmt by stmt
• Stmt s, “d: v <- x op y”, generates d
• Stmt s, “d: v <- x op y”, kills all other defs(v)
Or,
• Gen[s] = { d }
• Kill[s] = defs(v) – { d }

Forward Must Data Flow Algorithm
Out(s) = Gen(s) for all statements s
W = {all statements}
Repeat
Take s from W
In(s) =  s’ ∈ pred(s) Out(s’)
Temp = Gen(s) ∪ (In(s) – Kill(s))
If (temp != Out(s)) {
Out(s) = temp
W = W ∪ succ(s)
}
Until W = ∅
