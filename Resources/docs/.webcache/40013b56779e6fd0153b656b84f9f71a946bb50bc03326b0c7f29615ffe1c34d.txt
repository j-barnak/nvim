## Appendix A C Language Facilities in the Library

Some of the facilities implemented by the C library really should be thought of as parts of the C language itself. These facilities ought to be documented in the C Language Manual, not in the library manual; but since we don’t have the language manual yet, and documentation for these features has been written, we are publishing it here.

- [Explicitly Checking Internal Consistency](https://sourceware.org/glibc/manual/latest/html_node/Consistency-Checking.html)
- [Variadic Functions](https://sourceware.org/glibc/manual/latest/html_node/Variadic-Functions.html)
- [Null Pointer Constant](https://sourceware.org/glibc/manual/latest/html_node/Null-Pointer-Constant.html)
- [Important Data Types](https://sourceware.org/glibc/manual/latest/html_node/Important-Data-Types.html)
- [Data Type Measurements](https://sourceware.org/glibc/manual/latest/html_node/Data-Type-Measurements.html)
