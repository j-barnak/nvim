# NAME

podman-artifact - Manage OCI artifacts

# SYNOPSIS

**podman artifact** *subcommand*

# DESCRIPTION

`podman artifact` is a set of subcommands that manage OCI artifacts.

OCI artifacts are a common way to distribute files that are associated with OCI images and containers. Podman is capable of managing (pulling, inspecting, pushing) these artifacts from its local “artifact store”.

# SUBCOMMANDS

| Command | Man Page | Description |
|----|----|----|
| add | [podman-artifact-add(1)](https://docs.podman.io/en/latest/markdown/podman-artifact-add.1.html) | Add an OCI artifact to local artifact store |
| extract | [podman-artifact-extract(1)](https://docs.podman.io/en/latest/markdown/podman-artifact-extract.1.html) | Extract an OCI artifact to a local path |
| inspect | [podman-artifact-inspect(1)](https://docs.podman.io/en/latest/markdown/podman-artifact-inspect.1.html) | Inspect an OCI artifact |
| ls | [podman-artifact-ls(1)](https://docs.podman.io/en/latest/markdown/podman-artifact-ls.1.html) | List OCI artifacts in local store (alias list) |
| pull | [podman-artifact-pull(1)](https://docs.podman.io/en/latest/markdown/podman-artifact-pull.1.html) | Pulls an artifact from a registry and stores it locally |
| push | [podman-artifact-push(1)](https://docs.podman.io/en/latest/markdown/podman-artifact-push.1.html) | Push an OCI artifact from local storage to an image registry |
| rm | [podman-artifact-rm(1)](https://docs.podman.io/en/latest/markdown/podman-artifact-rm.1.html) | Remove one or more OCI artifacts from local storage |
