# NAME

podman-kube - Play containers, pods or volumes based on a structured input file

# SYNOPSIS

**podman kube** *subcommand*

# DESCRIPTION

The kube command recreates containers, pods or volumes based on the input from a structured (like YAML) file input. Containers are automatically started.

Note: The kube commands in podman focus on simplifying the process of moving containers from podman to a Kubernetes environment and from a Kubernetes environment back to podman. Podman is not replicating the kubectl CLI. Once containers are deployed to a Kubernetes cluster from podman, please use `kubectl` to manage the workloads in the cluster.

# COMMANDS

| Command | Man Page | Description |
|----|----|----|
| apply | [podman-kube-apply(1)](https://docs.podman.io/en/latest/markdown/podman-kube-apply.1.html) | Apply Kubernetes YAML based on containers, pods, or volumes to a Kubernetes cluster |
| down | [podman-kube-down(1)](https://docs.podman.io/en/latest/markdown/podman-kube-down.1.html) | Remove containers and pods based on Kubernetes YAML. |
| generate | [podman-kube-generate(1)](https://docs.podman.io/en/latest/markdown/podman-kube-generate.1.html) | Generate Kubernetes YAML based on containers, pods or volumes. |
| play | [podman-kube-play(1)](https://docs.podman.io/en/latest/markdown/podman-kube-play.1.html) | Create containers, pods and volumes based on Kubernetes YAML. |
