# Constant EXE_EXTENSION Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/std/env.rs.html#1172)

``` rust
pub const EXE_EXTENSION: &str;
```

Expand description

Specifies the file extension, if any, used for executable binaries on this platform. An example value may be: `"exe"`, or an empty string (`""`).

Full list of possible values

- `"bin"`
- `"exe"`
- `"efi"`
- `"js"`
- `"sgxs"`
- `"elf"`
- `"wasm"`
- `""` (an empty string)
