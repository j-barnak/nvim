🔬This is a nightly-only experimental API. (`reborrow` [\#145612](https://github.com/rust-lang/rust/issues/145612))

Expand description

Allows value to be reborrowed as exclusive, creating a copy of the value that disables the source for reads and writes for the lifetime of the copy.

## Dyn Compatibility

This trait **is** [dyn compatible](https://doc.rust-lang.org/1.98.1/reference/items/traits.html#dyn-compatibility).

*In older versions of Rust, dyn compatibility was called "object safety".*
