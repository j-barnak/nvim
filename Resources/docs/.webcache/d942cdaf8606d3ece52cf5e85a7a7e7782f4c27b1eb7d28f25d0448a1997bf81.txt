# Function vars Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/std/env.rs.html#135-137)

``` rust
pub fn vars() -> Vars ⓘ
```

Expand description

Returns an iterator of (variable, value) pairs of strings, for all the environment variables of the current process.

The returned iterator contains a snapshot of the process’s environment variables at the time of this invocation. Modifications to environment variables afterwards will not be reflected in the returned iterator.

## Panics

While iterating, the returned iterator will panic if any key or value in the environment is not valid unicode. If this is not desired, consider using [`env::vars_os()`](https://doc.rust-lang.org/std/env/fn.vars_os.html "fn std::env::vars_os").

## Examples

``` rust
// Print all environment variables.
for (key, value) in std::env::vars() {
    println!("{key}: {value}");
}
```
