pub trait CheckedCastFromInt<T>: Sized {
    // Required methods
    fn checked_cast_from(value: T) -> Option<Self>;

ⓘ *This trait cannot be implemented outside `core`.*

🔬This is a nightly-only experimental API. (`integer_casts` [\#157388](https://github.com/rust-lang/rust/issues/157388))

Expand description

Fallible conversion between integers.

Converts `value` to this type, returning `None` if overflow would have occurred.

[Source](https://doc.rust-lang.org/src/core/convert/num.rs.html#662)

🔬This is a nightly-only experimental API. (`integer_casts` [\#157388](https://github.com/rust-lang/rust/issues/157388))

Converts `value` to this type, assuming overflow cannot occur.

##### Safety

This results in undefined behavior when `value` will overflow when converted to this type.

[Source](https://doc.rust-lang.org/src/core/convert/num.rs.html#670)

🔬This is a nightly-only experimental API. (`integer_casts` [\#157388](https://github.com/rust-lang/rust/issues/157388))

Converts `value` to this type, panicking on overflow.

##### Panics

This function will always panic on overflow, regardless of whether overflow checks are enabled.

## Dyn Compatibility

This trait is **not** [dyn compatible](https://doc.rust-lang.org/1.98.1/reference/items/traits.html#dyn-compatibility).

*In older versions of Rust, dyn compatibility was called "object safety".*
