🔬This is a nightly-only experimental API. (`cmp_minmax` [\#115939](https://github.com/rust-lang/rust/issues/115939))

Expand description

Returns minimum and maximum values with respect to the specified key function.

Returns `[v1, v2]` if the comparison determines them to be equal.

## Examples

``` rust
#![feature(cmp_minmax)]
use std::cmp;

assert_eq!(cmp::minmax_by_key(-2, 1, |x: &i32| x.abs()), [1, -2]);
assert_eq!(cmp::minmax_by_key(-2, 2, |x: &i32| x.abs()), [-2, 2]);

// You can destructure the result using array patterns
let [min, max] = cmp::minmax_by_key(-42, 17, |x: &i32| x.abs());
assert_eq!(min, 17);
assert_eq!(max, -42);
```
