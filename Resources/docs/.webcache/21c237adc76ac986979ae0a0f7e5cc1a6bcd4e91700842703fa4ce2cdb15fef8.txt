class angr.analyses.xrefs.XRefsAnalysis  
Bases: [`ForwardAnalysis`](https://docs.angr.io/en/latest/api/angr.analyses.forward_analysis.forward_analysis.html#angr.analyses.forward_analysis.forward_analysis.ForwardAnalysis "angr.analyses.forward_analysis.forward_analysis.ForwardAnalysis"), [`Analysis`](https://docs.angr.io/en/latest/api/angr.analyses.analysis.html#angr.analyses.analysis.Analysis "angr.analyses.analysis.Analysis")

XRefsAnalysis recovers in-depth x-refs (cross-references) in disassembly code.

Here is an example:

    .text:
    000023C8                 LDR     R2, =time_now
    000023CA                 LDR     R3, [R2]
    000023CC                 ADDS    R3, #1
    000023CE                 STR     R3, [R2]
    000023D0                 BX      LR

    .bss:
    1FFF36F4 time_now        % 4

You will have the following x-refs for time_now:

    23c8 - offset
    23ca - read access
    23ce - write access
