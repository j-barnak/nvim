# miasm.jitter.jitload

## Classes

### class `CallbackHandler(object)`

Handle a list of callback

- **`__init__(self)`**
- **`add_callback(self, key, callback)`** - Add a callback to the key @key, iff the @callback isn't already
- **`set_callback(self, key, *args)`** - Set the list of callback for key 'key'
- **`get_callbacks(self, key)`** - Return the list of callbacks associated to key 'key'
- **`remove_callback(self, callback)`** - Remove the callback from the list.
- **`has_callbacks(self, key)`**
- **`remove_key(self, key)`** - Remove and return all callbacks associated to @key
- **`call_callbacks(self, key, *args)`** - Call callbacks associated to key 'key' with arguments args. While
- **`__call__(self, key, *args)`** - Wrapper for call_callbacks

### class `CallbackHandlerBitflag(CallbackHandler)`

Handle a list of callback with conditions on bitflag

- **`call_callbacks(self, bitflag, *args)`** - Call each callbacks associated with bit set in bitflag. While

### class `ExceptionHandle(object)`

Return type for exception handler

- **`__init__(self, except_flag)`**
- **`memoryBreakpoint(cls)`**
- **`__eq__(self, to_cmp)`**
- **`__ne__(self, to_cmp)`**

### class `JitterException(Exception)`

Raised when any unhandled exception occurs (in jitter.vm or jitter.cpu)

- **`__init__(self, exception_flag)`**
- **`__str__(self)`**
- **`exception_flag_to_str(self)`**

### class `Jitter(object)`

Main class for JIT handling

- **`__init__(self, lifter, jit_type='gcc')`** - Init an instance of jitter.
- **`init_exceptions_handler(self)`** - Add common exceptions handlers
- **`add_breakpoint(self, addr, callback)`** - Add a callback associated with addr.
- **`set_breakpoint(self, addr, *args)`** - Set callbacks associated with addr.
- **`get_breakpoint(self, addr)`** - Return breakpoints handlers for address @addr
- **`remove_breakpoints_by_callback(self, callback)`** - Remove callbacks associated with breakpoint.
- **`remove_breakpoints_by_address(self, address)`** - Remove all breakpoints associated with @address.
- **`add_exception_handler(self, flag, callback)`** - Add a callback associated with an exception flag.
- **`run_at(self, pc)`** - Wrapper on JiT backend. Run the code at PC and return the next PC.
- **`runiter_once(self, pc)`** - Iterator on callbacks results on code running from PC.
- **`init_run(self, pc)`** - Create an iterator on pc with runiter.
- **`continue_run(self, step=False, trace=False)`** - PRE: init_run.
- **`run(self, addr)`** - Launch emulation
- **`run_until(self, addr, trace=False)`** - PRE: init_run.
- **`init_stack(self)`**
- **`get_exception(self)`**
- **`get_c_str(self, addr, max_char=None)`** - Get C str from vm.
- **`set_c_str(self, addr, value)`** - Set C str str from vm.
- **`get_str_ansi(self, addr, max_char=None)`**
- **`get_str_unic(self, addr, max_char=None)`**
- **`handle_lib(jitter)`** - Resolve the name of the function which cause the handler call. Then
- **`handle_function(self, f_addr)`** - Add a breakpoint which will trigger the function handler
- **`add_lib_handler(self, libs, user_globals=None)`** - Add a function to handle libs call with breakpoints
- **`eval_expr(self, expr)`** - Eval expression @expr in the context of the current instance. Side
- **`set_trace_log(self, trace_instr=True, trace_regs=True, trace_new_blocks=False)`** - Activate/Deactivate trace log options

Function decorator to allow the use of .func_args_*() methods
with either the number of arguments or the list of the argument
names.

The wrapper is also used to log the argument values.
