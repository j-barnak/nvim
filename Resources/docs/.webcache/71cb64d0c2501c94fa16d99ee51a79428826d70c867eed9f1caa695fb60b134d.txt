Expand description

Reverses the bytes in an integer type `T`.

Note that, unlike most intrinsics, this is safe to call; it does not require an `unsafe` block. Therefore, implementations must not require the user to uphold any safety invariants.

The stabilized versions of this intrinsic are available on the integer primitives via the `swap_bytes` method. For example, [`u32::swap_bytes`](https://doc.rust-lang.org/std/primitive.u32.html#method.swap_bytes "method u32::swap_bytes")
