# angr.procedures.posix.chroot

class angr.procedures.posix.chroot.chroot  
Bases: [`SimProcedure`](https://docs.angr.io/en/latest/api/angr.sim_procedure.html#angr.sim_procedure.SimProcedure "angr.sim_procedure.SimProcedure")

Changes the root directory of the emulated filesystem (`state.fs`) to the given path.

The new root is resolved inside the filesystem the state already has, so this can only narrow what the guest is able to reach.
