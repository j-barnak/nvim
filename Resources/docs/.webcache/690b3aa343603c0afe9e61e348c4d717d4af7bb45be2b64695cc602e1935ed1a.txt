**BFS** (*UnixWare Boot File System*) is a SCO specification for a KISS [filesystem](https://wiki.osdev.org/File_Systems "File Systems") meant to be used in a [bootloader](https://wiki.osdev.org/Bootloader "Bootloader") stage. It only offers one directory (the root) and due to the way information about blocks are stored, only one file may be opened for writing at a time.
