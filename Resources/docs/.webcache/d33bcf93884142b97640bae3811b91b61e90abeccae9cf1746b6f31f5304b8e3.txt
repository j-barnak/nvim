# Rust: Releases

For the latest features, along with compatibility with the latest versions of the Rust toolchain, consider using the `main` branch of the [seL4/rust-sel4](https://github.com/seL4/rust-sel4) repository.

Releases serve as snapshots of that branch:

- Release [rust-sel4 5.0.0](https://github.com/seL4/rust-sel4/releases/tag/v5.0.0) (compatible with seL4 version [16.0.0](https://docs.sel4.systems/releases/sel4/16.0.0.html) and Microkit version [2.3.0)](https://docs.sel4.systems/releases/microkit/2.3.0.html) **(latest)**

- Release [rust-sel4 4.0.0](https://github.com/seL4/rust-sel4/releases/tag/v4.0.0) (compatible with seL4 version [15.0.0](https://docs.sel4.systems/releases/sel4/15.0.0.html) and Microkit version [2.2.0)](https://docs.sel4.systems/releases/microkit/2.2.0.html)

- Release [rust-sel4 3.0.0](https://github.com/seL4/rust-sel4/releases/tag/v3.0.0) (compatible with seL4 version [14.0.0](https://docs.sel4.systems/releases/sel4/14.0.0.html) and Microkit version [2.1.0)](https://docs.sel4.systems/releases/microkit/2.1.0.html)

- Release [rust-sel4 2.0.0](https://github.com/seL4/rust-sel4/releases/tag/v2.0.0) (compatible with seL4 version [13.0.0](https://docs.sel4.systems/releases/sel4/13.0.0.html) and Microkit version [2.0.1)](https://docs.sel4.systems/releases/microkit/2.0.1.html)

- Release [rust-sel4 1.0.0](https://github.com/seL4/rust-sel4/releases/tag/v1.0.0) (compatible with seL4 version [13.0.0](https://docs.sel4.systems/releases/sel4/13.0.0.html) and Microkit version [1.3.0)](https://docs.sel4.systems/releases/microkit/1.3.0.html)
