# Function align_of Copy item path

1.0.0 (const: 1.24.0) · [Source](https://doc.rust-lang.org/src/core/mem/mod.rs.html#540)

``` rust
pub const fn align_of<T>() -> usize
```

Expand description

Returns the [ABI](https://en.wikipedia.org/wiki/Application_binary_interface)-required minimum alignment of a type, in bytes.

Every reference to a value of the type `T` must be a multiple of this number.

This is the alignment used for struct fields. It may be smaller than the preferred alignment.

## Examples

``` rust
assert_eq!(4, align_of::<i32>());
```

(Caution: [it is not guaranteed](https://doc.rust-lang.org/reference/type-layout.html#r-layout.primitive) that the alignment of `i32` is `4`; that is, the above assertion does not pass on all platforms.)
