# NAME

podman-container - Manage containers

# SYNOPSIS

**podman container** *subcommand*

# DESCRIPTION

The container command allows management of containers

# COMMANDS

| Command | Man Page | Description |
|----|----|----|
| attach | [podman-attach(1)](https://docs.podman.io/en/latest/markdown/podman-attach.1.html) | Attach to a running container. |
| checkpoint | [podman-container-checkpoint(1)](https://docs.podman.io/en/latest/markdown/podman-container-checkpoint.1.html) | Checkpoint one or more running containers. |
| cleanup | [podman-container-cleanup(1)](https://docs.podman.io/en/latest/markdown/podman-container-cleanup.1.html) | Clean up the container’s network and mountpoints. |
| clone | [podman-container-clone(1)](https://docs.podman.io/en/latest/markdown/podman-container-clone.1.html) | Create a copy of an existing container. |
| commit | [podman-commit(1)](https://docs.podman.io/en/latest/markdown/podman-commit.1.html) | Create new image based on the changed container. |
| cp | [podman-cp(1)](https://docs.podman.io/en/latest/markdown/podman-cp.1.html) | Copy files/folders between a container and the local filesystem. |
| create | [podman-create(1)](https://docs.podman.io/en/latest/markdown/podman-create.1.html) | Create a new container. |
| diff | [podman-container-diff(1)](https://docs.podman.io/en/latest/markdown/podman-container-diff.1.html) | Inspect changes on a container’s filesystem |
| exec | [podman-exec(1)](https://docs.podman.io/en/latest/markdown/podman-exec.1.html) | Execute a command in a running container. |
| exists | [podman-container-exists(1)](https://docs.podman.io/en/latest/markdown/podman-container-exists.1.html) | Check if a container exists in local storage |
| export | [podman-export(1)](https://docs.podman.io/en/latest/markdown/podman-export.1.html) | Export a container’s filesystem contents as a tar archive. |
| init | [podman-init(1)](https://docs.podman.io/en/latest/markdown/podman-init.1.html) | Initialize a container |
| inspect | [podman-container-inspect(1)](https://docs.podman.io/en/latest/markdown/podman-container-inspect.1.html) | Display a container’s configuration. |
| kill | [podman-kill(1)](https://docs.podman.io/en/latest/markdown/podman-kill.1.html) | Kill the main process in one or more containers. |
| list | [podman-ps(1)](https://docs.podman.io/en/latest/markdown/podman-ps.1.html) | List the containers on the system.(alias ls) |
| logs | [podman-logs(1)](https://docs.podman.io/en/latest/markdown/podman-logs.1.html) | Display the logs of a container. |
| mount | [podman-mount(1)](https://docs.podman.io/en/latest/markdown/podman-mount.1.html) | Mount a working container’s root filesystem. |
| pause | [podman-pause(1)](https://docs.podman.io/en/latest/markdown/podman-pause.1.html) | Pause one or more containers. |
| port | [podman-port(1)](https://docs.podman.io/en/latest/markdown/podman-port.1.html) | List port mappings for the container. |
| prune | [podman-container-prune(1)](https://docs.podman.io/en/latest/markdown/podman-container-prune.1.html) | Remove all stopped containers not associated with pods from local storage. |
| ps | [podman-ps(1)](https://docs.podman.io/en/latest/markdown/podman-ps.1.html) | Print out information about containers. |
| rename | [podman-rename(1)](https://docs.podman.io/en/latest/markdown/podman-rename.1.html) | Rename an existing container. |
| restart | [podman-restart(1)](https://docs.podman.io/en/latest/markdown/podman-restart.1.html) | Restart one or more containers. |
| restore | [podman-container-restore(1)](https://docs.podman.io/en/latest/markdown/podman-container-restore.1.html) | Restore one or more containers from a checkpoint. |
| rm | [podman-rm(1)](https://docs.podman.io/en/latest/markdown/podman-rm.1.html) | Remove one or more containers. |
| run | [podman-run(1)](https://docs.podman.io/en/latest/markdown/podman-run.1.html) | Run a command in a container. |
| runlabel | [podman-container-runlabel(1)](https://docs.podman.io/en/latest/markdown/podman-container-runlabel.1.html) | Execute a command as described by a container-image label. |
| start | [podman-start(1)](https://docs.podman.io/en/latest/markdown/podman-start.1.html) | Start one or more containers. |
| stats | [podman-stats(1)](https://docs.podman.io/en/latest/markdown/podman-stats.1.html) | Display a live stream of one or more container’s resource usage statistics. |
| stop | [podman-stop(1)](https://docs.podman.io/en/latest/markdown/podman-stop.1.html) | Stop one or more running containers. |
| top | [podman-top(1)](https://docs.podman.io/en/latest/markdown/podman-top.1.html) | Display the running processes of a container. |
| unmount | [podman-unmount(1)](https://docs.podman.io/en/latest/markdown/podman-unmount.1.html) | Unmount a working container’s root filesystem.(Alias unmount) |
| unpause | [podman-unpause(1)](https://docs.podman.io/en/latest/markdown/podman-unpause.1.html) | Unpause one or more containers. |
| update | [podman-update(1)](https://docs.podman.io/en/latest/markdown/podman-update.1.html) | Update the cgroup configuration of a given container. |
| wait | [podman-wait(1)](https://docs.podman.io/en/latest/markdown/podman-wait.1.html) | Wait on one or more containers to stop and print their exit codes. |
