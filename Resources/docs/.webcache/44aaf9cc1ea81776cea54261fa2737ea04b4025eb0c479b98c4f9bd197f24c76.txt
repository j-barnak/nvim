#  Python API - Methods and namespaces of the triton module

------------------------------------------------------------------------

This project works using a `TritonContext` which contains all the required internal state to simulate your instructions. You may also find [helpers](https://github.com/JonathanSalwan/Triton/tree/master/src/examples/python) to wrap more generic concepts.
