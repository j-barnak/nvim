Like [`list_for_each_entry()`](#drgn.helpers.linux.list.list_for_each_entry "drgn.helpers.linux.list.list_for_each_entry"), but validates the list like [`validate_list()`](#drgn.helpers.linux.list.validate_list "drgn.helpers.linux.list.validate_list") while iterating.

Note that this may yield duplicate entries before a cycle is detected.

    def validate_my_list(prog):
         for entry in validate_list_for_each_entry(
             "struct my_entry",
             prog["my_list"].address_of_(),
             "list",
         ):
             if entry.value < 0:
                 raise ValidationError("list contains negative entry")
