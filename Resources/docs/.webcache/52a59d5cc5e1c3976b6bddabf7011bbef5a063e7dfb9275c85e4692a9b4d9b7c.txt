OS-specific extensions to [`fs::Metadata`](https://doc.rust-lang.org/std/fs/struct.Metadata.html "struct std::fs::Metadata").

## Required Methods

1.1.0 · [Source](https://doc.rust-lang.org/src/std/os/linux/fs.rs.html#42)

👎Deprecated since 1.8.0:

other methods of this trait are now preferred

Gain a reference to the underlying `stat` structure which contains the raw information returned by the OS.

The contents of the returned [`stat`](https://doc.rust-lang.org/std/os/linux/raw/struct.stat.html "struct std::os::linux::raw::stat") are **not** consistent across Unix platforms. The `os::unix::fs::MetadataExt` trait contains the cross-Unix abstractions contained within the raw stat.

##### Examples

``` rust
use std::fs;
use std::io;
use std::os::linux::fs::MetadataExt;

fn main() -> io::Result<()> {
    let meta = fs::metadata("some_file")?;
    let stat = meta.as_raw_stat();
    Ok(())
}
```
