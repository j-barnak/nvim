Expand description

Creates a new iterator that endlessly repeats a single element.

The `repeat()` function repeats a single value over and over again.

Infinite iterators like `repeat()` are often used with adapters like [`Iterator::take()`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.take "method std::iter::Iterator::take"), in order to make them finite.

If you know the number of repetitions in advance, consider using [`repeat_n()`](https://doc.rust-lang.org/std/iter/fn.repeat_n.html "fn std::iter::repeat_n") instead, as it is more efficient and conveys the intent more clearly.

Use [`str::repeat()`](https://doc.rust-lang.org/std/primitive.str.html#method.repeat) instead of this function if you just want to repeat a char/string `n` times.

If the element type of the iterator you need does not implement `Clone`, or if you do not want to keep the repeated element in memory, you can instead use the [`repeat_with()`](https://doc.rust-lang.org/std/iter/fn.repeat_with.html "fn std::iter::repeat_with") function.

## Examples

Basic usage:

``` rust
use std::iter;

// the number four 4ever:
let mut fours = iter::repeat(4);

assert_eq!(Some(4), fours.next());
assert_eq!(Some(4), fours.next());
assert_eq!(Some(4), fours.next());
assert_eq!(Some(4), fours.next());
assert_eq!(Some(4), fours.next());

// yup, still four
assert_eq!(Some(4), fours.next());
```

Going finite with [`Iterator::take()`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.take "method std::iter::Iterator::take"):

``` rust
use std::iter;

// that last example was too many fours. Let's only have four fours.
let mut four_fours = iter::repeat(4).take(4);

assert_eq!(Some(4), four_fours.next());
assert_eq!(Some(4), four_fours.next());
assert_eq!(Some(4), four_fours.next());
assert_eq!(Some(4), four_fours.next());

// ... and now we're done
assert_eq!(None, four_fours.next());
```
