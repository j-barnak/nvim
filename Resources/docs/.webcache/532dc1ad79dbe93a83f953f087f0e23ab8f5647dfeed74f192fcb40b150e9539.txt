# Enum TryRecvError Copy item path

[Source](https://doc.rust-lang.org/src/std/sync/oneshot.rs.html#341-349)

``` rust
pub enum TryRecvError<T> {
    Empty(Receiver<T>),
    Disconnected,
}
```

🔬This is a nightly-only experimental API. (`oneshot_channel` [\#143674](https://github.com/rust-lang/rust/issues/143674))

Expand description

An error returned from the [`try_recv`](https://doc.rust-lang.org/std/sync/oneshot/struct.Receiver.html#method.try_recv "method std::sync::oneshot::Receiver::try_recv") method.

See the documentation for [`try_recv`](https://doc.rust-lang.org/std/sync/oneshot/struct.Receiver.html#method.try_recv "method std::sync::oneshot::Receiver::try_recv") for more information on how to use this error.

## Variants

🔬This is a nightly-only experimental API. (`oneshot_channel` [\#143674](https://github.com/rust-lang/rust/issues/143674))

The [`Sender`](https://doc.rust-lang.org/std/sync/oneshot/struct.Sender.html "struct std::sync::oneshot::Sender") has not sent a message yet, but it might in the future (as it has not yet disconnected). This variant contains the [`Receiver`](https://doc.rust-lang.org/std/sync/oneshot/struct.Receiver.html "struct std::sync::oneshot::Receiver") that [`try_recv`](https://doc.rust-lang.org/std/sync/oneshot/struct.Receiver.html#method.try_recv "method std::sync::oneshot::Receiver::try_recv") took ownership over.

🔬This is a nightly-only experimental API. (`oneshot_channel` [\#143674](https://github.com/rust-lang/rust/issues/143674))

The corresponding [`Sender`](https://doc.rust-lang.org/std/sync/oneshot/struct.Sender.html "struct std::sync::oneshot::Sender") half of this channel has become disconnected, and there will never be any more data sent over the channel.
