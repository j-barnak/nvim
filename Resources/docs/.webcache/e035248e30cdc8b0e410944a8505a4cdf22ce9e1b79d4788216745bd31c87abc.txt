### 33.4 Using `sysconf`

When your system has configurable system limits, you can use the `sysconf` function to find out the value that applies to any particular machine. The function and the associated `parameter` constants are declared in the header file `unistd.h`.

- [Definition of `sysconf`](https://sourceware.org/glibc/manual/latest/html_node/Sysconf-Definition.html)
- [Constants for `sysconf` Parameters](https://sourceware.org/glibc/manual/latest/html_node/Constants-for-Sysconf.html)
- [Examples of `sysconf`](https://sourceware.org/glibc/manual/latest/html_node/Examples-of-Sysconf.html)
