# 2.1. When building Valgrind, 'make' dies partway with an assertion failure, something like this: % make: expand.c:489: allocated_variable_append: Assertion 'current_variable_set_list-&gt;next != 0' failed.

It's probably a bug in 'make'. Some, but not all, instances of version 3.79.1 have this bug, see [this](http://www.mail-archive.com/bug-make@gnu.org/msg01658.html). Try upgrading to a more recent version of 'make'. Alternatively, we have heard that unsetting the CFLAGS environment variable avoids the problem.
