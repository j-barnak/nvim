# Function from_fn Copy item path

1.93.0 (const: 1.95.0) · [Source](https://doc.rust-lang.org/src/core/fmt/builders.rs.html#1232)

``` rust
pub const fn from_fn<F>(f: F) -> FromFn<F>where
    F: Fn(&mut Formatter<'_>) -> Result<(), Error>,
```

Expand description

Creates a type whose [`fmt::Debug`](https://doc.rust-lang.org/std/fmt/trait.Debug.html "trait std::fmt::Debug") and [`fmt::Display`](https://doc.rust-lang.org/std/fmt/trait.Display.html "trait std::fmt::Display") impls are forwarded to the provided closure.

## Examples

``` rust
use std::fmt;

let value = 'a';
assert_eq!(format!("{}", value), "a");
assert_eq!(format!("{:?}", value), "'a'");

let wrapped = fmt::from_fn(|f| write!(f, "{value:?}"));
assert_eq!(format!("{}", wrapped), "'a'");
assert_eq!(format!("{:?}", wrapped), "'a'");
```
