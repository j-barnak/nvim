Expand description

The global memory allocator.

This type implements the [`Allocator`](https://doc.rust-lang.org/std/alloc/trait.Allocator.html "trait std::alloc::Allocator") trait by forwarding calls to the allocator registered with the `#[global_allocator]` attribute if there is one, or the `std` crate’s default.

Note: while this type is unstable, the functionality it provides can be accessed through the [free functions in `alloc`](https://doc.rust-lang.org/alloc/alloc/index.html#functions "mod alloc::alloc").
