# 7.4. Nested *`if/then`* Condition Tests

Condition tests using the *`if/then`* construct may be nested. The net result is equivalent to using the [*&&*](https://tldp.org/LDP/abs/html/ops.html#LOGOPS1) compound comparison operator.

``` bash
a=3

if [ "$a" -gt 0 ]
then
  if [ "$a" -lt 5 ]
  then
    echo "The value of \"a\" lies somewhere between 0 and 5."
  fi
fi

# Same result as:

if [ "$a" -gt 0 ] && [ "$a" -lt 5 ]
then
  echo "The value of \"a\" lies somewhere between 0 and 5."
fi
```

[Example 37-4](https://tldp.org/LDP/abs/html/bashver2.html#CARDS) and [Example 17-11](https://tldp.org/LDP/abs/html/system.html#BACKLIGHT) demonstrate nested *`if/then`* condition tests.
