If you want to write an operating system in C, you'll [need a cross-compiler](https://wiki.osdev.org/Why_do_I_need_a_Cross_Compiler "Why do I need a Cross Compiler"). However, [building a GCC cross-compiler](https://wiki.osdev.org/GCC_Cross-Compiler "GCC Cross-Compiler") can be painful. If you just want to write C (not C++), you can use [zig cc](https://andrewkelley.me/post/zig-cc-powerful-drop-in-replacement-gcc-clang.html) - a C cross-compiler that comes with the [Zig programming language](https://ziglang.org/). There are [pre-compiled binaries](https://ziglang.org/download/) for Windows, Linux, MacOS, and FreeBSD.

## Bare-Bones with zig cc

This section describes how to build [Bare Bones](https://wiki.osdev.org/Bare_Bones "Bare Bones") using zig cc. First off, install the following software:

- [Zig](https://ziglang.org/download/) (tested with version 0.6.0)
- GNU binutils (we just care about the [linker](https://wiki.osdev.org/LD "LD") - if ld --version reports "GNU ld", you're good to go)
- [NASM](https://wiki.osdev.org/NASM "NASM")

Start off with the standard [Bare Bones](https://wiki.osdev.org/Bare_Bones "Bare Bones") setup, but use the boot.asm file provided in [Bare Bones with NASM](https://wiki.osdev.org/Bare_Bones_with_NASM "Bare Bones with NASM") instructions (since Zig does not come with an assembler, just a C compiler). At that point, you can continue with [Bare Bones](https://wiki.osdev.org/Bare_Bones "Bare Bones"), but instead of using i686-elf-gcc, use the following command to build kernel.c:

``` shell-session
$ zig build-obj --c-source kernel.c -target i386-freestanding
```

This should create a kernel.o file, just the same as if you had used gcc.

When you get to the linking step, we won't be able to use i686-elf-gcc, but luckily, modern versions of [GNU ld](https://wiki.osdev.org/LD "LD") are able to emulate almost any other linker, so we can use the system ld like so:

``` shell-session
$ ld -m elf_i386 -T linker.ld -o myos.bin boot.o kernel.o
```

And at that point, you can carry on with [Bare Bones](https://wiki.osdev.org/Bare_Bones "Bare Bones"), and you should have an operating system, compiled without having to compile your own cross-compiler!
