# angr.utils.loader

angr.utils.loader.is_pc(*project*, *ins_addr*, *addr*)  
Check if the given address is program counter (PC) or not. This function is for handling the case on some bizarre architectures where PC is always the currently executed instruction address plus a constant value.

Parameters:  
- **project** ([`Project`](https://docs.angr.io/en/latest/api/angr.project.html#angr.project.Project "angr.project.Project")) – An angr Project instance.

- **ins_addr** ([`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")) – The address of an instruction. We calculate PC using this instruction address.

- **addr** ([`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")) – The address to check against.

Return type:  
[`bool`](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")

Returns:  
True if the given instruction address is the PC, False otherwise.
