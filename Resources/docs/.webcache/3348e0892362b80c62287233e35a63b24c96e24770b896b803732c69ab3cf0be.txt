Expand description

Minimum with the current value using a signed comparison. `T` must be a signed integer type.

The stabilized version of this intrinsic is available on the [`atomic`](https://doc.rust-lang.org/std/sync/atomic/index.html "mod std::sync::atomic") signed integer types via the `fetch_min` method. For example, [`AtomicI32::fetch_min`](https://doc.rust-lang.org/std/sync/atomic/struct.Atomic.html#method.fetch_min "method std::sync::atomic::Atomic::fetch_min").
