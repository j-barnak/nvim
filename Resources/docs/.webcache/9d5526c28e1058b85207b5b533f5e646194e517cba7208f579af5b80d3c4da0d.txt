# Constant DLL_SUFFIX Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/std/env.rs.html#1129)

``` rust
pub const DLL_SUFFIX: &str;
```

Expand description

Specifies the filename suffix, if any, used for shared libraries on this platform. An example value may be: `".so"`, `".elf"`, or `".dll"`.

The possible values are identical to those of [`DLL_EXTENSION`](https://doc.rust-lang.org/std/env/consts/constant.DLL_EXTENSION.html "constant std::env::consts::DLL_EXTENSION"), but with the leading period included.
