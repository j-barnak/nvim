### [Specification](#specification)

Here’s what we’ll add to our basic language in this tutorial. (This is also the point where our project stops resembling traditional BASIC, so purists may want to look away.)

-

  We’ll add the def statement, which will let us create callable [functions](https://beautifulracket.com/basic-3/functions.html).

-

  We’ll support [imports](https://beautifulracket.com/basic-3/imports.html) from existing Racket libraries by adding an import statement that’s equivalent to Racket’s [require](http://docs.racket-lang.org/reference/require.html#(form._((lib._racket/private/base..rkt)._require))).

-

  We’ll alter our language so every program automatically [exports](https://beautifulracket.com/basic-3/exports.html) its defined functions and variables.

-

  We’ll see how to reprogram [the REPL](https://beautifulracket.com/basic-3/the-repl.html) to understand BASIC-style statements and expressions.

-

  For fun, we’ll see how we can handle [command-line arguments](https://beautifulracket.com/basic-3/command-line-arguments.html).
