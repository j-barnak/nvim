Analysis of ARM MTE
1: char *ptr = new char[16];

2: ptr[17] = 42;
3: delete [] ptr;
Color mismatch
4: ptr[3] = 0; //use after free

• Where to store tags (key and lock)?
• Pointer tag is stored in top unused bits inside the
pointer (no extra register needed)
• Physical memory tag is stored in hardware (new
hardware needed for both DRAM and cache)
• Limited tag bits
• Cannot ensure two allocations have different colors
• But can ensure that the tags of sequential
allocations are always different
