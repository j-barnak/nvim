# Linux Kernel / Nulls Lists

The `drgn.helpers.linux.list_nulls` module provides helpers for working with the special version of lists (`struct`` ``hlist_nulls_head` and `struct`` ``hlist_nulls_node`) in [`include/linux/list_nulls.h`](https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/include/linux/list_nulls.h) where the end of list is not a `NULL` pointer, but a “nulls” marker.
