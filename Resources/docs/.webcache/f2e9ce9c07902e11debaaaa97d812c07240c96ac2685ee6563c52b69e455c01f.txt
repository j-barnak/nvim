# Module mem Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/core/lib.rs.html#263)

Expand description

Basic functions for dealing with memory, values, and types.

The contents of this module can be seen as belonging to a few families:

- [`drop`](https://doc.rust-lang.org/std/mem/fn.drop.html "fn std::mem::drop"), [`replace`](https://doc.rust-lang.org/std/mem/fn.replace.html "fn std::mem::replace"), [`swap`](https://doc.rust-lang.org/std/mem/fn.swap.html "fn std::mem::swap"), and [`take`](https://doc.rust-lang.org/std/mem/fn.take.html "fn std::mem::take") are safe functions for moving values in particular ways. They are useful in everyday Rust code.

- [`size_of`](https://doc.rust-lang.org/std/mem/fn.size_of.html "fn std::mem::size_of"), [`size_of_val`](https://doc.rust-lang.org/std/mem/fn.size_of_val.html "fn std::mem::size_of_val"), [`align_of`](https://doc.rust-lang.org/std/mem/fn.align_of.html "fn std::mem::align_of"), [`align_of_val`](https://doc.rust-lang.org/std/mem/fn.align_of_val.html "fn std::mem::align_of_val"), and [`offset_of`](https://doc.rust-lang.org/std/mem/macro.offset_of.html "macro std::mem::offset_of") give information about the representation of values in memory.

- [`discriminant`](https://doc.rust-lang.org/std/mem/fn.discriminant.html "fn std::mem::discriminant") allows comparing the variants of [`enum`](https://doc.rust-lang.org/std/keyword.enum.html) values while ignoring their fields.

- [`forget`](https://doc.rust-lang.org/std/mem/fn.forget.html "fn std::mem::forget") and [`ManuallyDrop`](https://doc.rust-lang.org/std/mem/struct.ManuallyDrop.html "struct std::mem::ManuallyDrop") prevent destructors from running, which is used in certain kinds of ownership transfer. [`needs_drop`](https://doc.rust-lang.org/std/mem/fn.needs_drop.html "fn std::mem::needs_drop") tells you whether a type’s destructor even does anything.

- [`transmute`](https://doc.rust-lang.org/std/mem/fn.transmute.html "fn std::mem::transmute"), [`transmute_copy`](https://doc.rust-lang.org/std/mem/fn.transmute_copy.html "fn std::mem::transmute_copy"), and [`MaybeUninit`](https://doc.rust-lang.org/std/mem/union.MaybeUninit.html "union std::mem::MaybeUninit") convert and construct values in [`unsafe`](https://doc.rust-lang.org/std/keyword.unsafe.html) ways.

See also the [`alloc`](https://doc.rust-lang.org/std/alloc/index.html) and [`ptr`](https://doc.rust-lang.org/std/ptr/index.html "mod std::ptr") modules for more primitive operations on memory.
