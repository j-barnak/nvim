🔬This is a nightly-only experimental API. (`core_intrinsics`)

Expand description

Bitwise or with the current value, returning the previous value. `T` must be an integer or pointer type. `U` must be the same as `T` if that is an integer type, or `usize` if `T` is a pointer type.

The stabilized version of this intrinsic is available on the [`atomic`](https://doc.rust-lang.org/std/sync/atomic/index.html "mod std::sync::atomic") types via the `fetch_or` method. For example, [`AtomicBool::fetch_or`](https://doc.rust-lang.org/std/sync/atomic/struct.Atomic.html#method.fetch_or "method std::sync::atomic::Atomic::fetch_or").
