🔬This is a nightly-only experimental API. (`core_intrinsics`)

Expand description

Loads the current value of the pointer. `T` must be an integer or pointer type.

The stabilized version of this intrinsic is available on the [`atomic`](https://doc.rust-lang.org/std/sync/atomic/index.html "mod std::sync::atomic") types via the `load` method. For example, [`AtomicBool::load`](https://doc.rust-lang.org/std/sync/atomic/struct.Atomic.html#method.load "method std::sync::atomic::Atomic::load").
