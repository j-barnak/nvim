# Constant MAIN_SEPARATOR_STR Copy item path

1.68.0 · [Source](https://doc.rust-lang.org/src/std/path.rs.html#295)

``` rust
pub const MAIN_SEPARATOR_STR: &str;
```

Expand description

The primary separator of path components for the current platform, represented as a [`&str`](https://doc.rust-lang.org/std/primitive.str.html "primitive str"); for example, this is `"/"` on Unix and `"\\"` on Windows.
