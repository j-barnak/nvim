``` rust
pub struct Weak<T, A = Global>where
    A: Allocator,

```

Expand description

`Weak` is a version of [`Rc`](https://doc.rust-lang.org/std/rc/struct.Rc.html "struct std::rc::Rc") that holds a non-owning reference to the managed allocation.

The allocation is accessed by calling [`upgrade`](https://doc.rust-lang.org/std/rc/struct.Weak.html#method.upgrade "method std::rc::Weak::upgrade") on the `Weak` pointer, which returns an [`Option`](https://doc.rust-lang.org/std/option/enum.Option.html "enum std::option::Option")`<`[`Rc`](https://doc.rust-lang.org/std/rc/struct.Rc.html "struct std::rc::Rc")`<T>>`.

Since a `Weak` reference does not count towards ownership, it will not prevent the value stored in the allocation from being dropped, and `Weak` itself makes no guarantees about the value still being present. Thus it may return [`None`](https://doc.rust-lang.org/std/option/enum.Option.html#variant.None "variant std::option::Option::None") when [`upgrade`](https://doc.rust-lang.org/std/rc/struct.Weak.html#method.upgrade "method std::rc::Weak::upgrade")d. Note however that a `Weak` reference *does* prevent the allocation itself (the backing store) from being deallocated.

A `Weak` pointer is useful for keeping a temporary reference to the allocation managed by [`Rc`](https://doc.rust-lang.org/std/rc/struct.Rc.html "struct std::rc::Rc") without preventing its inner value from being dropped. It is also used to prevent circular references between [`Rc`](https://doc.rust-lang.org/std/rc/struct.Rc.html "struct std::rc::Rc") pointers, since mutual owning references would never allow either [`Rc`](https://doc.rust-lang.org/std/rc/struct.Rc.html "struct std::rc::Rc") to be dropped. For example, a tree could have strong [`Rc`](https://doc.rust-lang.org/std/rc/struct.Rc.html "struct std::rc::Rc") pointers from parent nodes to children, and `Weak` pointers from children back to their parents.

The typical way to obtain a `Weak` pointer is to call [`Rc::downgrade`](https://doc.rust-lang.org/std/rc/struct.Rc.html#method.downgrade "associated function std::rc::Rc::downgrade").

1.45.0 · [Source](https://doc.rust-lang.org/src/alloc/rc.rs.html#3319)

Converts a raw pointer previously created by [`into_raw`](https://doc.rust-lang.org/std/rc/struct.Weak.html#method.into_raw "method std::rc::Weak::into_raw") back into `Weak<T>`.

This can be used to safely get a strong reference (by calling [`upgrade`](https://doc.rust-lang.org/std/rc/struct.Weak.html#method.upgrade "method std::rc::Weak::upgrade") later) or to deallocate the weak count by dropping the `Weak<T>`.

It takes ownership of one weak reference (with the exception of pointers created by [`new`](https://doc.rust-lang.org/std/rc/struct.Weak.html#method.new "associated function std::rc::Weak::new"), as these don’t own anything; the method still works on them).

##### Safety

The pointer must have originated from the [`into_raw`](https://doc.rust-lang.org/std/rc/struct.Weak.html#method.into_raw "method std::rc::Weak::into_raw") and must still own its potential weak reference, and `ptr` must point to a block of memory allocated by the global allocator.

It is allowed for the strong count to be 0 at the time of calling this. Nevertheless, this takes ownership of one weak reference currently represented as a raw pointer (the weak count is not modified by this operation) and therefore it must be paired with a previous call to [`into_raw`](https://doc.rust-lang.org/std/rc/struct.Weak.html#method.into_raw "method std::rc::Weak::into_raw").

##### Examples

``` rust
use std::rc::{Rc, Weak};

let strong = Rc::new("hello".to_owned());

let raw_1 = Rc::downgrade(&strong).into_raw();
let raw_2 = Rc::downgrade(&strong).into_raw();

assert_eq!(2, Rc::weak_count(&strong));

assert_eq!("hello", &*unsafe { Weak::from_raw(raw_1) }.upgrade().unwrap());
assert_eq!(1, Rc::weak_count(&strong));

drop(strong);

// Decrement the last weak count.
assert!(unsafe { Weak::from_raw(raw_2) }.upgrade().is_none());
```

1.45.0 · [Source](https://doc.rust-lang.org/src/alloc/rc.rs.html#3392)

Returns a raw pointer to the object `T` pointed to by this `Weak<T>`.

The pointer is valid only if there are some strong references. The pointer may be dangling, unaligned or even [`null`](https://doc.rust-lang.org/std/ptr/fn.null.html "fn std::ptr::null") otherwise.

##### Examples

``` rust
use std::rc::Rc;
use std::ptr;

let strong = Rc::new("hello".to_owned());
let weak = Rc::downgrade(&strong);
// Both point to the same object
assert!(ptr::eq(&*strong, weak.as_ptr()));
// The strong here keeps it alive, so we can still access the object.
assert_eq!("hello", unsafe { &*weak.as_ptr() });

drop(strong);
// But not any more. We can do weak.as_ptr(), but accessing the pointer would lead to
// undefined behavior.
// assert_eq!("hello", unsafe { &*weak.as_ptr() });
```

Consumes the `Weak<T>`, returning the wrapped pointer and allocator.

This converts the weak pointer into a raw pointer, while still preserving the ownership of one weak reference (the weak count is not modified by this operation). It can be turned back into the `Weak<T>` with [`from_raw_in`](https://doc.rust-lang.org/std/rc/struct.Weak.html#method.from_raw_in "associated function std::rc::Weak::from_raw_in").

The same restrictions of accessing the target of the pointer as with [`as_ptr`](https://doc.rust-lang.org/std/rc/struct.Weak.html#method.as_ptr "method std::rc::Weak::as_ptr") apply.

##### Examples

``` rust
#![feature(allocator_api)]
use std::rc::{Rc, Weak};
use std::alloc::System;

let strong = Rc::new_in("hello".to_owned(), System);
let weak = Rc::downgrade(&strong);
let (raw, alloc) = weak.into_raw_with_allocator();

assert_eq!(1, Rc::weak_count(&strong));
assert_eq!("hello", unsafe { &*raw });

drop(unsafe { Weak::from_raw_in(raw, alloc) });
assert_eq!(0, Rc::weak_count(&strong));
```

1.4.0 · [Source](https://doc.rust-lang.org/src/alloc/rc.rs.html#3542-3544)

Attempts to upgrade the `Weak` pointer to an [`Rc`](https://doc.rust-lang.org/std/rc/struct.Rc.html "struct std::rc::Rc"), delaying dropping of the inner value if successful.

Returns [`None`](https://doc.rust-lang.org/std/option/enum.Option.html#variant.None "variant std::option::Option::None") in the following cases:

1.  The inner value has since been dropped or moved out.

2.  This `Weak` does not point to an allocation.

3.  The owning reference this `Weak` is associated with is either not fully-constructed or does not allow an upgrade.

##### Examples

``` rust
use std::rc::Rc;

let five = Rc::new(5);

let weak_five = Rc::downgrade(&five);

let strong_five: Option<Rc<_>> = weak_five.upgrade();
assert!(strong_five.is_some());

// Destroy all strong pointers.
drop(strong_five);
drop(five);

assert!(weak_five.upgrade().is_none());
```

1.39.0 · [Source](https://doc.rust-lang.org/src/alloc/rc.rs.html#3643)

Returns `true` if the two `Weak`s point to the same allocation similar to [`ptr::eq`](https://doc.rust-lang.org/std/ptr/fn.eq.html "fn std::ptr::eq"), or if both don’t point to any allocation (because they were created with `Weak::new()`). However, this function ignores the metadata of `dyn Trait` pointers.

##### Notes

Since this compares pointers it means that `Weak::new()` will equal each other, even though they don’t point to any allocation.

##### Examples

``` rust
use std::rc::Rc;

let first_rc = Rc::new(5);
let first = Rc::downgrade(&first_rc);
let second = Rc::downgrade(&first_rc);

assert!(first.ptr_eq(&second));

let third_rc = Rc::new(5);
let third = Rc::downgrade(&third_rc);

assert!(!first.ptr_eq(&third));
```

Comparing `Weak::new`.

``` rust
use std::rc::{Rc, Weak};

let first = Weak::new();
let second = Weak::new();
assert!(first.ptr_eq(&second));

let third_rc = Rc::new(());
let third = Rc::downgrade(&third_rc);
assert!(!first.ptr_eq(&third));
```

Drops the `Weak` pointer.

##### Examples

``` rust
use std::rc::{Rc, Weak};

struct Foo;

impl Drop for Foo {
    fn drop(&mut self) {
        println!("dropped!");
    }
}

let foo = Rc::new(Foo);
let weak_foo = Rc::downgrade(&foo);
let other_weak_foo = Weak::clone(&weak_foo);

drop(weak_foo);   // Doesn't print anything
drop(foo);        // Prints "dropped!"

assert!(other_weak_foo.upgrade().is_none());
```
