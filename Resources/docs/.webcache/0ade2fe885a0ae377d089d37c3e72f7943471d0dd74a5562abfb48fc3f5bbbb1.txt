Expand description

Equivalent to C’s `signed int` (`int`) type.

This type will almost always be [`i32`](https://doc.rust-lang.org/std/primitive.i32.html "primitive i32"), but may differ on some esoteric systems. The C standard technically only requires that this type be a signed integer that is at least the size of a [`short`](https://doc.rust-lang.org/std/os/raw/type.c_short.html "type std::os::raw::c_short"); some systems define it as an [`i16`](https://doc.rust-lang.org/std/primitive.i16.html "primitive i16"), for example.
