### Register

class Register : public LIEF::assembly::riscv::[Operand](#_CPPv4N4LIEF8assembly5riscv7OperandE "LIEF::assembly::riscv::Operand")    
This class represents a register operand.

RISC-V exposes two kinds of registers: regular registers (GPR, FPR, vector, …) and control and status registers (CSR / system registers).

    csrr    a0, mstatus
            |   |
     +------+   +-------+
     |                  |
     v                  v
     REG              SYSREG
