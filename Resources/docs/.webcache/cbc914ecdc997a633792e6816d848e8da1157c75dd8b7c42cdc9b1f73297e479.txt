# Copy propagation

In [compiler theory](https://en.wikipedia.org/wiki/Compiler_theory "Compiler theory"), **copy propagation** is the process of replacing the occurrences of targets of direct assignments with their values.^([\[1\]](#cite_note-dragonbook-1)) A direct assignment is an instruction of the form `x = y`, which simply assigns the value of `y` to `x`.

From the following code:

```
y = x
z = 3 + y
```

Copy propagation would yield:

```
z = 3 + x
```

Copy propagation often makes use of [reaching definitions](https://en.wikipedia.org/wiki/Reaching_definitions "Reaching definitions") and [def-use chains](https://en.wikipedia.org/wiki/Def-use_chains "Def-use chains") when computing which occurrences of the target may be safely replaced. If all [upwards exposed uses](https://en.wikipedia.org/wiki/Upwards_exposed_uses "Upwards exposed uses") of the target may be safely modified, the assignment operation may be eliminated.

Copy propagation is a useful "clean up" optimization frequently used after other compiler passes have already been run. Some optimizations—such as classical implementations of [elimination of common sub expressions](https://en.wikipedia.org/wiki/Elimination_of_common_sub_expressions "Elimination of common sub expressions")^([\[1\]](#cite_note-dragonbook-1))—*require* that copy propagation be run afterwards in order to achieve an increase in efficiency.
