Lattices
• All our dataflow analyses map program points
to elements of a lattice.
• A complete lattice L = (S, ≤, ∨, ∧, ⊥, T) is
formed by:

15-411/611

– A set S
– A partial order ≤ between elements of S.
– A least element ⊥
– A greatest element T
– A join operator ∨
– A meet operator ∧

14

Least Upper Bound & Join
• If L = (S, ≤, ∨, ∧, ⊥, T) is a complete lattice,
and e1 ∈ S and e2 ∈ S, then
least upper bound of {e1, e2} ≡ elub= (e2 ∨ e1) ∈ S
• ∨ is the “join” operator
• elub, the least upper bound, has the properties:
– e1 ≤ elub and e2 ≤ elub
– For all e' ∈ S, if e1 ≤ e' and e2 ≤ e', then elub ≤ e‘

• least upper bound of S’⊆S, is pairwise lub of all
elements of S’
• For L to be a lattice, for all S’⊆S, lub(S’) ∈ S

15-411/611

Note: lub(S’) may not be in S’

15

Greatest Lower Bound & Meet
• If L = (S, ≤, ∨, ∧, ⊥, T) is a complete lattice,
and e1 ∈ S and e2 ∈ S, then
greatest lower bound of {e1, e2} ≡ eglb= (e2 ∧ e1) ∈ S
• ∧ is the “meet” operator
• eglb, the greatest lower bound, has the properties:
– eglb ≤ e1 and eglb ≤ e2
– For all e' ∈ S, if e1 ≤ e' and e2 ≤ e', then e' ≤ eglb

• greatest lower bound of S’⊆S, is pairwise glb of
all elements of S’
• For L to be a lattice, for all S’⊆S, glb(S’) ∈ S

15-411/611

Note: glb(S’) may not be in S’

Properties of join (and meet)
• Join is idempotent:
x∨x=x
• Join is commutative: y ∨ x = x ∨ y
• Join is associative:
x ∨ (y ∨ z) = (x ∨ y) ∨ z
• Join has a multiplicative one:
for all x in S, (⊥∨ x) = x
• Join has a multiplicative zero:
for all x in S, (T ∨ x) = T

Semilattices
• Notice the dataflow analysis we looked at
have either the join or meet operator, e.g.,
– available expressions uses meet: ∧ is intersection
– liveness uses join: ∨ is union

• If only one of meet or join are defined, we call
it a semilattice.

15-411/611

Partial Order
• A partial order is a pair (S, ≤) such that:
– ≤ ⊆ S×S
– ≤ is reflexive, i.e.,
x≤x
– ≤ is anti-symmetric, i.e.,
x ≤ y and y ≤ x implies x=y
– ≤ is transitive, i.e.,
x ≤ y and x ≤ z implies x ≤z

Partial Order, ∨, ∧, and Semi-Lattice
• Join, least upper bound, on a semi-lattice
defines a partial order:
x ≤ y iff x ∨ y=y
• Meet, greatest lower bound, on a semilattice defines a partial order:
x ≤ y iff x ∧ y=x
