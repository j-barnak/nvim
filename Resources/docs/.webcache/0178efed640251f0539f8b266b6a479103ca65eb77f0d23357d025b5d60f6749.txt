# [`pwnlib.runner`](#module-pwnlib.runner "pwnlib.runner") — Running Shellcode

pwnlib.runner.run_assembly(*assembly*)[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/runner.py#L14-L43)  
Given an assembly listing, assemble and execute it.

Returns:  
A [`pwnlib.tubes.process.process`](https://docs.pwntools.com/en/stable/tubes/processes.html#pwnlib.tubes.process.process "pwnlib.tubes.process.process") tube to interact with the process.

Example

    >>> p = run_assembly('mov ebx, 3; mov eax, SYS_exit; int 0x80;')
    >>> p.wait_for_close()
    >>> p.poll()
    3

    >>> p = run_assembly('mov r0, #12; mov r7, #1; svc #0', arch='arm')
    >>> p.wait_for_close()
    >>> p.poll()
    12

pwnlib.runner.run_shellcode(*bytes*, *\*\*kw*)[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/runner.py#L45-L71)  
Given assembled machine code bytes, execute them.

Example

    >>> insn_bytes = asm('mov ebx, 3; mov eax, SYS_exit; int 0x80;')
    >>> p = run_shellcode(insn_bytes)
    >>> p.wait_for_close()
    >>> p.poll()
    3

    >>> insn_bytes = asm('mov r0, #12; mov r7, #1; svc #0', arch='arm')
    >>> p = run_shellcode(insn_bytes, arch='arm')
    >>> p.wait_for_close()
    >>> p.poll()
    12
