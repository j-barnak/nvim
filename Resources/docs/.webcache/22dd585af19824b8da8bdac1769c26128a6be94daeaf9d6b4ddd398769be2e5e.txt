# Function size_of_val Copy item path

1.0.0 (const: 1.85.0) · [Source](https://doc.rust-lang.org/src/core/mem/mod.rs.html#408)

``` rust
pub const fn size_of_val<T>(val: &T) -> usizewhere
    T: ?Sized,
```

Expand description

Returns the size of the pointed-to value in bytes.

This is usually the same as [`size_of::<T>()`](https://doc.rust-lang.org/std/mem/fn.size_of.html "fn std::mem::size_of"). However, when `T` *has* no statically-known size, e.g., a slice [`[T]`](https://doc.rust-lang.org/std/primitive.slice.html "primitive slice") or a [trait object](https://doc.rust-lang.org/book/ch17-02-trait-objects.html), then `size_of_val` can be used to get the dynamically-known size.

## Examples

``` rust
assert_eq!(4, size_of_val(&5i32));

let x: [u8; 13] = [0; 13];
let y: &[u8] = &x;
assert_eq!(13, size_of_val(y));
```
