# angr.analyses.decompiler.peephole_optimizations.utils

angr.analyses.decompiler.peephole_optimizations.utils.get_expr_shift_left_amount(*expr*)  
Get the shift amount of a shift-left or multiplication operation if the shift amount is a constant.

Parameters:  
**expr** ([`BinaryOp`](https://docs.angr.io/en/latest/api/angr.ailment.expression.html#angr.ailment.expression.BinaryOp "angr.ailment.expression.BinaryOp")) – The shift-left or multiplication expression (must be a BinaryOp).

Return type:  
[`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)") \| [`None`](https://docs.python.org/3/library/constants.html#None "(in Python v3.14)")

Returns:  
The shift amount if it is a constant, or None if it is not.
