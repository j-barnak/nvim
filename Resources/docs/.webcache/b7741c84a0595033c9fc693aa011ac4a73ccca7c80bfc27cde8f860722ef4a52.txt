When using a complex system like DynamoRIO, problems can be challenging to diagnose. This section contains some debugging tips and shows how to get help.

Extensive tips for [Debugging](https://dynamorio.org/page_debugging.html) are separated onto [their own page](https://dynamorio.org/page_debugging.html). Similarly, DynamoRIO's [Logging](https://dynamorio.org/page_logging.html) is [described here](https://dynamorio.org/page_logging.html).

When using the [DrCacheSim](https://dynamorio.org/page_drcachesim.html) tool's [offline traces](https://dynamorio.org/sec_drcachesim_offline.html), see [DrCacheSim Offline Trace Debugging](https://dynamorio.org/page_debug_memtrace.html).

#  Discussion Forum

For questions and discussion, join the [DynamoRIO Users group](http://groups.google.com/group/dynamorio-users/).

If you are sure a problem you hit is a bug in DynamoRIO, see the instructions for [Reporting Problems](https://dynamorio.org/page_bug_reporting.html).
