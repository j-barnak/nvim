With [the tokenizer](https://beautifulracket.com/basic/the-tokenizer.html) and [the parser](https://beautifulracket.com/basic/the-parser.html) complete, our reader will follow the pattern we’ve used before:

basic/main.rkt

\#lang br/quicklang
(require "parser.rkt" "tokenizer.rkt")

(define (read-syntax path port)
  (define parse-tree (parse path (make-tokenizer port path)))
  (strip-bindings
   #\`(module basic-mod basic/expander
       #,parse-tree)))

(module+ reader
  (provide read-syntax))

    #lang br/quicklang
    (require "parser.rkt" "tokenizer.rkt")

    (define (read-syntax path port)

![copy to clipboard](https://beautifulracket.com/fonts/feather-v1.1/svg/download.svg)

None of this is new material.

First, we make a parse tree. We call make-tokenizer with our input port. This time, we also pass our path as an argument, to help with generating [source locations](https://beautifulracket.com/appendix/glossary.html#source-location). make-tokenizer returns a token-retrieving function, which we pass to parse. In turn, [the parser](https://beautifulracket.com/basic/the-parser.html) uses this function to retrieve tokens and arrange them into a parse tree according to the rules of our [grammar](https://beautifulracket.com/appendix/glossary.html#grammar).

To insert the parse tree into our module expression, we use the [quasisyntax](https://beautifulracket.com/appendix/glossary.html#quasisyntax) notation we used for [the wires reader](https://beautifulracket.com/wires/the-reader.html). We wrap this new module expression with [strip-bindings](http://docs.racket-lang.org/br/index.html#(def._((lib._br/syntax..rkt)._strip-bindings))) to make sure it has no [bindings](https://beautifulracket.com/appendix/glossary.html#binding) before it’s passed to the expander.

Finally, we [provide](http://docs.racket-lang.org/reference/require.html#(form._((lib._racket/private/base..rkt)._provide))) our read-syntax function through a reader submodule, where Racket will look for it when we invoke \#lang basic.

Now we’re ready to start [the expander](https://beautifulracket.com/basic/the-expander.html).
