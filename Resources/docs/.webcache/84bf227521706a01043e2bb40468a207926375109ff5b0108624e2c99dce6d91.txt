# miasm.expression.expression_helper

## Classes

### class `Variables_Identifier(object)`

Identify variables in an expression.
Returns:
- variables with their corresponding values
- original expression with variables translated

- **`__init__(self, expr, var_prefix='v')`** - Set the expression @expr to handle and launch variable identification
- **`is_var_identifier(self, expr)`** - Return True iff @expr is a variable identifier
- **`find_variables_rec(self, expr)`** - Recursive method called by find_variable to expand @expr.
- **`vars(self)`**
- **`equation(self)`**
- **`__str__(self)`** - Display variables and final equation

### class `ExprRandom(object)`

Return an expression randomly generated

- **`identifier(cls, size=32)`** - Return a random identifier
- **`number(cls, size=32)`** - Return a random number
- **`atomic(cls, size=32)`** - Return an atomic Expression
- **`operation(cls, size=32, depth=1)`** - Return an ExprOp
- **`slice(cls, size=32, depth=1)`** - Return an ExprSlice
- **`compose(cls, size=32, depth=1)`** - Return an ExprCompose
- **`memory(cls, size=32, depth=1)`** - Return an ExprMem
- **`_gen(cls, size=32, depth=1)`** - Internal function for generating sub-expression according to options
- **`get(cls, size=32, depth=1, clean=True)`** - Return a randomly generated expression

### class `CondConstraint(object)`

Stand for a constraint on an Expr

- **`__init__(self, expr)`**
- **`__repr__(self)`**
- **`to_constraint(self)`** - Transform itself into a constraint using Expr

### class `CondConstraintZero(CondConstraint)`

Stand for a constraint like 'A == 0'

- **`to_constraint(self)`**

### class `CondConstraintNotZero(CondConstraint)`

Stand for a constraint like 'A != 0'

- **`to_constraint(self)`**

### class `ConstrainedValues(set)`

Set of ConstrainedValue

- **`__str__(self)`**

Return a list of missing interval in all_interval

### `expr_cmpu(arg1, arg2)`

Returns a one bit long Expression:
* 1 if @arg1 is strictly greater than @arg2 (unsigned)
* 0 otherwise.

### `expr_cmps(arg1, arg2)`

Returns a one bit long Expression:
* 1 if @arg1 is strictly greater than @arg2 (signed)
* 0 otherwise.

### `possible_values(expr)`

Return possible values for expression @expr, associated with their
condition constraint as a ConstrainedValues instance
@expr: Expr instance
