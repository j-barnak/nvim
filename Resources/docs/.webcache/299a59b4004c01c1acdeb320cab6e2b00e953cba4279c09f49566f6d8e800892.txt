## Required Methods

1.0.0 · [Source](https://doc.rust-lang.org/src/std/os/windows/io/raw.rs.html#189)

Extracts the raw socket.

This function is typically used to **borrow** an owned socket. When used in this way, this method does **not** pass ownership of the raw socket to the caller, and the socket is only guaranteed to be valid while the original object has not yet been destroyed.

However, borrowing is not strictly required. See [`AsSocket::as_socket`](https://doc.rust-lang.org/std/os/windows/io/trait.AsSocket.html#tymethod.as_socket "method std::os::windows::io::AsSocket::as_socket") for an API which strictly borrows a socket.
