## VBR

### Introduction

A **Volume Boot Record** (**VBR**) is the first sector of a partition (unlike [MBR](https://wiki.osdev.org/MBR "MBR") which is the first sector of a hard disk). A VBR (just like a MBR) also contains some code and data, but it's far less standard. Instead of a [Partition Table](https://wiki.osdev.org/Partition_Table "Partition Table") it usually holds some file system information, like the [BIOS Parameter Block](https://wiki.osdev.org/FAT#BPB_.28BIOS_Parameter_Block.29 "FAT") (although it's not needed nowadays, many OS's have kept it for compatibility). The code is always OS specific, but in common all versions function the same: locate the kernel on the partition, load and execute it. A really good example of a VBR is the original *DOS bootsector*, which knew [FAT](https://wiki.osdev.org/FAT "FAT") and loaded IO.SYS and MSDOS.SYS from the root directory.

### Implementations

This is file system specific, but the usual is a JMP followed by FS info.
