Integer Overflows
 An integer overflow occurs when an integer is

increased beyond its maximum value or
decreased beyond its minimum value
 Standard integer types (signed)
 signed char, short int, int, long int, long long int

 Signed overflow vs unsigned overflow
 An unsigned overflow occurs when the

underlying representation can no longer
represent an integer value.
 A signed overflow occurs when a value is carried
over to the sign bit

Use After Free
 Error: Program frees memory on the heap,

but then references that memory as if it were
still valid
 Adversary can control data written using the

freed pointer
 AKA use of dangling pointers

Use After Free
int main(int argc, char **argv) {
char *buf1, *buf2, *buf3;
buf1 = (char *) malloc(BUFSIZE1);
free(buf1);
buf2 = (char *) malloc(BUFSIZE2);
buf3 = (char *) malloc(BUFSIZE2);
strncpy(buf1, argv[1], BUFSIZE1‐1);
…
}

What happens here?

Use After Free
 When the first buffer is freed, that memory is

available for reuse right away
 Then, the following buffers are possibly
allocated within that memory region
buf2 = (char *) malloc(BUFSIZE2);
buf3 = (char *) malloc(BUFSIZE2);
 Finally, the write using the freed pointer may

overwrite buf2 and buf3 (and their metadata)
strncpy(buf1, argv[1], BUFSIZE1‐1);

Use After Free
 Most effective attacks exploit data of another type

 Provides the same affect as we did with use‐

any arbitrary type B

Type Confusion Safety
 Upcasts are always safe because they only

reduce the type structure
 That is, subtypes extend the structure

definitions only
 Thus, downcasts (as in the example) and

arbitrary casts (that do not follow the
