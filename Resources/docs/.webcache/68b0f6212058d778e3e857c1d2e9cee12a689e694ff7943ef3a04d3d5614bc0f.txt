Expand description

The file descriptor for the standard output stream of the current process.

See [`io::stdout()`](https://doc.rust-lang.org/std/io/fn.stdout.html "fn std::io::stdout") for the higher level handle, which should be preferred whenever possible. See [`STDERR`](https://doc.rust-lang.org/std/os/fd/constant.STDERR.html "constant std::os::fd::STDERR") for why the file descriptor might be required and caveats. In addition to the issues discussed there, note that [`Stdout`](https://doc.rust-lang.org/std/io/struct.Stdout.html "struct std::io::Stdout") is buffered by default, and writing to the file descriptor will bypass this buffer.
