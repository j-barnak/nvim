# Chapter 3. Installation

# 3.1. Downloading Bochs

You can download Bochs from our web site at [bochs.sourceforge.net](https://bochs.sourceforge.io). First, you need to choose what version to get: a recent release or a development version. If you trying to get things working for the first time, a release version is recommended since it has been tested the most. The development versions may have some newer bug fixes and new features, but have not been tested as much as the releases. A snapshot of the current state of the source tree in ZIP format is available on [GitHub](https://github.com/bochs-emu/Bochs/) when you press the **Code** button.

Second, you can choose to compile Bochs from source code or install a binary (if one is available for your platform). Binary packages will be quicker to install, and most include a small demo of a guest operating system called DLX Linux to get you started. However, some features can only be enabled if you compile Bochs yourself, for example the Bochs debugger. For multiuser systems, you will probably need system administrator privileges (root) to install a binary package. If you decide to get a binary, download it to your hard disk, uncompress it, then go to the section called [Installing a Binary](https://bochs.sourceforge.io/doc/docbook/user/install-binary.html) for more information.

If you are going to compile Bochs yourself, you need the gzipped tarball containing the source code, called `bochs-`*`version`*`.tar.gz`. For Windows a ZIP package with sources and prebuilt Makefiles is available. To unpack a compressed TAR file[\[1\]](#FTN.AEN381) on a Unix machine[\[2\]](#FTN.AEN383) , type

```
  gunzip -c bochs-version.tar.gz | tar -xvf -
```

This creates a directory called `bochs-`*`version`* full of files. This directory will be referred to as `$BOCHS`. Go into `$BOCHS` and you are ready to compile. Instructions for compiling Bochs are in the section, [Compiling Bochs](https://bochs.sourceforge.io/doc/docbook/user/compiling.html).

Alternatively, you can also obtain the sources for any Bochs version using GIT. See the [GIT instructions](https://bochs.sourceforge.io/doc/docbook/user/get-src-git.html) for details.

### Notes

[\[1\]](https://bochs.sourceforge.io/doc/docbook/user/installation.html#AEN381)

A TAR file is a single file that contains many files packed inside. Bochs TAR files are compressed with a program called gzip, and another program called gunzip is used to uncompress them.

[\[2\]](https://bochs.sourceforge.io/doc/docbook/user/installation.html#AEN383)

On Windows, look for software called WinZip to unpack the TAR.
