# Function read Copy item path

1.26.0 · [Source](https://doc.rust-lang.org/src/std/fs.rs.html#340-349)

``` rust
pub fn read<P: AsRef<Path>>(path: P) -> Result<Vec<u8>>
```

Expand description

Reads the entire contents of a file into a bytes vector.

This is a convenience function for using [`File::open`](https://doc.rust-lang.org/std/fs/struct.File.html#method.open "associated function std::fs::File::open") and [`read_to_end`](https://doc.rust-lang.org/std/io/trait.Read.html#method.read_to_end "method std::io::Read::read_to_end") with fewer imports and without an intermediate variable.

## Errors

This function will return an error if `path` does not already exist. Other errors may also be returned according to [`OpenOptions::open`](https://doc.rust-lang.org/std/fs/struct.OpenOptions.html#method.open "method std::fs::OpenOptions::open").

While reading from the file, this function handles [`io::ErrorKind::Interrupted`](https://doc.rust-lang.org/std/io/enum.ErrorKind.html#variant.Interrupted "variant std::io::ErrorKind::Interrupted") with automatic retries. See [io::Read](https://doc.rust-lang.org/std/io/trait.Read.html "trait std::io::Read") documentation for details.

## Examples

``` rust
use std::fs;

fn main() -> Result<(), Box<dyn std::error::Error + 'static>> {
    let data: Vec<u8> = fs::read("image.jpg")?;
    assert_eq!(data[0..3], [0xFF, 0xD8, 0xFF]);
    Ok(())
}
```
