### Memory

class Memory : public LIEF::assembly::powerpc::[Operand](#_CPPv4N4LIEF8assembly7powerpc7OperandE "LIEF::assembly::powerpc::Operand")    
This class represents a memory operand.

PowerPC has two addressing forms:

    lwz   3, 8(4)              lwzx   3, 4, 5
           |  |                       |  |  |
    +------+  +---+            +------+   |  +---+
    |             |           |          |      |
    v             v           v          v      v
    Disp         Base        Reg        Base   Index

Public Functions

REG base() const    
The base register.

For `lwz`` ``3,`` ``8(4)` it would return `4`.

&nbsp;

[offset_t](#_CPPv4N4LIEF8assembly7powerpc8operands6Memory8offset_tE "LIEF::assembly::powerpc::operands::Memory::offset_t") offset() const    
The addressing offset.

It can be either:

- An index register (e.g. `lwzx`` ``3,`` ``4,`` ``5`)

- A displacement (e.g. `lwz`` ``3,`` ``8(4)`)

&nbsp;

~Memory() override = default
