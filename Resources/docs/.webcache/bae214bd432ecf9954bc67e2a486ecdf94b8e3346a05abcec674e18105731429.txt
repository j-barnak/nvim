🔬This is a nightly-only experimental API. (`core_intrinsics`)

Expand description

Moves a value out of scope without running drop glue.

This exists solely for [`crate::mem::forget_unsized`](https://doc.rust-lang.org/std/mem/fn.forget_unsized.html "fn std::mem::forget_unsized"); normal `forget` uses `ManuallyDrop` instead.

Note that, unlike most intrinsics, this is safe to call; it does not require an `unsafe` block. Therefore, implementations must not require the user to uphold any safety invariants.
