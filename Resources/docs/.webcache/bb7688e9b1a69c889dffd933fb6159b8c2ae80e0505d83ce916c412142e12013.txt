# Linux Kernel / HugeTLB

The `drgn.helpers.linux.hugetlb` module provides helpers for working with HugeTLB pages.

drgn.helpers.linux.hugetlb.for_each_hstate(*prog: [drgn.Program](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Program "drgn.Program")*) → [Iterator](https://docs.python.org/3/library/typing.html#typing.Iterator "(in Python v3.14)")\[[drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")\]  
Iterate over all HugeTLB page size states.

    >>> [h.name.string_() for h in for_each_hstate()]
    [b'hugepages-1048576kB', b'hugepages-2048kB']

Parameters:  
**prog** – Program, which [may be omitted to use the default program argument](https://drgn.readthedocs.io/en/latest/api_reference.html#default-program).

Returns:  
Iterator of `struct`` ``hstate`` ``*` objects.
