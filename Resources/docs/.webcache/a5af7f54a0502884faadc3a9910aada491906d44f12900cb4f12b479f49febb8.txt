DynamoRIO provides additional optional capabilities via DynamoRIO Extensions, separate libraries that a client can link to. The Extensions that are provided with the DynamoRIO distribution are:

- [Basic Block Duplicator](https://dynamorio.org/page_drbbdup.html)
- [Callstack Walking](https://dynamorio.org/page_drcallstack.html)
- [Container Data Structures](https://dynamorio.org/page_drcontainers.html)
- [Code Coverage Library](https://dynamorio.org/page_drcovlib.html)
- [Graphical Application Framework](https://dynamorio.org/page_drgui.html)
- [Multi-Instrumentation Manager](https://dynamorio.org/page_drmgr.html)
- [DynamoRIO Option Parser](https://dynamorio.org/page_droption.html)
- [Intel PT Tracing](https://dynamorio.org/page_drpttracer.html)
- [Register Management](https://dynamorio.org/page_drreg.html)
- [Machine State Comparison Library](https://dynamorio.org/page_drstatecmp.html)
- [Symbol Access Library](https://dynamorio.org/page_drsyms.html)
- [Dr. Syscall: System Call Monitoring Extension](https://dynamorio.org/page_drsyscall.html)
- [Instrumentation Utilities](https://dynamorio.org/page_drutil.html)
- [Function Wrapping and Replacing Extension](https://dynamorio.org/page_drwrap.html)
- [DynamoRIO eXtension utilities](https://dynamorio.org/page_drx.html)
- [Umbra: Shadow Memory Extension](https://dynamorio.org/page_drmf_umbra.html)
- [System Call Monitoring Extension](https://dynamorio.org/page_drmf_drsyscall.html)
- [Symbol Lookup Cache Extension](https://dynamorio.org/page_drmf_drsymcache.html)
