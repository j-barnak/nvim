🔬This is a nightly-only experimental API. (`waker_fn` [\#149580](https://github.com/rust-lang/rust/issues/149580))

Available on **`target_has_atomic=ptr`** only.

Expand description

Converts a closure into a [`Waker`](https://doc.rust-lang.org/std/task/struct.Waker.html "struct std::task::Waker").

The closure gets called every time the waker is woken.

## Examples

``` rust
#![feature(waker_fn)]
use std::task::waker_fn;

let waker = waker_fn(|| println!("woken"));

waker.wake_by_ref(); // Prints "woken".
waker.wake();        // Prints "woken".
```
