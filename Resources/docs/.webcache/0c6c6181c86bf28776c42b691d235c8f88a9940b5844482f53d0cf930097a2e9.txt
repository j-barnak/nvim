Expand description

Performs rotate right.

Note that, unlike most intrinsics, this is safe to call; it does not require an `unsafe` block. Therefore, implementations must not require the user to uphold any safety invariants.

The stabilized versions of this intrinsic are available on the integer primitives via the `rotate_right` method. For example, [`u32::rotate_right`](https://doc.rust-lang.org/std/primitive.u32.html#method.rotate_right "method u32::rotate_right")
