- **`concat_left(self, other_bits)`** - Return a new bits instance for @other_bits . self
- **`mask(self)`**
- **`__invert__(self)`**
- **`__int__(self)`**
- **`__and__(self, other_bits)`**
- **`__eq__(self, other_bits)`**
- **`__getitem__(self, info)`**
- **`pop_count(self)`** - Population count: number of bit set
- **`__str__(self)`**
