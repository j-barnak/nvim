# miasm.expression.simplifications_cond

## Functions

### `__ExprOp_cond(op, arg1, arg2)`

Return an ExprOp standing for arg1 op arg2 with size to 1

### `ExprOp_inf_signed(arg1, arg2)`

Return an ExprOp standing for arg1 <s arg2

### `ExprOp_inf_unsigned(arg1, arg2)`

Return an ExprOp standing for arg1 <s arg2

### `ExprOp_equal(arg1, arg2)`

Return an ExprOp standing for arg1 == arg2

### `__check_msb(e)`

If @e stand for the most significant bit of its arg, return the arg;
False otherwise

### `__match_expr_wrap(e, to_match, jok_list)`

Wrapper around match_expr to canonize pattern

### `expr_simp_inf_signed(expr_simp, e)`

((x - y) ^ ((x ^ y) & ((x - y) ^ x))) [31:32] == x <s y

### `expr_simp_inf_unsigned_inversed(expr_simp, e)`

((x - y) ^ ((x ^ y) & ((x - y) ^ x))) ^ x ^ y [31:32] == x <u y

### `expr_simp_inverse(expr_simp, e)`

(x <u y) ^ ((x ^ y) [31:32]) == x <s y,
(x <s y) ^ ((x ^ y) [31:32]) == x <u y

### `expr_simp_equal(expr_simp, e)`

(x - y)?(0:1) == (x == y)
