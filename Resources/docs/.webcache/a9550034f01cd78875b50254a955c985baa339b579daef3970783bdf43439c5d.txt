# miasm.expression.simplifications_common

## Functions

### `simp_cst_propagation(e_s, expr)`

This passe includes:
- Constant folding
- Common logical identities
- Common binary identities

### `simp_cond_op_int(_, expr)`

Extract conditions from operations

### `simp_cond_factor(e_s, expr)`

Merge similar conditions

### `simp_slice(e_s, expr)`

Slice optimization

### `simp_compose(e_s, expr)`

Commons simplification on ExprCompose

### `simp_cond(_, expr)`

Common simplifications on ExprCond.
Eval exprcond src1/src2 with satifiable/unsatisfiable condition propagation

### `simp_mem(_, expr)`

Common simplifications on ExprMem:
@32[x?a:b] => x?@32[a]:@32[b]

### `test_cc_eq_args(expr, *sons_op)`

Return True if expression's arguments match the list in sons_op, and their
sub arguments are identical. Ex:
CC_S<=(
          FLAG_SIGN_SUB(A, B),
          FLAG_SUB_OF(A, B),
          FLAG_EQ_CMP(A, B)
)

### `simp_cc_conds(_, expr)`

High level simplifications. Example:
CC_U<(FLAG_SUB_CF(A, B) => A <u B

### `simp_cond_flag(_, expr)`

FLAG_EQ_CMP(X, Y)?A:B => (X == Y)?A:B

### `simp_sub_cf_zero(_, expr)`

FLAG_SUB_CF(0, X) => (X)?1:0

### `simp_cond_cc_flag(expr_simp, expr)`

ExprCond(CC_><(bit), X, Y) => ExprCond(bit, X, Y)
ExprCond(CC_U>=(bit), X, Y) => ExprCond(bit, Y, X)

### `simp_cond_sub_cf(expr_simp, expr)`

ExprCond(FLAG_SUB_CF(A, B), X, Y) => ExprCond(A <u B, X, Y)

### `simp_cmp_int(expr_simp, expr)`

({X, 0} == int) => X == int[:]
X + int1 == int2 => X == int2-int1
X ^ int1 == int2 => X == int1^int2

### `simp_cmp_int_arg(_, expr)`

(0x10 <= R0) ? A:B
=>
(R0 < 0x10) ? B:A

### `simp_cmp_bijective_op(expr_simp, expr)`

A + B == A => A == 0

X + A == X + B => A == B
X ^ A == X ^ B => A == B

### `simp_subwc_cf(_, expr)`

### `simp_subwc_of(_, expr)`

SUBWC_OF(A, B, SUB_CF(C, D)) => SUB_OF({A, C}, {B, D})

### `simp_sign_subwc_cf(_, expr)`

### `simp_double_zeroext(_, expr)`

### `simp_double_signext(_, expr)`

### `simp_zeroext_eq_cst(_, expr)`

A.zeroExt(X) == int => A == int[:A.size]

### `simp_cond_zeroext(_, expr)`

X.zeroExt()?(A:B) => X ? A:B
X.signExt()?(A:B) => X ? A:B

### `simp_ext_eq_ext(_, expr)`

A.zeroExt(X) == B.zeroExt(X) => A == B
A.signExt(X) == B.signExt(X) => A == B

### `simp_cond_eq_zero(_, expr)`

(X == 0)?(A:B) => X?(B:A)

### `simp_sign_inf_zeroext(expr_s, expr)`

[!] Ensure before: X.zeroExt(X.size) => X

X.zeroExt() <s 0 => 0
X.zeroExt() <=s 0 => X == 0

X.zeroExt() <s cst => X.zeroExt() <u cst (cst positive)
X.zeroExt() <=s cst => X.zeroExt() <=u cst (cst positive)

X.zeroExt() <s cst => 0 (cst negative)
X.zeroExt() <=s cst => 0 (cst negative)

### `simp_zeroext_and_cst_eq_cst(expr_s, expr)`

A.zeroExt(X) & ... & int == int => A & ... & int[:A.size] == int[:A.size]

### `test_one_bit_set(arg)`

Return True if arg has form 1 << X

### `simp_x_and_cst_eq_cst(_, expr)`

(x & ... & onebitmask == onebitmask) ? A:B => (x & ... & onebitmask) ? A:B

### `simp_cmp_int_int(_, expr)`

IntA <s IntB => int
IntA <u IntB => int
IntA <=s IntB => int
IntA <=u IntB => int
IntA == IntB => int

### `simp_ext_cst(_, expr)`

### `simp_ext_cond_int(e_s, expr)`

### `simp_slice_of_ext(_, expr)`

C.zeroExt(X)[A:B] => 0 if A >= size(C)
C.zeroExt(X)[A:B] => C[A:B] if B <= size(C)
A.zeroExt(X)[0:Y] => A.zeroExt(Y)

### `simp_slice_of_sext(e_s, expr)`

### `simp_cond_logic_ext(expr_s, expr)`

### `simp_cond_sign_bit(_, expr)`

### `simp_cond_add(expr_s, expr)`

### `simp_cond_eq_1_0(expr_s, expr)`

### `simp_add_multiple(_, expr)`

X + X => 2 * X
X + X * int1 => X * (1 + int1)
X * int1 + (- X) => X * (int1 - 1)
X + (X << int1) => X * (1 + 2 ** int1)
Correct even if addition overflow/underflow

{X 0 8, 0x123456 8 32} & 0xFFFFFF => {X 0 8, 0x1234 8 24, 0x0 24 32}
