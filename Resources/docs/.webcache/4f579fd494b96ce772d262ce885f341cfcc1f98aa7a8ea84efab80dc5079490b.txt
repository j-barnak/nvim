exception angr.errors.AngrDecompilationComplexityError  
Bases: [`AngrDecompilationError`](#angr.errors.AngrDecompilationError "angr.errors.AngrDecompilationError")

Raised when a function exceeds one of the decompiler’s complexity limits. The decompiler gives up before starting the expensive work instead of running for an unbounded amount of time.

Variables:  
- **limit_name** – Name of the decompilation option that sets the limit, e.g. “max_function_blocks”.

- **limit** – The configured limit.

- **actual** – The measured size that exceeded the limit.

- **func_addr** – Address of the offending function, if known.

- **unit** – What `actual` counts, e.g. “basic blocks”.
