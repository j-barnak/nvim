# Trait RemAssign Copy item path

1.8.0 (const: [unstable](https://github.com/rust-lang/rust/issues/143802 "Tracking issue for const_ops")) · [Source](https://doc.rust-lang.org/src/core/ops/arith.rs.html#1028)

``` rust
pub trait RemAssign<Rhs = Self> {
    // Required method
    fn rem_assign(&mut self, rhs: Rhs);
}
```

Expand description

The remainder assignment operator `%=`.

## Examples

``` rust
use std::ops::RemAssign;

struct CookieJar { cookies: u32 }

impl RemAssign<u32> for CookieJar {
    fn rem_assign(&mut self, piles: u32) {
        self.cookies %= piles;
    }
}

let mut jar = CookieJar { cookies: 31 };
let piles = 4;

println!("Splitting up {} cookies into {} even piles!", jar.cookies, piles);

jar %= piles;

println!("{} cookies remain in the cookie jar!", jar.cookies);
```

Performs the `%=` operation.

##### Example

``` rust
let mut x: u32 = 12;
x %= 10;
assert_eq!(x, 2);
```
