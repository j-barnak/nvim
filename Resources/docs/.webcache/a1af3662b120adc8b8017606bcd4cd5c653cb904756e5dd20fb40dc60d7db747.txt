Expand description

RAII structure used to release the shared read access of a lock when dropped.

This structure is created by the [`read`](https://doc.rust-lang.org/std/sync/struct.RwLock.html#method.read "method std::sync::RwLock::read") and [`try_read`](https://doc.rust-lang.org/std/sync/struct.RwLock.html#method.try_read "method std::sync::RwLock::try_read") methods on [`RwLock`](https://doc.rust-lang.org/std/sync/struct.RwLock.html "struct std::sync::RwLock").

🔬This is a nightly-only experimental API. (`mapped_lock_guards` [\#117108](https://github.com/rust-lang/rust/issues/117108))

Makes a [`MappedRwLockReadGuard`](https://doc.rust-lang.org/std/sync/struct.MappedRwLockReadGuard.html "struct std::sync::MappedRwLockReadGuard") for a component of the borrowed data, e.g. an enum variant.

The `RwLock` is already locked for reading, so this cannot fail.

This is an associated function that needs to be used as `RwLockReadGuard::map(...)`. A method would interfere with methods of the same name on the contents of the `RwLockReadGuard` used through `Deref`.

##### Panics

If the closure panics, the guard will be dropped (unlocked) and the RwLock will not be poisoned.

🔬This is a nightly-only experimental API. (`mapped_lock_guards` [\#117108](https://github.com/rust-lang/rust/issues/117108))

Makes a [`MappedRwLockReadGuard`](https://doc.rust-lang.org/std/sync/struct.MappedRwLockReadGuard.html "struct std::sync::MappedRwLockReadGuard") for a component of the borrowed data. The original guard is returned as an `Err(...)` if the closure returns `None`.

The `RwLock` is already locked for reading, so this cannot fail.

This is an associated function that needs to be used as `RwLockReadGuard::filter_map(...)`. A method would interfere with methods of the same name on the contents of the `RwLockReadGuard` used through `Deref`.

##### Panics

If the closure panics, the guard will be dropped (unlocked) and the RwLock will not be poisoned.
