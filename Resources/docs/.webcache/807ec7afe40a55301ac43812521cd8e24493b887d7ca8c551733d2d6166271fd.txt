# Linux Kernel / Common

Linux kernel specializations of [`common`](#module-drgn.helpers.common "drgn.helpers.common") helpers.

*class *drgn.helpers.linux.common.IdentifiedTaskStruct

*class *drgn.helpers.linux.common.IdentifiedTaskStack  
[`IdentifiedAddress`](#drgn.helpers.common.memory.IdentifiedAddress "drgn.helpers.common.memory.IdentifiedAddress") for an address in a kernel stack.

*class *drgn.helpers.linux.common.IdentifiedSlabObject  
[`IdentifiedAddress`](#drgn.helpers.common.memory.IdentifiedAddress "drgn.helpers.common.memory.IdentifiedAddress") for an address from the slab allocator.

*class *drgn.helpers.linux.common.IdentifiedPage
