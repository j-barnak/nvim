drgn.helpers.linux.vmstat.global_numa_event_state(*prog: [drgn.Program](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Program "drgn.Program")*, *item: [drgn.IntegerLike](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.IntegerLike "drgn.IntegerLike")*) → [int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")  
Get the global value of a NUMA statistic.

Note

This is only valid if the kernel was compiled with `CONFIG_NUMA`. Before Linux 4.14, these items (e.g., `NUMA_HIT`) were zone statistics, so on kernel versions before 4.14, this is an alias of [`global_zone_page_state()`](#drgn.helpers.linux.vmstat.global_zone_page_state "drgn.helpers.linux.vmstat.global_zone_page_state").

Parameters:  
- **prog** – Program, which [may be omitted to use the default program argument](https://drgn.readthedocs.io/en/latest/api_reference.html#default-program).

- **item** – `enum`` ``numa_stat_item` (or `enum`` ``zone_stat_item` on Linux \< 4.14)
