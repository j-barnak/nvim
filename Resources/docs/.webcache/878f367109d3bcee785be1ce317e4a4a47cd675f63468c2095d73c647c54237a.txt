# Type Alias c_float Copy item path

1.1.0 · [Source](https://doc.rust-lang.org/src/std/os/raw/mod.rs.html#17-26)

``` rust
pub type c_float = c_float;
```

Expand description

Equivalent to C’s `float` type.

This type will almost always be [`f32`](https://doc.rust-lang.org/std/primitive.f32.html "primitive f32"), which is guaranteed to be an [IEEE 754 single-precision float](https://en.wikipedia.org/wiki/IEEE_754) in Rust. That said, the standard technically only guarantees that it be a floating-point number, and it may have less precision than `f32` or not follow the IEEE-754 standard at all.
