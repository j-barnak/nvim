PearPC is an open source [PowerPC](https://wiki.osdev.org/PowerPC "PowerPC") emulator released under the GPL. It can run on a Windows, Linux, or FreeBSD host and is capable of running many PowerPC operating systems, including Mac OS X, Darwin, and Linux.

PearPC includes a just-in-time (JIT) compiler for x86 hosts, resulting in execution being extremely fast.

## Hardware

- G5 (64-bit PowerPC) CPU emulation
- No sound emulation (however there is a fork called ppc-snd)
- 3Com 3C905C or Realtek 8139 ethernet emulation
