# Constant MAIN_SEPARATOR Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/std/path.rs.html#290)

``` rust
pub const MAIN_SEPARATOR: char = _; // '/'
```

Expand description

The primary separator of path components for the current platform, represented as a [`char`](https://doc.rust-lang.org/std/primitive.char.html "primitive char"); for example, this is `'/'` on Unix and `'\\'` on Windows.
