[Source](https://doc.rust-lang.org/src/core/portable-simd/crates/core_simd/src/simd/cmp/ord.rs.html#45)

🔬This is a nightly-only experimental API. (`portable_simd` [\#86656](https://github.com/rust-lang/rust/issues/86656))

Restrict each element to a certain interval.

For each element, returns `max` if `self` is greater than `max`, and `min` if `self` is less than `min`. Otherwise returns `self`.

##### Panics

Panics if `min > max` on any element.
