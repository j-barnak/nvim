# miasm.ir.analysis

## Classes

### class `LifterModelCall(Lifter)`

IR Analysis
This class provides higher level manipulations on IR, such as dead
instruction removals.

This class can be used as a common parent with
`miasm.ir.ir::Lifter` class.

For instance:
    class LifterModelCall_x86_16(Lifter_X86_16, LifterModelCall)

- **`call_effects(self, addr, instr)`** - Default modelisation of a function call to @addr. This may be used to:
- **`add_instr_to_current_state(self, instr, block, assignments, ir_blocks_all, gen_pc_updt)`** - Add the IR effects of an instruction to the current state.
- **`sizeof_char(self)`** - Return the size of a char in bits
- **`sizeof_short(self)`** - Return the size of a short in bits
- **`sizeof_int(self)`** - Return the size of an int in bits
- **`sizeof_long(self)`** - Return the size of a long in bits
- **`sizeof_pointer(self)`** - Return the size of a void* in bits
