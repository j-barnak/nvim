🔬This is a nightly-only experimental API. (`mpmc_channel` [\#126840](https://github.com/rust-lang/rust/issues/126840))

Expand description

Creates a new synchronous, bounded channel.

All data sent on the [`Sender`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html "struct std::sync::mpmc::Sender") will become available on the [`Receiver`](https://doc.rust-lang.org/std/sync/mpmc/struct.Receiver.html "struct std::sync::mpmc::Receiver") in the same order as it was sent. Like asynchronous [`channel`](https://doc.rust-lang.org/std/sync/mpmc/fn.channel.html "fn std::sync::mpmc::channel")s, the [`Receiver`](https://doc.rust-lang.org/std/sync/mpmc/struct.Receiver.html "struct std::sync::mpmc::Receiver") will block until a message becomes available. `sync_channel` differs greatly in the semantics of the sender, however.

This channel has an internal buffer on which messages will be queued. `bound` specifies the buffer size. When the internal buffer becomes full, future sends will *block* waiting for the buffer to open up. Note that a buffer size of 0 is valid, in which case this becomes “rendezvous channel” where each [`send`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html#method.send "method std::sync::mpmc::Sender::send") will not return until a [`recv`](https://doc.rust-lang.org/std/sync/mpmc/struct.Receiver.html#method.recv "method std::sync::mpmc::Receiver::recv") is paired with it.

The [`Sender`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html "struct std::sync::mpmc::Sender") can be cloned to [`send`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html#method.send "method std::sync::mpmc::Sender::send") to the same channel multiple times. The [`Receiver`](https://doc.rust-lang.org/std/sync/mpmc/struct.Receiver.html "struct std::sync::mpmc::Receiver") also can be cloned to have multi receivers.

Like asynchronous channels, if the [`Receiver`](https://doc.rust-lang.org/std/sync/mpmc/struct.Receiver.html "struct std::sync::mpmc::Receiver") is disconnected while trying to [`send`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html#method.send "method std::sync::mpmc::Sender::send") with the [`Sender`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html "struct std::sync::mpmc::Sender"), the [`send`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html#method.send "method std::sync::mpmc::Sender::send") method will return a [`SendError`](https://doc.rust-lang.org/std/sync/mpsc/struct.SendError.html "struct std::sync::mpsc::SendError"). Similarly, If the [`Sender`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html "struct std::sync::mpmc::Sender") is disconnected while trying to [`recv`](https://doc.rust-lang.org/std/sync/mpmc/struct.Receiver.html#method.recv "method std::sync::mpmc::Receiver::recv"), the [`recv`](https://doc.rust-lang.org/std/sync/mpmc/struct.Receiver.html#method.recv "method std::sync::mpmc::Receiver::recv") method will return a [`RecvError`](https://doc.rust-lang.org/std/sync/mpsc/struct.RecvError.html "struct std::sync::mpsc::RecvError").

## Examples

``` rust
use std::sync::mpsc::sync_channel;
use std::thread;

let (sender, receiver) = sync_channel(1);

// this returns immediately
sender.send(1).unwrap();

thread::spawn(move || {
    // this will block until the previous message has been received
    sender.send(2).unwrap();
});

assert_eq!(receiver.recv().unwrap(), 1);
assert_eq!(receiver.recv().unwrap(), 2);
```
