🔬This is a nightly-only experimental API. (`core_intrinsics`)

Expand description

Stores the value at the specified memory location. `T` must be an integer or pointer type.

The stabilized version of this intrinsic is available on the [`atomic`](https://doc.rust-lang.org/std/sync/atomic/index.html "mod std::sync::atomic") types via the `store` method. For example, [`AtomicBool::store`](https://doc.rust-lang.org/std/sync/atomic/struct.Atomic.html#method.store "method std::sync::atomic::Atomic::store").
