🔬This is a nightly-only experimental API. (`core_intrinsics`)

Expand description

Performs an unchecked division, resulting in undefined behavior where `y == 0` or `x == T::MIN && y == -1`

Safe wrappers for this intrinsic are available on the integer primitives via the `checked_div` method. For example, [`u32::checked_div`](https://doc.rust-lang.org/std/primitive.u32.html#method.checked_div "method u32::checked_div")
