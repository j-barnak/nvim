Organize code into [modules](https://doc.rust-lang.org/reference/items/modules.html).

Use `mod` to create new [modules](https://doc.rust-lang.org/reference/items/modules.html) to encapsulate code, including other modules:

``` rust
mod foo {
    mod bar {
        type MyType = (u8, u8);
        fn baz() {}
    }
}
```

Like [`struct`](https://doc.rust-lang.org/std/keyword.struct.html)s and [`enum`](https://doc.rust-lang.org/std/keyword.enum.html)s, a module and its content are private by default, inaccessible to code outside of the module.

To learn more about allowing access, see the documentation for the [`pub`](https://doc.rust-lang.org/std/keyword.pub.html) keyword.
