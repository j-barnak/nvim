drgn.helpers.linux.kernfs.kernfs_walk(*parent: [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")*, *path: [drgn.Path](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Path "drgn.Path")*, *follow_symlinks: [bool](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)") = True*) → [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")  
Find the kernfs node with the given path from the given parent kernfs node.

Parameters:  
- **parent** – `struct`` ``kernfs_node`` ``*`

- **path** – Path name.

- **follow_symlinks** – If True (default), all symbolic links encountered in the path, including the final component, are followed and the function returns the target node. If False, all intermediate symlinks are still followed, but if the final component is a symlink, the function returns the symlink node itself rather than its target.

Returns:  
`struct`` ``kernfs_node`` ``*` (`NULL` if not found)
