### 20.8 Arithmetic Functions

The C library provides functions to do basic operations on floating-point numbers. These include absolute value, maximum and minimum, normalization, bit twiddling, rounding, and a few others.

- [Absolute Value](https://sourceware.org/glibc/manual/latest/html_node/Absolute-Value.html)
- [Normalization Functions](https://sourceware.org/glibc/manual/latest/html_node/Normalization-Functions.html)
- [Rounding Functions](https://sourceware.org/glibc/manual/latest/html_node/Rounding-Functions.html)
- [Remainder Functions](https://sourceware.org/glibc/manual/latest/html_node/Remainder-Functions.html)
- [Setting and modifying single bits of FP values](https://sourceware.org/glibc/manual/latest/html_node/FP-Bit-Twiddling.html)
- [Floating-Point Comparison Functions](https://sourceware.org/glibc/manual/latest/html_node/FP-Comparison-Functions.html)
- [Miscellaneous FP arithmetic functions](https://sourceware.org/glibc/manual/latest/html_node/Misc-FP-Arithmetic.html)
