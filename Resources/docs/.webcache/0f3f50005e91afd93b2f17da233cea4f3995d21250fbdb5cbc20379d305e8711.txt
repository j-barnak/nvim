# angr.knowledge_plugins.comments

class angr.knowledge_plugins.comments.CommentKind  
Bases: [`IntEnum`](https://docs.python.org/3/library/enum.html#enum.IntEnum "(in Python v3.14)")

How a comment is displayed.

`PLAIN` shows only at its own address. `FUNCTION` renders as a header block above the function, which is also what the decompiler does with a comment on a function entry. `REPEATABLE` additionally shows at every location referencing the commented address.

PLAIN = 0  

FUNCTION = 1  

REPEATABLE = 2
