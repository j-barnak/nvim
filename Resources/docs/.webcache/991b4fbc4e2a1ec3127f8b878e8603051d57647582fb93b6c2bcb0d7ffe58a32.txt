# Linux Kernel / Boot

The `drgn.helpers.linux.boot` module provides helpers for inspecting the Linux kernel boot configuration.

drgn.helpers.linux.boot.kaslr_offset(*prog: [drgn.Program](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Program "drgn.Program")*) → [int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")  
Get the kernel address space layout randomization offset (zero if it is disabled).

Parameters:  
**prog** – Program, which [may be omitted to use the default program argument](https://drgn.readthedocs.io/en/latest/api_reference.html#default-program).
