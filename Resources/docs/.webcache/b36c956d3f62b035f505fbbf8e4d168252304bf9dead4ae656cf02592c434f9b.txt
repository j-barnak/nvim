# Function var Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/std/env.rs.html#228-236)

``` rust
pub fn var<K: AsRef<OsStr>>(key: K) -> Result<String, VarError>
```

Expand description

Fetches the environment variable `key` from the current process.

## Errors

Returns [`VarError::NotPresent`](https://doc.rust-lang.org/std/env/enum.VarError.html#variant.NotPresent "variant std::env::VarError::NotPresent") if:

- The variable is not set.
- The variable’s name contains an equal sign or NUL (`'='` or `'\0'`).

Returns [`VarError::NotUnicode`](https://doc.rust-lang.org/std/env/enum.VarError.html#variant.NotUnicode "variant std::env::VarError::NotUnicode") if the variable’s value is not valid Unicode. If this is not desired, consider using [`var_os`](https://doc.rust-lang.org/std/env/fn.var_os.html "fn std::env::var_os").

Use [`env!`](https://doc.rust-lang.org/std/macro.env.html "macro std::env") or [`option_env!`](https://doc.rust-lang.org/std/macro.option_env.html "macro std::option_env") instead if you want to check environment variables at compile time.

## Examples

``` rust
use std::env;

let key = "HOME";
match env::var(key) {
    Ok(val) => println!("{key}: {val:?}"),
    Err(e) => println!("couldn't interpret {key}: {e}"),
}
```
