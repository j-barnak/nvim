# miasm.analysis.binary

## Classes

### class `ContainerSignatureException(Exception)`

The container does not match the current container signature

### class `ContainerParsingException(Exception)`

Error during container parsing

### class `Container(object)`

Container abstraction layer

This class aims to offer a common interface for abstracting container
such as PE or ELF.

- **`from_string(cls, data, loc_db, *args, **kwargs)`** - Instantiate a container and parse the binary
- **`register_container(cls, container)`** - Add a Container format
- **`register_fallback(cls, container)`** - Set the Container fallback format
- **`from_stream(cls, stream, loc_db, *args, **kwargs)`** - Instantiate a container and parse the binary
- **`parse(self, data, *args, **kwargs)`** - Launch parsing of @data
- **`__init__(self, data, loc_db, **kwargs)`** - Alias for 'parse'
- **`bin_stream(self)`** - Return the BinStream instance corresponding to container content
- **`executable(self)`** - Return the abstract instance standing for parsed executable
- **`entry_point(self)`** - Return the detected entry_point
- **`arch(self)`** - Return the guessed architecture
- **`loc_db(self)`** - LocationDB instance preloaded with container symbols (if any)
- **`symbol_pool(self)`** - [DEPRECATED API]

### class `ContainerPE(Container)`

Container abstraction for PE

- **`parse(self, data, vm=None, **kwargs)`**

### class `ContainerELF(Container)`

Container abstraction for ELF

- **`parse(self, data, vm=None, addr=0, apply_reloc=False, **kwargs)`** - Load an ELF from @data

### class `ContainerUnknown(Container)`

Container abstraction for unknown format

- **`parse(self, data, vm=None, addr=0, **kwargs)`**
