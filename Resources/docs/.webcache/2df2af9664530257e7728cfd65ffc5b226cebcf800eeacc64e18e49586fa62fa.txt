Expand description

Equivalent to C’s `unsigned char` type.

This type will always be [`u8`](https://doc.rust-lang.org/std/primitive.u8.html "primitive u8"), but is included for completeness. It is defined as being an unsigned integer the same size as a C [`char`](https://doc.rust-lang.org/std/os/raw/type.c_char.html "type std::os::raw::c_char").
