Expand description

Stores a value if the current value is the same as the `old` value. `T` must be an integer or pointer type. The comparison may spuriously fail.

The stabilized version of this intrinsic is available on the [`atomic`](https://doc.rust-lang.org/std/sync/atomic/index.html "mod std::sync::atomic") types via the `compare_exchange_weak` method. For example, [`AtomicBool::compare_exchange_weak`](https://doc.rust-lang.org/std/sync/atomic/struct.Atomic.html#method.compare_exchange_weak "method std::sync::atomic::Atomic::compare_exchange_weak").
