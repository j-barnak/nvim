# The seL4 microkernel

The seL4 kernel itself is the core software program, running in privilege mode, providing applications with a minimal abstraction layer above the hardware. Applications can be built directly on top of seL4, or, for an easier entry point, using frameworks like [Microkit](https://docs.sel4.systems/projects/microkit/) or [CAmkES](https://docs.sel4.systems/projects/camkes/).

General information about the [seL4 microkernel](https://sel4.systems/About/), including details about its [formal verification](https://sel4.systems/Verification/) are found on the [seL4 main site](https://sel4.systems/), which also contains other sources of learning, such as [publications](https://sel4.systems/Research/publications.html), [courses](https://sel4.systems/Research/courses.html), and a [white paper](https://sel4.systems/About/whitepaper.html), as well as an extensive [FAQ](https://sel4.systems/About/FAQ.html).

We welcome contributions to seL4. Please see [how to contribute](https://docs.sel4.systems/projects/sel4/kernel-contribution.html).

The seL4 kernel itself is open source and [licensed](https://sel4.systems/Legal/license.html) under the GPL, version 2. Application code, operating system components, and drivers can have any license, proprietary or open source. The GPL propagation clause of the kernel license stops at the kernel/user code boundary.
