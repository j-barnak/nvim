**Remote File System** (**RFS**) was introduced in UNIX System V to compete with [NFS](https://wiki.osdev.org/NFS "NFS") and such. Unlike NFS, RFS is a connection-oriented system, so if, for example, two different machines access a file on a server, they get about the same semantics as if two processes on a single machine accessed the file. Note that NFS and RFS are both built on top of some sort of [local file system](https://wiki.osdev.org/File_Systems "File Systems"), which determines things like inodes and such.
