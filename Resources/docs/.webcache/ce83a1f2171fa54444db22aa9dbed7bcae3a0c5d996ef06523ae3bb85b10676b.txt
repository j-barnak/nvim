# Trait Product Copy item path

1.12.0 (const: [unstable](https://github.com/rust-lang/rust/issues/92476 "Tracking issue for const_iter")) · [Source](https://doc.rust-lang.org/src/core/iter/traits/accum.rs.html#40)

``` rust
pub trait Product<A = Self>: Sized {
    // Required method
    fn product<I>(iter: I) -> Self
       where I: Iterator<Item = A>;
}
```

Expand description

Trait to represent types that can be created by multiplying elements of an iterator.

This trait is used to implement [`Iterator::product()`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.product "method std::iter::Iterator::product"). Types which implement this trait can be generated by using the [`product()`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.product "method std::iter::Iterator::product") method on an iterator. Like [`FromIterator`](https://doc.rust-lang.org/std/iter/trait.FromIterator.html "trait std::iter::FromIterator"), this trait should rarely be called directly.

## Required Methods

Takes an iterator and generates `Self` from the elements by multiplying the items.

## Dyn Compatibility

This trait is **not** [dyn compatible](https://doc.rust-lang.org/1.98.1/reference/items/traits.html#dyn-compatibility).

*In older versions of Rust, dyn compatibility was called "object safety".*
