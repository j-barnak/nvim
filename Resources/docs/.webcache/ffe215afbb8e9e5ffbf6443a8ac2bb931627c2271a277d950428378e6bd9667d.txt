# Struct Sink Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/core/io/util.rs.html#101)

``` rust
#[non_exhaustive]pub struct Sink;
```

Expand description

A writer which will move data into the void.

This struct is generally created by calling [`sink()`](https://doc.rust-lang.org/std/io/fn.sink.html "fn std::io::sink"). Please see the documentation of [`sink()`](https://doc.rust-lang.org/std/io/fn.sink.html "fn std::io::sink") for more details.
