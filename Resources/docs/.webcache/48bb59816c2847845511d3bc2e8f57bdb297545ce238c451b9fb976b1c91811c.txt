15‐411/611                                                         9
                      Flow-based May-Alias
             • At each program point a set of tuples:
                             (t, d, k)
               – t: variable
               – d: alias class
               – k: offset into alias class
             • (t,d,k) means variable t may point to alias
               class d, or
             • t‐k points to d
