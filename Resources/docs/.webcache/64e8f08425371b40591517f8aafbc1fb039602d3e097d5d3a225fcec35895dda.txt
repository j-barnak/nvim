# miasm.analysis.debugging

## Classes

### class `DebugBreakpoint(object)`

Debug Breakpoint parent class

### class `DebugBreakpointSoft(DebugBreakpoint)`

Stand for software breakpoint

- **`__init__(self, addr)`**
- **`__str__(self)`**

### class `DebugBreakpointTerminate(DebugBreakpoint)`

Stand for an execution termination

- **`__init__(self, status)`**
- **`__str__(self)`**

### class `DebugBreakpointMemory(DebugBreakpoint)`

Stand for memory breakpoint

- **`__init__(self, addr, size, access_type)`**
- **`__str__(self)`**
- **`get_access_type(cls, read=False, write=False)`**

### class `Debugguer(object)`

Debugguer linked with a Jitter instance

- **`__init__(self, myjit)`** - myjit : jitter instance
- **`init_run(self, addr)`**
- **`add_breakpoint(self, addr)`** - Add bp @addr
- **`init_memory_breakpoint(self)`** - Set exception handler on EXCEPT_BREAKPOINT_MEMORY
- **`add_memory_breakpoint(self, addr, size, read=False, write=False)`** - add mem bp @[addr, addr + size], on read/write/both
- **`remove_breakpoint(self, dbs)`** - remove the DebugBreakpointSoft instance
- **`remove_breakpoint_by_addr(self, addr)`** - remove breakpoints @ addr
- **`remove_memory_breakpoint(self, dbm)`** - remove the DebugBreakpointMemory instance
- **`remove_memory_breakpoint_by_addr_access(self, addr, read=False, write=False)`** - remove breakpoints @ addr
- **`get_breakpoint_by_addr(self, addr)`**
- **`get_breakpoints(self)`**
- **`active_trace(self, mn=None, regs=None, newbloc=None)`**
- **`handle_exception(self, res)`**
- **`step(self)`** - Step in jit
- **`run(self)`**
- **`get_mem(self, addr, size=15)`** - hexdump @addr, size
- **`get_mem_raw(self, addr, size=15)`** - hexdump @addr, size
- **`watch_mem(self, addr, size=15)`**
- **`on_step(self)`**
- **`get_reg_value(self, reg_name)`**
- **`set_reg_value(self, reg_name, value)`**
- **`get_gpreg_all(self)`** - Return general purposes registers
