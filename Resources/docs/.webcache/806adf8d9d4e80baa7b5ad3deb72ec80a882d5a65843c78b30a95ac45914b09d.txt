**OVMF** (Open Virtual Machine Firmware) is an [UEFI](https://wiki.osdev.org/UEFI "UEFI") implementation to be used in virtual machines or emulators, such as [QEMU](https://wiki.osdev.org/QEMU "QEMU"). It is free and open source software. It is part of Tianocore's [EDK II](https://wiki.osdev.org/EDK2 "EDK2") project.

Many Linux distributions let you install OVMF with their default installer.

For example on Debian/Ubuntu and derivatives:

``` text
 sudo apt install ovmf
```

Or on Arch/Manjaro and derivatives:

``` text
 sudo pacman -S ovmf
```
