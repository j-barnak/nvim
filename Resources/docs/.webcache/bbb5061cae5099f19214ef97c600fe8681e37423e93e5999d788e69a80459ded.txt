# Trait FromEndianBytes Copy item path

[Source](https://doc.rust-lang.org/src/std/io/mod.rs.html#2918-2924)

``` rust
pub trait FromEndianBytes: Sealed + Sized { }
```

🔬This is a nightly-only experimental API. (`read_le_be_internals`)

Expand description

Trait for types that can be converted from a fixed-size byte array with a specified endianness

## Dyn Compatibility

This trait is **not** [dyn compatible](https://doc.rust-lang.org/1.98.1/reference/items/traits.html#dyn-compatibility).

*In older versions of Rust, dyn compatibility was called "object safety".*
