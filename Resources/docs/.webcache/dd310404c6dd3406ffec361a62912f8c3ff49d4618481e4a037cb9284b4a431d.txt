# Function sink Copy item path

``` rust
pub const fn sink() -> Sink ⓘ
```

Expand description

Creates an instance of a writer which will successfully consume all data.

All calls to [`write`](https://doc.rust-lang.org/std/io/trait.Write.html#tymethod.write) on the returned instance will return [`Ok(buf.len())`](https://doc.rust-lang.org/std/result/enum.Result.html#variant.Ok "variant std::result::Result::Ok") and the contents of the buffer will not be inspected.

## Examples

``` rust
use std::io::{self, Write};

let buffer = vec![1, 2, 3, 5, 8];
let num_bytes = io::sink().write(&buffer).unwrap();
assert_eq!(num_bytes, 5);
```
