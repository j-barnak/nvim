This equivalent to the [`read_at`](https://doc.rust-lang.org/std/os/wasi/fs/trait.FileExt.html#tymethod.read_at "method std::os::wasi::fs::FileExt::read_at") method, except that it is passed a [`BorrowedCursor`](https://doc.rust-lang.org/std/io/struct.BorrowedCursor.html "struct std::io::BorrowedCursor") rather than `&mut [u8]` to allow use with uninitialized buffers. ## Provided Methods

[Source](https://doc.rust-lang.org/src/std/os/wasi/fs.rs.html#84-98)

🔬This is a nightly-only experimental API. (`wasi_ext` [\#71213](https://github.com/rust-lang/rust/issues/71213))

Reads the exact number of byte required to fill `buf` from the given offset.

The offset is relative to the start of the file and thus independent from the current cursor.

The current file cursor is not affected by this function.

Similar to [`Read::read_exact`](https://doc.rust-lang.org/std/io/trait.Read.html#method.read_exact "method std::io::Read::read_exact") but uses [`read_at`](https://doc.rust-lang.org/std/os/wasi/fs/trait.FileExt.html#tymethod.read_at "method std::os::wasi::fs::FileExt::read_at") instead of `read`.

##### Errors

If this function encounters an error of the kind [`io::ErrorKind::Interrupted`](https://doc.rust-lang.org/std/io/enum.ErrorKind.html#variant.Interrupted "variant std::io::ErrorKind::Interrupted") then the error is ignored and the operation will continue.

If this function encounters an “end of file” before completely filling the buffer, it returns an error of the kind [`io::ErrorKind::UnexpectedEof`](https://doc.rust-lang.org/std/io/enum.ErrorKind.html#variant.UnexpectedEof "variant std::io::ErrorKind::UnexpectedEof"). The contents of `buf` are unspecified in this case.

If any other read error is encountered then this function immediately returns. The contents of `buf` are unspecified in this case.

If this function returns an error, it is unspecified how many bytes it has read, but it will never read more than would be necessary to completely fill the buffer.

[Source](https://doc.rust-lang.org/src/std/os/wasi/fs.rs.html#152-167)

🔬This is a nightly-only experimental API. (`wasi_ext` [\#71213](https://github.com/rust-lang/rust/issues/71213))

Attempts to write an entire buffer starting from a given offset.

The offset is relative to the start of the file and thus independent from the current cursor.

The current file cursor is not affected by this function.

This method will continuously call [`write_at`](https://doc.rust-lang.org/std/os/wasi/fs/trait.FileExt.html#tymethod.write_at "method std::os::wasi::fs::FileExt::write_at") until there is no more data to be written or an error of non-[`io::ErrorKind::Interrupted`](https://doc.rust-lang.org/std/io/enum.ErrorKind.html#variant.Interrupted "variant std::io::ErrorKind::Interrupted") kind is returned. This method will not return until the entire buffer has been successfully written or such an error occurs. The first error that is not of [`io::ErrorKind::Interrupted`](https://doc.rust-lang.org/std/io/enum.ErrorKind.html#variant.Interrupted "variant std::io::ErrorKind::Interrupted") kind generated from this method will be returned.

##### Errors

This function will return the first error of non-[`io::ErrorKind::Interrupted`](https://doc.rust-lang.org/std/io/enum.ErrorKind.html#variant.Interrupted "variant std::io::ErrorKind::Interrupted") kind that [`write_at`](https://doc.rust-lang.org/std/os/wasi/fs/trait.FileExt.html#tymethod.write_at "method std::os::wasi::fs::FileExt::write_at") returns.
