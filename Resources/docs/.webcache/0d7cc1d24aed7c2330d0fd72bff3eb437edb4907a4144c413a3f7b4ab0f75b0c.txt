jsonic proves that a DSL can be a simple & practical tool for solving a programming problem. We needed fewer than [50 lines of code](https://beautifulracket.com/jsonic/source-listing.html) for jsonic—making it even shorter than [bf](https://beautifulracket.com/bf/source-listing.html). Undoubtedly, writing a whole JSON-generation library in our favorite programming language would’ve been more work.

Of course, one reason jsonic can be small is that it relies heavily on Racket: as an implementation language, as the language for the embedded expressions, and for the json library, which handles the heavy lifting.

But that’s a good thing. All we need to do is design and implement the interface for our little language.

The other reason jsonic is small is that we’ve treated it as a tool for personal use. If we were sharing this DSL with others, we’d want to include tests, documentation, better error messages, and integration with DrRacket (about which, [more shortly](https://beautifulracket.com/jsonic-2/)).

Mostly, this jsonic tutorial was meant to nail down the basic two-part framework of a Racket-implemented language that we saw in [stacker](https://beautifulracket.com/stacker/) and [bf](https://beautifulracket.com/bf/):

1.

    A [reader](https://beautifulracket.com/appendix/glossary.html#reader) that converts the source code into parenthesized S-expressions. We made our reader by chaining a [tokenizer](https://beautifulracket.com/appendix/glossary.html#tokenizer) to a [grammar](https://beautifulracket.com/appendix/glossary.html#grammar)-based [parser](https://beautifulracket.com/appendix/glossary.html#parser).

2.

    An [expander](https://beautifulracket.com/appendix/glossary.html#expander) that adds bindings to the code produced by the reader, so the code can be evaluated as a Racket program. We made our expander by relying on [macros](https://beautifulracket.com/appendix/glossary.html#macro) and helper functions.

The next tutorials are going to assume that we’re completely cool with these ingredients. If any of these concepts are unclear, this is a good moment to review.
