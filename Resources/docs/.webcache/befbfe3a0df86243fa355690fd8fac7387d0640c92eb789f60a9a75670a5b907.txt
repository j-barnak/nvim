# Struct Ready Copy item path

1.48.0 · [Source](https://doc.rust-lang.org/src/core/future/ready.rs.html#12)

pub struct Ready<T>(/* private fields */);

Expand description

A future that is immediately ready with a value.

This `struct` is created by [`ready()`](https://doc.rust-lang.org/std/future/fn.ready.html "fn std::future::ready"). See its documentation for more.

## Implementations

[Source](https://doc.rust-lang.org/src/core/future/ready.rs.html#27)

1.82.0 · [Source](https://doc.rust-lang.org/src/core/future/ready.rs.html#45)

Consumes the `Ready`, returning the wrapped value.

##### Panics

Will panic if this [`Ready`](https://doc.rust-lang.org/std/future/struct.Ready.html "struct std::future::Ready") was already polled to completion.

##### Examples

``` rust
use std::future;

let a = future::ready(1);
assert_eq!(a.into_inner(), 1);
```
