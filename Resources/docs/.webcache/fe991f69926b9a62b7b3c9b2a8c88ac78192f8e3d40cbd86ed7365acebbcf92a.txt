# Macro writeln Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/core/macros/mod.rs.html#641)

``` rust
macro_rules! writeln {
    ($dst:expr $(,)?) => { ... };
    ($dst:expr, $($arg:tt)*) => { ... };
    ($($arg:tt)*) => { ... };
}
```

Expand description

Writes formatted data into a buffer, with a newline appended.

On all platforms, the newline is the LINE FEED character (`\n`/`U+000A`) alone (no additional CARRIAGE RETURN (`\r`/`U+000D`).

For more information, see [`write!`](https://doc.rust-lang.org/std/macro.write.html "macro std::write"). For information on the format string syntax, see [`std::fmt`](https://doc.rust-lang.org/std/fmt/index.html).

## Examples

``` rust
use std::io::{Write, Result};

fn main() -> Result<()> {
    let mut w = Vec::new();
    writeln!(&mut w)?;
    writeln!(&mut w, "test")?;
    writeln!(&mut w, "formatted {}", "arguments")?;

    assert_eq!(&w[..], "\ntest\nformatted arguments\n".as_bytes());
    Ok(())
}
```
