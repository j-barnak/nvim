# Struct Chain Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/core/io/util.rs.html#136)

``` rust
#[non_exhaustive]pub struct Chain<T, U> { /* private fields */ }
```

Expand description

Adapter to chain together two readers.

This struct is generally created by calling [`chain`](https://doc.rust-lang.org/std/io/trait.Read.html#method.chain) on a reader. Please see the documentation of [`chain`](https://doc.rust-lang.org/std/io/trait.Read.html#method.chain) for more details.

## Implementations

[Source](https://doc.rust-lang.org/src/core/io/util.rs.html#148)

1.20.0 · [Source](https://doc.rust-lang.org/src/core/io/util.rs.html#168)

Consumes the `Chain`, returning the wrapped readers.

##### Examples

``` rust
use std::io;
use std::io::prelude::*;
use std::fs::File;

fn main() -> io::Result<()> {
    let mut foo_file = File::open("foo.txt")?;
    let mut bar_file = File::open("bar.txt")?;

    let chain = foo_file.chain(bar_file);
    let (foo_file, bar_file) = chain.into_inner();
    Ok(())
}
```

1.20.0 · [Source](https://doc.rust-lang.org/src/core/io/util.rs.html#195)

Gets references to the underlying readers in this `Chain`.

Care should be taken to avoid modifying the internal I/O state of the underlying readers as doing so may corrupt the internal state of this `Chain`.

##### Examples

``` rust
use std::io;
use std::io::prelude::*;
use std::fs::File;

fn main() -> io::Result<()> {
    let mut foo_file = File::open("foo.txt")?;
    let mut bar_file = File::open("bar.txt")?;

    let chain = foo_file.chain(bar_file);
    let (foo_file, bar_file) = chain.get_ref();
    Ok(())
}
```

1.20.0 · [Source](https://doc.rust-lang.org/src/core/io/util.rs.html#222)

Gets mutable references to the underlying readers in this `Chain`.

Care should be taken to avoid modifying the internal I/O state of the underlying readers as doing so may corrupt the internal state of this `Chain`.

##### Examples

``` rust
use std::io;
use std::io::prelude::*;
use std::fs::File;

fn main() -> io::Result<()> {
    let mut foo_file = File::open("foo.txt")?;
    let mut bar_file = File::open("bar.txt")?;

    let mut chain = foo_file.chain(bar_file);
    let (foo_file, bar_file) = chain.get_mut();
    Ok(())
}
```
