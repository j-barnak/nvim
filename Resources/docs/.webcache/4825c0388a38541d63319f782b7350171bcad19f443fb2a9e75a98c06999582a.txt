Expand description

The error returned by [`try_insert`](https://doc.rust-lang.org/std/collections/struct.HashMap.html#method.try_insert "method std::collections::HashMap::try_insert") when the key already exists.

Contains the occupied entry, key, and the value that was not inserted.
