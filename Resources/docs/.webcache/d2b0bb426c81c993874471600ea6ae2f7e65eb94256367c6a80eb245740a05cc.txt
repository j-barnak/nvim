Expand description

Reallocates memory with the global allocator.

This function forwards calls to the [`GlobalAlloc::realloc`](https://doc.rust-lang.org/std/alloc/trait.GlobalAlloc.html#method.realloc "method std::alloc::GlobalAlloc::realloc") method of the allocator registered with the `#[global_allocator]` attribute if there is one, or the `std` crate’s default.

This function is expected to be deprecated in favor of the `grow` and `shrink` methods of the [`Global`](https://doc.rust-lang.org/std/alloc/struct.Global.html "struct std::alloc::Global") type when it and the [`Allocator`](https://doc.rust-lang.org/std/alloc/trait.Allocator.html "trait std::alloc::Allocator") trait become stable.

## Safety

See [`GlobalAlloc::realloc`](https://doc.rust-lang.org/std/alloc/trait.GlobalAlloc.html#method.realloc "method std::alloc::GlobalAlloc::realloc").
