Expand description

Equivalent to C’s `signed char` type.

This type will always be [`i8`](https://doc.rust-lang.org/std/primitive.i8.html "primitive i8"), but is included for completeness. It is defined as being a signed integer the same size as a C [`char`](https://doc.rust-lang.org/std/os/raw/type.c_char.html "type std::os::raw::c_char").
