# Experimental / Kmodify

The `drgn.helpers.experimental.kmodify` module provides experimental helpers for modifying the state of the running kernel. This works by loading a temporary kernel module, so the kernel must support loadable kernel modules (`CONFIG_MODULES=y`) and allow loading unsigned modules (`CONFIG_MODULE_SIG_FORCE=n`). It is currently only implemented for x86-64.

Warning

These helpers are powerful but **extremely** dangerous. Use them with care.

drgn.helpers.experimental.kmodify.write_memory(*prog: [drgn.Program](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Program "drgn.Program")*, *address: [drgn.IntegerLike](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.IntegerLike "drgn.IntegerLike")*, *value: [bytes](https://docs.python.org/3/library/stdtypes.html#bytes "(in Python v3.14)")*) → [None](https://docs.python.org/3/library/constants.html#None "(in Python v3.14)")  
Write a byte string to kernel memory.

    >>> os.uname().sysname
    'Linux'
    >>> write_memory(prog["init_uts_ns"].name.sysname.address_, b"Lol\0")
    >>> os.uname().sysname
    'Lol'

Warning

This attempts to detect writes to bad addresses and raise a [`FaultError`](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.FaultError "drgn.FaultError"), but this is best-effort and may still crash the kernel. Writing bad data can of course also cause a crash when the data is used. Additionally, this is not atomic, so the data may be accessed while it is partially written.

Parameters:  
- **prog** – Program, which [may be omitted to use the default program argument](https://drgn.readthedocs.io/en/latest/api_reference.html#default-program).

- **address** – Address to write to.

- **value** – Byte string to write.

Raises:  
[**FaultError**](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.FaultError "drgn.FaultError") – if the address cannot be written to

&nbsp;

drgn.helpers.experimental.kmodify.set_bit(*nr: [drgn.IntegerLike](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.IntegerLike "drgn.IntegerLike")*, *bitmap: [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")*) → [None](https://docs.python.org/3/library/constants.html#None "(in Python v3.14)")  
Atomically set a bit in kernel memory.

Warning

This attempts to detect bad addresses and raise a [`FaultError`](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.FaultError "drgn.FaultError"), but this is best-effort and may still crash the kernel. In particular, this function will crash the kernel if the target address is read-only. Writing an invalid bit can of course also cause a crash when the data is used.

Parameters:  
- **nr** – Bit number.

- **bitmap** – `unsigned`` ``long`` ``*`

&nbsp;

drgn.helpers.experimental.kmodify.clear_bit(*nr: [drgn.IntegerLike](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.IntegerLike "drgn.IntegerLike")*, *bitmap: [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")*) → [None](https://docs.python.org/3/library/constants.html#None "(in Python v3.14)")  
Atomically clear a bit in kernel memory.

Warning

The warnings about [`set_bit()`](#drgn.helpers.experimental.kmodify.set_bit "drgn.helpers.experimental.kmodify.set_bit") also apply to `clear_bit()`.

Parameters:  
- **nr** – Bit number.

- **bitmap** – `unsigned`` ``long`` ``*`

&nbsp;

drgn.helpers.experimental.kmodify.write_object(*object: [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")*, *value: [Any](https://docs.python.org/3/library/typing.html#typing.Any "(in Python v3.14)")*, *\**, *dereference: [Optional](https://docs.python.org/3/library/typing.html#typing.Optional "(in Python v3.14)")\[[bool](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")\] = None*) → [None](https://docs.python.org/3/library/constants.html#None "(in Python v3.14)")  
Write to an object in kernel memory.

    >>> os.system("uptime -p")
    up 12 minutes
    >>> write_object(prog["init_time_ns"].offsets.boottime.tv_sec, 1000000000)
    >>> os.system("uptime -p")
    up 3 decades, 1 year, 37 weeks, 1 hour, 59 minutes

Bit fields are currently only supported if they are either byte-aligned or a single bit. Writes to a bit field are atomic with respect to other bit fields.

Warning

The warnings about [`write_memory()`](#drgn.helpers.experimental.kmodify.write_memory "drgn.helpers.experimental.kmodify.write_memory") and [`set_bit()`](#drgn.helpers.experimental.kmodify.set_bit "drgn.helpers.experimental.kmodify.set_bit") also apply to `write_object()`.

Parameters:  
- **object** – Object to write to.

- **value** – Value to write. This may be an [`Object`](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object") or a Python value. Either way, it will be converted to the type of *object*.

- **dereference** – If *object* is a pointer, whether to dereference it. If `True`, then write to the object pointed to by *object* (`*ptr`` ``=`` ``value`). If `False`, then write to the pointer itself (`ptr`` ``=`` ``value`). This is a common source of confusion, so it is required if *object* is a pointer.

Raises:  
- [**ValueError**](https://docs.python.org/3/library/exceptions.html#ValueError "(in Python v3.14)") – if *object* is not a reference object (i.e., its address is not known)

- [**TypeError**](https://docs.python.org/3/library/exceptions.html#TypeError "(in Python v3.14)") – if *object* is a pointer and *dereference* is not given

- [**TypeError**](https://docs.python.org/3/library/exceptions.html#TypeError "(in Python v3.14)") – if *object* is not a pointer and *dereference* is `True`

- [**NotImplementedError**](https://docs.python.org/3/library/exceptions.html#NotImplementedError "(in Python v3.14)") – if *object* is a bit field that is not byte-aligned or a single bit

&nbsp;

drgn.helpers.experimental.kmodify.call_function(*prog: [drgn.Program](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Program "drgn.Program")*, *func: [Union](https://docs.python.org/3/library/typing.html#typing.Union "(in Python v3.14)")\[[str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)"), [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")\]*, *\*args: [Any](https://docs.python.org/3/library/typing.html#typing.Any "(in Python v3.14)")*) → [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")  
Call a function in the kernel.

    >>> task = find_task(99)
    >>> if task:
    ...     call_function("wake_up_process", task)
    ...
    (int)1

Arguments can be either [`Object`](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")s or Python values. The function return value is returned as an [`Object`](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object"):

    >>> # GFP_KERNEL isn't in the kernel debug info
    >>> # We have to use this trick to get it.
    >>> for flag in prog["gfpflag_names"]:
    ...     if flag.name.string_() == b"GFP_KERNEL":
    ...             GFP_KERNEL = flag.mask
    ...             break
    ...
    >>> # kmalloc() is actually a macro.
    >>> # We have to call the underlying function.
    >>> p = call_function("__kmalloc_noprof", 13, GFP_KERNEL)
    >>> p
    (void *)0xffff991701ef43c0
    >>> identify_address(p)
    'slab object: kmalloc-16+0x0'
    >>> call_function("kfree", p)
    (void)<absent>
    >>> identify_address(p)
    'free slab object: kmalloc-16+0x0'

Variadic functions are also supported:

    >>> call_function("_printk", "Hello, world! %d\n", Object(prog, "int", 1234))
    (int)18
    >>> os.system("dmesg | tail -1")
    [ 1138.223004] Hello, world! 1234

Constructed values can be passed by pointer using [`pass_pointer()`](#drgn.helpers.experimental.kmodify.pass_pointer "drgn.helpers.experimental.kmodify.pass_pointer"):

    >>> sb = prog["init_fs"].root.mnt.mnt_sb
    >>> sb.s_shrink.scan_objects
    (unsigned long (*)(struct shrinker *, struct shrink_control *))super_cache_scan+0x0 = 0xffffffffbda4c487
    >>> sc = pass_pointer(Object(prog, "struct shrink_control",
    ...                   {"gfp_mask": GFP_KERNEL, "nr_to_scan": 100, "nr_scanned": 100}))
    >>> call_function(sb.s_shrink.scan_objects, sb.s_shrink, sc)
    (unsigned long)31

If the function modifies the passed value, the [`pass_pointer`](#drgn.helpers.experimental.kmodify.pass_pointer "drgn.helpers.experimental.kmodify.pass_pointer") object is updated:

    >>> sc.object
    (struct shrink_control){
            .gfp_mask = (gfp_t)3264,
            .nid = (int)0,
            .nr_to_scan = (unsigned long)1,
            .nr_scanned = (unsigned long)100,
            .memcg = (struct mem_cgroup *)0x0,
    }

Note

It is not possible to call some functions, including inlined functions and function-like macros. If the unavailable function is a wrapper around another function, sometimes the wrapped function can be called instead.

Warning

Calling a function incorrectly may cause the kernel to crash or misbehave in various ways.

The function is called from process context. Note that the function may have context, locking, or reference counting requirements.

Parameters:  
- **prog** – Program, which [may be omitted to use the default program argument](https://drgn.readthedocs.io/en/latest/api_reference.html#default-program).

- **func** – Function to call. May be a function name, function object, or function pointer object.

- **args** – Function arguments. [`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)"), [`float`](https://docs.python.org/3/library/functions.html#float "(in Python v3.14)"), and [`bool`](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)") arguments are converted as “literals” with `Object(prog,`` ``value=...)`. [`str`](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)") and [`bytes`](https://docs.python.org/3/library/stdtypes.html#bytes "(in Python v3.14)") arguments are converted to `char` array objects. [`pass_pointer`](#drgn.helpers.experimental.kmodify.pass_pointer "drgn.helpers.experimental.kmodify.pass_pointer") arguments are copied to the kernel, passed by pointer, and copied back.

Returns:  
Function return value.

Raises:  
- [**TypeError**](https://docs.python.org/3/library/exceptions.html#TypeError "(in Python v3.14)") – if the passed arguments have incorrect types for the function

- [**ObjectAbsentError**](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.ObjectAbsentError "drgn.ObjectAbsentError") – if the function cannot be called because it is inlined

- [**LookupError**](https://docs.python.org/3/library/exceptions.html#LookupError "(in Python v3.14)") – if a function with the given name is not found (possibly because it is actually a function-like macro)

&nbsp;

drgn.helpers.experimental.kmodify.call_functions(*prog: [drgn.Program](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Program "drgn.Program")*, *calls: [Sequence](https://docs.python.org/3/library/typing.html#typing.Sequence "(in Python v3.14)")\[[Sequence](https://docs.python.org/3/library/typing.html#typing.Sequence "(in Python v3.14)")\[[Any](https://docs.python.org/3/library/typing.html#typing.Any "(in Python v3.14)")\]\]*) → [None](https://docs.python.org/3/library/constants.html#None "(in Python v3.14)")  
Call multiple functions in the kernel.

This is more efficient than calling [`call_function()`](#drgn.helpers.experimental.kmodify.call_function "drgn.helpers.experimental.kmodify.call_function") multiple times because it only inserts one kernel module.

    >>> leaked_namespaces
    [Object(prog, 'struct net *', value=0xffff8f568869af80), ...]
    >>> call_functions([("netns_put", ns) for ns in leaked_namespaces])

Function return values are ignored. Use [`call_function()`](#drgn.helpers.experimental.kmodify.call_function "drgn.helpers.experimental.kmodify.call_function") if you need the return value.

Warning

See [`call_function()`](#drgn.helpers.experimental.kmodify.call_function "drgn.helpers.experimental.kmodify.call_function") for warnings about calling kernel functions.

Parameters:  
- **prog** – Program, which [may be omitted to use the default program argument](https://drgn.readthedocs.io/en/latest/api_reference.html#default-program).

- **calls** – List of calls, where each call is a tuple of `(func,`` ``*args)`. See [`call_function()`](#drgn.helpers.experimental.kmodify.call_function "drgn.helpers.experimental.kmodify.call_function") for details on *func* and *args*.

&nbsp;

*class *drgn.helpers.experimental.kmodify.pass_pointer(*object: [Any](https://docs.python.org/3/library/typing.html#typing.Any "(in Python v3.14)")*)  
Wrapper used to pass values to [`call_function()`](#drgn.helpers.experimental.kmodify.call_function "drgn.helpers.experimental.kmodify.call_function") or [`call_functions()`](#drgn.helpers.experimental.kmodify.call_functions "drgn.helpers.experimental.kmodify.call_functions") by pointer.

Parameters:  
**object** – [`Object`](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object") or Python value to wrap.

object*: [Any](https://docs.python.org/3/library/typing.html#typing.Any "(in Python v3.14)")*  
Wrapped object. Updated to an [`Object`](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object") containing the final value after the function call.
