# miasm.jitter.jitcore

## Classes

### class `JitCore(object)`

JiT management. This is an abstract class

- **`__init__(self, lifter, bin_stream)`** - Initialise a JitCore instance.
- **`ir_arch(self)`**
- **`set_options(self, **kwargs)`** - Set options relative to the backend
- **`clear_jitted_blocks(self)`** - Reset all jitted blocks
- **`add_disassembly_splits(self, *args)`** - The disassembly engine will stop on address in args if they
- **`remove_disassembly_splits(self, *args)`** - The disassembly engine will no longer stop on address in args
- **`load(self)`** - Initialise the Jitter
- **`set_block_min_max(self, cur_block)`** - Update cur_block to set min/max address
- **`add_block_to_mem_interval(self, vm, block)`** - Update vm to include block addresses in its memory range
- **`add_block(self, block)`** - Add a block to JiT and JiT it.
- **`disasm_and_jit_block(self, addr, vm)`** - Disassemble a new block and JiT it
- **`run_at(self, cpu, offset, stop_offsets)`** - Run from the starting address @offset.
- **`blocks_to_memrange(self, blocks)`** - Return an interval instance standing for blocks addresses
- **`__updt_jitcode_mem_range(self, vm)`** - Rebuild the VM blocks address memory range
- **`del_block_in_range(self, ad1, ad2)`** - Find and remove jitted block in range [ad1, ad2].
- **`updt_automod_code_range(self, vm, mem_range)`** - Remove jitted code in range @mem_range
- **`updt_automod_code(self, vm)`** - Remove jitted code updated by memory write
- **`hash_block(self, block)`** - Build a hash of the block @block
- **`disasm_cb(self)`**
- **`disasm_cb(self, value)`**
