Jbd2 is a journaling system used in [Ext3](https://wiki.osdev.org/Ext3 "Ext3"), [Ext4](https://wiki.osdev.org/Ext4 "Ext4"), and [OCFS2](https://wiki.osdev.org/index.php?title=OCFS2&action=edit&redlink=1 "OCFS2 (page does not exist)"). This system allows for changes to the filesystem to be reapplied based on the transaction state. See [Journaling](https://wiki.osdev.org/Journaling "Journaling") for a generic description of filesystem journaling.
