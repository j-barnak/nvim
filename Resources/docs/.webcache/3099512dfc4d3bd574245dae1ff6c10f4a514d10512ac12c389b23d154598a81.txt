`symquery` is a symbol querying tool that operates on Linux, Mac, and Windows and supports the Windows PDB, Linux ELF, Mac Mach-O, and Windows PECOFF formats with DWARF2 line information. It is part of the [Dr. Memory tool suite](http://drmemory.org). It is also included with DynamoRIO versions 5.0.0 and higher.

If this documentation is part of a DynamoRIO public release, [this link](https://dynamorio.org/drmemory/drmemory/docs/html/page_symquery.html) should point at the local documentation provided with the release package. [This one](https://dynamorio.org/page_symquery.html) points to the online documentation.
