# Struct LazyCell Copy item path

1.80.0 · [Source](https://doc.rust-lang.org/src/core/cell/lazy.rs.html#54)

``` rust
pub struct LazyCell<T, F = fn() -> T> { /* private fields */ }
```

Expand description

A value which is initialized on the first access.

For a thread-safe version of this struct, see [`std::sync::LazyLock`](https://doc.rust-lang.org/std/sync/struct.LazyLock.html).

## Poisoning

If the initialization closure passed to [`LazyCell::new`](https://doc.rust-lang.org/std/cell/struct.LazyCell.html#method.new "associated function std::cell::LazyCell::new") panics, the cell will be poisoned. Once the cell is poisoned, any threads that attempt to access this cell (via a dereference or via an explicit call to [`force()`](https://doc.rust-lang.org/std/cell/struct.LazyCell.html#method.force "associated function std::cell::LazyCell::force")) will panic.

This concept is similar to that of poisoning in the [`std::sync::poison`](https://doc.rust-lang.org/std/sync/poison/index.html) module. A key difference, however, is that poisoning in `LazyCell` is *unrecoverable*. All future accesses of the cell from other threads will panic, whereas a type in [`std::sync::poison`](https://doc.rust-lang.org/std/sync/poison/index.html) like [`std::sync::poison::Mutex`](https://doc.rust-lang.org/std/sync/poison/struct.Mutex.html) allows recovery via [`PoisonError::into_inner()`](https://doc.rust-lang.org/std/sync/poison/struct.PoisonError.html#method.into_inner).

## Examples

``` rust
use std::cell::LazyCell;

let lazy: LazyCell<i32> = LazyCell::new(|| {
    println!("initializing");
    92
});
println!("ready");
println!("{}", *lazy);
println!("{}", *lazy);

// Prints:
//   ready
//   initializing
//   92
//   92
```

Forces the evaluation of this lazy value and returns a reference to the result.

This is equivalent to the `Deref` impl, but is explicit.

##### Panics

If the initialization closure panics (the one that is passed to the [`new()`](https://doc.rust-lang.org/std/cell/struct.LazyCell.html#method.new "associated function std::cell::LazyCell::new") method), the panic is propagated to the caller, and the cell becomes poisoned. This will cause all future accesses of the cell (via [`force()`](https://doc.rust-lang.org/std/cell/struct.LazyCell.html#method.force "associated function std::cell::LazyCell::force") or a dereference) to panic.

##### Examples

``` rust
use std::cell::LazyCell;

let lazy = LazyCell::new(|| 92);

assert_eq!(LazyCell::force(&lazy), &92);
assert_eq!(&*lazy, &92);
```

Forces the evaluation of this lazy value and returns a mutable reference to the result.

##### Panics

If the initialization closure panics (the one that is passed to the [`new()`](https://doc.rust-lang.org/std/cell/struct.LazyCell.html#method.new "associated function std::cell::LazyCell::new") method), the panic is propagated to the caller, and the cell becomes poisoned. This will cause all future accesses of the cell (via [`force()`](https://doc.rust-lang.org/std/cell/struct.LazyCell.html#method.force "associated function std::cell::LazyCell::force") or a dereference) to panic.

##### Examples

``` rust
use std::cell::LazyCell;

let mut lazy = LazyCell::new(|| 92);

let p = LazyCell::force_mut(&mut lazy);
assert_eq!(*p, 92);
*p = 44;
assert_eq!(*lazy, 44);
```

1.94.0 · [Source](https://doc.rust-lang.org/src/core/cell/lazy.rs.html#277)

Returns a mutable reference to the value if initialized. Otherwise (if uninitialized or poisoned), returns `None`.

##### Examples

``` rust
use std::cell::LazyCell;

let mut lazy = LazyCell::new(|| 92);

assert_eq!(LazyCell::get_mut(&mut lazy), None);
let _ = LazyCell::force(&lazy);
*LazyCell::get_mut(&mut lazy).unwrap() = 44;
assert_eq!(*lazy, 44);
```
