**eXtended System Descriptor Table (XSDT)** - the 64-bit version of the ACPI [RSDT](https://wiki.osdev.org/RSDT "RSDT")

## Introduction

*"the XSDT provides identical functionality to the RSDT but accommodates physical addresses of DESCRIPTION HEADERs that are larger than 32-bits."* - ACPI Specification v5.0. This means all addresses are now 64 bits. If the pointer to the XSDT is valid, the OS ***MUST*** use the XSDT. All of the addresses will probably be 32 bits, and if you are not using PAE, you couldn't use higher than 32 bits, but the spec says you should use this anyway.

## Detecting the XSDT

To find the XSDT you need first to locate and check the [RSDP](https://wiki.osdev.org/RSDP "RSDP"), then use the XsdtPointer (if it exists).

## Validating the XSDT

You only need to sum all the bytes in the table and compare the result to 0.

## Structure

The XSDT is the main System Description Table. However there are many kinds of SDT. All the SDT may be split into two parts. One (the header) which is common to all the SDT and another (data) which is different for each table. The structure of the header is:

``` c
struct ACPISDTHeader {
  char Signature[4];
  uint32_t Length;
  uint8_t Revision;
  uint8_t Checksum;
  char OEMID[6];
  char OEMTableID[8];
  uint32_t OEMRevision;
  uint32_t CreatorID;
  uint32_t CreatorRevision;
};
```

### Header fields

#### Signature

All the ACPI tables have a 4 byte Signature field (except the RSDP which has an 8 byte one). Using the signature, you can determine what table are you working with.

#### Length

Total size of the table, inclusive of the header.

#### Checksum

A 8 bit checksum field of the whole table, inclusive of the header. All bytes of the table summed must be equal to 0 (mod 0x100). You should always do a checksum of the table before using it, even if you found the table linked by other tables.

``` c
bool doChecksum(ACPISDTHeader *tableHeader)
{
    unsigned char sum = 0;

    for (int i = 0; i < tableHeader->Length; i++)
    {
        sum += ((char *) tableHeader)[i];
    }

    return sum == 0;
}
```

### Other fields

The XSDT contains pointers to other tables:

``` c
struct XSDT {
  struct ACPISDTHeader h;
  uint64_t PointerToOtherSDT[(h.Length - sizeof(h)) / 8];
};
```

**Important**: Note that the 'PointerToOtherSDT' field as defined above should be aligned to a 4-byte boundary and not the default 8-byte alignment for a uint64_t. The offset to the first pointer from the beginning of the XSDT table is 36 bytes.

## How to use

Well, suppose you want to find the [FADT](https://wiki.osdev.org/FADT "FADT"). The FADT, being a SDT has a ACPISDTHeader. It's signature is "FACP". You may use this code:

``` c
void *findFACP(void *RootSDT)
{
    XSDT *xsdt = (XSDT *) RootSDT;
    int entries = (xsdt->h.Length - sizeof(xsdt->h)) / 8;

    for (int i = 0; i < entries; i++)
    {
        ACPISDTHeader *h = (ACPISDTHeader *) xsdt->PointerToOtherSDT[i];
        if (!strncmp(h->Signature, "FACP", 4))
            return (void *) h;
    }

    // No FACP found
    return NULL;
}
```

## What can you find?

### Defined by ACPI

The ACPI Specification 5.0 has direct definitions for the following System Descriptor tables, identified by their signatures:

- "APIC": Multiple APIC Description Table ([MADT](https://wiki.osdev.org/MADT "MADT"))
- "BGRT": Boot Graphics Resource Table ([BGRT](https://wiki.osdev.org/BGRT "BGRT"); only supported on UEFI systems)
- "BERT": Boot Error Record Table ([BERT](https://wiki.osdev.org/index.php?title=BERT&action=edit&redlink=1 "BERT (page does not exist)"))
- "CPEP": Corrected Platform Error Polling Table ([CPEP](https://wiki.osdev.org/index.php?title=CPEP&action=edit&redlink=1 "CPEP (page does not exist)"))
- "DSDT": Differentiated System Description Table ([DSDT](https://wiki.osdev.org/DSDT "DSDT"))
- "ECDT": Embedded Controller Boot Resources Table ([ECDT](https://wiki.osdev.org/index.php?title=ECDT&action=edit&redlink=1 "ECDT (page does not exist)"))
- "EINJ": Error Injection Table ([EINJ](https://wiki.osdev.org/index.php?title=EINJ&action=edit&redlink=1 "EINJ (page does not exist)"))
- "ERST": Error Record Serialization Table ([ERST](https://wiki.osdev.org/index.php?title=ERST&action=edit&redlink=1 "ERST (page does not exist)"))
- "FACP": Fixed ACPI Description Table ([FADT](https://wiki.osdev.org/FADT "FADT"))
- "FACS": Firmware ACPPI Control Structure ([FACS](https://wiki.osdev.org/index.php?title=FACS&action=edit&redlink=1 "FACS (page does not exist)"))
- "HEST": Hardware Error Source Table ([HEST](https://wiki.osdev.org/index.php?title=HEST&action=edit&redlink=1 "HEST (page does not exist)"))
- "MSCT": Maximum System Characteristics Table ([MSCT](https://wiki.osdev.org/index.php?title=MSCT&action=edit&redlink=1 "MSCT (page does not exist)"))
- "MPST": Memory Power State Table ([MPST](https://wiki.osdev.org/index.php?title=MPST&action=edit&redlink=1 "MPST (page does not exist)"))
- "OEMx": OEM Specific Information Tables (Any table with a signature beginning with "OEM" falls into this definition)
- "PMTT" Platform Memory Topology Table ([PMTT](https://wiki.osdev.org/index.php?title=PMTT&action=edit&redlink=1 "PMTT (page does not exist)"))
- "PSDT": Persistent System Description Table ([PSDT](https://wiki.osdev.org/index.php?title=PSDT&action=edit&redlink=1 "PSDT (page does not exist)"))
- "RASF": ACPI RAS FeatureTable ([RASF](https://wiki.osdev.org/index.php?title=RASF&action=edit&redlink=1 "RASF (page does not exist)"))
- "RSDT": Root System Description Table ([RSDT](https://wiki.osdev.org/RSDT "RSDT"); 32-bit version of the XSDT)
- "SBST": Smart Battery Specification Table ([SBST](https://wiki.osdev.org/index.php?title=SBST&action=edit&redlink=1 "SBST (page does not exist)"))
- "SLIT": System Locality System Information Table ([SLIT](https://wiki.osdev.org/index.php?title=SLIT&action=edit&redlink=1 "SLIT (page does not exist)"))
- "SRAT": System Resource Affinity Table ([SRAT](https://wiki.osdev.org/SRAT "SRAT"))
- "SSDT": Secondary System Description Table ([SSDT](https://wiki.osdev.org/SSDT "SSDT"))
- "XSDT": Extended System Description Table (This wiki page; included for completeness)

### Reserved by ACPI

The ACPI specification maintains reservations for additional third party defined description tables. Each third party submitting a request for a reservation also maintains a specification for these tables, located on individual sites. See the ACPI spec ([\[1\]](https://uefi.org/specifications)) for more information.
