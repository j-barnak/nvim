# Linux Kernel / Priority-Sorted Lists

The `drgn.helpers.linux.plist` module provides helpers for working with descending-priority-sorted doubly-linked lists (`struct`` ``plist_head` and `struct`` ``plist_node`) from [`include/linux/plist.h`](https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/include/linux/plist.h).
