# Linux Kernel / Interrupts

The `drgn.helpers.linux.irq` module provides helpers for working with IRQs and interrupt descriptors.

drgn.helpers.linux.irq.irq_get_nr_irqs(*prog: [drgn.Program](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Program "drgn.Program")*) → [int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")  
Get the number of IRQs on the system.

Parameters:  
**prog** – Program, which [may be omitted to use the default program argument](https://drgn.readthedocs.io/en/latest/api_reference.html#default-program).

&nbsp;

drgn.helpers.linux.irq.irq_to_desc(*prog: [drgn.Program](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Program "drgn.Program")*, *irq: [drgn.IntegerLike](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.IntegerLike "drgn.IntegerLike")*) → [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")  
Get the interrupt descriptor for an IRQ number.

Parameters:  
- **prog** – Program, which [may be omitted to use the default program argument](https://drgn.readthedocs.io/en/latest/api_reference.html#default-program).

- **irq** – IRQ number.

Returns:  
`struct`` ``irq_desc`` ``*` (`NULL` if not found)

drgn.helpers.linux.irq.irq_desc_action_names(*desc: [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")*) → [List](https://docs.python.org/3/library/typing.html#typing.List "(in Python v3.14)")\[[bytes](https://docs.python.org/3/library/stdtypes.html#bytes "(in Python v3.14)")\]  
Get a list of the names of actions set on an interrupt descriptor.

Actions without names (e.g., `chained_action`) are skipped.

    >>> irq_desc_action_names(irq_to_desc(27))
    [b'i2c_designware.0', b'idma64.0']

Parameters:  
**desc** – `struct`` ``irq_desc`` ``*`
