## 4. Interfacing with Solvers

Solvers maintain a set of formulas and supports satisfiability checking, and scope management: Formulas that are added under one scope can be retracted when the scope is popped. In this section we describe the interface to solvers. Section [5](#sec-using-solvers "5. Using Solvers") provides a set of use cases and section [6](#sec-solver-implementations "6. Solver Implementations") describes the underlying solver implementations available in Z3.
