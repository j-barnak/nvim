Expand description

Describes the result of a process after it has terminated.

This `struct` is used to represent the exit status or other termination of a child process. Child processes are created via the [`Command`](https://doc.rust-lang.org/std/process/struct.Command.html "struct std::process::Command") struct and their exit status is exposed through the [`status`](https://doc.rust-lang.org/std/process/struct.Command.html#method.status "method std::process::Command::status") method, or the [`wait`](https://doc.rust-lang.org/std/process/struct.Child.html#method.wait "method std::process::Child::wait") method of a [`Child`](https://doc.rust-lang.org/std/process/struct.Child.html "struct std::process::Child") process.

An `ExitStatus` represents every possible disposition of a process. On Unix this is the **wait status**. It is *not* simply an *exit status* (a value passed to `exit`).

For proper error reporting of failed processes, print the value of `ExitStatus` or `ExitStatusError` using their implementations of [`Display`](https://doc.rust-lang.org/std/fmt/trait.Display.html "trait std::fmt::Display").

## Differences from `ExitCode`

[`ExitCode`](https://doc.rust-lang.org/std/process/struct.ExitCode.html "struct std::process::ExitCode") is intended for terminating the currently running process, via the `Termination` trait, in contrast to `ExitStatus`, which represents the termination of a child process. These APIs are separate due to platform compatibility differences and their expected usage; it is not generally possible to exactly reproduce an `ExitStatus` from a child for the current process after the fact.

Returns the exit code of the process, if any.

In Unix terms the return value is the **exit status**: the value passed to `exit`, if the process finished by calling `exit`. Note that on Unix the exit status is truncated to 8 bits, and that values that didn’t come from a program’s call to `exit` may be invented by the runtime system (often, for example, 255, 254, 127 or 126).

On Unix, this will return `None` if the process was terminated by a signal. [`ExitStatusExt`](https://doc.rust-lang.org/std/os/unix/process/trait.ExitStatusExt.html "trait std::os::unix::process::ExitStatusExt") is an extension trait for extracting any such signal, and other details, from the `ExitStatus`.

##### Examples

``` rust
use std::process::Command;

let status = Command::new("mkdir")
    .arg("projects")
    .status()
    .expect("failed to execute mkdir");

match status.code() {
    Some(code) => println!("Exited with status code: {code}"),
    None => println!("Process terminated by signal")
}
```
