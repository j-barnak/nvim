# miasm.expression.simplifications

## Classes

### class `ExpressionSimplifier(ExprVisitorCallbackBottomToTop)`

Wrapper on expression simplification passes.

Instance handle passes lists.

Available passes lists are:
 - commons: common passes such as constant folding
 - heavy  : rare passes (for instance, in case of obfuscation)

- **`__init__(self)`**
- **`enable_passes(self, passes)`** - Add passes from @passes
- **`apply_simp(self, expression)`** - Apply enabled simplifications on expression
- **`expr_simp_inner(self, expression)`** - Apply enabled simplifications on expression and find a stable state
- **`expr_simp(self, expression)`** - Call simplification recursively
- **`__call__(self, expression)`** - Call simplification recursively
