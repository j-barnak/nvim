🔬This is a nightly-only experimental API. (`core_intrinsics`)

Expand description

Performs an exact division, resulting in undefined behavior where `x % y != 0` or `y == 0` or `x == T::MIN && y == -1`

This intrinsic does not have a stable counterpart.
