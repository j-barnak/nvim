**The Smaller C Linker** (smlrl) comes with the [Smaller C](https://wiki.osdev.org/Smaller_C "Smaller C") compiler.

## About

### Advantages

- Free software (BSD 2-Clause License)
- Supported input formats: [ELF](https://wiki.osdev.org/ELF "ELF") (for both 16-bit and 32-bit code)
- Supported output formats: [COM](https://wiki.osdev.org/COM "COM"), [MZ](https://wiki.osdev.org/MZ "MZ"), [PE](https://wiki.osdev.org/PE "PE"), [ELF](https://wiki.osdev.org/ELF "ELF"), [Mach-O](https://wiki.osdev.org/Mach-O "Mach-O"), [a.out](https://wiki.osdev.org/A.out "A.out"), flat binary
- Can set the code address
- Supports .a (ELF) library files

### Disadvantages

- No 64-bit support
- Produces non-relocatable [ELF](https://wiki.osdev.org/ELF "ELF") and [MACH-O](https://wiki.osdev.org/MACH-O "MACH-O") for a given or default address (however, [PE](https://wiki.osdev.org/PE "PE") and [a.out](https://wiki.osdev.org/A.out "A.out") are relocatable)
- May not work with ELF files produced by anything other than [NASM](https://wiki.osdev.org/NASM "NASM"), [YASM](https://wiki.osdev.org/YASM "YASM"), [FASM](https://wiki.osdev.org/FASM "FASM")
- Strips debugging information
- Can't create [shared libraries](https://wiki.osdev.org/Shared_library "Shared library")
