# angr.engines.hook

class angr.engines.hook.HooksMixin  
Bases: [`SuccessorsEngine`](https://docs.angr.io/en/latest/api/angr.engines.successors.html#angr.engines.successors.SuccessorsEngine "angr.engines.successors.SuccessorsEngine"), [`ProcedureMixin`](https://docs.angr.io/en/latest/api/angr.engines.procedure.html#angr.engines.procedure.ProcedureMixin "angr.engines.procedure.ProcedureMixin")

A SimEngine mixin which adds a SimSuccessors handler which will look into the project’s hooks and run the hook at the current address.

Will respond to the following parameters provided to the step stack:

- procedure: A SimProcedure instance to force-run instead of consulting the current hooks

- ret_to: An address to force-return-to at the end of the procedure
