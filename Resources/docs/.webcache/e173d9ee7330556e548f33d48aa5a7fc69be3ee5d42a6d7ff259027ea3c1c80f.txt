# Trait BuildHasher Copy item path


Expand description

A trait for creating instances of [`Hasher`](https://doc.rust-lang.org/std/hash/trait.Hasher.html "trait std::hash::Hasher").

A `BuildHasher` is typically used (e.g., by [`HashMap`](https://doc.rust-lang.org/std/collections/struct.HashMap.html)) to create [`Hasher`](https://doc.rust-lang.org/std/hash/trait.Hasher.html "trait std::hash::Hasher")s for each key such that they are hashed independently of one another, since [`Hasher`](https://doc.rust-lang.org/std/hash/trait.Hasher.html "trait std::hash::Hasher")s contain state.

For each instance of `BuildHasher`, the [`Hasher`](https://doc.rust-lang.org/std/hash/trait.Hasher.html "trait std::hash::Hasher")s created by [`build_hasher`](https://doc.rust-lang.org/std/hash/trait.BuildHasher.html#tymethod.build_hasher "method std::hash::BuildHasher::build_hasher") should be identical. That is, if the same stream of bytes is fed into each hasher, the same output will also be generated.

## Examples

``` rust
use std::hash::{BuildHasher, Hasher, RandomState};

let s = RandomState::new();
let mut hasher_1 = s.build_hasher();
let mut hasher_2 = s.build_hasher();

hasher_1.write_u32(8128);
hasher_2.write_u32(8128);

assert_eq!(hasher_1.finish(), hasher_2.finish());
```

## Required Methods

1.7.0 · [Source](https://doc.rust-lang.org/src/core/hash/mod.rs.html#656)

Creates a new hasher.

Each call to `build_hasher` on the same instance should produce identical [`Hasher`](https://doc.rust-lang.org/std/hash/trait.Hasher.html "trait std::hash::Hasher")s.

##### Examples

``` rust
use std::hash::{BuildHasher, RandomState};

let s = RandomState::new();
let new_s = s.build_hasher();
```

## Provided Methods

1.71.0 · [Source](https://doc.rust-lang.org/src/core/hash/mod.rs.html#694-697)

Calculates the hash of a single value.

This is intended as a convenience for code which *consumes* hashes, such as the implementation of a hash table or in unit tests that check whether a custom [`Hash`](https://doc.rust-lang.org/std/hash/trait.Hash.html "trait std::hash::Hash") implementation behaves as expected.

This must not be used in any code which *creates* hashes, such as in an implementation of [`Hash`](https://doc.rust-lang.org/std/hash/trait.Hash.html "trait std::hash::Hash"). The way to create a combined hash of multiple values is to call [`Hash::hash`](https://doc.rust-lang.org/std/hash/trait.Hash.html#tymethod.hash "method std::hash::Hash::hash") multiple times using the same [`Hasher`](https://doc.rust-lang.org/std/hash/trait.Hasher.html "trait std::hash::Hasher"), not to call this method repeatedly and combine the results.

##### Example

``` rust
use std::cmp::{max, min};
use std::hash::{BuildHasher, Hash, Hasher};
struct OrderAmbivalentPair<T: Ord>(T, T);
impl<T: Ord + Hash> Hash for OrderAmbivalentPair<T> {
    fn hash<H: Hasher>(&self, hasher: &mut H) {
        min(&self.0, &self.1).hash(hasher);
        max(&self.0, &self.1).hash(hasher);
    }
}

// Then later, in a `#[test]` for the type...
let bh = std::hash::RandomState::new();
assert_eq!(
    bh.hash_one(OrderAmbivalentPair(1, 2)),
    bh.hash_one(OrderAmbivalentPair(2, 1))
);
assert_eq!(
    bh.hash_one(OrderAmbivalentPair(10, 2)),
    bh.hash_one(&OrderAmbivalentPair(2, 10))
);
```
