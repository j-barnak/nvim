## Functions

[from_fn](https://doc.rust-lang.org/std/array/fn.from_fn.html "fn std::array::from_fn")  
Creates an array where each element is produced by calling `f` with that element’s index while walking forward through the array.

[from_mut](https://doc.rust-lang.org/std/array/fn.from_mut.html "fn std::array::from_mut")  
Converts a mutable reference to `T` into a mutable reference to an array of length 1 (without copying).

[from_ref](https://doc.rust-lang.org/std/array/fn.from_ref.html "fn std::array::from_ref")

[repeat](https://doc.rust-lang.org/std/array/fn.repeat.html "fn std::array::repeat")  
Creates an array of type `[T; N]` by repeatedly cloning a value.

[try_from_fn](https://doc.rust-lang.org/std/array/fn.try_from_fn.html "fn std::array::try_from_fn")Experimental  
Creates an array `[T; N]` where each fallible array element `T` is returned by the `cb` call. Unlike [`from_fn`](https://doc.rust-lang.org/std/array/fn.from_fn.html "fn std::array::from_fn"), where the element creation can’t fail, this version will return an error if any element creation was unsuccessful.
