## 34 Cryptographic Functions

The GNU C Library includes only one type of special-purpose cryptographic functions; these allow use of a source of cryptographically strong pseudorandom numbers, if such a source is provided by the operating system. Programs that need general-purpose cryptography should use a dedicated cryptography library, such as [libgcrypt](https://www.gnu.org/software/libgcrypt/).
