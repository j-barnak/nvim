# [Utilities](https://dioxuslabs.com/learn/0.7/guides/utilities/#utilities)

The utilities section provides a collection of useful libraries that can be used alongside dioxus.

- [Logging](https://dioxuslabs.com/learn/0.7/guides/utilities/logging) Covers how to use dioxus-logger to configure logging for your project.
- [Internationalization](https://dioxuslabs.com/learn/0.7/guides/utilities/internationalization) Explains how to use dioxus-i8n to support multiple languages in your application.
- [Tailwind](https://dioxuslabs.com/learn/0.7/guides/utilities/tailwind) Provides setup instructions for using dioxus with Tailwind CSS.
