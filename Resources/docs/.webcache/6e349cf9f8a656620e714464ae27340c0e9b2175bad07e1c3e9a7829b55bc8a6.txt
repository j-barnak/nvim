# 2.2. Preliminary Exercises

1.  System administrators often write scripts to automate common tasks. Give several instances where such scripts would be useful.

2.  Write a script that upon invocation shows the [time and date](https://tldp.org/LDP/abs/html/timedate.html#DATEREF), [lists all logged-in users](https://tldp.org/LDP/abs/html/system.html#WHOREF), and gives the system [uptime](https://tldp.org/LDP/abs/html/system.html#UPTIMEREF). The script then [saves this information](https://tldp.org/LDP/abs/html/io-redirection.html#IOREDIRREF) to a logfile.
