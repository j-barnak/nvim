The **WAET** (Windows ACPI Emulated Devices Table) is a table in [ACPI](https://wiki.osdev.org/ACPI "ACPI") running in guest partitions in a virtual machine environment.

  

## Table Format

| ACPI Standard Header | Field                 | Byte length | Byte offset | Description                                                          |
|----------------------|-----------------------|-------------|-------------|----------------------------------------------------------------------|
| Yes                  | Signature             | 4           | 0x0         | Signature for the WAET                                               |
| Yes                  | Length                | 4           | 0x4         | Length, in bytes, of the WAET                                        |
| Yes                  | Revision              | 1           | 0x8         | 1                                                                    |
| Yes                  | Checksum              | 1           | 0x9         | Entire table, which must sum to zero                                 |
| Yes                  | OEMID                 | 6           | 0x10        | Original equipment manufacturer (OEM) identifier (ID)                |
| Yes                  | OEM Table ID          | 8           | 0x16        | Manufacturer model ID                                                |
| Yes                  | OEM Revision          | 4           | 0x24        | OEM revision for supplied OEM table ID                               |
| Yes                  | Creator ID            | 4           | 0x28        | Vendor ID of the ASL compiler utility that created the table         |
| Yes                  | Creator Revision      | 4           | 0x32        | Revision of the ASL compiler utility that created the table          |
| No                   | Emulated Device Flags | 4           | 0x36        | Container of a bitmask of Windows behavior that this system requires |

### Emulated Device Flags

| Bit offset | Description                                                                                                                                                                                                                                                     |
|------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 0          | RTC good Indicates whether the [RTC](https://wiki.osdev.org/RTC) has been enhanced not to require acknowledgment after it asserts an interrupt. With this bit set, an interrupt handler can bypass reading the RTC register C to unlatch the pending interrupt. |
| 1          | ACPI PM timer good Indicates whether the ACPI PM timer has been enhanced not to require multiple reads. With this bit set, only one read of the ACPI PM timer is necessary to obtain a reliable value.                                                          |
| 31:2       | Reserved; must return 0 when read.                                                                                                                                                                                                                              |
