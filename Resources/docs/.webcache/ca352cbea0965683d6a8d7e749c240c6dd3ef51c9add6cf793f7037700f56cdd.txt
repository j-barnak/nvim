# Trait VaArgSafe Copy item path

[Source](https://doc.rust-lang.org/src/core/ffi/va_list.rs.html#316)

``` rust
pub unsafe trait VaArgSafe: Copy { }
```

ⓘ *This trait cannot be implemented outside `core`.*

🔬This is a nightly-only experimental API. (`c_variadic` [\#44930](https://github.com/rust-lang/rust/issues/44930))

Expand description

Types that are valid to read using [`VaList::next_arg`](https://doc.rust-lang.org/std/ffi/struct.VaList.html#method.next_arg "method std::ffi::VaList::next_arg").

This trait is implemented for primitive types that have a variable argument application-binary interface (ABI) on the current platform. It is always implemented for:

- [`c_int`](https://doc.rust-lang.org/std/ffi/type.c_int.html "type std::ffi::c_int"), [`c_long`](https://doc.rust-lang.org/std/ffi/type.c_long.html "type std::ffi::c_long") and [`c_longlong`](https://doc.rust-lang.org/std/ffi/type.c_longlong.html "type std::ffi::c_longlong")
- [`c_uint`](https://doc.rust-lang.org/std/ffi/type.c_uint.html "type std::ffi::c_uint"), [`c_ulong`](https://doc.rust-lang.org/std/ffi/type.c_ulong.html "type std::ffi::c_ulong") and [`c_ulonglong`](https://doc.rust-lang.org/std/ffi/type.c_ulonglong.html "type std::ffi::c_ulonglong")
- [`c_double`](https://doc.rust-lang.org/std/ffi/type.c_double.html "type std::ffi::c_double")
- `*const T` and `*mut T`

Implementations for e.g. `i32` or `usize` shouldn’t be relied upon directly, because they may not be available on all platforms.

## Safety

When C passes variable arguments, signed integers smaller than [`c_int`](https://doc.rust-lang.org/std/ffi/type.c_int.html "type std::ffi::c_int") are promoted to [`c_int`](https://doc.rust-lang.org/std/ffi/type.c_int.html "type std::ffi::c_int"), unsigned integers smaller than [`c_uint`](https://doc.rust-lang.org/std/ffi/type.c_uint.html "type std::ffi::c_uint") are promoted to [`c_uint`](https://doc.rust-lang.org/std/ffi/type.c_uint.html "type std::ffi::c_uint"), and [`c_float`](https://doc.rust-lang.org/std/ffi/type.c_float.html "type std::ffi::c_float") is promoted to [`c_double`](https://doc.rust-lang.org/std/ffi/type.c_double.html "type std::ffi::c_double"). Implementing this trait for types that are subject to this promotion rule is invalid.

## Dyn Compatibility

This trait is **not** [dyn compatible](https://doc.rust-lang.org/1.98.1/reference/items/traits.html#dyn-compatibility).

*In older versions of Rust, dyn compatibility was called "object safety".*
