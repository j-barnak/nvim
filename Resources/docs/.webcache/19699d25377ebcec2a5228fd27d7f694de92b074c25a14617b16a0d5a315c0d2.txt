# Booleans & conditionals

### [Booleans](#booleans)

True is spelled #true or #t. False is spelled #false or #f. When used in a conditional expression, every value other than #false counts as true. There are no “falsish” values.

    (if #false  'true 'false) ; 'false
    (if "#f"    'true 'false) ; 'true
    (if "false" 'true 'false) ; 'true
    (if 0       'true 'false) ; 'true
    (if null    'true 'false) ; 'true
    (if ""      'true 'false) ; 'true
    (if (+ 0 0) 'true 'false) ; 'true

That was easy.

If you need to flip a Boolean from true to false or vice versa, use [not](http://docs.racket-lang.org/reference/booleans.html#(def._((quote._~23~25kernel)._not))).

    (if (not #false) 'true 'false) ; 'true
    (if (not #true)  'true 'false) ; 'false
    (if (not 0)      'true 'false) ; 'false
    (if (not "")     'true 'false) ; 'false

[and](http://docs.racket-lang.org/reference/if.html#(form._((lib._racket/private/letstx-scheme..rkt)._and))) and [or](http://docs.racket-lang.org/reference/if.html#(form._((lib._racket/private/letstx-scheme..rkt)._or))) work in the usual short-circuiting way. That is, they stop when they reach a false or true value, respectively. So nothing bad will happen when you run these, because the second condition on each line is never reached:

    (and #false 'start-zombie-apocalypse)
    (or #true 'destroy-solar-system)

[andmap](http://docs.racket-lang.org/reference/pairs.html#(def._((lib._racket/private/map..rkt)._andmap))) and [ormap](http://docs.racket-lang.org/reference/pairs.html#(def._((lib._racket/private/map..rkt)._ormap))) will apply a predicate to every member of a list, so these:

    (and (odd? 1) (odd? 2) (odd? 3))
    (or (even? 1) (even? 2) (even? 3))

Can be written more compactly:

    (andmap odd? '(1 2 3))
    (ormap even? '(1 2 3))

See [loops](https://beautifulracket.com/explainer/loops.html) for other convenient forms of and and or.

### [Conditionals](#conditionals)

[if](http://docs.racket-lang.org/reference/if.html#(form._((quote._~23~25kernel)._if))) has one conditional expression followed by two result expressions—the first is evaluated if the condition is true, otherwise the second is evaluated. If you need multiple expressions in a branch, you can put them inside an empty [let](http://docs.racket-lang.org/reference/let.html#(form._((lib._racket/private/letstx-scheme..rkt)._let))).

    (if (= 42 (* 6 7))
      'true-result
      'false-result) ; correct form

    (if (= 42 (* 6 7))
      "foo"
      42
      'true-result
      'false-result) ; wrong: too many expressions after `if`

    (if (= 42 (* 6 7))
      (let ()
        "foo"
        42
        'true-result)
      'false-result) ; correct form

If you only need one branch, use [when](http://docs.racket-lang.org/reference/when_unless.html#(form._((lib._racket/private/letstx-scheme..rkt)._when))). Like if, when starts with a conditional expression. Unlike if, the body of when can contain any number of expressions. If the condition is true, the last body expression is returned as the result. If the condition is false, the whole when expression returns <#void>, a special constant used to signal the absence of a result.

> Or its logical inverse, unless .

    (when (= 42 (* 6 7))
        "foo"
        42
        'true-result) ; correct form

[cond](http://docs.racket-lang.org/reference/if.html#(form._((lib._racket/private/letstx-scheme..rkt)._cond))) supports any number of condition branches, and an optional else branch. cond evaluates the condition on the left side of each branch, and stops at the first one that evaluates as true (precisely, the first one that’s not #false). Then it evaluates the right side of the branch. Like when, the right side can have any number of expressions, and only the last expression is returned as the result. If no branches match, you get <#void>.

    (cond
     [(= 42 (* 6 7))
        "foo"
        42
        'first-true-result]
     [(= 42 (+ 21 21)) 'second-true-result]
     [else 'else-result])

    'first-true-result

cond offers a couple of tricks that if and when do not.

First, if you omit the right side of a cond branch, the value of the conditional will be used as the return value:

    (cond
     [(or -42 #false)]
     [else 'else-result])

    -42

Second, you can capture the conditional value and use it on the right side of the branch with the [=>](http://docs.racket-lang.org/reference/if.html#(form._((lib._racket/private/letstx-scheme..rkt)._~3d~3e))) operator. The right side of the branch must be a function that accepts one argument. The return value of the cond is the function applied to the conditional value. This is useful when the conditional relies on an operation that’s expensive, or can only be done once.

    (cond
     [(or -42 #false) => abs] ; right side becomes (abs -42)
     [else 'else-result])

    42

### [Case](#case)

[case](http://docs.racket-lang.org/reference/case.html#(form._((lib._racket/private/more-scheme..rkt)._case))) creates a conditional that compares a value against lists of literal values. At the top is the value to be compared. Like [cond](http://docs.racket-lang.org/reference/if.html#(form._((lib._racket/private/letstx-scheme..rkt)._cond))), a series of branches follow. If the value is [equal?](http://docs.racket-lang.org/reference/Equality.html#(def._((quote._~23~25kernel)._equal~3f))) to one of the items in the list on the left, then the right side of the branch is evaluated and returned as the result. An optional else branch catches anything else:

    (define (c x)
      (case x
        [(foo bar)     'got-symbol]
        [("zim" "zam") 'got-string]
        [(42 84)       'got-number]
        [else          'got-nothing]))

    (c 'foo)  ; 'got-symbol
    (c "zim") ; 'got-string
    (c 42)    ; 'got-number
    (c #true) ; 'got-nothing

For reasons unclear, the left-hand lists don’t use a ' prefix; they simply behave as if there were one already there.

### [Match](#match)

[match](http://docs.racket-lang.org/reference/match.html#(form._((lib._racket/match..rkt)._match))) is a more general version of case. The basic form is the same: the value to be matched goes at the top, and a series of branches follow. If the value matches the pattern on the left-hand side of a branch, the right-hand side is evaluated and returned as the result.

Unlike case, [match](http://docs.racket-lang.org/reference/match.html#(form._((lib._racket/match..rkt)._match))) supports a wider pattern vocabulary that can match literal values, but also [predicates](https://beautifulracket.com/appendix/glossary.html#predicate), [lists](https://beautifulracket.com/appendix/glossary.html#list), [pairs](https://beautifulracket.com/appendix/glossary.html#pair), [structure types](https://beautifulracket.com/appendix/glossary.html#structure-type), and other values. Moreover, match can also assign elements of the match to internal variables for further processing:

    (struct thing (x y))

    (define (m in)
      (match in
        ["foo"       'got-foo]    ; literal match
        [(? number?) 'got-number] ; predicate match
        [(list a b c) (list b)]   ; list match + assignment
        [(thing i j)  (+ i j)]    ; structure match + assignment
        [_           'no-match])) ; catches anything else

    (m "foo")         ; 'got-foo
    (m 42)            ; 'got-number
    (m (list 1 2 3))  ; '(2)
    (m (thing 25 52)) ; 77
    (m "bar")         ; 'no-match
