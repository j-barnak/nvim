``` rust
pub enum SendTimeoutError<T> {
    Timeout(T),
    Disconnected(T),
}
```

🔬This is a nightly-only experimental API. (`mpmc_channel` [\#126840](https://github.com/rust-lang/rust/issues/126840))

Expand description

An error returned from the [`send_timeout`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html#method.send_timeout "method std::sync::mpmc::Sender::send_timeout") method.

The error contains the message being sent so it can be recovered.

## Variants

🔬This is a nightly-only experimental API. (`mpmc_channel` [\#126840](https://github.com/rust-lang/rust/issues/126840))

The message could not be sent because the channel is full and the operation timed out.

If this is a zero-capacity channel, then the error indicates that there was no receiver available to receive the message and the operation timed out.

🔬This is a nightly-only experimental API. (`mpmc_channel` [\#126840](https://github.com/rust-lang/rust/issues/126840))

The message could not be sent because the channel is disconnected.
