                          FIRST sets
   • We use next k characters in input stream to guide
     the selection of the proper production.
   • Given: A := α | β we want next input character to
     decide between α and β.
   • FIRST(α) =     set of terminals that can begin
                    any string derived from α.
   • IOW: a ∈ FIRST(α) iff α ⇒* aγ for some γ

   • FIRST(α) ∩ FIRST(β) = ∅ → no backtracking needed


15-411/611                      © 2019-20 Goldstein      4
                 Computing FIRST(α)
      • Given X := A B C, FIRST(X) = FIRST(A B C)
      • Can we ignore B or C?
      • Consider:
           A := a
             |
           B := b
             |A
           C := c

                     Computing FIRST(α)
      • Given X := A B C, FIRST(X) = FIRST(A B C)
      • Can we ignore B or C?
      • Consider:
           A := a
             |
           B := b
             |A
           C := c
      • FIRST(X) must also include FIRST(C)
      • IOW:
             – Must keep track of NTs that are nullable
             – For nullable NTs, determine FOLLOWS(NT)

                             nullable(A)
             • nullable(A) is true if A can derive the empty
               string
             • For example:
                   B := X Y b
                   X := x
                      | YY
                   Y :=
             In this case, nullable(X) = nullable(Y) = true
                           nullable(B) = false

15-411/611                        © 2019-20 Goldstein          7
                  FOLLOW(A)
   • FOLLOW(A) is the set of terminals that can
     immediately follow A in a sentential form.
   • I.e.,
     a ∈ FOLLOW(A) iff S ⇒* αAaβ for some α and β

             – accept: success

                              LR(1) Items
      • An LR(1) item is an LR(0) item combined with a
        single terminal (the lookahead)
      • [X → α  β, a] Means
             – α is at top of stack
             – Input string is derivable from βa
      • In other words, when we reduce X → αβ, a had
        better be the look ahead symbol.
      • Or, Only put ‘reduce by X → αβ’ in action[s,a]
      • Can construct states as before, but have to
        modify closure

15-411/611                          © 2019-20 Goldstein   109
                   What LR(1) Items Mean
             • [X →  α β γ, a]
               input is consistent with X → α β γ
             • [X → α  β γ, a]
               input is consistent with X → α β γ and we
               have already recognized α
             • [X → α β  γ, a]
               input is consistent with X → α β γ and we
               have already recognized α β
             • [X → α β γ , a]
               input is consistent with X → α β γ and if
               lookahead symbol is a, then we can reduce
               to X

                           LR(1) Closure
             closure(state)
                repeat
                   foreach item A → a•Xb, t in state
                      foreach production X → w
                        and each terminal t’ in FIRST(bt)
                         state.add(X → •w, t’)
                until state does not change
                return state
