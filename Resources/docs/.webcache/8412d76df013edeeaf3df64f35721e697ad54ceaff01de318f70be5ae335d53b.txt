Expand description

An async-aware version of the [`FnMut`](https://doc.rust-lang.org/std/ops/trait.FnMut.html "trait std::ops::FnMut") trait.

All `async fn` and functions returning futures implement this trait.

## Required Associated Types

[Source](https://doc.rust-lang.org/src/core/ops/async_function.rs.html#28)

🔬This is a nightly-only experimental API. (`async_fn_traits`)

Future returned by [`AsyncFnMut::async_call_mut`](https://doc.rust-lang.org/std/ops/trait.AsyncFnMut.html#tymethod.async_call_mut "method std::ops::AsyncFnMut::async_call_mut") and [`AsyncFn::async_call`](https://doc.rust-lang.org/std/ops/trait.AsyncFn.html#tymethod.async_call "method std::ops::AsyncFn::async_call").

## Required Methods

[Source](https://doc.rust-lang.org/src/core/ops/async_function.rs.html#34)

🔬This is a nightly-only experimental API. (`async_fn_traits`)

Call the [`AsyncFnMut`](https://doc.rust-lang.org/std/ops/trait.AsyncFnMut.html "trait std::ops::AsyncFnMut"), returning a future which may borrow from the called closure.

## Dyn Compatibility

This trait is **not** [dyn compatible](https://doc.rust-lang.org/1.98.1/reference/items/traits.html#dyn-compatibility).

*In older versions of Rust, dyn compatibility was called "object safety".*
