🔬This is a nightly-only experimental API. (`set_permissions_nofollow` [\#141607](https://github.com/rust-lang/rust/issues/141607))

Expand description

Set the permissions of a file, unless it is a symlink.

Note that the non-final path elements are allowed to be symlinks.

## Platform-specific behavior

Currently unimplemented on Windows.

On Unix platforms, this results in a [`FilesystemLoop`](https://doc.rust-lang.org/std/io/enum.ErrorKind.html#variant.FilesystemLoop "variant std::io::ErrorKind::FilesystemLoop") error if the last element is a symlink.

This behavior may change in the future.
