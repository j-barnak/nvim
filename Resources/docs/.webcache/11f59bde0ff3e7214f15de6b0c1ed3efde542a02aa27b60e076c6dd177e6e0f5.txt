# angr.utils.cpp

angr.utils.cpp.is_cpp_funcname_ctor(*name*)

Parameters:  
**name** ([`str`](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – The demangled C++ function name.

Return type:  
[`bool`](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")

Returns:  
True if the function name is a constructor, False otherwise.
