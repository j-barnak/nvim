# Isolation & Security

The mechanisms that separate, confine, and protect workloads — from containers to access control to running whole guests.

- [Cgroups (cgroups/)](https://kernel-internals.org/cgroups/) — accounting for and limiting resources per group of processes; the basis of containers
- [Security (security/)](https://kernel-internals.org/security/) — LSMs, capabilities, seccomp, and the kernel's access-control machinery
- [Virtualization (virtualization/)](https://kernel-internals.org/virtualization/) — KVM and how the kernel runs guest machines
- [Crypto (crypto/)](https://kernel-internals.org/crypto/) — the kernel's cryptographic API and hardware acceleration
- [Livepatch (livepatch/)](https://kernel-internals.org/livepatch/) — patching a running kernel without rebooting
