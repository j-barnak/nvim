Intel SGX Overview
Security goal:
• Isolation between the enclave and the rest of the
system without trusting OS-managed page tables
Concretely:
• Enclave code/data map to the PRM
• Different enclaves access their own memory regions
• Other code cannot access the PRM

Alternative Solutions
• Naïve idea:
• Let the trusted component handle page management
• Problem: Large TCB

• Keystone’s approach:
• Leverage RISC-V’s PMP registers to enforce coarsegrained isolation
• Let the application to manage their page mappings

• AMD SEV:
• Rely on encryption. But symmetric key vulnerability
• Recent version introduces reverse page table
