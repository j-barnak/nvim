Iterator over the properties of this class.

property protocols → Iterator\[[lief.objc.Protocol](#lief.objc.Protocol "lief.objc.Protocol") \| None\]  
Iterator over the different protocols implemented by this class.

property super_class → [lief.objc.Class](#lief.objc.Class "lief.objc.Class") \| None  
Parent class in case of inheritance.

This is set **only** when the superclass is defined in the same binary. For root classes (e.g. `NSObject`) or superclasses imported from another image, it is `None` even though [`super_name`](#lief.objc.Class.super_name "lief.objc.Class.super_name") / [`demangled_super_name`](#lief.objc.Class.demangled_super_name "lief.objc.Class.demangled_super_name") may still be resolved.

property super_name → str  
(raw) name of the superclass (empty for root classes or when it could not be resolved).
