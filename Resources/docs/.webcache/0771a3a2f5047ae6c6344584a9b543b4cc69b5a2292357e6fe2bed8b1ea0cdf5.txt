Expand description

Helper struct for safely printing paths with [`format!`](https://doc.rust-lang.org/std/macro.format.html "macro std::format") and `{}`.

A [`Path`](https://doc.rust-lang.org/std/path/struct.Path.html "struct std::path::Path") might contain non-Unicode data. This `struct` implements the [`Display`](https://doc.rust-lang.org/std/fmt/trait.Display.html "trait std::fmt::Display") trait in a way that mitigates that. It is created by the [`display`](https://doc.rust-lang.org/std/path/struct.Path.html#method.display "method std::path::Path::display") method on [`Path`](https://doc.rust-lang.org/std/path/struct.Path.html "struct std::path::Path"). This may perform lossy conversion, depending on the platform. If you would like an implementation which escapes the path please use [`Debug`](https://doc.rust-lang.org/std/fmt/derive.Debug.html "derive std::fmt::Debug") instead.

## Examples

``` rust
use std::path::Path;

let path = Path::new("/tmp/foo.rs");

println!("{}", path.display());
```
