# [`pwnlib.elf.config`](#module-pwnlib.elf.config "pwnlib.elf.config") — Kernel Config Parsing

Kernel-specific ELF functionality

pwnlib.elf.config.parse_kconfig(*data*)[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/elf/config.py#L198-L261)  
Parses configuration data from a kernel .config.

Parameters:  
**data** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Configuration contents.

Returns:  
A [`dict`](https://docs.python.org/3/library/stdtypes.html#dict "(in Python v3.14)") mapping configuration options. “Not set” is converted into `None`, `y` and `n` are converted into [`bool`](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)"). Numbers are converted into [`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)"). All other values are as-is. Each key has `CONFIG_` stripped from the beginning.

Examples

    >>> parse_kconfig('FOO=3')
    {'FOO': 3}
    >>> parse_kconfig('FOO=y')
    {'FOO': True}
    >>> parse_kconfig('FOO=n')
    {'FOO': False}
    >>> parse_kconfig('FOO=bar')
    {'FOO': 'bar'}
    >>> parse_kconfig('# FOO is not set')
    {'FOO': None}
