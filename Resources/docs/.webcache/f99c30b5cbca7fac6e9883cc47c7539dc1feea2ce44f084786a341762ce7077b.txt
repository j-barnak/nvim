# Linux Kernel / Swap Space

The `drgn.helpers.linux.swap` module provides helpers for inspecting swap partitions and swap files.

Iterate over all swap devices.

Parameters:  
**prog** – Program, which [may be omitted to use the default program argument](https://drgn.readthedocs.io/en/latest/api_reference.html#default-program).

drgn.helpers.linux.swap.swap_total_usage(*prog: [drgn.Program](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Program "drgn.Program")*) → [drgn.helpers.linux.mm.PageUsage](#drgn.helpers.linux.mm.PageUsage "drgn.helpers.linux.mm.PageUsage")  
Get the total number of swap pages and the number of free swap pages on all swap devices.

    >>> usage = swap_total_usage()
    >>> usage
    PageUsage(pages=2097151, free_pages=1704798)
    >>> usage.used_pages
    392353
