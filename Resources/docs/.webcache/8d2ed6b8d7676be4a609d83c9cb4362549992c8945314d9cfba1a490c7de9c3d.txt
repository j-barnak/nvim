Expand description

The sending half of a oneshot channel.

## Examples

``` rust
#![feature(oneshot_channel)]
use std::sync::oneshot;
use std::thread;

let (sender, receiver) = oneshot::channel();

thread::spawn(move || {
    sender.send("Hello from thread!").unwrap();
});

assert_eq!(receiver.recv().unwrap(), "Hello from thread!");
```

`Sender` cannot be sent between threads if it is sending non-`Send` types.

[ⓘ](# "This example deliberately fails to compile")

``` rust
#![feature(oneshot_channel)]
use std::sync::oneshot;
use std::thread;
use std::ptr;

let (sender, receiver) = oneshot::channel();

struct NotSend(*mut ());
thread::spawn(move || {
    sender.send(NotSend(ptr::null_mut()));
});

let reply = receiver.try_recv().unwrap();
```

## Implementations

🔬This is a nightly-only experimental API. (`oneshot_channel` [\#143674](https://github.com/rust-lang/rust/issues/143674))

Attempts to send a value through this channel. This can only fail if the corresponding [`Receiver<T>`](https://doc.rust-lang.org/std/sync/oneshot/struct.Receiver.html "struct std::sync::oneshot::Receiver") has been dropped.

This method is non-blocking (wait-free).

##### Examples

``` rust
#![feature(oneshot_channel)]
use std::sync::oneshot;
use std::thread;

let (tx, rx) = oneshot::channel();

thread::spawn(move || {
    // Perform some computation.
    let result = 2 + 2;
    tx.send(result).unwrap();
});

assert_eq!(rx.recv().unwrap(), 4);
```
