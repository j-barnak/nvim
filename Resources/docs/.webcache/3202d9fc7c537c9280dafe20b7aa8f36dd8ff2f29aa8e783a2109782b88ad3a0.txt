``` rust
pub fn format(args: Arguments<'_>) -> String
```

Expand description

Takes an [`Arguments`](https://doc.rust-lang.org/std/fmt/struct.Arguments.html "struct std::fmt::Arguments") struct and returns the resulting formatted string.

The [`Arguments`](https://doc.rust-lang.org/std/fmt/struct.Arguments.html "struct std::fmt::Arguments") instance can be created with the [`format_args!`](https://doc.rust-lang.org/std/macro.format_args.html "macro std::format_args") macro.

## Examples

Basic usage:

``` rust
use std::fmt;

let s = fmt::format(format_args!("Hello, {}!", "world"));
assert_eq!(s, "Hello, world!");
```

Please note that using [`format!`](https://doc.rust-lang.org/std/macro.format.html "macro std::format") might be preferable. Example:

``` rust
let s = format!("Hello, {}!", "world");
assert_eq!(s, "Hello, world!");
```
