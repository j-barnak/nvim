Expand description

Helper struct for safely printing an [`OsStr`](https://doc.rust-lang.org/std/ffi/struct.OsStr.html "struct std::ffi::OsStr") with [`format!`](https://doc.rust-lang.org/std/macro.format.html "macro std::format") and `{}`.

An [`OsStr`](https://doc.rust-lang.org/std/ffi/struct.OsStr.html "struct std::ffi::OsStr") might contain non-Unicode data. This `struct` implements the [`Display`](https://doc.rust-lang.org/std/fmt/trait.Display.html "trait std::fmt::Display") trait in a way that mitigates that. It is created by the [`display`](https://doc.rust-lang.org/std/ffi/struct.OsStr.html#method.display "method std::ffi::OsStr::display") method on [`OsStr`](https://doc.rust-lang.org/std/ffi/struct.OsStr.html "struct std::ffi::OsStr"). This may perform lossy conversion, depending on the platform. If you would like an implementation which escapes the [`OsStr`](https://doc.rust-lang.org/std/ffi/struct.OsStr.html "struct std::ffi::OsStr") please use [`Debug`](https://doc.rust-lang.org/std/fmt/derive.Debug.html "derive std::fmt::Debug") instead.

## Examples

``` rust
use std::ffi::OsStr;

let s = OsStr::new("Hello, world!");
println!("{}", s.display());
```
