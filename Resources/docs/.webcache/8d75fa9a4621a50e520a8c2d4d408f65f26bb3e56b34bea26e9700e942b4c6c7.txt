Expand description

An IPv6 socket address.

IPv6 socket addresses consist of an [`IPv6` address](https://doc.rust-lang.org/std/net/struct.Ipv6Addr.html "struct std::net::Ipv6Addr"), a 16-bit port number, as well as fields containing the traffic class, the flow label, and a scope identifier (see [IETF RFC 2553, Section 3.3](https://tools.ietf.org/html/rfc2553#section-3.3) for more details).

See [`SocketAddr`](https://doc.rust-lang.org/std/net/enum.SocketAddr.html "enum std::net::SocketAddr") for a type encompassing both IPv4 and IPv6 socket addresses.

## Portability

`SocketAddrV6` is intended to be a portable representation of socket addresses and is likely not the same as the internal socket address type used by the target operating system’s API. Like all `repr(Rust)` structs, however, its exact layout remains undefined and should not be relied upon between builds.

## Textual representation

`SocketAddrV6` provides a [`FromStr`](https://doc.rust-lang.org/std/str/trait.FromStr.html "trait std::str::FromStr") implementation, based on the bracketed format recommended by [IETF RFC 5952](https://tools.ietf.org/html/rfc5952#section-6), with scope identifiers based on those specified in [IETF RFC 4007](https://tools.ietf.org/html/rfc4007#section-11).

It accepts addresses consisting of the following elements, in order:

- A left square bracket (`[`)
- The [textual representation](https://doc.rust-lang.org/std/net/struct.Ipv6Addr.html#textual-representation "struct std::net::Ipv6Addr") of an IPv6 address
- *Optionally*, a percent sign (`%`) followed by the scope identifier encoded as a decimal integer
- A right square bracket (`]`)
- A colon (`:`)
- The port, encoded as a decimal integer.

For example, the string `[2001:db8::413]:443` represents a `SocketAddrV6` with the address `2001:db8::413` and port `443`. The string `[2001:db8::413%612]:443` represents the same address and port, with a scope identifier of `612`.

Other formats are not accepted.

## Examples

``` rust
use std::net::{Ipv6Addr, SocketAddrV6};

let socket = SocketAddrV6::new(Ipv6Addr::new(0x2001, 0xdb8, 0, 0, 0, 0, 0, 1), 8080, 0, 0);

assert_eq!("[2001:db8::1]:8080".parse(), Ok(socket));
assert_eq!(socket.ip(), &Ipv6Addr::new(0x2001, 0xdb8, 0, 0, 0, 0, 0, 1));
assert_eq!(socket.port(), 8080);

let mut with_scope = socket.clone();
with_scope.set_scope_id(3);
assert_eq!("[2001:db8::1%3]:8080".parse(), Ok(with_scope));
```
