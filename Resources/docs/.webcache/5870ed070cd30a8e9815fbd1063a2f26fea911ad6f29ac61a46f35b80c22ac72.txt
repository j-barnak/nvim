# Struct BuildHasherDefault Copy item path

1.7.0 · [Source](https://doc.rust-lang.org/src/core/hash/mod.rs.html#751)

``` rust
pub struct BuildHasherDefault<H>(/* private fields */);
```

Expand description

Used to create a default [`BuildHasher`](https://doc.rust-lang.org/std/hash/trait.BuildHasher.html "trait std::hash::BuildHasher") instance for types that implement [`Hasher`](https://doc.rust-lang.org/std/hash/trait.Hasher.html "trait std::hash::Hasher") and [`Default`](https://doc.rust-lang.org/std/default/trait.Default.html "trait std::default::Default").

`BuildHasherDefault<H>` can be used when a type `H` implements [`Hasher`](https://doc.rust-lang.org/std/hash/trait.Hasher.html "trait std::hash::Hasher") and [`Default`](https://doc.rust-lang.org/std/default/trait.Default.html "trait std::default::Default"), and you need a corresponding [`BuildHasher`](https://doc.rust-lang.org/std/hash/trait.BuildHasher.html "trait std::hash::BuildHasher") instance, but none is defined.

Any `BuildHasherDefault` is [zero-sized](https://doc.rust-lang.org/nomicon/exotic-sizes.html#zero-sized-types-zsts). It can be created with [`default`](https://doc.rust-lang.org/std/hash/struct.BuildHasherDefault.html#method.default "associated function std::hash::BuildHasherDefault::default"). When using `BuildHasherDefault` with [`HashMap`](https://doc.rust-lang.org/std/collections/struct.HashMap.html) or [`HashSet`](https://doc.rust-lang.org/std/collections/struct.HashSet.html), this doesn’t need to be done, since they implement appropriate [`Default`](https://doc.rust-lang.org/std/default/trait.Default.html "trait std::default::Default") instances themselves.

## Examples

Using `BuildHasherDefault` to specify a custom [`BuildHasher`](https://doc.rust-lang.org/std/hash/trait.BuildHasher.html "trait std::hash::BuildHasher") for [`HashMap`](https://doc.rust-lang.org/std/collections/struct.HashMap.html):

``` rust
use std::collections::HashMap;
use std::hash::{BuildHasherDefault, Hasher};

#[derive(Default)]
struct MyHasher;

impl Hasher for MyHasher {
    fn write(&mut self, bytes: &[u8]) {
        // Your hashing algorithm goes here!
       unimplemented!()
    }

    fn finish(&self) -> u64 {
        // Your hashing algorithm goes here!
        unimplemented!()
    }
}

type MyBuildHasher = BuildHasherDefault<MyHasher>;

let hash_map = HashMap::<u32, u32, MyBuildHasher>::default();
```
