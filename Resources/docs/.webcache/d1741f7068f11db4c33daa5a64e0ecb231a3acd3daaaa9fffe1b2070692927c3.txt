Expand description

Returns the number of bits set in an integer type `T`

Note that, unlike most intrinsics, this is safe to call; it does not require an `unsafe` block. Therefore, implementations must not require the user to uphold any safety invariants.

The stabilized versions of this intrinsic are available on the integer primitives via the `count_ones` method. For example, [`u32::count_ones`](https://doc.rust-lang.org/std/primitive.u32.html#method.count_ones "method u32::count_ones")
