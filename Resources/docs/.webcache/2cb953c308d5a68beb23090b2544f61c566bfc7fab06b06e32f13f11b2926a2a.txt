Expand description

`RandomState` is the default state for [`HashMap`](https://doc.rust-lang.org/std/collections/struct.HashMap.html "struct std::collections::HashMap") types.

A particular instance `RandomState` will create the same instances of [`Hasher`](https://doc.rust-lang.org/std/hash/trait.Hasher.html "trait std::hash::Hasher"), but the hashers created by two different `RandomState` instances are unlikely to produce the same result for the same values.

## Examples

``` rust
use std::collections::HashMap;
use std::hash::RandomState;

let s = RandomState::new();
let mut map = HashMap::with_hasher(s);
map.insert(1, 2);
```
