*This page is about the ACPI SSDT (Secondary System Descriptor Table)* It contains additional AML to interact with devices.

## SSDT

### Introduction

|                                                                                          |     |
|------------------------------------------------------------------------------------------|-----|
| This page or section is a stub . You can help the wiki by accurately contributing to it. |     |

The SSDT is an ACPI decriptor table. It is encoded in AML in exactly the same way as the [DSDT](https://wiki.osdev.org/DSDT "DSDT"). It acts as a supplement to the DSDT.
