# Type Alias c_int Copy item path

1.64.0 · [Source](https://doc.rust-lang.org/src/core/ffi/primitives.rs.html#28)

``` rust
pub type c_int = i32;
```

Expand description

Equivalent to C’s `signed int` (`int`) type.

This type will almost always be [`i32`](https://doc.rust-lang.org/std/primitive.i32.html "primitive i32"), but may differ on some esoteric systems. The C standard technically only requires that this type be a signed integer that is at least the size of a [`short`](https://doc.rust-lang.org/std/ffi/type.c_short.html "type std::ffi::c_short"); some systems define it as an [`i16`](https://doc.rust-lang.org/std/primitive.i16.html "primitive i16"), for example.
