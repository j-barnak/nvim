# miasm.jitter.codegen

Module to generate C code for a given native @block

## Module variables

- `TRANSLATOR_NO_SYMBOL = TranslatorC(loc_db=None)`
- `SIZE_TO_MASK = {size: TRANSLATOR_NO_SYMBOL.from_expr(ExprInt(0, size).mask) for size in (1, 2, 3, 7, 8, 16, 32, 64)}`

## Classes

### class `Attributes(object)`

Store an irblock attributes

- **`__init__(self, log_mn=False, log_regs=False)`**

### class `CGen(object)`

Helper to generate C code for a given AsmBlock

- **`__init__(self, lifter)`**
- **`ir_arch(self)`**
- **`init_arch_C(self)`** - Iinitialize jitter internals
- **`dst_to_c(self, src)`** - Translate Expr @src into C code
- **`patch_c_id(self, expr)`** - Replace ExprId in @expr with corresponding C variables
- **`id_to_c(self, expr)`** - Translate Expr @expr into corresponding C code
- **`add_label_index(self, dst2index, loc_key)`** - Insert @lbl to the dictionary @dst2index with a uniq value
- **`assignblk_to_irbloc(self, instr, assignblk)`** - Ensure IRDst is always set in the head @assignblk of the @instr
- **`block2assignblks(self, block)`** - Return the list of irblocks for a native @block
- **`add_local_var(self, dst_var, dst_index, expr)`** - Add local variable used to store temporary result
- **`get_mem_prefetch(self, assignblk)`** - Generate temporary variables used to fetch memory used in the @assignblk
- **`gen_c_assignments(self, assignblk)`** - Return C information used to generate the C code of the @assignblk
- **`gen_check_memory_exception(self, address)`** - Generate C code to check memory exceptions
- **`gen_check_cpu_exception(self, address)`** - Generate C code to check cpu exceptions
- **`traverse_expr_dst(self, expr, dst2index)`** - Generate the index of the destination label for the @expr
- **`gen_assignblk_dst(self, dst)`** - Generate C code to handle instruction destination
- **`gen_post_instr_checks(self, attrib)`** - Generate C code for handling potential exceptions
- **`gen_pre_code(self, instr_attrib)`** - Callback to generate code BEFORE the instruction execution
- **`gen_post_code(self, attrib, pc_value)`** - Callback to generate code AFTER the instruction execution
- **`gen_goto_code(self, attrib, instr_offsets, dst)`** - Generate C code for a potential destination @dst
- **`gen_dst_goto(self, attrib, instr_offsets, dst2index)`** - Generate code for possible @dst2index.
- **`gen_c_code(self, attrib, c_dst, c_assignmnts)`** - Generate the C code for assignblk.
- **`get_caracteristics(self, assignblk, attrib)`** - Set the carateristics in @attrib according to the @assignblk
- **`get_attributes(self, instr, irblocks, log_mn=False, log_regs=False)`** - Get the carateristics of each @irblocks. Returns the corresponding
- **`gen_bad_block(self)`** - Generate the C code for a bad_block instance
- **`get_block_post_label(self, block)`** - Get label next to the @block
- **`gen_init(self, block)`** - Generate the init C code for a @block
- **`gen_irblock(self, instr_attrib, attributes, instr_offsets, irblock)`** - Generate the C code for an @irblock
- **`gen_finalize(self, block)`** - Generate the C code for the final block instruction
- **`gen_c(self, block, log_mn=False, log_regs=False)`** - Generate the C code for the @block and return it as a list of lines
