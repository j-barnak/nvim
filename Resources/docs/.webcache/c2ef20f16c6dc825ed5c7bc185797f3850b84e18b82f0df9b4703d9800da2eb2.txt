# Linux Kernel / Wait Queues

The `drgn.helpers.linux.wait` module provides helpers for working with wait queues (`wait_queue_head_t` and `wait_queue_entry_t`) from [`include/linux/wait.h`](https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/include/linux/wait.h).

Note

Since Linux 4.13, entries in a wait queue have type `wait_queue_entry_t`. Before that, the type was named `wait_queue_t`.

drgn.helpers.linux.wait.waitqueue_active(*wq: [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")*) → [bool](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")  
Return whether a wait queue has any waiters.

drgn.helpers.linux.wait.waitqueue_for_each_task(*wq: [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")*) → [Iterator](https://docs.python.org/3/library/typing.html#typing.Iterator "(in Python v3.14)")\[[drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")\]  
Iterate over all tasks waiting on a wait queue.

Warning

This comes from `wait_queue_entry_t::private`, which usually stores a task. However, some wait queue entries store a different pointer type, in which case this will return garbage.

Parameters:  
**wq** – `wait_queue_head_t`` ``*`

Returns:  
Iterator of `struct`` ``task_struct`` ``*` objects.
