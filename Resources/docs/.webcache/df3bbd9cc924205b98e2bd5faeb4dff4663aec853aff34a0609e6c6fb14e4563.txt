# Struct Take Copy item path

``` rust
#[non_exhaustive]pub struct Take<T> { /* private fields */ }
```

Expand description

Reader adapter which limits the bytes read from an underlying reader.

This struct is generally created by calling [`take`](https://doc.rust-lang.org/std/io/trait.Read.html#method.take) on a reader. Please see the documentation of [`take`](https://doc.rust-lang.org/std/io/trait.Read.html#method.take) for more details.

1.0.0 · [Source](https://doc.rust-lang.org/src/core/io/util.rs.html#285)

Returns the number of bytes that can be read before this instance will return EOF.

##### Note

This instance may reach `EOF` after reading fewer bytes than indicated by this method if the underlying [`Read`](https://doc.rust-lang.org/std/io/trait.Read.html) instance reaches EOF.

##### Examples

``` rust
use std::io;
use std::io::prelude::*;
use std::fs::File;

fn main() -> io::Result<()> {
    let f = File::open("foo.txt")?;

    // read at most five bytes
    let handle = f.take(5);

    println!("limit: {}", handle.limit());
    Ok(())
}
```

1.27.0 · [Source](https://doc.rust-lang.org/src/core/io/util.rs.html#320)

Sets the number of bytes that can be read before this instance will return EOF. This is the same as constructing a new `Take` instance, so the amount of bytes read and the previous limit value don’t matter when calling this method.

##### Examples

``` rust
use std::io;
use std::io::prelude::*;
use std::fs::File;

fn main() -> io::Result<()> {
    let f = File::open("foo.txt")?;

    // read at most five bytes
    let mut handle = f.take(5);
    handle.set_limit(10);

    assert_eq!(handle.limit(), 10);
    Ok(())
}
```

1.15.0 · [Source](https://doc.rust-lang.org/src/core/io/util.rs.html#346)

Consumes the `Take`, returning the wrapped reader.

##### Examples

``` rust
use std::io;
use std::io::prelude::*;
use std::fs::File;

fn main() -> io::Result<()> {
    let mut file = File::open("foo.txt")?;

    let mut buffer = [0; 5];
    let mut handle = file.take(5);
    handle.read(&mut buffer)?;

    let file = handle.into_inner();
    Ok(())
}
```

1.20.0 · [Source](https://doc.rust-lang.org/src/core/io/util.rs.html#375)

Gets a reference to the underlying reader.

Care should be taken to avoid modifying the internal I/O state of the underlying reader as doing so may corrupt the internal limit of this `Take`.

##### Examples

``` rust
    let file = handle.get_ref();
    Ok(())
}
```
