Expand description

An async-aware version of the [`Fn`](https://doc.rust-lang.org/std/ops/trait.Fn.html "trait std::ops::Fn") trait.

All `async fn` and functions returning futures implement this trait.

## Required Methods

[Source](https://doc.rust-lang.org/src/core/ops/async_function.rs.html#14)

🔬This is a nightly-only experimental API. (`async_fn_traits`)

Call the [`AsyncFn`](https://doc.rust-lang.org/std/ops/trait.AsyncFn.html "trait std::ops::AsyncFn"), returning a future which may borrow from the called closure.

## Dyn Compatibility

This trait is **not** [dyn compatible](https://doc.rust-lang.org/1.98.1/reference/items/traits.html#dyn-compatibility).

*In older versions of Rust, dyn compatibility was called "object safety".*
