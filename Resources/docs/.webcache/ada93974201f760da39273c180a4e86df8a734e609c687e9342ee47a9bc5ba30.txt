# Common / Types

The `drgn.helpers.common.type` module provides generic helpers for working with types in ways that aren’t provided by the core drgn library.

drgn.helpers.common.type.enum_type_to_class(*type: [drgn.Type](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Type "drgn.Type")*, *name: [str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")*, *exclude: [Container](https://docs.python.org/3/library/typing.html#typing.Container "(in Python v3.14)")\[[str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")\] = ()*, *prefix: [str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)") = ''*) → [Type](https://docs.python.org/3/library/typing.html#typing.Type "(in Python v3.14)")\[[enum.IntEnum](https://docs.python.org/3/library/enum.html#enum.IntEnum "(in Python v3.14)")\]  
Get an [`enum.IntEnum`](https://docs.python.org/3/library/enum.html#enum.IntEnum "(in Python v3.14)") class from an enumerated [`drgn.Type`](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Type "drgn.Type").

Parameters:  
- **type** – Enumerated type to convert.

- **name** – Name of the `IntEnum` type to create.

- **exclude** – Container (e.g., list or set) of enumerator names to exclude from the created `IntEnum`.

- **prefix** – Prefix to strip from the beginning of enumerator names.

drgn.helpers.common.type.member_at_offset(*type: [Union](https://docs.python.org/3/library/typing.html#typing.Union "(in Python v3.14)")\[[drgn.Type](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Type "drgn.Type"), [str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")\]*, *offset: [drgn.IntegerLike](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.IntegerLike "drgn.IntegerLike")*) → [str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")  
Return the name of the member at an offset in a type.

This is effectively the opposite of [`offsetof()`](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.offsetof "drgn.offsetof").

    >>> prog.type("struct list_head")
    struct list_head {
            struct list_head *next;
            struct list_head *prev;
    }
    >>> member_at_offset("struct list_head", 0)
    'next'
    >>> member_at_offset("struct list_head", 8)
    'prev'

This includes nested structures and array elements:

    >>> prog.type("struct sigpending")
    struct sigpending {
            struct list_head list;
            sigset_t signal;
    }
    >>> prog.type("sigset_t")
    typedef struct {
            unsigned long sig[1];
    } sigset_t
    >>> member_at_offset("struct sigpending", 0)
    'list.next'
    >>> member_at_offset("struct sigpending", 8)
    'list.prev'
    >>> member_at_offset("struct sigpending", 16)
    'signal.sig[0]'

This also includes all possible matches for a union:

    >>> prog.type("union mc_target")
    union mc_target {
            struct folio *folio;
            swp_entry_t ent;
    }
    >>> prog.type("swp_entry_t")
    typedef struct {
            unsigned long val;
    } swp_entry_t
    >>> member_at_offset("union mc_target", 0)
    'folio or ent.val'

Offsets in the middle of a member are represented:

    >>> member_at_offset("struct list_head", 4)
    'next+0x4'

Offsets in padding or past the end of the type are also represented:

    >>> prog.type("struct autogroup")
    struct autogroup {
            struct kref kref;
            struct task_group *tg;
            struct rw_semaphore lock;
            unsigned long id;
            int nice;
    }
    >>> member_at_offset("struct autogroup", 4)
    '<padding between kref and tg>'
    >>> member_at_offset("struct autogroup", 70)
    '<padding at end>'
    >>> member_at_offset("struct autogroup", 72)
    '<end>'
    >>> member_at_offset("struct autogroup", 80)
    '<past end>'

Parameters:  
- **type** – Type to check. If given as a string, it is looked up in the [default program](https://drgn.readthedocs.io/en/latest/api_reference.html#default-program).

- **offset** – Offset in bytes.

Raises:  
[**TypeError**](https://docs.python.org/3/library/exceptions.html#TypeError "(in Python v3.14)") – if *type* is not a structure, union, class, or array type (or a typedef of one of those)

drgn.helpers.common.type.typeof_member(*type: [Union](https://docs.python.org/3/library/typing.html#typing.Union "(in Python v3.14)")\[[drgn.Type](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Type "drgn.Type"), [str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")\]*, *member: [str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")*) → [drgn.Type](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Type "drgn.Type")  
Get the type of a member in a [`Type`](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Type "drgn.Type").

This corresponds to the `typeof_member()` macro used in the Linux kernel and other projects.

Parameters:  
- **type** – Structure, union, or class type. If given as a string, it is looked up in the [default program](https://drgn.readthedocs.io/en/latest/api_reference.html#default-program).

- **member** – Name of member. May include one or more member references and zero or more array subscripts.

Raises:  
- [**TypeError**](https://docs.python.org/3/library/exceptions.html#TypeError "(in Python v3.14)") – if *type* is not a structure, union, or class type

- [**LookupError**](https://docs.python.org/3/library/exceptions.html#LookupError "(in Python v3.14)") – if *type* does not have a member with the given name

## Linux Kernel

The `drgn.helpers.linux` package contains several modules for working with data structures and subsystems in the Linux kernel. The helpers are available from the individual modules in which they are defined and from this top-level package. E.g., the following are both valid:

    >>> from drgn.helpers.linux.list import list_for_each_entry
    >>> from drgn.helpers.linux import list_for_each_entry

Iterator macros (`for_each_foo`) are a common idiom in the Linux kernel. The equivalent drgn helpers are implemented as Python [generators](https://docs.python.org/3/tutorial/classes.html#tut-generators "(in Python v3.14)"). For example, the following code in C:

    list_for_each(pos, head)
            do_something_with(pos);

Translates to the following code in Python:

    for pos in list_for_each(head):
        do_something_with(pos)
