\[**python api**\] All information about the Register Python object.

#  Description

------------------------------------------------------------------------

This object is used to represent a register operand according to the CPU architecture.

##  Example

\>\>\> ctxt.processing(inst)

0

\>\>\> print(inst)

0x40000: mov ah, byte ptr \[rdx + rcx\*2 + 0x100\]

\>\>\> op0 = inst.getOperands()\[0\]

\>\>\> print(op0)

ah:8 bv\[15..8\]

\>\>\> op0.getName()

'ah'

\>\>\> op0.getSize()

1

\>\>\> op0.getBitSize()

8

\>\>\> ctxt.getParentRegister(op0).getName()

'rax'

##  Constructor

\>\>\> ah = ctxt.getRegister(REG.X86_64.AH)

\>\>\> print(ah)

ah:8 bv\[15..8\]

\>\>\> print(ah.getBitSize())

8

\>\>\> print(ctxt.registers.rax)

rax:64 bv\[63..0\]

#  Python API - Methods of the Register class

------------------------------------------------------------------------

- **integer getBitSize(void)**  
  Returns the size (in bits) of the register.  
  e.g: `64`
- **[BitsVector](https://triton-library.github.io/documentation/doxygen/py_BitsVector_page.html) getBitvector(void)**  
  Returns the bit vector of the register.
- **[EXTEND](https://triton-library.github.io/documentation/doxygen/py_EXTEND_page.html) getExtendSize(void)**  
  Returns the size (in bits) of the extend. Mainly used for AArch64.  
  e.g: `16`
- **[EXTEND](https://triton-library.github.io/documentation/doxygen/py_EXTEND_page.html) getExtendType(void)**  
  Returns the extend type of the operand. Mainly used for AArch64.  
  e.g: `EXTEND.ARM.UXTW`
- **[REG](https://triton-library.github.io/documentation/doxygen/py_REG_page.html) getId(void)**  
  Returns the enum of the register.  
  e.g: `REG.X86_64.RBX`
- **string getName(void)**  
  Returns the name of the register.  
  e.g: `rbx`
- **[SHIFT](https://triton-library.github.io/documentation/doxygen/py_SHIFT_page.html) getShiftType(void)**  
  Returns the shift type of the operand. Mainly used for AArch64.  
  e.g: `SHIFT.ARM.LSL`
- **integer getShiftImmediate(void)**  
  Returns the shift immediate value of the operand. Mainly used for AArch64 and ARM32.  
  e.g: `2`
- **[REG](https://triton-library.github.io/documentation/doxygen/py_REG_page.html) getShiftRegister(void)**  
  Returns the shift register of the operand. Mainly used for ARM32.  
  e.g: `REG.ARM32.R0`
- **integer getSize(void)**  
  Returns the size (in bytes) of the register.  
  e.g: `8`
- **[OPERAND](https://triton-library.github.io/documentation/doxygen/py_OPERAND_page.html) getType(void)**  
  Returns the type of the register. In this case this function returns `OPERAND.REG`.
- **[VAS](https://triton-library.github.io/documentation/doxygen/py_VAS_page.html) getVASType(void)**  
  Returns the vector arrangement specifier. Mainly used for AArch64.  
  e.g: `VAS.ARM.v8B`
- **bool isMutable(void)**  
  Returns true if this register is mutable. Mainly used in AArch64 to define that some registers like XZR are immutable.
- **bool isOverlapWith([Register](https://triton-library.github.io/documentation/doxygen/py_Register_page.html) other)**  
  Returns true if `other` and `self` overlap.
