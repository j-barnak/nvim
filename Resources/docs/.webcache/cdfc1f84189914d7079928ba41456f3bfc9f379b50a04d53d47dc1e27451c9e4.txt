Expand description

Converts a mutable slice of bytes to a mutable string slice.

This is an alias to [`str::from_utf8_mut`](https://doc.rust-lang.org/std/primitive.str.html#method.from_utf8_mut "associated function str::from_utf8_mut").

## Examples

Basic usage:

``` rust
use std::str;

// "Hello, Rust!" as a mutable vector
let mut hellorust = vec![72, 101, 108, 108, 111, 44, 32, 82, 117, 115, 116, 33];

// As we know these bytes are valid, we can use `unwrap()`
let outstr = str::from_utf8_mut(&mut hellorust).unwrap();

assert_eq!("Hello, Rust!", outstr);
```

Incorrect bytes:

``` rust
use std::str;

// Some invalid bytes in a mutable vector
let mut invalid = vec![128, 223];

assert!(str::from_utf8_mut(&mut invalid).is_err());
```

See the docs for [`Utf8Error`](https://doc.rust-lang.org/std/str/struct.Utf8Error.html "struct std::str::Utf8Error") for more details on the kinds of errors that can be returned.
