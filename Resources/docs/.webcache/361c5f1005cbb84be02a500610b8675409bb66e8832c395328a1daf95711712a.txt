# [`pwnlib.replacements`](#module-pwnlib.replacements "pwnlib.replacements") — Replacements for various functions

Improved replacements for standard functions

pwnlib.replacements.sleep(*n*)[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/replacements.py#L7-L20)  
Replacement for [`time.sleep()`](https://docs.python.org/3/library/time.html#time.sleep "(in Python v3.14)"), which does not return if a signal is received.

Parameters:  
**n** ([*int*](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")) – Number of seconds to sleep.
