- **addr** ([*int*](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")) – Basic block address of this indirect jump.

- **block** – The basic block. The type is determined by the backend being used. It’s pyvex.IRSB if pyvex is used as the backend.

- **jumpkind** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – The jumpkind.

- **func_graph_complete** ([`bool`](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – True if the function graph is complete at this point (except for nodes that this indirect jump node dominates).
