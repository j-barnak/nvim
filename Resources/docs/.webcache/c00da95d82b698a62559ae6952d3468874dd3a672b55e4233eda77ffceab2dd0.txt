pwnlib.util.proc.pidof(*target*) → int list[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/util/proc.py#L20-L66)  
Get PID(s) of target. The returned PID(s) depends on the type of target:

- [`str`](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)"): PIDs of all processes with a name matching target.

- [`pwnlib.tubes.process.process`](https://docs.pwntools.com/en/stable/tubes/processes.html#pwnlib.tubes.process.process "pwnlib.tubes.process.process"): singleton list of the PID of target.

- [`pwnlib.tubes.sock.sock`](https://docs.pwntools.com/en/stable/tubes/sockets.html#pwnlib.tubes.sock.sock "pwnlib.tubes.sock.sock"): singleton list of the PID at the remote end of target if it is running on the host. Otherwise an empty list.

- [`pwnlib.tubes.ssh.ssh_channel`](https://docs.pwntools.com/en/stable/tubes/ssh.html#pwnlib.tubes.ssh.ssh_channel "pwnlib.tubes.ssh.ssh_channel"): singleton list of the PID of target on the remote system.

- [`tuple`](https://docs.python.org/3/library/stdtypes.html#tuple "(in Python v3.14)"): singleton list of the PID at the local end of the  
  connection to target if it is running on the host. Otherwise an empty list.

Parameters:  
**target** ([*object*](https://docs.python.org/3/library/functions.html#object "(in Python v3.14)")) – The target whose PID(s) to find.

Returns:  
A list of found PIDs.

Example

    >>> l = tubes.listen.listen()
    >>> p = process(['curl', '-s', 'http://127.0.0.1:%d'%l.lport])
    >>> pidof(p) == pidof(l) == pidof(('127.0.0.1', l.rport))
    True
