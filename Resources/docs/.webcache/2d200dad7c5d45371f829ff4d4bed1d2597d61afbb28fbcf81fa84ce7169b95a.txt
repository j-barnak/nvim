# 9.21. Notes about experimental GeForce emulation usage

The GeForce graphics emulation currently implements basic support for four GeForce models. Most of the 2D features are present, but 3D is still WIP. Several Windows versions up to Win 7 have been reported to work under consideration of these limitations.

![](https://bochs.sourceforge.io/doc/docbook/images/undercon.png) to be completed

These bochsrc settings are required for all GeForce models:

```
  vga: extension=geforce
  pci: chipset=i440bx, slot5=geforce
  
```

These bochsrc settings must be picked from related columns of the table below:

```
  geforce: model=Model
  vgaromimage: file=VGABIOS
  
```

**Table 9-5. GeForce models and required VGABIOS**

| Model         | VGABIOS                             |     |
|---------------|-------------------------------------|-----|
| geforce2      | Leadtek.2Pro.64.010403_AGP.bin      |     |
| geforce3      | Leadtek.3Ti500.64.011105_AGP.bin    |     |
| geforcefx5900 | Leadtek.FX5900XT.128.041026_AGP.bin |     |
| geforce6800   | Leadtek.6800GT.256.040702_AGP.bin   |     |
