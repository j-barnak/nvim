# Function null Copy item path

1.0.0 (const: 1.24.0) · [Source](https://doc.rust-lang.org/src/core/ptr/mod.rs.html#852)

``` rust
pub const fn null<T>() -> *const Twhere
    T: Thin + ?Sized,
```

Expand description

Creates a null raw pointer.

This function is equivalent to zero-initializing the pointer: `MaybeUninit::<*const T>::zeroed().assume_init()`. The resulting pointer has the address 0.

## Examples

``` rust
use std::ptr;

let p: *const i32 = ptr::null();
assert!(p.is_null());
assert_eq!(p as usize, 0); // this pointer has the address 0
```
