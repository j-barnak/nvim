# Function current_dir Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/std/env.rs.html#53-55)

``` rust
pub fn current_dir() -> Result<PathBuf>
```

Expand description

Returns the current working directory as a [`PathBuf`](https://doc.rust-lang.org/std/path/struct.PathBuf.html "struct std::path::PathBuf").

## Platform-specific behavior

This function [currently](https://doc.rust-lang.org/std/io/index.html#platform-specific-behavior "mod std::io") corresponds to the `getcwd` function on Unix and the `GetCurrentDirectoryW` function on Windows.

## Errors

Returns an [`Err`](https://doc.rust-lang.org/std/result/enum.Result.html#variant.Err "variant std::result::Result::Err") if the current working directory value is invalid. Possible cases:

- Current directory does not exist.
- There are insufficient permissions to access the current directory.

## Examples

``` rust
use std::env;

fn main() -> std::io::Result<()> {
    let path = env::current_dir()?;
    println!("The current directory is {}", path.display());
    Ok(())
}
```
