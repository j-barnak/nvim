# Microkit Supported Platforms

The following platforms are supported by the seL4 Microkit. See also the section on [Board Support Packages](https://docs.sel4.systems/projects/microkit/manual/latest/#bsps) in the Microkit manual.

Microkit currently supports [Arm](#arm) AArch64 and [RISC-V](#risc-v) boards. x64 support is on the [roadmap](https://docs.sel4.systems/projects/microkit/roadmap.html).

## Not in the list above?

See the section on [adding platform support](https://docs.sel4.systems/projects/microkit/manual/latest/#adding-platform-support) for how to add a new platform to Microkit. To add a platform to Microkit it must be supported by seL4 first. See the seL4 page on [supported platforms](https://docs.sel4.systems/Hardware/#not-in-the-lists-above) for options on that.
