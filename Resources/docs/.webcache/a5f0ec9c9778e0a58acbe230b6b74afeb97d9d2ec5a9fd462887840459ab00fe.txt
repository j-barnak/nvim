# [`pwnlib.filesystem`](#module-pwnlib.filesystem "pwnlib.filesystem") — Manipulating Files Locally and Over SSH

Provides a Python2-compatible [`pathlib`](https://docs.python.org/3/library/pathlib.html#module-pathlib "(in Python v3.14)") interface for paths on the local filesystem (.Path) as well as on remote filesystems, via SSH (.SSHPath).

Handles file abstraction for local vs. remote (via ssh)

*class *pwnlib.filesystem.Path(*\*args*, *\*\*kwargs*)[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/filesystem.py#L824-L1410)  
PurePath subclass that can make system calls.

Path represents a filesystem path but unlike PurePath, also offers methods to do system calls on path objects. Depending on your system, instantiating a Path will return either a PosixPath or a WindowsPath object. You can also instantiate a PosixPath or WindowsPath directly, but cannot instantiate a WindowsPath on a POSIX system or vice versa.

Construct a PurePath from one or several strings and or existing PurePath objects. The strings and path objects are combined so as to yield a canonicalized path, which is incorporated into the new PurePath object.

*class *pwnlib.filesystem.SSHPath(*\*args*, *\*\*kwargs*)[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/filesystem.py#L22-L793)  
Represents a file that exists on a remote filesystem.

See [`ssh`](https://docs.pwntools.com/en/stable/tubes/ssh.html#pwnlib.tubes.ssh.ssh "pwnlib.tubes.ssh.ssh") for more information on how to set up an SSH connection. See [`pathlib.Path`](#pwnlib.filesystem.Path "pathlib.Path") for documentation on what members and properties this object has.

Parameters:  
- **name** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Name of the file

- **ssh** ([*ssh*](https://docs.pwntools.com/en/stable/tubes/ssh.html#pwnlib.tubes.ssh.ssh "pwnlib.tubes.ssh.ssh")) – [`ssh`](https://docs.pwntools.com/en/stable/tubes/ssh.html#pwnlib.tubes.ssh.ssh "pwnlib.tubes.ssh.ssh") object for manipulating remote files

Note

You can avoid having to supply `ssh=` on every `SSHPath` by setting `context.ssh_session`. In these examples we provide `ssh=` for clarity.

Examples

First, create an SSH connection to the server.

    >>> ssh_conn = ssh('travis', 'example.pwnme')

Let’s use a temporary directory for our tests

    >>> _ = ssh_conn.set_working_directory()

Next, you can create SSHPath objects to represent the paths to files on the remote system.

    >>> f = SSHPath('filename', ssh=ssh_conn)
    >>> f.touch()
    >>> f.exists()
    True
    >>> f.resolve().path # doctests: +ELLIPSIS
    '/tmp/.../filename'
    >>> f.write_text('asdf ❤️')
    >>> f.read_bytes()
    b'asdf \xe2\x9d\xa4\xef\xb8\x8f'

`context.ssh_session` must be set to use the `SSHPath.mktemp()` or `SSHPath.mkdtemp()` methods.

    >>> context.ssh_session = ssh_conn
    >>> SSHPath.mktemp()
    SSHPath('...', ssh=ssh(user='travis', host='127.0.0.1'))
