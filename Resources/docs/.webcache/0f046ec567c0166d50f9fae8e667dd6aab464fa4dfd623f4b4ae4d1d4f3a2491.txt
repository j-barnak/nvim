# Linux Kernel / Users

The `drgn.helpers.linux.user` module provides helpers for working with users in the Linux kernel.

drgn.helpers.linux.user.kuid_val(*uid: [Union](https://docs.python.org/3/library/typing.html#typing.Union "(in Python v3.14)")\[[drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object"), [drgn.IntegerLike](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.IntegerLike "drgn.IntegerLike")\]*) → [int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")  
Return the UID value of a `kuid_t`.

Parameters:  
**uid** – `kuid_t` object. May also be an integer, in which case its value is returned.

Parameters:  
- **prog** – Program, which [may be omitted to use the default program argument](https://drgn.readthedocs.io/en/latest/api_reference.html#default-program).

Returns:  
`struct`` ``user_struct`` ``*` (`NULL` if not found)
