# SLUBStick (USENIX Security 2024) — presentation page

The source for this entry is the USENIX Security '24 presentation page:
https://www.usenix.org/conference/usenixsecurity24/presentation/maar-slubstick

A plain (non-browser) fetch of this URL is answered by a Cloudflare
"Just a moment..." interactive challenge (HTTP 403), which cannot be
cleared without executing the page's JavaScript. Per the build's
no-user-agent-spoofing rule, the abstract page body was therefore not
captured here and must be fetched manually from a browser.

The underlying paper is "SLUBStick: Arbitrary Memory Writes through
Practical Software Cross-Cache Attacks within the Linux Kernel" by Lukas
Maar, Stefan Gast, Martin Unterguggenberger, Mathias Oberhuber, and
Stefan Mangard (Graz University of Technology). The full paper text is
carried in the SLUB provider (chapter "SLUBStick ... USENIX Security 2024
paper").
