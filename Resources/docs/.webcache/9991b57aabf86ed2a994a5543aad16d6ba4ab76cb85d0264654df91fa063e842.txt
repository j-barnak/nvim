## Synopsis

You walk into that fated patch of grass then a shiny Pikachu suddenly appears. But uh-oh, you only have five PokéBalls 😔. If only you had a way to save this moment in time!

## Objectives

Gain the ability to save and restore emulator states by implementing save states. Understand the memento design pattern and how to implement it. Know the difference between shallow and deep copying. Lastly, learn how to serialize and deserialize objects.

## Terminology

### Component

The definition of a component in this article means a part of the emulator that contains states like the CPU, GPU, memory bus, ..etc.

### Save State

A save state is an object that contains an emulator's exact state the moment it was saved. It contains properties like the registers, pc, joypad state, or memory contents.

I have a question for my computer scientists/software engineers. Which design pattern best fits the description of a save state? If you answered the [memento design pattern](https://refactoring.guru/design-patterns/memento), you're right!

### Memento Design Pattern

![](https://us-east-1.graphassets.com/AQCULhpXqR4ORhEGqTS46z/EwRglaESuKb5VZyjoklW)

[Memento](https://refactoring.guru/design-patterns/memento) is a behavioral design pattern that allows the saving and restoration of an object's state without revealing the internal details of its implementation.

For us, each component is an **originator** that contains a nested class to represent its **memento/snapshot**. The **caretaker** represents the emulator that controls the creation and restoration of snapshots.

### Shallow Copying

![](https://us-east-1.graphassets.com/AQCULhpXqR4ORhEGqTS46z/resize=w:265,h:274,fit:crop/auto_image/compress/OmBYFsuoScixnVeEmB1r)

Shallow copying means copying an object reference, and the cloned object points to the original object.

Imagine you have a backend service with `Customers` and periodically create customer backups.

``` java
public class Customer {
  int[] orderNumbers;
  String name;
  int age;

  // Shallow copying
  public Customer(int[] orderNumbers, String name, int age) {
    this.orderNumbers = orderNumbers;
    this.name = name;
    this.age = age;
  }
}
```

``` java
// Creating a customer
int[] orders = [12, 3, 1];
String name = "Naruto Uzamaki";
int age = 16;

Customer customer = new Customer(orders, name, age);

// Creating a customer backup
Customer customerBackup = new Customer(customer.orderNumbers, customer.name,
 customer.age);
```

**Shallow copies** have a fatal flaw since each object shares the same reference with the original; if the original updates, the copy updates.

Primitive data types aren't object references, so they are unaffected.

``` java
// Primitive data type are unnafected by changes in the original
System.out.println(customer.name); // Naruto Uzamaki
System.out.println(backupCusomer.name); // Naruto Uzamaki

customer.updateName("Sasuke Uchiha");

System.out.println(customer.name); // Sasuke Uchiha
System.out.println(backupCustomer.name); // Naruto Uzamaki

// Object are affected by changes in the original
System.out.println(Arrays.toString(customer.orders)); // [12, 3, 1]
System.out.println(Arrays.toString(backupCusomer.orders)); // [12, 3, 1]

customer.order[2] = 0xDEADBEEF

System.out.println(Arrays.toString(customer.orders)); // [12, 3, 0xDEADBEEF]
System.out.println(Arrays.toString(backupCusomer.orders)); // [12, 3, 0xDEADBEEF]
```

This technique isn't viable when making independent copies (such as snapshots of components). Luckily, **deep copying** comes to the rescue.

### Deep Copying / Defensive Copying

![](https://us-east-1.graphassets.com/AQCULhpXqR4ORhEGqTS46z/resize=w:265,h:274,fit:crop/auto_image/compress/Th1dNg3RNSC2Nd4EzGJw)

**Deep copying** or **defensive copying** creates an independent copy by copying the object itself rather than passing a reference. This way changes in the original don't affect the copy.

Below is a modification of the `Customer` class with deep copying.

``` java
public class Customer {
  int[] orderNumbers;
  String name;
  int age;

  public Customer(int[] orderNumbers, String name, int age) {
    // Deep copy the order numbers array object
    this.orderNumbers = Arrays.copyOf(orderNumbers, orderNumbers.length);

    // Primitive data types aren't
    // object references.
    this.name = name;
    this.age = age;
  }
}
```

Getters can also utilize **deep copying** to return a **defensive copy** to prevent the caller from modifying the underlying object.

``` java
// Return a defensive copy of the order numbers object.
public int[] getOrderNumbers() {
  return Arrays.copyOf(orderNumbers, orderNumbers.length);
}
```

### Serializable

`Serializable` is a Java interface that enables classes to be represented as a sequence of bytes or serializable. This sequence can be sent over the network or saved to a file. Each object field in a serialized class must also implement `Serializable`.

Classes that implement `Serializable` require a `serialVersionUID` variable to detect compatibility changes when deserializing. The `serialVersionUID` must increment on each [incompatible class change](https://docs.oracle.com/javase/6/docs/platform/serialization/spec/version.html#6678). For example, removing a class field makes the class incompatible with previously serialized versions.

Now we can save `Customer` backups to a file.

``` java
// Implement Serializable
class Customer implements Serializable {
  long serialVersionUID = 0
  ...
}

// Save the customer to a file.
public void saveCustomerToFile(Customer customer, String fileName) {
  ObjectOutputStream objectOutputStream = new ObjectOutputStream(
      new FileOutputStream(fileName));
  objectOutputStream.writeObject(customer);
  objectOutputStream.close();
}
```

## Save State / Snapshot Design

Studying the memento pattern, we learn that the **originator** creates **snapshots** that contain internal attributes. In our case, the originator represents a component.

We define an **interface** to expose methods for creating and restoring snapshots to share functionality. Each component has a unique snapshot class, so we introduce the generic type `<T>` for representing the snapshot.

``` java
public interface Snapshotable<T> {
  T createSnapshot();
  boolean restoreSnapshot(T snapshot);
}
```

Each component implements `Snapshotable` and passes a nested snapshot class as the generic `<T>`. The nested snapshot replaces the `T` in the implemented `Snapshotable` methods for that component.

``` java
class CPUSnapshot {
  private final int[] pipeline;
  private final int[] registers;

  // Deep copy attributes
  CPUSnapshot(int[] pipeline, int[] registers) {
    this.pipeline = Arrays.copyOf(pipeline, pipeline.length);
    this.registers = Arrays.copyOf(registers, registers.length);
  }

  // Return a defensive copy
  public int[] getPipeline() {
    return Arrays.copyOf(pipeline, pipeline.length);
  }

  // Return a defensive copy
  public int[] getRegisters() {
    return Arrays.copyOf(registers, registers.length);
  }
}

public class CPU implements Snapshotable<CPUSnapshot> {
  ...

  @Override
  public CPUSnapshot createSnapshot() {
    ...
  }

  @Override
  public boolean restoreSnapshot(CPUSnapshot snapshot) {
    ...
  }
}
```

To prevent issues with **shallow copying** the snapshot needs to be [immutable](https://docs.oracle.com/javase/tutorial/essential/concurrency/immutable.html). The constructor **deep copies** each attribute, and getters return **deep copies** to prevent callers from modifying the underlying object.

Since snapshots are nested classes, attributes are passed directly to the snapshots' constructor by the component rather than passing the component object itself, preventing the need to create getters for each attribute which could leak implementation details.

## Creating the Component Snapshots

Now we create all the nested snapshot classes.

``` java
class CPUSnapshot {
  private final int[] pipeline;
  private final int[] registers;

  // Deep copy attributes
  CPUSnapshot(int[] pipeline, int[] registers) {
    this.pipeline = Arrays.copyOf(pipeline, pipeline.length);
    this.registers = Arrays.copyOf(registers, registers.length);
  }

  // Return a defensive copy
  public int[] getPipeline() {
    return Arrays.copyOf(pipeline, pipeline.length);
  }

  // Return a defensive copy
  public int[] getRegisters() {
    return Arrays.copyOf(registers, registers.length);
  }
}

public class CPU implements Snapshotable<CPUSnapshot> {
  private MemoryBus memoryBus;

  private static final int PIPELINE_LENGTH = 3;

  // 3 Stage pipeline
  private int[] pipeline = new int[PIPELINE_LENGTH];

  // General Purpose Registers
  private int[] registers = new int[15];

  public CPU(MemoryBus memoryBus) {
    this.memoryBus = memoryBus;
  }

  @Override
  public CPUSnapshot createSnapshot() {
    return new CPUSnapshot(pipeline, registers);
  }

  @Override
  public boolean restoreSnapshot(CPUSnapshot snapshot) {
    this.pipeline = snapshot.getPipeline();
    this.registers = snapshot.getRegisters();
    return true;
  }
}
```

## Creating a Save State

Create a `SaveState` class to contain all the snapshots and represent a **save state**. Next, collect all the snapshots then initialize a `SaveState` object. This creates a perfect snapshot of the emulator's current state.

``` java
public class SaveState {
  private CPUSnapshot cpuSnapshot;
  private JoypadSnapshot joypadSnapshot;
  private LCDSnapshot lcdSnapshot;
  private MemoryBusSnapshot memoryBusSnapshot;

  public SaveState(CPUSnapshot cpuSnapshot, JoypadSnapshot joypadSnapshot,
   LCDSnapshot lcdSnapshot, MemoryBusSnapshot memoryBusSnapshot) {
    this.cpuSnapshot = cpuSnapshot;
    this.joypadSnapshot = joypadSnapshot;
    this.lcdSnapshot = lcdSnapshot;
    this.memoryBusSnapshot = memoryBusSnapshot;
  }

  public CPUSnapshot getCPUSnapshot() {
    return cpuSnapshot;
  }

  public JoypadSnapshot getJoypadSnapshot() {
    return joypadSnapshot;
  }

  public LCDSnapshot getLCDSnapshot() {
    return lcdSnapshot;
  }

  public MemoryBusSnapshot getMemoryBusSnapshot() {
    return memoryBusSnapshot;
  }
}
```

## Restoring a Save State

To restore a **save state**, restore each component using its corresponding **snapshot** contained in a `SaveState` object to restore the emulator to the moment the save state was created.

``` java
public void restoreSaveState(SaveState saveState) {
  cpu.restoreSnapshot(saveState.getCPUSnapshot());
  joypad.restoreSnapshot(saveState.getJoypadSnapshot());
  lcd.restoreSnapshot(saveState.getLCDSnapshot());
  memoryBus.restoreSnapshot(saveState.getMemoryBusSnapshot());
}
...
SaveState saveState = 
  new SaveState(cpuSnapshot, joypadSnapshot, lcdSnapshot memoryBusSnapshot);

restoreSaveState(saveState);
```

### Saving to a File

Saving a **save state** to a file is as simple as it sounds. Write the serialized `SaveState` object to a file.

``` java
public static void serializeSaveState(SaveState saveState, String fileName) {
  try {
    ObjectOutputStream objectOutputStream = new ObjectOutputStream(
        new FileOutputStream(fileName));
    objectOutputStream.writeObject(saveState);
    objectOutputStream.close();
  } catch (Exception ex) {
     ex.printStackTrace();
  }
}
```

### Loading from a File

Again, just as easy as it sounds, read the `SaveState` object bytes into a `SaveState` object.

``` java
public static SaveState deserializeSaveState(String fileName) {
  ObjectInputStream saveStateBytes = new ObjectInputStream(
      new BufferedInputStream(new FileInputStream(
        fileName)));

  return (SaveState) saveStateBytes.readObject();
}
```

### Compressing with Gzip

In a full-fledged emulator, a save state can get mighty big. Let's add `gzip` compression to the mix to save precious bytes.

``` java
public static void serializeSaveState(SaveState saveState, String fileName) {
  // Add GZIPOutputStream in-front of the FileOutputStream
  ObjectOutputStream compressedObjectOutputStream = new ObjectOutputStream(
        new GZIPOutputStream(new FileOutputStream(fileName)));
  compressedObjectOutputStream.writeObject(saveState);
  compressedObjectOutputStream.close();
}

public static SaveState deserializeSaveState(String fileName) {
  // Add GZIPInputStream in-front of the FileInputStream
  ObjectInputStream decompressedSaveStateBytes = new ObjectInputStream(
      new BufferedInputStream(new GZIPInputStream(new FileInputStream(
        fileName))));

  return (SaveState) decompressedSaveStateBytes.readObject();
}
```
