# Plugins

drgn can be extended with plugins. A drgn plugin is a Python module defining one or more hook functions that are called at specific times. Plugins can also register [commands](#api-commands).

By default, drgn loads installed modules registered as [entry points](https://drgn.readthedocs.io/en/latest/advanced_usage.html#writing-plugins) for the `drgn.plugins` group. The [`DRGN_PLUGINS`](https://drgn.readthedocs.io/en/latest/advanced_usage.html#envvar-DRGN_PLUGINS) and [`DRGN_DISABLE_PLUGINS`](https://drgn.readthedocs.io/en/latest/advanced_usage.html#envvar-DRGN_DISABLE_PLUGINS) environment variables can be used to configure this.

The following hooks are currently defined:

drgn_prog_set(*prog: [drgn.Program](#drgn.Program "drgn.Program")*) → [None](https://docs.python.org/3/library/constants.html#None "(in Python v3.14)")  
Called after the program target has been set (e.g., one of [`drgn.Program.set_core_dump()`](#drgn.Program.set_core_dump "drgn.Program.set_core_dump"), [`drgn.Program.set_kernel()`](#drgn.Program.set_kernel "drgn.Program.set_kernel"), or [`drgn.Program.set_pid()`](#drgn.Program.set_pid "drgn.Program.set_pid") has been called).

A `drgn_priority` integer attribute can be assigned to a hook function to define when it is called relative to other plugins. Hook functions with lower `drgn_priority` values are called earlier. Functions with equal `drgn_priority` values are called in an unspecified order. The default if not defined is 50.

See [Writing Plugins](https://drgn.readthedocs.io/en/latest/advanced_usage.html#writing-plugins) for an example.
