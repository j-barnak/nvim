What is Verilog?

Verilog is a hardware description language — it
describes digital circuits, not software programs. 


When you write Verilog, you are specifying digital logic
behavior: logic gates, flip-flops, and latches.

Conditionals are used for data-dependent behavior in
combinational logic. Assignment within a conditional will be
synthesized as a multiplexer.

Sized literals are of the form size (in bits), base (hex,
decimal, or binary), and literal.

Bit-slicing enables accessing a subset of the bits from a
signal (from MSB to LSB).

// --- bitwise ops (operate bit-by-bit on vectors) ---

logic [7:0] a = 8'h0f;

logic [7:0] b = 8'h33;

logic [7:0] bw_and = a & b;

Bitwise operations apply Boolean functions bit-by-bit on
given bitvectors.

Logical operations allow Boolean operations on bitvectors
where they are true only if nonzero.
