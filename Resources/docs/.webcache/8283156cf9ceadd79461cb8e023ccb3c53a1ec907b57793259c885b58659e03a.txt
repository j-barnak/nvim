Operations on ASCII strings and characters.

Most string operations in Rust act on UTF-8 strings. However, at times it makes more sense to only consider the ASCII character set for a specific operation.

The [`AsciiExt`](https://doc.rust-lang.org/std/ascii/trait.AsciiExt.html "trait std::ascii::AsciiExt") trait provides methods that allow for character operations that only act on the ASCII subset and leave non-ASCII characters alone.

The [`escape_default`](https://doc.rust-lang.org/std/ascii/fn.escape_default.html "fn std::ascii::escape_default") function provides an iterator over the bytes of an escaped version of the character given.
