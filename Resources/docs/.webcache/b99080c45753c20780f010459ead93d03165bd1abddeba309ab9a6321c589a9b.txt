# 5.3. Updating the online documentation

After generating the HTML documentation on Linux or with Cygwin, the files must be updated in the `Bochs-sfsite` GIT repository on SourceForge (subdirectory `doc/docbook`) and then uploaded to the Bochs webspace. See [previous section](https://bochs.sourceforge.io/doc/docbook/development/update-website.html) for details. The updated files can be accessed from the sidebar of the Bochs website.

In addition to this a file called `bochsdoc.tar.gz` must be generated with the **make**. This file also must be uploaded to the location of the online documentation on SF using **sftp**. This file will be downloaded in the build process on platforms that cannot generate the HTML docs.
