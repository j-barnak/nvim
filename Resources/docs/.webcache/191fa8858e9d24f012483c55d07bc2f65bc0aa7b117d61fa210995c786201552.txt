Expand description

Equivalent to C’s `unsigned long long` type.

This type will almost always be [`u64`](https://doc.rust-lang.org/std/primitive.u64.html "primitive u64"), but may differ on some systems. The C standard technically only requires that this type be an unsigned integer with the size of a [`long long`](https://doc.rust-lang.org/std/os/raw/type.c_longlong.html "type std::os::raw::c_longlong"), although in practice, no system would have a `long long` that is not a `u64`, as most systems do not have a standardised [`u128`](https://doc.rust-lang.org/std/primitive.u128.html "primitive u128") type.
