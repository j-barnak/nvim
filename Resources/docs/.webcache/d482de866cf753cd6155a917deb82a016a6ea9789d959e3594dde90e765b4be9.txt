# Enum TrySendError Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/std/sync/mpsc.rs.html#466-480)

``` rust
pub enum TrySendError<T> {
    Full(T),
    Disconnected(T),
}
```

Expand description

This enumeration is the list of the possible error outcomes for the [`try_send`](https://doc.rust-lang.org/std/sync/mpsc/struct.SyncSender.html#method.try_send "method std::sync::mpsc::SyncSender::try_send") method.

## Variants

1.0.0

The data could not be sent on the [`sync_channel`](https://doc.rust-lang.org/std/sync/mpsc/fn.sync_channel.html "fn std::sync::mpsc::sync_channel") because it would require that the callee block to send the data.

If this is a buffered channel, then the buffer is full at this time. If this is not a buffered channel, then there is no [`Receiver`](https://doc.rust-lang.org/std/sync/mpsc/struct.Receiver.html "struct std::sync::mpsc::Receiver") available to acquire the data.

1.0.0

This [`sync_channel`](https://doc.rust-lang.org/std/sync/mpsc/fn.sync_channel.html "fn std::sync::mpsc::sync_channel")’s receiving half has disconnected, so the data could not be sent. The data is returned back to the callee in this case.
