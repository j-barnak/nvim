## AbstractInstructionBackend

*class *qbindiff.loader.backend.AbstractInstructionBackend[\[source\]](https://diffing.quarkslab.com/_modules/qbindiff/loader/backend/abstract.html#AbstractInstructionBackend)  
Bases: [`object`](https://docs.python.org/3/library/functions.html#object "(in Python v3.13)")

This is an abstract class and should not be used as is. It represents a generic backend loader for a Instruction

MAX_ID* = 3000*  
Max instruction ID. All the instruction IDs will be in the range \[0, MAX_ID\]

*abstract property *addr*: [int](https://docs.python.org/3/library/functions.html#int "(in Python v3.13)")*  
The address of the instruction

*abstract property *bytes*: [bytes](https://docs.python.org/3/library/stdtypes.html#bytes "(in Python v3.13)")*  
Returns the bytes representation of the instruction

*abstract property *comment*: [str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.13)")*  
Comment associated with the instruction

*property *groups*: [list](https://docs.python.org/3/library/stdtypes.html#list "(in Python v3.13)")\[InstructionGroup\]*  
Returns a list of groups of this instruction. Provided with the INSTR_GROUP capability

*abstract property *id*: [int](https://docs.python.org/3/library/functions.html#int "(in Python v3.13)")*  
Returns the instruction ID as a non negative int. The ID is in the range \[0, MAX_ID\]. The value MAX_ID means that there is no ID available.

Warning

The backend is responsible for creating this value, different backends should not be considered compatible between each other. (For example IDA relies on IDA IDs while quokka relies on capstone IDs)

*abstract property *mnemonic*: [str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.13)")*  
Returns the instruction mnemonic as a string

*abstract property *operands*: Iterator\[[AbstractOperandBackend](#qbindiff.loader.backend.AbstractOperandBackend "qbindiff.loader.backend.AbstractOperandBackend")\]*  
Returns an iterator over backend operand objects

*property *pcode_ops*: [list](https://docs.python.org/3/library/stdtypes.html#list "(in Python v3.13)")\[PcodeOp\]*  
List of PcodeOp associated with the instruction. Provided with the PCODE capability

*abstract property *references*: [dict](https://docs.python.org/3/library/stdtypes.html#dict "(in Python v3.13)")\[[ReferenceType](https://diffing.quarkslab.com/qbindiff/doc/source/api/loader.html#qbindiff.loader.types.ReferenceType "qbindiff.loader.types.ReferenceType"), [list](https://docs.python.org/3/library/stdtypes.html#list "(in Python v3.13)")\[[Data](https://diffing.quarkslab.com/qbindiff/doc/source/api/loader.html#qbindiff.loader.Data "qbindiff.loader.Data") \| [Structure](https://diffing.quarkslab.com/qbindiff/doc/source/api/loader.html#qbindiff.loader.Structure "qbindiff.loader.Structure") \| [StructureMember](https://diffing.quarkslab.com/qbindiff/doc/source/api/loader.html#qbindiff.loader.StructureMember "qbindiff.loader.StructureMember")\]\]*
