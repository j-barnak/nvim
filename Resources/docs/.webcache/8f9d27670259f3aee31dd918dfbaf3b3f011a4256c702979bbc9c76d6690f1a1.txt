#### 1.2.3 Berkeley Unix

The GNU C Library defines facilities from some versions of Unix which are not formally standardized, specifically from the 4.2 BSD, 4.3 BSD, and 4.4 BSD Unix systems (also known as *Berkeley Unix*) and from *SunOS* (a popular 4.2 BSD derivative that includes some Unix System V functionality). These systems support most of the ISO C and POSIX facilities, and 4.4 BSD and newer releases of SunOS in fact support them all.

The BSD facilities include symbolic links (see [Symbolic Links](https://sourceware.org/glibc/manual/latest/html_node/Symbolic-Links.html)), the `select` function (see [Waiting for Input or Output](https://sourceware.org/glibc/manual/latest/html_node/Waiting-for-I_002fO.html)), the BSD signal functions (see [BSD Signal Handling](https://sourceware.org/glibc/manual/latest/html_node/BSD-Signal-Handling.html)), and sockets (see [Sockets](https://sourceware.org/glibc/manual/latest/html_node/Sockets.html)).
