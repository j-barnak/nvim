1.19.0 · [Source](https://doc.rust-lang.org/src/core/cmp.rs.html#684)

#[repr(transparent)]pub struct Reverse<T>(pub T);

Expand description

A helper struct for reverse ordering.

This struct is a helper to be used with functions like [`Vec::sort_by_key`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.sort_by_key) and can be used to reverse order a part of a key.

## Examples

``` rust
use std::cmp::Reverse;

let mut v = vec![1, 2, 3, 4, 5, 6];
v.sort_by_key(|&num| (num > 3, Reverse(num)));
assert_eq!(v, vec![3, 2, 1, 6, 5, 4]);
```
