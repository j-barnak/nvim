# NAME

podman-generate - Generate structured data based on containers, pods or volumes

# SYNOPSIS

**podman generate** *subcommand*

# DESCRIPTION

The generate command creates structured output (like YAML) based on a container, pod or volume.

# COMMANDS

| Command | Man Page | Description |
|----|----|----|
| kube | [podman-kube-generate(1)](https://docs.podman.io/en/latest/markdown/podman-kube-generate.1.html) | Generate Kubernetes YAML based on containers, pods or volumes. |
| spec | [podman-generate-spec(1)](https://docs.podman.io/en/latest/markdown/podman-generate-spec.1.html) | Generate Specgen JSON based on containers or pods. |
| systemd | [podman-generate-systemd(1)](https://docs.podman.io/en/latest/markdown/podman-generate-systemd.1.html) | \[DEPRECATED\] Generate systemd unit file(s) for a container or pod. |
