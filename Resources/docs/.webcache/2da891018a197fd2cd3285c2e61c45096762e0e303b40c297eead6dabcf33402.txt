# [`pwnlib.flag`](#module-pwnlib.flag "pwnlib.flag") — CTF Flag Management

pwnlib.flag.submit_flag(*flag*, *exploit='unnamed-exploit'*, *target='unknown-target'*, *server='flag-submission-server'*, *port='31337'*, *team='unknown-team'*)[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/flag.py#L21-L72)  
Submits a flag to the game server

Parameters:  
- **flag** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – The flag to submit.

- **exploit** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Exploit identifier, optional

- **target** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Target identifier, optional

- **server** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Flag server host name, optional

- **port** ([*int*](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")) – Flag server port, optional

- **team** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Team identifier, optional

Optional arguments are inferred from the environment, or omitted if none is set.

Returns:  
A string indicating the status of the key submission, or an error code.

    >>> l = listen()
    >>> _ = submit_flag('flag', server='localhost', port=l.lport)
