# miasm.ir.translators.translator

## Classes

### class `Translator(object)`

Abstract parent class for translators.

- **`register(cls, translator)`** - Register a translator
- **`to_language(cls, target_lang, *args, **kwargs)`** - Return the corresponding translator instance
- **`available_languages(cls)`** - Return the list of registered languages
- **`__init__(self, cache_size=1000)`** - Instance a translator
- **`from_ExprInt(self, expr)`** - Translate an ExprInt
- **`from_ExprId(self, expr)`** - Translate an ExprId
- **`from_ExprLoc(self, expr)`** - Translate an ExprLoc
- **`from_ExprCompose(self, expr)`** - Translate an ExprCompose
- **`from_ExprSlice(self, expr)`** - Translate an ExprSlice
- **`from_ExprOp(self, expr)`** - Translate an ExprOp
- **`from_ExprMem(self, expr)`** - Translate an ExprMem
- **`from_ExprAssign(self, expr)`** - Translate an ExprAssign
- **`from_ExprCond(self, expr)`** - Translate an ExprCond
- **`from_expr(self, expr)`** - Translate an expression according to its type
