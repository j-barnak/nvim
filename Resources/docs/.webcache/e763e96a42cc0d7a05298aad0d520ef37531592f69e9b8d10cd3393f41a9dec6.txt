# angr.analyses.decompiler.optimization_pass_registry

Stable name resolution for decompiler optimization passes and peephole optimizations.

angr.analyses.decompiler.optimization_pass_registry.name_to_pass(*name*)  
Resolve a class name back to its registered pass class. Returns None for names that are not registered at the time this method is called. Peephole passes might be defined by analyses or plugins that have not yet been imported.
