CLI can refer to multiple things:

- [Common Language Infrastructure](https://wiki.osdev.org/index.php?title=Common_Language_Infrastructure&action=edit&redlink=1 "Common Language Infrastructure (page does not exist)") of the .NET framework
- [Command Line](https://wiki.osdev.org/Command_Line "Command Line") Interface
- [CLear Interrupt](https://wiki.osdev.org/CLI_(Assembly) "CLI (Assembly)") flag - An assembly instruction to disable all interrupts
