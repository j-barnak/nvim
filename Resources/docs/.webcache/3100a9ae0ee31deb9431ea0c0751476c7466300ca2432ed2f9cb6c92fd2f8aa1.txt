## What is SILO

SILO stands for "Sparc Improved boot LOader", it is a Linux [bootloader](https://wiki.osdev.org/Bootloader "Bootloader") on [SPARC](https://wiki.osdev.org/index.php?title=SPARC&action=edit&redlink=1 "SPARC (page does not exist)") and [UltraSPARC](https://wiki.osdev.org/UltraSPARC "UltraSPARC") platforms. SILO can load Linux, Solaris from [ext2](https://wiki.osdev.org/Ext2 "Ext2"), [ext3](https://wiki.osdev.org/Ext3 "Ext3"), [FFS\_(BSD)](https://wiki.osdev.org/FFS_(BSD) "FFS (BSD)"), [ISO_9660](https://wiki.osdev.org/ISO_9660 "ISO 9660") and ROMFS

SILO is capable of booting uncompressed or gzipped kernel images from the filesystems it supports.

## SILO usage

When SILO is loaded at the boot prompt the path to the image to be booted can be passed manually or via an alias from the silo.conf file. Pressing tab lists aliases in the silo.conf file. Typing "halt" sends you back to the boot prom. Pressing "enter" or "return" boots the defualt image.

## Installation

To create a bootable cdrom image for [QEMU](https://wiki.osdev.org/QEMU "QEMU") or real hardware. Note that second.b (the secondary bootblock) and silo.conf need to be edited to reflect your target filesystem and should be in the boot directory of the target filesystem.

``` text
mkisofs -G /boot/isofs.b -B ... -r -o IMAGENAME DIRECTORY_TREE
```

For floppy drive images. The following should be done with silo on an actual [SPARC](https://wiki.osdev.org/index.php?title=SPARC&action=edit&redlink=1 "SPARC (page does not exist)") or emulated machine. Another option is to try and get intelsilo to work. [genromfs](https://wiki.osdev.org/index.php?title=Genromfs&action=edit&redlink=1 "Genromfs (page does not exist)") should be downloaded and installed if you have not already done so.

``` text
genromfs -d floppy/ -f /dev/ram -A 2048,/.. -a 512 -V 'My installation disk'
mount -t romfs /dev/ram /mnt
silo -r /mnt -F -i /boot/fd.b -b /boot/second.b -C /etc/silo.conf
umount /mnt
dd if=/dev/ram of=floppy.img bs=1440k count=1
```

## Caveats

SILO can only load images within the first 1GB of a disk. This means that partitions and or files beyond 1GB are not bootable.
