BFI (Build Floppy Image) creates FAT12-formatted floppy images from the command line, inserting the user's bootsector and files. It is created using the [Win Image](https://wiki.osdev.org/Win_Image "Win Image") SDK. BFI is available [here](http://www.nu2.nu/bfi/) ([archive](https://web.archive.org/web/20090301055639/http://nu2.nu/bfi/))
