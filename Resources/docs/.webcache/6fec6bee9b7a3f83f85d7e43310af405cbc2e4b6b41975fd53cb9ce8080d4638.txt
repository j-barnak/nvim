# angr.analyses.cfg.pe_msvc_eh_structs

Struct definitions and parsing utilities for MSVC C++ exception handling structures found in x86 PE binaries.

References: - \_\_\_CxxFrameHandler3: The MSVC C++ exception handler for 32-bit binaries. - \_\_EH_prolog3 / \_\_EH_prolog3_catch / \_\_EH_prolog3_GS: C++ EH prolog helpers. - \_\_SEH_prolog4 / \_\_SEH_prolog4_GS: SEH prolog helpers. - FuncInfo: Describes exception handling metadata for a function. - UnwindMapEntry: Describes state unwinding actions during exception handling.
