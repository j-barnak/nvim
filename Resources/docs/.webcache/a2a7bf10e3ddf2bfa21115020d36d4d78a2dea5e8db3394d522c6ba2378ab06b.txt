### 27.8 Process Completion Status

If the exit status value (see [Program Termination](https://sourceware.org/glibc/manual/latest/html_node/Program-Termination.html)) of the child process is zero, then the status value reported by `waitpid` or `wait` is also zero. You can test for other kinds of information encoded in the returned status value using the following macros. These macros are defined in the header file `sys/wait.h`.

Macro: `int` **WIFEXITED** `(int ``status``)`  
Preliminary: \| MT-Safe \| AS-Safe \| AC-Safe \| See [POSIX Safety Concepts](https://sourceware.org/glibc/manual/latest/html_node/POSIX-Safety-Concepts.html).

This macro returns a nonzero value if the child process terminated normally with `exit` or `_exit`.

&nbsp;

Macro: `int` **WEXITSTATUS** `(int ``status``)`  
Preliminary: \| MT-Safe \| AS-Safe \| AC-Safe \| See [POSIX Safety Concepts](https://sourceware.org/glibc/manual/latest/html_node/POSIX-Safety-Concepts.html).

If `WIFEXITED` is true of `status`, this macro returns the low-order 8 bits of the exit status value from the child process. See [Exit Status](https://sourceware.org/glibc/manual/latest/html_node/Exit-Status.html).

&nbsp;

Macro: `int` **WIFSIGNALED** `(int ``status``)`  
Preliminary: \| MT-Safe \| AS-Safe \| AC-Safe \| See [POSIX Safety Concepts](https://sourceware.org/glibc/manual/latest/html_node/POSIX-Safety-Concepts.html).

This macro returns a nonzero value if the child process terminated because it received a signal that was not handled. See [Signal Handling](https://sourceware.org/glibc/manual/latest/html_node/Signal-Handling.html).

&nbsp;

Macro: `int` **WTERMSIG** `(int ``status``)`  
Preliminary: \| MT-Safe \| AS-Safe \| AC-Safe \| See [POSIX Safety Concepts](https://sourceware.org/glibc/manual/latest/html_node/POSIX-Safety-Concepts.html).

If `WIFSIGNALED` is true of `status`, this macro returns the signal number of the signal that terminated the child process.

&nbsp;

Macro: `int` **WCOREDUMP** `(int ``status``)`  
Preliminary: \| MT-Safe \| AS-Safe \| AC-Safe \| See [POSIX Safety Concepts](https://sourceware.org/glibc/manual/latest/html_node/POSIX-Safety-Concepts.html).

This macro returns a nonzero value if the child process terminated and produced a core dump.

This macro was originally a BSD extension, but was added in POSIX.1-2024.

&nbsp;

Macro: `int` **WIFSTOPPED** `(int ``status``)`  
Preliminary: \| MT-Safe \| AS-Safe \| AC-Safe \| See [POSIX Safety Concepts](https://sourceware.org/glibc/manual/latest/html_node/POSIX-Safety-Concepts.html).

This macro returns a nonzero value if the child process is stopped.

&nbsp;

Macro: `int` **WSTOPSIG** `(int ``status``)`  
Preliminary: \| MT-Safe \| AS-Safe \| AC-Safe \| See [POSIX Safety Concepts](https://sourceware.org/glibc/manual/latest/html_node/POSIX-Safety-Concepts.html).

If `WIFSTOPPED` is true of `status`, this macro returns the signal number of the signal that caused the child process to stop.
