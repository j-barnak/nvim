classmethod parse_header(*file_obj*)  
Parse only the FLIRT signature header (no function tree).

The returned object has `root` set to None. Use [`parse()`](#angr.analyses.flirt.flirt_sig.FlirtSignatureParsed.parse "angr.analyses.flirt.flirt_sig.FlirtSignatureParsed.parse") if you also need the function tree, or call `parse_tree_from()` later on a separately opened file to populate `root` on demand.
