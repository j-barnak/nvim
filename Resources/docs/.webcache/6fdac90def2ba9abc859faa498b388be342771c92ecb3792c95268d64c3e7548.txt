Expand description

Equivalent to C’s `unsigned long` type.

This type will always be [`u32`](https://doc.rust-lang.org/std/primitive.u32.html "primitive u32") or [`u64`](https://doc.rust-lang.org/std/primitive.u64.html "primitive u64"). Most notably, many Linux-based systems assume an `u64`, but Windows assumes `u32`. The C standard technically only requires that this type be an unsigned integer with the size of a [`long`](https://doc.rust-lang.org/std/os/raw/type.c_long.html "type std::os::raw::c_long"), although in practice, no system would have a `ulong` that is neither a `u32` nor `u64`.
