pub struct ChildStdout { /* private fields */ }

Expand description

A handle to a child process’s standard output (stdout).

This struct is used in the [`stdout`](https://doc.rust-lang.org/std/process/struct.Child.html#structfield.stdout "field std::process::Child::stdout") field on [`Child`](https://doc.rust-lang.org/std/process/struct.Child.html "struct std::process::Child").

When an instance of `ChildStdout` is [dropped](https://doc.rust-lang.org/std/ops/trait.Drop.html "trait std::ops::Drop"), the `ChildStdout`’s underlying file handle will be closed.

Converts a [`ChildStdout`](https://doc.rust-lang.org/std/process/struct.ChildStdout.html "struct std::process::ChildStdout") into a [`Stdio`](https://doc.rust-lang.org/std/process/struct.Stdio.html "struct std::process::Stdio").

##### Examples

`ChildStdout` will be converted to `Stdio` using `Stdio::from` under the hood.

``` rust
use std::process::{Command, Stdio};

let hello = Command::new("echo")
    .arg("Hello, world!")
    .stdout(Stdio::piped())
    .spawn()
    .expect("failed echo command");

let reverse = Command::new("rev")
    .stdin(hello.stdout.unwrap())  // Converted into a Stdio here
    .output()
    .expect("failed reverse command");

assert_eq!(reverse.stdout, b"!dlrow ,olleH\n");
```
