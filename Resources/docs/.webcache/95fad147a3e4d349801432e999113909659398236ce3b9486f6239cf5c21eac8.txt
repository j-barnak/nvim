# Function align_of_val Copy item path

1.0.0 (const: 1.85.0) · [Source](https://doc.rust-lang.org/src/core/mem/mod.rs.html#578)

``` rust
pub const fn align_of_val<T>(val: &T) -> usizewhere
    T: ?Sized,
```

Expand description

Returns the [ABI](https://en.wikipedia.org/wiki/Application_binary_interface)-required minimum alignment of the type of the value that `val` points to, in bytes.

This function is identical to [`align_of::<T>()`](https://doc.rust-lang.org/std/mem/fn.align_of.html "fn std::mem::align_of") whenever `T: `[`Sized`](https://doc.rust-lang.org/std/marker/trait.Sized.html "trait std::marker::Sized"), but also supports determining the alignment required by a `dyn Trait` value, which is the alignment of the underlying concrete type.

## Examples

``` rust
assert_eq!(4, align_of_val(&5i32));
```

(Caution: [it is not guaranteed](https://doc.rust-lang.org/reference/type-layout.html#r-layout.primitive) that the alignment of `i32` is `4`; that is, this example assertion does not pass on all platforms.)

`dyn` types may have different alignments for different values; `align_of_val` can be used to learn those alignments:

``` rust
let a: &dyn ToString = &1234u16;
let b: &dyn ToString = &String::from("abcd");

assert_eq!(align_of_val(a), align_of::<u16>());
assert_eq!(align_of_val(b), align_of::<String>());
```
