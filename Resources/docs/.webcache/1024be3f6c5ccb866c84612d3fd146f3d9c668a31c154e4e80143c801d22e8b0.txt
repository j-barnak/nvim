### class `heap(object)`

Light heap simulation

- **`next_addr(self, size)`** - @size: the size to allocate
- **`alloc(self, jitter, size, perm=PAGE_READ | PAGE_WRITE, cmt='')`** - @jitter: a jitter instance
- **`vm_alloc(self, vm, size, perm=PAGE_READ | PAGE_WRITE, cmt='')`** - @vm: a VmMngr instance
- **`get_size(self, vm, ptr)`** - @vm: a VmMngr instance
