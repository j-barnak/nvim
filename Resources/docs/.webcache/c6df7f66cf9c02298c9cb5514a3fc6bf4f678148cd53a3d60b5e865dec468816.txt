# Enum Locality Copy item path

[Source](https://doc.rust-lang.org/src/core/hint.rs.html#897)

``` rust
#[non_exhaustive]pub enum Locality {
    L3,
    L2,
    L1,
}
```

🔬This is a nightly-only experimental API. (`hint_prefetch` [\#146941](https://github.com/rust-lang/rust/issues/146941))

Expand description

The expected temporal locality of a memory prefetch operation.

Locality expresses how likely the prefetched data is to be reused soon, and therefore which level of cache it should be brought into.

The locality is just a hint, and may be ignored on some targets or by the hardware.

Used with functions like [`prefetch_read`](https://doc.rust-lang.org/std/hint/fn.prefetch_read.html "fn std::hint::prefetch_read") and [`prefetch_write`](https://doc.rust-lang.org/std/hint/fn.prefetch_write.html "fn std::hint::prefetch_write").

Typically prefetches into L3 cache (if the CPU supports it).

Typically prefetches into L2 cache.

Typically prefetches into L1 cache.
