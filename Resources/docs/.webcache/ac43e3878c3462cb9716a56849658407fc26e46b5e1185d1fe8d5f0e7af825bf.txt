🔬This is a nightly-only experimental API. (`waker_fn` [\#149580](https://github.com/rust-lang/rust/issues/149580))

Expand description

Converts a closure into a [`LocalWaker`](https://doc.rust-lang.org/std/task/struct.LocalWaker.html "struct std::task::LocalWaker").

The closure gets called every time the local waker is woken.

## Examples

``` rust
#![feature(local_waker)]
#![feature(waker_fn)]
use std::task::local_waker_fn;

let waker = local_waker_fn(|| println!("woken"));

waker.wake_by_ref(); // Prints "woken".
waker.wake();        // Prints "woken".
```
