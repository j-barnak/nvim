🔬This is a nightly-only experimental API. (`slice_range` [\#76393](https://github.com/rust-lang/rust/issues/76393))

Expand description

Performs bounds checking of a range without panicking.

This is a version of [`range()`](https://doc.rust-lang.org/std/slice/fn.range.html "fn std::slice::range") that returns [`None`](https://doc.rust-lang.org/std/option/enum.Option.html#variant.None "variant std::option::Option::None") instead of panicking.

## Examples

``` rust
#![feature(slice_range)]

use std::slice;

let v = [10, 40, 30];
assert_eq!(Some(1..2), slice::try_range(1..2, ..v.len()));
assert_eq!(Some(0..2), slice::try_range(..2, ..v.len()));
assert_eq!(Some(1..3), slice::try_range(1.., ..v.len()));
```

Returns [`None`](https://doc.rust-lang.org/std/option/enum.Option.html#variant.None "variant std::option::Option::None") when [`Index::index`](https://doc.rust-lang.org/std/ops/trait.Index.html#tymethod.index "method std::ops::Index::index") would panic:

``` rust
#![feature(slice_range)]

use std::slice;

assert_eq!(None, slice::try_range(2..1, ..3));
assert_eq!(None, slice::try_range(1..4, ..3));
assert_eq!(None, slice::try_range(1..=usize::MAX, ..3));
```
