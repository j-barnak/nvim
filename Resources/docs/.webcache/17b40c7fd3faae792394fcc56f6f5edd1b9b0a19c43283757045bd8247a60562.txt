# Function copy Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/std/io/copy.rs.html#62-73)

``` rust
pub fn copy<R, W>(reader: &mut R, writer: &mut W) -> Result<u64>where
    R: Read + ?Sized,
    W: Write + ?Sized,
```

Expand description

Copies the entire contents of a reader into a writer.

This function will continuously read data from `reader` and then write it into `writer` in a streaming fashion until `reader` returns EOF.

On success, the total number of bytes that were copied from `reader` to `writer` is returned.

If you want to copy the contents of one file to another and you’re working with filesystem paths, see the [`fs::copy`](https://doc.rust-lang.org/std/fs/fn.copy.html "fn std::fs::copy") function.

## Errors

This function will return an error immediately if any call to [`read`](https://doc.rust-lang.org/std/io/trait.Read.html#tymethod.read "method std::io::Read::read") or [`write`](https://doc.rust-lang.org/std/io/trait.Write.html#tymethod.write "method std::io::Write::write") returns an error. All instances of [`ErrorKind::Interrupted`](https://doc.rust-lang.org/std/io/enum.ErrorKind.html#variant.Interrupted "variant std::io::ErrorKind::Interrupted") are handled by this function and the underlying operation is retried.

## Examples

``` rust
use std::io;

fn main() -> io::Result<()> {
    let mut reader: &[u8] = b"hello";
    let mut writer: Vec<u8> = vec![];

    io::copy(&mut reader, &mut writer)?;

    assert_eq!(&b"hello"[..], &writer[..]);
    Ok(())
}
```

## Platform-specific behavior

On Linux (including Android), this function uses `copy_file_range(2)`, `sendfile(2)` or `splice(2)` syscalls to move data directly between file descriptors if possible.

Note that platform-specific behavior [may change in the future](https://doc.rust-lang.org/std/io/index.html#platform-specific-behavior "mod std::io").
