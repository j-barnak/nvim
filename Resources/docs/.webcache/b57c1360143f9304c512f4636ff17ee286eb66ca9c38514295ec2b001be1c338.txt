# Searching Memory

Memory can be searched for specific values or patterns with the following functions.

drgn.search_memory(*value: [Union](https://docs.python.org/3/library/typing.html#typing.Union "(in Python v3.14)")\[[bytes](https://docs.python.org/3/library/stdtypes.html#bytes "(in Python v3.14)"), [str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")\]*, *\**, *alignment: [int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)") = 1*) → [MemorySearchIterator](#drgn.MemorySearchIterator "drgn.MemorySearchIterator")\[[int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")\]  
Search for all non-overlapping occurrences of a byte string in the [default program’s](#default-program) memory.

    for address in search_memory(b"VMCOREINFO"):
        print(hex(address))

Parameters:  
- **value** – Byte string to search for. If given as a [`str`](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)"), then this searches for its UTF-8 encoding.

- **alignment** – Only consider addresses aligned to this value (i.e., `address`` ``%`` ``alignment`` ``==`` ``0`). Must be a power of two.

Returns:  
Iterator of addresses where the string is found.

&nbsp;

drgn.search_memory(*value: [Union](https://docs.python.org/3/library/typing.html#typing.Union "(in Python v3.14)")\[[IntegerLike](#drgn.IntegerLike "drgn.IntegerLike"), [Object](#drgn.Object "drgn.Object")\]*) → [MemorySearchIterator](#drgn.MemorySearchIterator "drgn.MemorySearchIterator")\[[int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")\]  
Search for all occurrences of a value in the [default program’s](#default-program) memory.

    ptr = stack_trace(pid)[2]["ptr"]
    for address in search_memory(ptr):
        print(hex(address))

Parameters:  
**value** – Value to search for. If given as an [`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)"), then it is interpreted as a program word-sized, naturally aligned unsigned integer. If given as an [`Object`](#drgn.Object "drgn.Object"), then its size and alignment are determined from its type.

Returns:  
Iterator of addresses where the value is found.

drgn.search_memory_word(*\*values: [Union](https://docs.python.org/3/library/typing.html#typing.Union "(in Python v3.14)")\[[IntegerLike](#drgn.IntegerLike "drgn.IntegerLike"), [Tuple](https://docs.python.org/3/library/typing.html#typing.Tuple "(in Python v3.14)")\[[IntegerLike](#drgn.IntegerLike "drgn.IntegerLike"), [IntegerLike](#drgn.IntegerLike "drgn.IntegerLike")\]\]*, *ignore_mask: [IntegerLike](#drgn.IntegerLike "drgn.IntegerLike") = 0*) → [MemorySearchIterator](#drgn.MemorySearchIterator "drgn.MemorySearchIterator")\[[Tuple](https://docs.python.org/3/library/typing.html#typing.Tuple "(in Python v3.14)")\[[int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)"), [int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")\]\]  
Search for all occurrences of one or more unsigned integers in the [default program’s](#default-program) memory.

[`search_memory_u16()`](#drgn.search_memory_u16 "drgn.search_memory_u16"), [`search_memory_u32()`](#drgn.search_memory_u32 "drgn.search_memory_u32"), and [`search_memory_u64()`](#drgn.search_memory_u64 "drgn.search_memory_u64") search for 16-, 32- or 64-bit unsigned integers, respectively. [`search_memory_word()`](#drgn.search_memory_word "drgn.search_memory_word") searches for program word-sized unsigned integers. Natural alignment is assumed (i.e., 2-byte alignment for 16-bit integers, 4-byte alignment for 32-bit integers, 8-byte alignment for 64-bit integers).

    for address, value in search_memory_word(
        0xdead000000000100, 0xdead000000000122
    ):
        print(hex(address), hex(value))

    for address, value in search_memory_word(
        0xdead000000000000, ignore_mask=0xffff
    ):
        print(hex(address), hex(value))

    obj = prog["obj"]
    for address, value in search_memory_word(
        (obj.address_, obj.address_ + sizeof(obj) - 1)
    ):
        print(hex(address), hex(value))

Parameters:  
- **values** – Values to search for. Each value may be a single integer or a `(min,`` ``max)` range (where both ends are included).

- **ignore_mask** – Mask of bits to ignore when comparing to single integers given in *values*. This is not used when comparing to ranges.

Returns:  
Iterator of addresses where the value is found and the found value.

drgn.search_memory_regex(*pattern: [bytes](https://docs.python.org/3/library/stdtypes.html#bytes "(in Python v3.14)")*) → [MemorySearchIterator](#drgn.MemorySearchIterator "drgn.MemorySearchIterator")\[[Tuple](https://docs.python.org/3/library/typing.html#typing.Tuple "(in Python v3.14)")\[[int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)"), [bytes](https://docs.python.org/3/library/stdtypes.html#bytes "(in Python v3.14)")\]\]  

&nbsp;

drgn.search_memory_regex(*pattern: [str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")*) → [MemorySearchIterator](#drgn.MemorySearchIterator "drgn.MemorySearchIterator")\[[Tuple](https://docs.python.org/3/library/typing.html#typing.Tuple "(in Python v3.14)")\[[int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)"), [str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")\]\]  
Search for all non-overlapping matches of a regular expression pattern in the program’s memory.

    # Search for anything that looks like root's password encrypted in
    # /etc/shadow.
    for address, match in search_memory_regex(rb"root:\$\w+\$[ -9;-~]+:"):
        print(hex(address), match)

Parameters:  
**pattern** – PCRE regular expression to search for. If given as [`bytes`](https://docs.python.org/3/library/stdtypes.html#bytes "(in Python v3.14)"), then search for 8-bit strings. If given as [`str`](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)"), then search for Unicode strings. Note that lookbehind assertions are not allowed.

Returns:  
Iterator of addresses where a match is found and the matching string.

To search programs other than the default program, these are also available as methods ([`Program.search_memory()`](#drgn.Program.search_memory "drgn.Program.search_memory"), [`Program.search_memory_u16()`](#drgn.Program.search_memory_u16 "drgn.Program.search_memory_u16"), [`Program.search_memory_u32()`](#drgn.Program.search_memory_u32 "drgn.Program.search_memory_u32"), [`Program.search_memory_u64()`](#drgn.Program.search_memory_u64 "drgn.Program.search_memory_u64"), [`Program.search_memory_word()`](#drgn.Program.search_memory_word "drgn.Program.search_memory_word"), and [`Program.search_memory_regex()`](#drgn.Program.search_memory_regex "drgn.Program.search_memory_regex")).

These functions/methods all return the following special iterator type.

*class *drgn.MemorySearchIterator  
Bases: [`Iterator`](https://docs.python.org/3/library/typing.html#typing.Iterator "(in Python v3.14)")\[`T`\]

Iterator returned by [memory searches](#api-searching-memory).

set_address_range(*min_address: [Optional](https://docs.python.org/3/library/typing.html#typing.Optional "(in Python v3.14)")\[[IntegerLike](#drgn.IntegerLike "drgn.IntegerLike")\] = None*, *max_address: [Optional](https://docs.python.org/3/library/typing.html#typing.Optional "(in Python v3.14)")\[[IntegerLike](#drgn.IntegerLike "drgn.IntegerLike")\] = None*, *physical: [bool](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)") = False*) → [Self](https://docs.python.org/3/library/typing.html#typing.Self "(in Python v3.14)")  
Set the address range to limit a memory search to.

This returns the iterator itself, so it can be used conveniently when the iterator is created:

    for address in search_memory(b"VMCOREINFO").set_address_range(physical=True):
        print(hex(address))

It can also be called during or after iteration, allowing an iterator to be reused for searching multiple ranges:

    it = search_memory_regex(some_complex_pattern)

    for min_address, max_address in address_ranges:
        it.set_address_range(min_address, max_address)
        for address, match in it:
            print(hex(address), match)

Parameters:  
- **min_address** – Minimum address to search (inclusive). Defaults to the program’s minimum address.

- **max_address** – Maximum address to search (inclusive). Defaults to the program’s maximum address.

- **physical** – Whether to search physical memory. Defaults to `False` (virtual memory).
