Expand description

A handle to the standard error stream of a process.

For more information, see the [`io::stderr`](https://doc.rust-lang.org/std/io/fn.stderr.html "fn std::io::stderr") method.

#### Note: Windows Portability Considerations

When operating in a console, the Windows implementation of this stream does not support non-UTF-8 byte sequences. Attempting to write bytes that are not valid UTF-8 will return an error.

In a process with a detached console, such as one using `#![windows_subsystem = "windows"]`, or in a child process spawned from such a process, the contained handle will be null. In such cases, the standard library’s `Read` and `Write` will do nothing and silently succeed. All other I/O operations, via the standard library or via raw Windows API calls, will fail.

1.0.0 · [Source](https://doc.rust-lang.org/src/std/io/stdio.rs.html#998-1003)

Locks this handle to the standard error stream, returning a writable guard.

The lock is released when the returned lock goes out of scope. The returned guard also implements the [`Write`](https://doc.rust-lang.org/std/io/trait.Write.html "trait std::io::Write") trait for writing data.

##### Examples

``` rust
use std::io::{self, Write};

fn foo() -> io::Result<()> {
    let stderr = io::stderr();
    let mut handle = stderr.lock();

    handle.write_all(b"hello world")?;

    Ok(())
}
```
