Expand description

Deallocates memory with the global allocator.

This function forwards calls to the [`GlobalAlloc::dealloc`](https://doc.rust-lang.org/std/alloc/trait.GlobalAlloc.html#tymethod.dealloc "method std::alloc::GlobalAlloc::dealloc") method of the allocator registered with the `#[global_allocator]` attribute if there is one, or the `std` crate’s default.

This function is expected to be deprecated in favor of the `deallocate` method of the [`Global`](https://doc.rust-lang.org/std/alloc/struct.Global.html "struct std::alloc::Global") type when it and the [`Allocator`](https://doc.rust-lang.org/std/alloc/trait.Allocator.html "trait std::alloc::Allocator") trait become stable.

## Safety

See [`GlobalAlloc::dealloc`](https://doc.rust-lang.org/std/alloc/trait.GlobalAlloc.html#tymethod.dealloc "method std::alloc::GlobalAlloc::dealloc").
