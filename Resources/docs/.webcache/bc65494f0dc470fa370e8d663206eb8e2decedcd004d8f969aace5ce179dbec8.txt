``` rust
pub const fn type_id_eq(a: TypeId, b: TypeId) -> bool
```

🔬This is a nightly-only experimental API. (`core_intrinsics`)

Expand description

Tests (at compile-time) if two [`crate::any::TypeId`](https://doc.rust-lang.org/std/any/struct.TypeId.html "struct std::any::TypeId") instances identify the same type. This is necessary because at const-eval time the actual discriminating data is opaque and cannot be inspected directly.

The stabilized version of this intrinsic is the [PartialEq](https://doc.rust-lang.org/std/cmp/trait.PartialEq.html "trait std::cmp::PartialEq") impl for [`core::any::TypeId`](https://doc.rust-lang.org/std/any/struct.TypeId.html "struct std::any::TypeId").
