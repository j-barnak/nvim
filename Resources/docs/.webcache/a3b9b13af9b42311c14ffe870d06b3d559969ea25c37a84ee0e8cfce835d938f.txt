# Trait DirEntryExt Copy item path

1.1.0 · [Source](https://doc.rust-lang.org/src/std/os/unix/fs.rs.html#985-1006)

``` rust
pub trait DirEntryExt {
    // Required method
    fn ino(&self) -> u64;
}
```

Available on **Unix** only.

Expand description

Unix-specific extension methods for [`fs::DirEntry`](https://doc.rust-lang.org/std/fs/struct.DirEntry.html "struct std::fs::DirEntry").

## Required Methods

1.1.0 · [Source](https://doc.rust-lang.org/src/std/os/unix/fs.rs.html#1005)

Returns the underlying `d_ino` field in the contained `dirent` structure.

##### Examples

``` rust
use std::fs;
use std::os::unix::fs::DirEntryExt;

if let Ok(entries) = fs::read_dir(".") {
    for entry in entries {
        if let Ok(entry) = entry {
            // Here, `entry` is a `DirEntry`.
            println!("{:?}: {}", entry.file_name(), entry.ino());
        }
    }
}
```
