\[**python api**\] All information about the REG Python namespace.

#  Description

------------------------------------------------------------------------

According to the CPU architecture, the REG namespace contains all enums of registers. It's possible to create a [Register](https://triton-library.github.io/documentation/doxygen/py_Register_page.html) from a register id using `getRegister` like this:

\>\>\> ah = ctxt.getRegister(REG.X86_64.AH)

\>\>\> print ah

ah:8 bv\[15..8\]

Note that creating a [TritonContext](https://triton-library.github.io/documentation/doxygen/py_TritonContext_page.html), you can directly access the constructed [Register](https://triton-library.github.io/documentation/doxygen/py_Register_page.html) according to your defined architecture.

\>\>\> ctxt.setArchitecture(ARCH.X86_64)

\>\>\> print ctxt.registers.zmm1

zmm1:512 bv\[511..0\]
