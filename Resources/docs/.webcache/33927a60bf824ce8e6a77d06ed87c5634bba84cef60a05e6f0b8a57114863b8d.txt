# Keyword type Copy item path

[Source](https://doc.rust-lang.org/src/std/core/src/keyword_docs.rs.html#2027)

Expand description

Define an [alias](https://doc.rust-lang.org/reference/items/type-aliases.html) for an existing type.

The syntax is `type Name = ExistingType;`.

## Examples

`type` does **not** create a new type:

``` rust
type Meters = u32;
type Kilograms = u32;

let m: Meters = 3;
let k: Kilograms = 3;

assert_eq!(m, k);
```

A type can be generic:

``` rust
type ArcMutex<T> = Arc<Mutex<T>>;
```

In traits, `type` is used to declare an [associated type](https://doc.rust-lang.org/reference/items/associated-items.html#associated-types):

``` rust
trait Iterator {
    // associated type declaration
    type Item;
    fn next(&mut self) -> Option<Self::Item>;
}

struct Once<T>(Option<T>);

impl<T> Iterator for Once<T> {
    // associated type definition
    type Item = T;
    fn next(&mut self) -> Option<Self::Item> {
        self.0.take()
    }
}
```
