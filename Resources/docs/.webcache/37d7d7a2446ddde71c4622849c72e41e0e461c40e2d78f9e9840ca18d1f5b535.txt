# miasm.analysis.sandbox

## Classes

### class `Sandbox(object)`

Parent class for Sandbox abstraction

- **`code_sentinelle(jitter)`**
- **`_classes_(cls)`** - Iterator on parent classes except Sanbox
- **`__init__(self, loc_db, fname, options, custom_methods=None, **kwargs)`** - Initialize a sandbox
- **`parser(cls, *args, **kwargs)`** - Return instance of instance parser with expecting options.
- **`run(self, addr=None)`** - Launch emulation (gdbserver, debugging, basic JIT).
- **`call(self, prepare_cb, addr, *args)`** - Direct call of the function at @addr, with arguments @args prepare in
