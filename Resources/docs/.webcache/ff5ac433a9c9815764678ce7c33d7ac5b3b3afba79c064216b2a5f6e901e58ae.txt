# [`pwnlib.tubes.ssh`](#module-pwnlib.tubes.ssh "pwnlib.tubes.ssh") — SSH

Parameters:  
- **user** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – The username to log in with

- **port** ([*int*](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")) – The port to connect to

- **password** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Try to authenticate using this password

- **key** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Try to authenticate using this private key. The string should be the actual private key.

- **keyfile** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Try to authenticate using this private key. The string should be a filename.

- **proxy_command** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Use this as a proxy command. It has approximately the same semantics as ProxyCommand from ssh(1).

- **proxy_sock** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Use this socket instead of connecting to the host.

- **timeout** – Timeout, in seconds

- **level** – Log level

- **cache** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – Cache downloaded files (by hash/size/timestamp)

- **ssh_agent** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – If `True`, enable usage of keys via ssh-agent

- **ignore_config** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – If `True`, disable usage of ~/.ssh/config and ~/.ssh/authorized_keys

- **raw** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – If `True`, assume a non-standard shell and don’t probe the environment

- **auth_none** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – If `True`, try to authenticate with no authentication methods

NOTE: The proxy_command and proxy_sock arguments is only available if a fairly new version of paramiko is used.

Example proxying:

     >>> s1 = ssh(host='example.pwnme')
     >>> r1 = s1.remote('localhost', 22)
     >>> s2 = ssh(host='example.pwnme', proxy_sock=r1.sock)
     >>> r2 = s2.remote('localhost', 22) # and so on...
     >>> for x in r2, s2, r1, s1: x.close()

process(*argv=None*, *executable=None*, *tty=True*, *cwd=None*, *env=None*, *ignore_environ=None*, *timeout=pwnlib.timeout.Timeout.default*, *run=True*, *stdin=0*, *stdout=1*, *stderr=2*, *preexec_fn=None*, *preexec_args=()*, *raw=True*, *aslr=None*, *setuid=None*, *shell=False*)[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/tubes/ssh.py#L787-L1028)  
Executes a process on the remote server, in the same fashion as pwnlib.tubes.process.process.

To achieve this, a Python script is created to call `os.execve` with the appropriate arguments.

As an added bonus, the `ssh_channel` object returned has a `pid` property for the process pid.

Parameters:  
- **argv** ([*list*](https://docs.python.org/3/library/stdtypes.html#list "(in Python v3.14)")) – List of arguments to pass into the process

- **executable** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Path to the executable to run. If `None`, `argv[0]` is used.

- **tty** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – Request a tty from the server. This usually fixes buffering problems by causing libc to write data immediately rather than buffering it. However, this disables interpretation of control codes (e.g. Ctrl+C) and breaks .shutdown.

- **cwd** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Working directory. If `None`, uses the working directory specified on `cwd` or set via [`set_working_directory()`](#pwnlib.tubes.ssh.ssh.set_working_directory "pwnlib.tubes.ssh.ssh.set_working_directory").

- **env** ([*dict*](https://docs.python.org/3/library/stdtypes.html#dict "(in Python v3.14)")) – Environment variables to add to the environment.

- **ignore_environ** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – Ignore default environment. By default use default environment iff env not specified.

- **timeout** ([*int*](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")) – Timeout to set on the tube created to interact with the process.

- **run** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – Set to `True` to run the program (default). If `False`, returns the path to an executable Python script on the remote server which, when executed, will do it.

- **stdin** ([*int*](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")*,* [*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – If an integer, replace stdin with the numbered file descriptor. If a string, a open a file with the specified path and replace stdin with its file descriptor. May also be one of `sys.stdin`, `sys.stdout`, `sys.stderr`. If `None`, the file descriptor is closed.

- **stdout** ([*int*](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")*,* [*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – See `stdin`.

- **stderr** ([*int*](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")*,* [*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – See `stdin`.

- **preexec_fn** (*callable*) – Function which is executed on the remote side before execve(). This **MUST** be a self-contained function – it must perform all of its own imports, and cannot refer to variables outside its scope.

- **preexec_args** ([*object*](https://docs.python.org/3/library/functions.html#object "(in Python v3.14)")) – Argument passed to `preexec_fn`. This **MUST** only consist of native Python objects.

- **raw** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – If `True`, disable TTY control code interpretation.

- **aslr** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – See [`pwnlib.tubes.process.process`](https://docs.pwntools.com/en/stable/tubes/processes.html#pwnlib.tubes.process.process "pwnlib.tubes.process.process") for more information.

- **setuid** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – See [`pwnlib.tubes.process.process`](https://docs.pwntools.com/en/stable/tubes/processes.html#pwnlib.tubes.process.process "pwnlib.tubes.process.process") for more information.

- **shell** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – Pass the command-line arguments to the shell.

Returns:  
A new SSH channel, or a path to a script if `run=False`.

Notes

Requires Python on the remote server.

Examples

    >>> s = ssh(host='example.pwnme')
    >>> sh = s.process('/bin/sh', env={'PS1':''})
    >>> sh.sendline(b'echo Hello; exit')
    >>> sh.recvall()
    b'Hello\n'
    >>> s.process(['/bin/echo', b'\xff']).recvall()
    b'\xff\n'
    >>> s.process(['readlink', '/proc/self/exe']).recvall()
    b'.../bin/readlink\n'
    >>> s.process(['LOLOLOL', '/proc/self/exe'], executable='readlink').recvall()
    b'.../bin/readlink\n'
    >>> s.process(['LOLOLOL\x00', '/proc/self/cmdline'], executable='cat').recvall()
    b'LOLOLOL\x00/proc/self/cmdline\x00'
    >>> sh = s.process(executable='/bin/sh')
    >>> str(sh.pid).encode() in s.pidof('sh')
    True
    >>> io = s.process(['pwd'], cwd='/tmp')
    >>> io.recvall()
    b'/tmp\n'
    >>> io.cwd
    '/tmp'
    >>> p = s.process(['python','-c','import os; os.write(1, os.read(2, 1024))'], stderr=0)
    >>> p.send(b'hello')
    >>> p.recv()
    b'hello'
    >>> s.process(['/bin/echo', 'hello']).recvall()
    b'hello\n'
    >>> s.process(['/bin/echo', 'hello'], stdout='/dev/null').recvall()
    b''
    >>> s.process(['/usr/bin/env'], env={}).recvall()
    b''
    >>> s.process('/usr/bin/env', env={'A':'B'}).recvall()
    b'A=B\n'

    >>> s.process('false', preexec_fn=1234)
    Traceback (most recent call last):
    ...
    PwnlibException: preexec_fn must be a function

    >>> s.process('false', preexec_fn=lambda: 1234)
    Traceback (most recent call last):
    ...
    PwnlibException: preexec_fn cannot be a lambda

    >>> def uses_globals():
    ...     foo = bar
    >>> print(s.process('false', preexec_fn=uses_globals).recvall().strip().decode())
    Traceback (most recent call last):
    ...
    NameError: ...name 'bar' is not defined

    >>> s.process('echo hello', shell=True).recvall()
    b'hello\n'

    >>> io = s.process(['cat'], timeout=5)
    >>> io.recvline()
    b''

    >>> # Testing that empty argv works
    >>> io = s.process([], executable='sh')
    >>> io.sendline(b'echo $0')
    >>> io.recvline()
    b'$ \n'
    >>> # Make sure that we have a shell
    >>> io.sendline(b'echo hello')
    >>> io.recvline()

set_working_directory(*wd=None*, *symlink=False*)[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/tubes/ssh.py#L1756-L1851)  
Sets the working directory in which future commands will be run (via ssh.run) and to which files will be uploaded/downloaded from if no path is provided

Note

This uses `mktemp`` ``-d` under the covers, sets permissions on the directory to `0700`. This means that setuid binaries will **not** be able to access files created in this directory.

In order to work around this, we also `chmod`` ``+x` the directory.

Parameters:  
- **wd** (*string*) – Working directory. Default is to auto-generate a directory based on the result of running ‘mktemp -d’ on the remote machine.

- **symlink** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")*,*[*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) –

  Create symlinks in the new directory.

  The default value, `False`, implies that no symlinks should be created.

  A string value is treated as a path that should be symlinked. It is passed directly to the shell on the remote end for expansion, so wildcards work.

  Any other value is treated as a boolean, where `True` indicates that all files in the “old” working directory should be symlinked.

Examples

    >>> s =  ssh(host='example.pwnme')
    >>> cwd = s.set_working_directory()
    >>> s.ls()
    b''
    >>> packing._decode(s.pwd()) == cwd
    True

    >>> s =  ssh(host='example.pwnme')
    >>> homedir = s.pwd()
    >>> _=s.touch('foo')

    >>> _=s.set_working_directory()
    >>> assert s.ls() == b''

    >>> _=s.set_working_directory(homedir)
    >>> assert b'foo' in s.ls().split(), s.ls().split()

    >>> _=s.set_working_directory(symlink=True)
    >>> assert b'foo' in s.ls().split(), s.ls().split()
    >>> assert homedir != s.pwd()

    >>> symlink=os.path.join(homedir,b'*')
    >>> _=s.set_working_directory(symlink=symlink)
    >>> assert b'foo' in s.ls().split(), s.ls().split()
    >>> assert homedir != s.pwd()

    >>> _=s.set_working_directory()
    >>> io = s.system('pwd')
    >>> io.recvallS().strip() == io.cwd
    True
    >>> io.cwd == s.cwd
    True
