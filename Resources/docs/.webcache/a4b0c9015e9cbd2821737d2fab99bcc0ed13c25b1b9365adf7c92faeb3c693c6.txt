# Custom serialization

Serde's [derive macro](https://serde.rs/derive.html) through `#[derive(Serialize, Deserialize)]` provides reasonable default serialization behavior for structs and enums and it can be customized to some extent using [attributes](https://serde.rs/attributes.html). For unusual needs, Serde allows full customization of the serialization behavior by manually implementing [`Serialize`](https://docs.rs/serde/1/serde/ser/trait.Serialize.html) and [`Deserialize`](https://docs.rs/serde/1/serde/de/trait.Deserialize.html) traits for your type.

The traits each have a single method:

```
pub trait Serialize {
    fn serialize<S>(&self, serializer: S) -> Result<S::Ok, S::Error>
    where
        S: Serializer;
}

pub trait Deserialize<'de>: Sized {
    fn deserialize<D>(deserializer: D) -> Result<Self, D::Error>
    where
        D: Deserializer<'de>;
}
```

These methods are generic over the serialization format, represented by the [`Serializer`](https://docs.rs/serde/1/serde/ser/trait.Serializer.html) and [`Deserializer`](https://docs.rs/serde/1/serde/de/trait.Deserializer.html) traits. For example there is one Serializer type for JSON and a different one for Postcard.
