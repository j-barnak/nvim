Expand description

A type alias for the result of a nonblocking locking method.

For more information, see [`LockResult`](https://doc.rust-lang.org/std/sync/type.LockResult.html "type std::sync::LockResult"). A `TryLockResult` doesn’t necessarily hold the associated guard in the [`Err`](https://doc.rust-lang.org/std/result/enum.Result.html#variant.Err "variant std::result::Result::Err") type as the lock might not have been acquired for other reasons.
