# Rust

Just like C/C++, Rust is a systems programming language. The tool stack for fuzzing is therefore related to the one described in the [C/C++ section](https://appsec.guide/docs/fuzzing/c-cpp/), because fuzzers in Rust may be based on those introduced earlier.

For a general introduction about fuzzing and setup (i.e., the harness, fuzzer runtime, instrumentation, and SUT), refer to the [introduction](https://appsec.guide/docs/fuzzing/#introduction-to-fuzzers).
