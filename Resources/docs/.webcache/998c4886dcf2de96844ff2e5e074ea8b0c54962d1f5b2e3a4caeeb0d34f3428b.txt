``` rust
pub const fn empty<T>() -> Empty<T> ⓘ
```

Expand description

Creates an iterator that yields nothing.

## Examples

Basic usage:

``` rust
use std::iter;

// this could have been an iterator over i32, but alas, it's just not.
let mut nope = iter::empty::<i32>();

assert_eq!(None, nope.next());
```
