# 9.3. Use mtools to manipulate disk images

Mtools is a set of programs that can read, write, and format DOS disk images. There are links to the Mtools main page and a Win32 port of Mtools on the [Bochs Links page](https://bochs.sourceforge.io/links.html), under Resources.

The mtools web site has a detailed manual. If anyone wants to write instructions specific to Bochs, we can add it right here.
