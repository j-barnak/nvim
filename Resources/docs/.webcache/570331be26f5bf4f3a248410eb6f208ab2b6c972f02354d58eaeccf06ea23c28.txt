Joliet is an extension to the [ISO 9660](https://wiki.osdev.org/ISO_9660 "ISO 9660") filesystem and was created by Microsoft in 1995. It allows longer filenames of up to 64 characters in 16-bit character set UCS-2, and relaxes some of the restrictions associated with full ISO 9660 compliance.
