`drltrace` is a library call tracing tool for all platforms. It is part of the [Dr. Memory tool suite](http://drmemory.org). It is also included with DynamoRIO versions 5.0.0 and higher.

If this documentation is part of a DynamoRIO public release, [this link](https://dynamorio.org/drmemory/drmemory/docs/html/page_drltrace.html) should point at the local documentation provided with the release package. [This one](https://dynamorio.org/page_drltrace.html) points to the online documentation.
