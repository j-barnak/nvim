A collection of powerful DynamoRIO-based tools are provided for direct use. A tool can be invoked using the option `-t` with the tool name. For example:

bin64/drrun -t drcov -- application arg1 arg2

Those interested in how the -t option works should see the section [End-User Tools](https://dynamorio.org/page_deploy.html#sec_tool_frontend).

- [Code Coverage Tool](https://dynamorio.org/page_drcov.html)
- [CPU Simulator](https://dynamorio.org/page_drcpusim.html)
- [Disassembly Tool](https://dynamorio.org/page_drdisas.html)
- [DrPoints](https://dynamorio.org/page_drpoints.html)
- [Dr. Memory Memory Debugging Tool](https://dynamorio.org/page_drmemory.html)
- [System Call Tracer for Windows](https://dynamorio.org/page_drstrace.html)
