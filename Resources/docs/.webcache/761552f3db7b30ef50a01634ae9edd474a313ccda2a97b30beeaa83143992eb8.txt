Expand description

The output of a finished process.

This is returned in a Result by either the [`output`](https://doc.rust-lang.org/std/process/struct.Command.html#method.output "method std::process::Command::output") method of a [`Command`](https://doc.rust-lang.org/std/process/struct.Command.html "struct std::process::Command"), or the [`wait_with_output`](https://doc.rust-lang.org/std/process/struct.Child.html#method.wait_with_output "method std::process::Child::wait_with_output") method of a [`Child`](https://doc.rust-lang.org/std/process/struct.Child.html "struct std::process::Child") process.

🔬This is a nightly-only experimental API. (`exit_status_error` [\#84908](https://github.com/rust-lang/rust/issues/84908))

Returns an error if a nonzero exit status was received.

If the [`Command`](https://doc.rust-lang.org/std/process/struct.Command.html "struct std::process::Command") exited successfully, `self` is returned.

This is equivalent to calling [`exit_ok`](https://doc.rust-lang.org/std/process/struct.ExitStatus.html#method.exit_ok "method std::process::ExitStatus::exit_ok") on [`Output.status`](https://doc.rust-lang.org/std/process/struct.Output.html#structfield.status "field std::process::Output::status").

Note that this will throw away the [`Output::stderr`](https://doc.rust-lang.org/std/process/struct.Output.html#structfield.stderr "field std::process::Output::stderr") field in the error case. If the child process outputs useful informantion to stderr, you can:

- Use `cmd.stderr(Stdio::inherit())` to forward the stderr child process to the parent’s stderr, usually printing it to console where the user can see it. This is usually correct for command-line applications.
- Capture `stderr` using a custom error type. This is usually correct for libraries.

##### Examples

``` rust
#![feature(exit_status_error)]
use std::process::Command;
assert!(Command::new("false").output().unwrap().exit_ok().is_err());
```
