# [`pwnlib.atexit`](#module-pwnlib.atexit "pwnlib.atexit") — Replacement for atexit

Replacement for the Python standard library’s atexit.py.

Whereas the standard [`atexit`](https://docs.python.org/3/library/atexit.html#module-atexit "(in Python v3.14)") module only defines [`atexit.register()`](https://docs.python.org/3/library/atexit.html#atexit.register "(in Python v3.14)"), this replacement module also defines [`unregister()`](#pwnlib.atexit.unregister "pwnlib.atexit.unregister").

This module also fixes a the issue that exceptions raised by an exit handler is printed twice when the standard [`atexit`](https://docs.python.org/3/library/atexit.html#module-atexit "(in Python v3.14)") is used.

pwnlib.atexit.register(*func*, *\*args*, *\*\*kwargs*)[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/atexit.py#L26-L60)  
Registers a function to be called on program termination. The function will be called with positional arguments args and keyword arguments kwargs, i.e. `func(*args,`` ``**kwargs)`. The current context is recorded and will be the one used when the handler is run.

E.g. to suppress logging output from an exit-handler one could write:

    with context.local(log_level = 'error'):
      atexit.register(handler)

An identifier is returned which can be used to unregister the exit-handler.

This function can be used as a decorator:

    @atexit.register
    def handler():
      ...

Notice however that this will bind `handler` to the identifier and not the actual exit-handler. The exit-handler can then be unregistered with:

    atexit.unregister(handler)

This function is thread safe.

&nbsp;

pwnlib.atexit.unregister(*ident*)[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/atexit.py#L62-L69)  
Remove the exit-handler identified by ident from the list of registered handlers. If ident isn’t registered this is a no-op.
