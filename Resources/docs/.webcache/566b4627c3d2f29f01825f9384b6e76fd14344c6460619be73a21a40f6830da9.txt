# 6.3. Text-mode is broken in some ancient DOS program

If you are using a program written for DOS which seems to use the text-mode but doesn't display the text properly, you can try the other VGA BIOS, either `VGABIOS-lgpl-latest.bin` or `VGABIOS-elpin-2.40`, see the [vgaromimage option](https://bochs.sourceforge.io/doc/docbook/user/bochsrc.html#BOCHSOPT-VGAROMIMAGE).

![](https://bochs.sourceforge.io/doc/docbook/images/undercon.png) Maybe it is a bug in the LGPL VGA BIOS, but for now, it seems to work.
