# miasm.jitter.jitcore_python

## Classes

### class `JitCore_Python(jitcore.JitCore)`

JiT management, using Miasm2 Symbol Execution engine as backend

- **`__init__(self, lifter, bin_stream)`**
- **`set_cpu_vm(self, cpu, vm)`**
- **`load(self)`** - Preload symbols according to current architecture
- **`arch_specific(self)`** - Return arch specific information for the current architecture
- **`add_block(self, asmblock)`** - Create a python function corresponding to an AsmBlock
- **`exec_wrapper(self, loc_key, cpu, _offset_to_jitted_func, _stop_offsets, _max_exec_per_call)`** - Call the function @loc_key with @cpu
