Expand description

Extracts the successful type of a [`Poll<T>`](https://doc.rust-lang.org/std/task/enum.Poll.html "enum std::task::Poll").

This macro bakes in propagation of [`Pending`](https://doc.rust-lang.org/std/task/enum.Poll.html#variant.Pending "variant std::task::Poll::Pending") signals by returning early.

## Examples

``` rust
use std::task::{ready, Context, Poll};
use std::future::{self, Future};
use std::pin::Pin;

pub fn do_poll(cx: &mut Context<'_>) -> Poll<()> {
    let mut fut = future::ready(42);
    let fut = Pin::new(&mut fut);

    let num = ready!(fut.poll(cx));
    // ... use num

    Poll::Ready(())
}
```

The `ready!` call expands to:

``` rust
let num = match fut.poll(cx) {
    Poll::Ready(t) => t,
    Poll::Pending => return Poll::Pending,
};
```
