# Linux Kernel / Lockless Lists

The `drgn.helpers.linux.llist` module provides helpers for working with the lockless, `NULL`-terminated, singly-linked list implementation in [`include/linux/llist.h`](https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/include/linux/llist.h) (`struct`` ``llist_head` and `struct`` ``llist_node`).
