Expand description

A barrier enables multiple threads to synchronize the beginning of some computation.

## Examples

``` rust
use std::sync::Barrier;
use std::thread;

let n = 10;
let barrier = Barrier::new(n);
thread::scope(|s| {
    for _ in 0..n {
        // The same messages will be printed together.
        // You will NOT see any interleaving.
        s.spawn(|| {
            println!("before wait");
            barrier.wait();
            println!("after wait");
        });
    }
});
```

Creates a new barrier that can block a given number of threads.

A barrier will block all threads which call [`wait()`](https://doc.rust-lang.org/std/sync/struct.Barrier.html#method.wait "method std::sync::Barrier::wait") until the `n`th thread calls [`wait()`](https://doc.rust-lang.org/std/sync/struct.Barrier.html#method.wait "method std::sync::Barrier::wait"), and then wake up all threads at once.

##### Examples

``` rust
use std::sync::Barrier;

let barrier = Barrier::new(10);
```

1.0.0 · [Source](https://doc.rust-lang.org/src/std/sync/barrier.rs.html#123-136)

Blocks the current thread until all threads have rendezvoused here.

Barriers are re-usable after all threads have rendezvoused once, and can be used continuously.

A single (arbitrary) thread will receive a [`BarrierWaitResult`](https://doc.rust-lang.org/std/sync/struct.BarrierWaitResult.html "struct std::sync::BarrierWaitResult") that returns `true` from [`BarrierWaitResult::is_leader()`](https://doc.rust-lang.org/std/sync/struct.BarrierWaitResult.html#method.is_leader "method std::sync::BarrierWaitResult::is_leader") when returning from this function, and all other threads will receive a result that will return `false` from [`BarrierWaitResult::is_leader()`](https://doc.rust-lang.org/std/sync/struct.BarrierWaitResult.html#method.is_leader "method std::sync::BarrierWaitResult::is_leader").

##### Examples

``` rust
use std::sync::Barrier;
use std::thread;

let n = 10;
let barrier = Barrier::new(n);
thread::scope(|s| {
    for _ in 0..n {
        // The same messages will be printed together.
        // You will NOT see any interleaving.
        s.spawn(|| {
            println!("before wait");
            barrier.wait();
            println!("after wait");
        });
    }
});
```
