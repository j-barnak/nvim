# Enum TryLockError Copy item path

[Source](https://doc.rust-lang.org/src/std/sync/poison.rs.html#210-219)

``` rust
pub enum TryLockError<T> {
    Poisoned(PoisonError<T>),
    WouldBlock,
}
```

🔬This is a nightly-only experimental API. (`sync_poison_mod` [\#134646](https://github.com/rust-lang/rust/issues/134646))

Expand description

An enumeration of possible errors associated with a [`TryLockResult`](https://doc.rust-lang.org/std/sync/type.TryLockResult.html "type std::sync::TryLockResult") which can occur while trying to acquire a lock, from the [`try_lock`](https://doc.rust-lang.org/std/sync/struct.Mutex.html#method.try_lock "method std::sync::Mutex::try_lock") method on a [`Mutex`](https://doc.rust-lang.org/std/sync/struct.Mutex.html "struct std::sync::Mutex") or the [`try_read`](https://doc.rust-lang.org/std/sync/struct.RwLock.html#method.try_read "method std::sync::RwLock::try_read") and [`try_write`](https://doc.rust-lang.org/std/sync/struct.RwLock.html#method.try_write "method std::sync::RwLock::try_write") methods on an [`RwLock`](https://doc.rust-lang.org/std/sync/struct.RwLock.html "struct std::sync::RwLock").
