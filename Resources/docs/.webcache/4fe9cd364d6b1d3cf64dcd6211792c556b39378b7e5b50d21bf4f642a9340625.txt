# Linux Kernel / Signals

The `drgn.helpers.linux.signal` module provides helpers for working with signals.

drgn.helpers.linux.signal.signal_names(*prog: [drgn.Program](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Program "drgn.Program")*) → [Mapping](https://docs.python.org/3/library/typing.html#typing.Mapping "(in Python v3.14)")\[[str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)"), [int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")\]  
Get a mapping from signal names to numbers on this kernel.

    >>> signal_names()
    {'SIGHUP': 1, 'SIGINT': 2, 'SIGQUIT': 3, ...}

If there are multiple names for the same number (e.g., `SIGCHLD` and `SIGCLD`), then the preferred name comes first.

Note that `SIGRTMIN` and `SIGRTMAX` are dynamic in userspace, so the values used in the kernel may differ from those in userspace.

Parameters:  
**prog** – Program, which [may be omitted to use the default program argument](https://drgn.readthedocs.io/en/latest/api_reference.html#default-program).

drgn.helpers.linux.signal.decode_sigset(*prog: [drgn.Program](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Program "drgn.Program")*, *sigset: [Union](https://docs.python.org/3/library/typing.html#typing.Union "(in Python v3.14)")\[[drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object"), [drgn.IntegerLike](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.IntegerLike "drgn.IntegerLike")\]*) → [str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")  
Get a human-readable representation of a signal set.

    >>> decode_sigset(task.blocked)

Parameters:

drgn.helpers.linux.signal.sigset_to_hex(*sigset: [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")*) → [str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")  
Get a hexadecimal representation of a signal set.

This matches how signal sets are represented in *[proc_pid_status(5)](http://man7.org/linux/man-pages/man5/proc_pid_status.5.html)*.

    >>> sigset_to_hex(task.blocked)
    '0000000000004002'

Parameters:  
**sigset** – `sigset_t` or `sigset_t`` ``*`
