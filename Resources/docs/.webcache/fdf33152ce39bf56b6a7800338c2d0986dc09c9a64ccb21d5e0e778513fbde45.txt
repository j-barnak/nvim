GNU Binary Utilities, commonly known as binutils is a suite of tools for creating and working with binary files. Instructions for cross compiling binutils can be found the [GCC Cross Compiler](https://wiki.osdev.org/GCC_Cross-Compiler#Binutils "GCC Cross-Compiler") page.

## Binutils Applications

Please note that this list is not complete.

|         |                                         |
|---------|-----------------------------------------|
| as      | GNU Assembler                           |
| ld      | GNU Linker                              |
| ar      | Archiver, used for creating libraries   |
| objdump | Displays information about binary files |
