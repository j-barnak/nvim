# Linux Kernel / Bitmaps

The `drgn.helpers.linux.bitmap` module provides helpers for working with bitmaps from [`include/linux/bitmap.h`](https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/include/linux/bitmap.h).

The following helpers from [`drgn.helpers.linux.bitops`](#module-drgn.helpers.linux.bitops "drgn.helpers.linux.bitops") also apply to bitmaps:

- [`for_each_set_bit()`](#drgn.helpers.linux.bitops.for_each_set_bit "drgn.helpers.linux.bitops.for_each_set_bit")

- [`for_each_clear_bit()`](#drgn.helpers.linux.bitops.for_each_clear_bit "drgn.helpers.linux.bitops.for_each_clear_bit")

- [`test_bit()`](#drgn.helpers.linux.bitops.test_bit "drgn.helpers.linux.bitops.test_bit")

drgn.helpers.linux.bitmap.bitmap_weight(*bitmap: [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")*, *size: [drgn.IntegerLike](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.IntegerLike "drgn.IntegerLike")*) → [int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")  
Return the number of set (one) bits in a bitmap

Parameters:  
- **bitmap** – `unsigned`` ``long`` ``*`

- **size** – Size of *bitmap* in bits.
