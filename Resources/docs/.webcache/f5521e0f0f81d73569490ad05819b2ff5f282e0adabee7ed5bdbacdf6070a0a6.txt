🔬This is a nightly-only experimental API. (`portable_simd` [\#86656](https://github.com/rust-lang/rust/issues/86656))

Expand description

Marker trait for types that may be used as SIMD mask elements.

## Safety

Type must be a signed integer.

## Dyn Compatibility

This trait is **not** [dyn compatible](https://doc.rust-lang.org/1.98.1/reference/items/traits.html#dyn-compatibility).

*In older versions of Rust, dyn compatibility was called "object safety".*
