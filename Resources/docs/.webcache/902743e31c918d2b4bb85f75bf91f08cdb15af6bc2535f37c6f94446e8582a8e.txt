# Struct UnixStream Copy item path

[Source](https://doc.rust-lang.org/src/std/os/windows/net/stream.rs.html#38)

``` rust
pub struct UnixStream(/* private fields */);
```

🔬This is a nightly-only experimental API. (`windows_unix_domain_sockets` [\#150487](https://github.com/rust-lang/rust/issues/150487))

Available on **Windows** only.

Expand description

A Unix stream socket.

Under Windows, it will only work starting from Windows 10 17063.

## Examples

``` rust
#![feature(windows_unix_domain_sockets)]
use std::os::windows::net::UnixStream;
use std::io::prelude::*;

fn main() -> std::io::Result<()> {
    let mut stream = UnixStream::connect("/path/to/my/socket")?;
    stream.write_all(b"hello world")?;
    let mut response = String::new();
    stream.read_to_string(&mut response)?;
    println!("{response}");
    Ok(())
}
```

##### Examples

``` rust
#![feature(windows_unix_domain_sockets)]
use std::os::windows::net::{UnixListener, UnixStream};

fn main() -> std::io::Result<()> {
    let listener = UnixListener::bind("/path/to/the/socket")?;
    let addr = listener.local_addr()?;

    let sock = match UnixStream::connect_addr(&addr) {
        Ok(sock) => sock,
        Err(e) => {
            println!("Couldn't connect: {e:?}");
            return Err(e)
        }
    };
    Ok(())
}
```

Sets the read timeout for the socket.

If the provided value is [`None`](https://doc.rust-lang.org/std/option/enum.Option.html#variant.None "variant std::option::Option::None"), then [`read`](https://doc.rust-lang.org/std/io/trait.Read.html#tymethod.read "method std::io::Read::read") calls will block indefinitely. An [`Err`](https://doc.rust-lang.org/std/result/enum.Result.html#variant.Err "variant std::result::Result::Err") is returned if the zero [`Duration`](https://doc.rust-lang.org/std/time/struct.Duration.html "struct std::time::Duration") is passed to this method.

##### Examples

``` rust
#![feature(windows_unix_domain_sockets)]
use std::os::windows::net::UnixStream;
use std::time::Duration;

fn main() -> std::io::Result<()> {
    let socket = UnixStream::connect("/tmp/sock")?;
    socket.set_read_timeout(Some(Duration::new(1, 0))).expect("Couldn't set read timeout");
    Ok(())
}
```

An [`Err`](https://doc.rust-lang.org/std/result/enum.Result.html#variant.Err "variant std::result::Result::Err") is returned if the zero [`Duration`](https://doc.rust-lang.org/std/time/struct.Duration.html "struct std::time::Duration") is passed to this method:

``` rust
#![feature(windows_unix_domain_sockets)]
use std::io;
use std::os::windows::net::UnixStream;
use std::time::Duration;

fn main() -> std::io::Result<()> {
    let socket = UnixStream::connect("/tmp/sock")?;
    let result = socket.set_read_timeout(Some(Duration::new(0, 0)));
    let err = result.unwrap_err();
    assert_eq!(err.kind(), io::ErrorKind::InvalidInput);
    Ok(())
}
```

Shuts down the read, write, or both halves of this connection.

This function will cause all pending and future I/O calls on the specified portions to immediately return with an appropriate value (see the documentation of [`Shutdown`](https://doc.rust-lang.org/std/net/enum.Shutdown.html "enum std::net::Shutdown")).

##### Examples

``` rust
#![feature(windows_unix_domain_sockets)]
use std::os::windows::net::UnixStream;
use std::net::Shutdown;

fn main() -> std::io::Result<()> {
    let socket = UnixStream::connect("/tmp/sock")?;
    socket.shutdown(Shutdown::Both).expect("shutdown function failed");
    Ok(())
}
```

Creates a new independently owned handle to the underlying socket.

The returned `UnixStream` is a reference to the same stream that this object references. Both handles will read and write the same stream of data, and options set on one stream will be propagated to the other stream.
