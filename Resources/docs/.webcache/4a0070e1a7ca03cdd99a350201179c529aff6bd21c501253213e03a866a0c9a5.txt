🔬This is a nightly-only experimental API. (`alloc_error_hook` [\#51245](https://github.com/rust-lang/rust/issues/51245))

Expand description

Unregisters the current allocation error hook, returning it.

*See also the function [`set_alloc_error_hook`](https://doc.rust-lang.org/std/alloc/fn.set_alloc_error_hook.html "fn std::alloc::set_alloc_error_hook").*

If no custom hook is registered, the default hook will be returned.
