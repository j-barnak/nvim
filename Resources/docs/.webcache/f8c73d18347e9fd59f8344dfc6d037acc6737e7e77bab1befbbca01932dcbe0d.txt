## 10 Pattern Matching

The GNU C Library provides pattern matching facilities for two kinds of patterns: regular expressions and file-name wildcards. The library also provides a facility for expanding variable and command references and parsing text into words in the way the shell does.

- [Wildcard Matching](https://sourceware.org/glibc/manual/latest/html_node/Wildcard-Matching.html)
- [Globbing](https://sourceware.org/glibc/manual/latest/html_node/Globbing.html)
- [Regular Expression Matching](https://sourceware.org/glibc/manual/latest/html_node/Regular-Expressions.html)
- [Shell-Style Word Expansion](https://sourceware.org/glibc/manual/latest/html_node/Word-Expansion.html)
