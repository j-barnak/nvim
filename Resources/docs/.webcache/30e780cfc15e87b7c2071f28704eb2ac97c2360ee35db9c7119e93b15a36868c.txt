The Yasm Modular Assembler is a relatively new assembler built with the intention to support many instruction sets and syntax formats. At the moment it can assemble intel syntax and AT&T syntax and has support for 64 bit instructions, and is almost fully compatible with both [NASM](https://wiki.osdev.org/NASM "NASM") and [GAS](https://wiki.osdev.org/GAS "GAS").
