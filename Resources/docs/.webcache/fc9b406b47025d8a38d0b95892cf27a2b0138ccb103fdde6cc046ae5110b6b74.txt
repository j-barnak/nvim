Expand description

An RAII implementation of a “scoped lock” of a re-entrant lock. When this structure is dropped (falls out of scope), the lock will be unlocked.

The data protected by the mutex can be accessed through this guard via its [`Deref`](https://doc.rust-lang.org/std/ops/trait.Deref.html "trait std::ops::Deref") implementation.

This structure is created by the [`lock`](https://doc.rust-lang.org/std/sync/struct.ReentrantLock.html#method.lock "method std::sync::ReentrantLock::lock") method on [`ReentrantLock`](https://doc.rust-lang.org/std/sync/struct.ReentrantLock.html "struct std::sync::ReentrantLock").

## Mutability

Unlike [`MutexGuard`](https://doc.rust-lang.org/std/sync/struct.MutexGuard.html "struct std::sync::MutexGuard"), `ReentrantLockGuard` does not implement [`DerefMut`](https://doc.rust-lang.org/std/ops/trait.DerefMut.html "trait std::ops::DerefMut"), because implementation of the trait would violate Rust’s reference aliasing rules. Use interior mutability (usually [`RefCell`](https://doc.rust-lang.org/std/cell/struct.RefCell.html "struct std::cell::RefCell")) in order to mutate the guarded data.
