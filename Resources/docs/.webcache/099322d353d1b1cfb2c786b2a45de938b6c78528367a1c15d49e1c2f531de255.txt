Creates a python wrapper script that triggers the syscall execve directly.

Parameters:  
- **argv** ([*list*](https://docs.python.org/3/library/stdtypes.html#list "(in Python v3.14)")) – List of arguments to pass into the process

- **executable** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Path to the executable to run. If `None`, `argv[0]` is used.

- **cwd** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Working directory. If `None`, uses the working directory specified on `cwd` or set via `set_working_directory()`.

- **env** ([*dict*](https://docs.python.org/3/library/stdtypes.html#dict "(in Python v3.14)")) – Environment variables to add to the environment.

- **ignore_environ** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – Ignore default environment. By default use default environment iff env not specified.

- **stdin** ([*int*](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")*,* [*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – If an integer, replace stdin with the numbered file descriptor. If a string, a open a file with the specified path and replace stdin with its file descriptor. May also be one of `sys.stdin`, `sys.stdout`, `sys.stderr`. If `None`, the file descriptor is closed.

- **stdout** ([*int*](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")*,* [*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – See `stdin`.

- **stderr** ([*int*](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")*,* [*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – See `stdin`.

- **preexec_fn** (*callable*) – Function which is executed on the remote side before execve(). This **MUST** be a self-contained function – it must perform all of its own imports, and cannot refer to variables outside its scope.

- **preexec_args** ([*object*](https://docs.python.org/3/library/functions.html#object "(in Python v3.14)")) – Argument passed to `preexec_fn`. This **MUST** only consist of native Python objects.

- **aslr** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – See [`pwnlib.tubes.process.process`](https://docs.pwntools.com/en/stable/tubes/processes.html#pwnlib.tubes.process.process "pwnlib.tubes.process.process") for more information.

- **setuid** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – See [`pwnlib.tubes.process.process`](https://docs.pwntools.com/en/stable/tubes/processes.html#pwnlib.tubes.process.process "pwnlib.tubes.process.process") for more information.

- **shell** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – Pass the command-line arguments to the shell.

Returns:  
A string containing the python script.

Create dictionaries over register sizes and relations

Given a list of lists of overlapping register names (e.g. \[‘eax’,’ax’,’al’,’ah’\]) and a list of input sizes, it returns the following:

- all_regs : list of all valid registers

- sizes\[reg\] : the size of reg in bits

- bigger\[reg\] : list of overlapping registers bigger than reg

- smaller\[reg\]: list of overlapping registers smaller than reg

Used in i386/AMD64 shellcode, e.g. the mov-shellcode.

Example

    >>> regs = [['eax', 'ax', 'al', 'ah'],['ebx', 'bx', 'bl', 'bh'],
    ... ['ecx', 'cx', 'cl', 'ch'],
    ... ['edx', 'dx', 'dl', 'dh'],
    ... ['edi', 'di'],
    ... ['esi', 'si'],
    ... ['ebp', 'bp'],
    ... ['esp', 'sp'],
    ... ]

pwnlib.util.misc.run_in_new_terminal(*command*, *terminal=None*, *args=None*, *kill_at_exit=True*, *preexec_fn=None*) → [int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/util/misc.py#L268-L515)  
Run a command in a new terminal.

When `terminal` is not set:  
- If `context.terminal` is set it will be used. If it is an iterable then `context.terminal[1:]` are default arguments.

- If a `pwntools-terminal` command exists in `$PATH`, it is used

- If tmux is detected (by the presence of the `$TMUX` environment variable), a new pane will be opened.

- If GNU Screen is detected (by the presence of the `$STY` environment variable), a new screen will be opened.

- If `$TERM_PROGRAM` is set, that is used.

- If X11 is detected (by the presence of the `$DISPLAY` environment variable), `x-terminal-emulator` is used.

- If KDE Konsole is detected (by the presence of the `$KONSOLE_VERSION` environment variable), a terminal will be split.

- If WSL (Windows Subsystem for Linux) is detected (by the presence of a `wsl.exe` binary in the `$PATH` and `/proc/sys/kernel/osrelease` containing `Microsoft`), a new `cmd.exe` window will be opened.

If kill_at_exit is `True`, try to close the command/terminal when the current process exits. This may not work for all terminal types.

Parameters:  
- **command** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – The command to run.

- **terminal** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Which terminal to use.

- **args** ([*list*](https://docs.python.org/3/library/stdtypes.html#list "(in Python v3.14)")) – Arguments to pass to the terminal

- **kill_at_exit** ([*bool*](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")) – Whether to close the command/terminal on process exit.

- **preexec_fn** (*callable*) – Callable to invoke before exec().

Note

The command is opened with `/dev/null` for stdin, stdout, stderr.

Returns:  
PID of the new terminal process

pwnlib.util.misc.size(*n*, *abbrev='B'*, *si=False*) → [str](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/util/misc.py#L68-L109)  
Convert the length of a bytestream to human readable form.

Parameters:  
- **n** ([*int*](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")*,iterable*) – The length to convert to human readable form, or an object which can have `len()` called on it.

- **abbrev** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – String appended to the size, defaults to `'B'`.

Example

    >>> size(451)
    '451B'
    >>> size(1000)
    '1000B'
    >>> size(1024)
    '1.00KB'
    >>> size(1024, ' bytes')
    '1.00K bytes'
    >>> size(1024, si = True)
    '1.02KB'
    >>> [size(1024 ** n) for n in range(7)]
    ['1B', '1.00KB', '1.00MB', '1.00GB', '1.00TB', '1.00PB', '1024.00PB']
    >>> size([])
    '0B'
    >>> size([1,2,3])
    '3B'

If all is `True` the set of all found locations is returned, else the first occurrence or `None` is returned.

Returns:  
If all is `True` the set of all locations where name was found, else the first location or `None` if not found.

Example

    >>> which('sh')
