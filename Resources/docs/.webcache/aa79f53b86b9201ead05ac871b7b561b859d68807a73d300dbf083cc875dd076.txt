Expand description

Configures whether the default panic hook will capture and display a backtrace.

The default value for this setting may be set by the `RUST_BACKTRACE` environment variable; see the details in [`get_backtrace_style`](https://doc.rust-lang.org/std/panic/fn.get_backtrace_style.html "fn std::panic::get_backtrace_style").
