# Function write Copy item path

1.26.0 · [Source](https://doc.rust-lang.org/src/std/fs.rs.html#419-424)

``` rust
pub fn write<P: AsRef<Path>, C: AsRef<[u8]>>(path: P, contents: C) -> Result<()>
```

Expand description

Writes a slice as the entire contents of a file.

This function will create a file if it does not exist, and will entirely replace its contents if it does.

Depending on the platform, this function may fail if the full directory path does not exist.

This is a convenience function for using [`File::create`](https://doc.rust-lang.org/std/fs/struct.File.html#method.create "associated function std::fs::File::create") and [`write_all`](https://doc.rust-lang.org/std/io/trait.Write.html#method.write_all "method std::io::Write::write_all") with fewer imports.

## Examples

``` rust
use std::fs;

fn main() -> std::io::Result<()> {
    fs::write("foo.txt", b"Lorem ipsum")?;
    fs::write("bar.txt", "dolor sit")?;
    Ok(())
}
```
