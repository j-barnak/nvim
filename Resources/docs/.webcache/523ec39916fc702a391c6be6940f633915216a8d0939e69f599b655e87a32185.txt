# [`pwnlib.util.getdents`](#module-pwnlib.util.getdents "pwnlib.util.getdents") — Linux binary directory listing

pwnlib.util.getdents.dirents(*buf*)[\[source\]](https://github.com/Gallopsled/pwntools/blob/7e5e79d00f/pwnlib/util/getdents.py#L34-L62)  
unpack_dents(buf) -\> list

Extracts data from a buffer emitted by getdents()

Parameters:  
**buf** ([*str*](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")) – Byte array

Returns:  
A list of filenames.

Example

    >>> data = '5ade6d010100000010002e0000000004010000000200000010002e2e006e3d04092b6d010300000010007461736b00045bde6d010400000010006664003b3504'
    >>> data = unhex(data)
    >>> print(dirents(data))
    ['.', '..', 'fd', 'task']
