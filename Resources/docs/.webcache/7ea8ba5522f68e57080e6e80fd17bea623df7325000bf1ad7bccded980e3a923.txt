# angr.ailment.expression

AIL Expression classes.

AIL expression instances are `angr.rustylib.ailment.Expression` – a single Rust pyclass wrapping the `AilExpression` enum. The per-variant classes in this module (`Const`, `BinaryOp`, `Load`, …) are Python-side *marker* classes:

- Each marker’s `__new__` calls one of the `Expression._new_*` factory static methods and returns the resulting `Expression` instance.

- A metaclass on each marker makes `isinstance(x,`` ``Const)` work by dispatching on the variant tag (`Expression.kind`). The `_AilMarkerMeta` checks the tag.

- For static type checkers each marker name is aliased to the `Expression` pyclass itself.

- Python-side subclassing of these markers is not supported.
