🔬This is a nightly-only experimental API. (`core_intrinsics`)

Expand description

Bitwise nand with the current value, returning the previous value. `T` must be an integer or pointer type. `U` must be the same as `T` if that is an integer type, or `usize` if `T` is a pointer type.

The stabilized version of this intrinsic is available on the [`AtomicBool`](https://doc.rust-lang.org/std/sync/atomic/type.AtomicBool.html "type std::sync::atomic::AtomicBool") type via the `fetch_nand` method. For example, [`AtomicBool::fetch_nand`](https://doc.rust-lang.org/std/sync/atomic/struct.Atomic.html#method.fetch_nand "method std::sync::atomic::Atomic::fetch_nand").
