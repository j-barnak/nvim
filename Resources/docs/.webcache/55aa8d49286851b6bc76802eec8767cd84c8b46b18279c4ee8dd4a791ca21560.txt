# Struct UnixListener Copy item path

1.10.0 · [Source](https://doc.rust-lang.org/src/std/os/unix/net/listener.rs.html#40)

``` rust
pub struct UnixListener(/* private fields */);
```

Available on **Unix** only.

Expand description

A structure representing a Unix domain socket server.

## Examples

``` rust
use std::thread;
use std::os::unix::net::{UnixStream, UnixListener};

fn handle_client(stream: UnixStream) {
    // ...
}

fn main() -> std::io::Result<()> {
    let listener = UnixListener::bind("/path/to/the/socket")?;

    // accept connections and process them, spawning a new thread for each one
    for stream in listener.incoming() {
        match stream {
            Ok(stream) => {
                /* connection succeeded */
                thread::spawn(|| handle_client(stream));
            }
            Err(err) => {
                /* connection failed */
                break;
            }
        }
    }
    Ok(())
}
```

Accepts a new incoming connection to this listener.

This function will block the calling thread until a new Unix connection is established. When established, the corresponding [`UnixStream`](https://doc.rust-lang.org/std/os/unix/net/struct.UnixStream.html "struct std::os::unix::net::UnixStream") and the remote peer’s address will be returned.

##### Examples

``` rust
use std::os::unix::net::UnixListener;

fn main() -> std::io::Result<()> {
    let listener = UnixListener::bind("/path/to/the/socket")?;

    match listener.accept() {
        Ok((socket, addr)) => println!("Got a client: {addr:?}"),
        Err(e) => println!("accept function failed: {e:?}"),
    }
    Ok(())
}
```

Creates a new independently owned handle to the underlying socket.

The returned `UnixListener` is a reference to the same socket that this object references. Both handles can be used to accept incoming connections and options set on one listener will affect the other.

1.10.0 · [Source](https://doc.rust-lang.org/src/std/os/unix/net/listener.rs.html#245-247)

Moves the socket into or out of nonblocking mode.

This will result in the `accept` operation becoming nonblocking, i.e., immediately returning from their calls. If the IO operation is successful, `Ok` is returned and no further action is required. If the IO operation could not be completed and needs to be retried, an error with kind [`io::ErrorKind::WouldBlock`](https://doc.rust-lang.org/std/io/enum.ErrorKind.html#variant.WouldBlock "variant std::io::ErrorKind::WouldBlock") is returned.

##### Examples

``` rust
use std::os::unix::net::UnixListener;

fn main() -> std::io::Result<()> {
    let listener = UnixListener::bind("/path/to/the/socket")?;
    listener.set_nonblocking(true).expect("Couldn't set non blocking");
    Ok(())
}
```

Returns an iterator over incoming connections.

The iterator will never return [`None`](https://doc.rust-lang.org/std/option/enum.Option.html#variant.None "variant std::option::Option::None") and will also not yield the peer’s [`SocketAddr`](https://doc.rust-lang.org/std/os/unix/net/struct.SocketAddr.html "struct std::os::unix::net::SocketAddr") structure.

##### Examples

``` rust
use std::thread;
use std::os::unix::net::{UnixStream, UnixListener};

fn handle_client(stream: UnixStream) {
    // ...
}

fn main() -> std::io::Result<()> {
    let listener = UnixListener::bind("/path/to/the/socket")?;

    for stream in listener.incoming() {
        match stream {
            Ok(stream) => {
                thread::spawn(|| handle_client(stream));
            }
            Err(err) => {
                break;
            }
        }
    }
    Ok(())
}
```
