# Function simd_extract_dyn Copy item path

[Source](https://doc.rust-lang.org/src/core/intrinsics/simd/mod.rs.html#55)

``` rust
pub const unsafe fn simd_extract_dyn<T, U>(x: T, idx: u32) -> U
```

🔬This is a nightly-only experimental API. (`core_intrinsics`)

Expand description

Extracts an element from a vector.

`T` must be a vector with element type `U`.

If the index is `const`, [`simd_extract`](https://doc.rust-lang.org/std/intrinsics/simd/fn.simd_extract.html "fn std::intrinsics::simd::simd_extract") may emit better assembly.

## Safety

`idx` must be in-bounds of the vector.
