# The REPL

*REPL* stands for *read–evaluate–print loop*. It’s pronounced *repple*. Racket’s REPL is an interactive prompt where you can type Racket expressions and see the results. The REPL is a quick way to run small evaluations.

The REPL is available two ways:

1.

    In your terminal window, by launching racket:

        ~ : racket
        Welcome to Racket v8.11.0.3.
        -> (* 6 7)
        42
        -> (current-milliseconds)
        -> 1779851764669
        -> (define xyzzy (random 100))
        -> xyzzy
        83

    You can specify a different language for this repl with the -I flag:

        ~ : racket -I br
        Welcome to Racket v8.11.0.3.
        -> (define-macro (foo THIS) #'42)
        -> (foo "you")
        42

2.

    You can also access the REPL in DrRacket, by using the prompt in the interactions panel:

        Welcome to DrRacket, version 8.11.0.3 [3m].
        Language: racket [custom]; memory limit: 3000 MB.
        > (* 6 7)
        42
        >

    Unlike the command-line REPL, the DrRacket REPL adopts the language specified by the [#lang line](https://beautifulracket.com/explainer/lang-line.html) at the top of the definitions panel. DrRacket also uses the REPL itself to print output from the program.

    The DrRacket REPL lets you use variables and functions from the source file in the definitions window (even if they’re not made available through provide). So if this is the program:

        (define foo "bar")
        (define (repeat str) (string-append str str))

    After you run the file (to update the definitions), you can use them at the DrRacket REPL:

        Welcome to DrRacket, version 8.11.0.3 [3m].
        Language: br [custom]; memory limit: 3000 MB.
        > foo
        "bar"
        > (repeat foo)
        "barbar"
        >

    Textual output is just the beginning of the DrRacket REPL. It can display a range of data formats, including [images](http://docs.racket-lang.org/teachpack/2htdpimage.html) and [interactive plots](http://docs.racket-lang.org/plot/renderer3d.html).

### [Making the REPL available in a language](#making-the-repl-available-in-a-language)

Custom languages can activate the REPL by providing [#%top-interaction](http://docs.racket-lang.org/reference/__top-interaction.html#(form._((lib._racket/private/base..rkt)._~23~25top-interaction))) from the expander. br/quicklang handles this for you, so languages made with br/quicklang automatically have REPL support.

More intricate REPL hacking is possible. For instance, the REPL can be configured to [use a custom reader](https://beautifulracket.com/basic-3/the-repl.html) (other than Racket’s default S-expression reader).
