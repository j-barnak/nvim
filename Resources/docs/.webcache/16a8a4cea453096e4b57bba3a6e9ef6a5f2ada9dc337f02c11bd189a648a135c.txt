# angr.analyses.decompiler.optimization_passes.duplication_reverter.errors

exception angr.analyses.decompiler.optimization_passes.duplication_reverter.errors.SAILRSemanticError  
Bases: [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception "(in Python v3.14)")

These types of errors may not kill the entire analysis, but they do kill the current working round. They are caused when some non-expected state happens, like a ConditionalJump that is not the last statement in a block.
