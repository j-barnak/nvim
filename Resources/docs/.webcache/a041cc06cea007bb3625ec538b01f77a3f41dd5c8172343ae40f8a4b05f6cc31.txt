# Type Alias c_ulonglong Copy item path

1.64.0 · [Source](https://doc.rust-lang.org/src/core/ffi/primitives.rs.html#35)

``` rust
pub type c_ulonglong = u64;
```

Expand description

Equivalent to C’s `unsigned long long` type.

This type will almost always be [`u64`](https://doc.rust-lang.org/std/primitive.u64.html "primitive u64"), but may differ on some systems. The C standard technically only requires that this type be an unsigned integer with the size of a [`long long`](https://doc.rust-lang.org/std/ffi/type.c_longlong.html "type std::ffi::c_longlong"), although in practice, no system would have a `long long` that is not a `u64`, as most systems do not have a standardised [`u128`](https://doc.rust-lang.org/std/primitive.u128.html "primitive u128") type.
