# Linux Kernel / XArrays

The `drgn.helpers.linux.xarray` module provides helpers for working with the [XArray](https://docs.kernel.org/core-api/xarray.html) data structure from [`include/linux/xarray.h`](https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/include/linux/xarray.h).

Note

XArrays were introduced in Linux 4.20 as a replacement for [radix trees](#radix-trees). To make it easier to work with data structures that were changed from a radix tree to an XArray (like `struct`` ``address_space::i_pages`), drgn treats XArrays and radix trees interchangeably in some cases.

Specifically, [`xa_load()`](#drgn.helpers.linux.xarray.xa_load "drgn.helpers.linux.xarray.xa_load") is equivalent to [`radix_tree_lookup()`](#drgn.helpers.linux.radixtree.radix_tree_lookup "drgn.helpers.linux.radixtree.radix_tree_lookup"), and [`xa_for_each()`](#drgn.helpers.linux.xarray.xa_for_each "drgn.helpers.linux.xarray.xa_for_each") is equivalent to [`radix_tree_for_each()`](#drgn.helpers.linux.radixtree.radix_tree_for_each "drgn.helpers.linux.radixtree.radix_tree_for_each"), except that the radix tree helpers assume `advanced=False`. (Therefore, [`xa_load()`](#drgn.helpers.linux.xarray.xa_load "drgn.helpers.linux.xarray.xa_load") and [`xa_for_each()`](#drgn.helpers.linux.xarray.xa_for_each "drgn.helpers.linux.xarray.xa_for_each") also accept a `struct`` ``radix_tree_root`` ``*`, and [`radix_tree_lookup()`](#drgn.helpers.linux.radixtree.radix_tree_lookup "drgn.helpers.linux.radixtree.radix_tree_lookup") and [`radix_tree_for_each()`](#drgn.helpers.linux.radixtree.radix_tree_for_each "drgn.helpers.linux.radixtree.radix_tree_for_each") also accept a `struct`` ``xarray`` ``*`.)

drgn.helpers.linux.xarray.xa_load(*xa: [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")*, *index: [drgn.IntegerLike](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.IntegerLike "drgn.IntegerLike")*, *\**, *advanced: [bool](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)") = False*) → [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")  
Look up the entry at a given index in an XArray.

    >>> entry = xa_load(inode.i_mapping.i_pages.address_of_(), 2)
    >>> cast("struct page *", entry)
    *(struct page *)0xffffed6980306f40 = {
        ...
    }

Parameters:  
- **xa** – `struct`` ``xarray`` ``*`

- **index** – Entry index.

- **advanced** – Whether to return nodes only visible to the XArray advanced API. If `False`, zero entries (see [`xa_is_zero()`](#drgn.helpers.linux.xarray.xa_is_zero "drgn.helpers.linux.xarray.xa_is_zero")) will be returned as `NULL`.

Returns:  
`void`` ``*` found entry, or `NULL` if not found.

&nbsp;

drgn.helpers.linux.xarray.xa_for_each(*xa: [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")*, *\**, *advanced: [bool](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)") = False*) → [Iterator](https://docs.python.org/3/library/typing.html#typing.Iterator "(in Python v3.14)")\[[Tuple](https://docs.python.org/3/library/typing.html#typing.Tuple "(in Python v3.14)")\[[int](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)"), [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")\]\]  
Iterate over all of the entries in an XArray.

    >>> for index, entry in xa_for_each(inode.i_mapping.i_pages.address_of_()):
    ...     print(index, entry)
    ...
    0 (void *)0xffffed6980356140
    1 (void *)0xffffed6980306f80
    2 (void *)0xffffed6980306f40
    3 (void *)0xffffed6980355b40

Parameters:  
- **xa** – `struct`` ``xarray`` ``*`

- **advanced** – Whether to return nodes only visible to the XArray advanced API. If `False`, zero entries (see [`xa_is_zero()`](#drgn.helpers.linux.xarray.xa_is_zero "drgn.helpers.linux.xarray.xa_is_zero")) will be skipped.

Returns:  
Iterator of (index, `void`` ``*`) tuples.

&nbsp;

drgn.helpers.linux.xarray.xa_is_value(*entry: [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")*) → [bool](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")  
Return whether an XArray entry is a value.

See [`xa_to_value()`](#drgn.helpers.linux.xarray.xa_to_value "drgn.helpers.linux.xarray.xa_to_value").

Parameters:  
**entry** – `void`` ``*`

&nbsp;

drgn.helpers.linux.xarray.xa_to_value(*entry: [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")*) → [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")  
Return the value in an XArray entry.

In addition to pointers, XArrays can store integers between 0 and `LONG_MAX`. If [`xa_is_value()`](#drgn.helpers.linux.xarray.xa_is_value "drgn.helpers.linux.xarray.xa_is_value") returns `True`, use this to get the stored integer.

    >>> entry = xa_load(xa, 9)
    >>> entry
    (void *)0xc9
    >>> xa_is_value(entry)
    True
    >>> xa_to_value(entry)
    (unsigned long)100

Parameters:  
**entry** – `void`` ``*`

Returns:  
`unsigned`` ``long`

&nbsp;

drgn.helpers.linux.xarray.xa_is_zero(*entry: [drgn.Object](https://drgn.readthedocs.io/en/latest/api_reference.html#drgn.Object "drgn.Object")*) → [bool](https://docs.python.org/3/library/functions.html#bool "(in Python v3.14)")  
Return whether an XArray entry is a “zero” entry.

A zero entry is an entry that was reserved but is not present. These are only visible to the XArray advanced API, so they are only returned by [`xa_load()`](#drgn.helpers.linux.xarray.xa_load "drgn.helpers.linux.xarray.xa_load") and [`xa_for_each()`](#drgn.helpers.linux.xarray.xa_for_each "drgn.helpers.linux.xarray.xa_for_each") when `advanced`` ``=`` ``True`.

    >>> entry = xa_load(xa, 10, advanced=True)
    >>> entry
    (void *)0x406
    >>> xa_is_zero(entry)
    True
    >>> xa_load(xa, 10)
    (void *)0

Parameters:  
**entry** – `void`` ``*`

## Experimental

The `drgn.helpers.experimental` package contains experimental helpers with no stability guarantees. They may change, move to another package, or be removed. They are not automatically imported by the CLI.
