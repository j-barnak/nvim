In [computer programming](https://en.wikipedia.org/wiki/Computer_programming "Computer programming"), a **dead store** is a [local variable](https://en.wikipedia.org/wiki/Local_variable "Local variable") that is assigned a [value](https://en.wikipedia.org/wiki/Value_(computer_science) "Value (computer science)") but is read by no following [instruction](https://en.wikipedia.org/wiki/Instruction_set_architecture "Instruction set architecture"). Dead stores waste [processor](https://en.wikipedia.org/wiki/Processor_(computing) "Processor (computing)") time and [memory](https://en.wikipedia.org/wiki/Computer_memory "Computer memory"), and may be detected through the use of [static program analysis](https://en.wikipedia.org/wiki/Static_program_analysis "Static program analysis"), and removed by an [optimizing compiler](https://en.wikipedia.org/wiki/Optimizing_compiler "Optimizing compiler").

If the purpose of a store is intentionally to overwrite data, for example when a [password](https://en.wikipedia.org/wiki/Password "Password") is being removed from memory, dead store [optimizations](https://en.wikipedia.org/wiki/Program_optimization "Program optimization") can cause the write not to happen, leading to a security issue. Some system [libraries](https://en.wikipedia.org/wiki/Library_(computing) "Library (computing)") have specific functions designed to avoid such dangerous optimizations, e.g. `explicit_bzero` on [OpenBSD](https://en.wikipedia.org/wiki/OpenBSD "OpenBSD").

## Examples

### Java

Dead store example in [Java](https://en.wikipedia.org/wiki/Java_(programming_language) "Java (programming language)"):

``` java
// DeadStoreExample.java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class DeadStoreExample {
    public static void main(String[] args) {
        List<String> list = new ArrayList<String>(); // This is a Dead Store, as the ArrayList is never read. 
        list = getList();
        System.out.println(list);
    }

    private static List<String> getList() {
        return new ArrayList<String>(Arrays.asList("Hello"));
    }
}
```

In the above code an `ArrayList<String>` object was instantiated but never used. Instead, in the next line the variable which references it is set to point to a different object. The `ArrayList` which was created when `list` was declared will now need to be de-allocated, for instance by a [garbage collector](https://en.wikipedia.org/wiki/Garbage_collection_(computer_science) "Garbage collection (computer science)").

### JavaScript

Dead store example in [JavaScript](https://en.wikipedia.org/wiki/JavaScript "JavaScript"):

``` javascript
function func(a, b) {
    var x;
    var i = 300;
    while (i--) {
        x = a + b; // dead store
    }
}
```

The code in the loop repeatedly overwrites the same variable, so it can be reduced to only one call.
