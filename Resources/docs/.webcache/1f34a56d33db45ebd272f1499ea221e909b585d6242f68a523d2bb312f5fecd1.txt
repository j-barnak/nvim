# Chapter 4. Setup

# 4.1. What does Bochs need?

These are the minimum requirements for running an OS inside of Bochs:

- the Bochs executable

- the BIOS image (usually called `BIOS-bochs-latest`)

- the VGA BIOS image (e.g. `VGABIOS-lgpl-latest.bin` or `VGABIOS-elpin-2.40`)

- at least one bootable media, either as disk image (floppy, hard disk or CD-ROM) or physical disk (floppy or CD-ROM)

> **Note**

> **Note**

In that case you have to pass the configuration options on the command line or to use the configuration interface to set up Bochs for the simulation. Running Bochs is easier if you use a configuration file (we call it `bochsrc`). See [Section 4.3](https://bochs.sourceforge.io/doc/docbook/user/bochsrc.html) for all supported options.

The easiest way to setup Bochs for the first time is to use the example configuration file called `bochsrc-sample.txt`. Locate that file (location depends on the (host) OS and on the installation facility used) and copy it to a location where Bochs looks for that file, see [Section 5.2](https://bochs.sourceforge.io/doc/docbook/user/search-order.html).

The next step is to change the configuration so that it fits your needs: You most likely want to setup a hard disk (see [Section 9.23](https://bochs.sourceforge.io/doc/docbook/user/using-bximage.html) and [Section 4.3.21](https://bochs.sourceforge.io/doc/docbook/user/bochsrc.html#BOCHSOPT-ATA-MASTER-SLAVE)), and install some OS on it using either a set of floppy disks (see [Section 4.3.19](https://bochs.sourceforge.io/doc/docbook/user/bochsrc.html#BOCHSOPT-FLOPPYAB)) or a CD-ROM (see [Section 4.3.21](https://bochs.sourceforge.io/doc/docbook/user/bochsrc.html#BOCHSOPT-ATA-MASTER-SLAVE) again) as installation media. Make sure you boot the emulation from the media you want, using the right setting as [boot option](https://bochs.sourceforge.io/doc/docbook/user/bochsrc.html#BOCHSOPT-BOOT).

If your keyboard output inside of Bochs is wrong, you may also need a keymap file to remap your keyboard layout to the U.S. layout. A set of keymap files for the X window system and SDL/SDL2 (Linux port) is distributed with Bochs. If your keyboard layout is not supported yet, you can create your own one by following the instructions given in [Section 4.4](https://bochs.sourceforge.io/doc/docbook/user/keymap.html).

A collection of disk images of different operating systems can be found at [https://bochs.sourceforge.io/diskimages.html](https://bochs.sourceforge.io/diskimages.html). Some disk images are the size of a floppy disk (1 meg compressed) and others are gigantic (160 meg compressed). If you want to create a disk image yourself, please see [Section 9.2](https://bochs.sourceforge.io/doc/docbook/user/diskimagehowto.html).
