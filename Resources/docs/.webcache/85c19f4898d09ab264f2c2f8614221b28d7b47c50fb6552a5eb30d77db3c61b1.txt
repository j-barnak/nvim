# Struct ChildStderr Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/std/process.rs.html#470-472)

``` rust
pub struct ChildStderr { /* private fields */ }
```

Expand description

A handle to a child process’s stderr.

This struct is used in the [`stderr`](https://doc.rust-lang.org/std/process/struct.Child.html#structfield.stderr "field std::process::Child::stderr") field on [`Child`](https://doc.rust-lang.org/std/process/struct.Child.html "struct std::process::Child").

When an instance of `ChildStderr` is [dropped](https://doc.rust-lang.org/std/ops/trait.Drop.html "trait std::ops::Drop"), the `ChildStderr`’s underlying file handle will be closed.

##### Examples

``` rust
use std::process::{Command, Stdio};

let reverse = Command::new("rev")
    .arg("non_existing_file.txt")
    .stderr(Stdio::piped())
    .spawn()
    .expect("failed reverse command");

let cat = Command::new("cat")
    .arg("-")
    .stdin(reverse.stderr.unwrap()) // Converted into a Stdio here
    .output()
    .expect("failed echo command");

assert_eq!(
    String::from_utf8_lossy(&cat.stdout),
    "rev: cannot open non_existing_file.txt: No such file or directory\n"
);
```
