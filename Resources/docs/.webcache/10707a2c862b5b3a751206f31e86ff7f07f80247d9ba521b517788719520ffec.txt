Let’s make stacker, a programming language that acts as a stack-based calculator:

![](https://beautifulracket.com/stacker/first-lang.gif)

Our stacker language maintains a [stack](https://beautifulracket.com/appendix/glossary.html#stack) of [arguments](https://beautifulracket.com/appendix/glossary.html#argument), which starts out empty. Each line of the program represents a new argument for the stack. If it’s a number, it’s simply pushed onto the top of the stack. But if it’s an operator—either + or \*—then the top two arguments from the stack are popped off, and replaced with the result of applying the operator (meaning arg1 + arg2 or arg1 \* arg2). So the sample program above means 3 \* (8 + 4), and when it runs, the result is 36.

The stack is implemented with a [list](https://beautifulracket.com/appendix/glossary.html#list), the basic data structure of Racket. By convention, the top of our stack will correspond to the left side of a Racket list. Let’s visualize how the stack changes after each instruction, using the rules described above:

; (list)
4 ; (list 4)
8 ; (list 8 4)
+ ; (list + 8 4) becomes (list 12)
3 ; (list 3 12)
\* ; (list \* 3 12) becomes (list 36)

    1
    2
    3
    4
    5
    6

    ; (list)
    4 ; (list 4)
    8 ; (list 8 4)
    + ; (list + 8 4) becomes (list 12)
    3 ; (list 3 12)
    * ; (list * 3 12) becomes (list 36)

![copy to clipboard](https://beautifulracket.com/fonts/feather-v1.1/svg/download.svg)

36 ; top value of (list 36)

    1

    36 ; top value of (list 36)

![copy to clipboard](https://beautifulracket.com/fonts/feather-v1.1/svg/download.svg)

Easy, right? If this seems like a weird way to do math, it’s called [Reverse Polish Notation](http://www.calculator.org/rpn.aspx), and it has a long history in calculating machines.

Though stacker is simple, it will give us a gentle introduction to Racket, including a tour of its language-making workflow. Every language project will follow the same basic steps.

stacker will also get us thinking about the idea of a “little language” made for a specialized purpose—known as a [domain-specific language](https://beautifulracket.com/appendix/glossary.html#domain-specific-language) or [DSL](https://beautifulracket.com/appendix/glossary.html#dsl). We can make general-purpose languages with Racket—and [later on](https://beautifulracket.com/basic/), we will. But languages don’t have to do everything. DSLs are valuable because they can be tailored to the problem at hand. And if you’ve programmed for a little while, it’s likely you’ve [already used DSLs](https://beautifulracket.com/appendix/domain-specific-languages.html).

### [Prerequisites](#prerequisites)

-

  Some general programming experience is assumed.

-

  No experience with Racket, Scheme, or Lisp is assumed.

-

  Install Racket and the beautiful-racket package as described in [Setup](https://beautifulracket.com/setup.html).

-

  Make sure your Racket installation works by trying the sample below. Click the “copy to clipboard” icon in the upper-right corner of the code sample (the button will appear when you hover over the box):

  \#lang reader stacker-demo/stacker
  4
  8
  +
  3
  \*

      1
      2
      3
      4
      5
      6

      #lang reader stacker-demo/stacker
      4
      8
      +
      3
      *

  ![copy to clipboard](https://beautifulracket.com/fonts/feather-v1.1/svg/download.svg)

-

  Paste the code into the upper pane of a new DrRacket window (also known as the *definitions area*), entirely replacing anything that’s there (including a \#lang line, if any):

  ![](https://beautifulracket.com/stacker/definition-area.gif)

-

  Click *Run*, and the result should appear in the lower pane (also known as the *interactions area* or *[REPL](https://beautifulracket.com/appendix/glossary.html#repl)*):

  ![](https://beautifulracket.com/stacker/first-lang.gif)

-

  Unlike this sample, most code samples in this book don’t have a \#lang line at the top. They’re presumed to use the Beautiful Racket language, \#lang br. This line will automatically appear at the top of every new DrRacket window if you [configured it to do so](https://beautifulracket.com/setup.html#setting-br-as-the-default-language). Otherwise (or if you’re not using DrRacket) you’ll need to add it yourself.

If the sample program worked, we can continue.
