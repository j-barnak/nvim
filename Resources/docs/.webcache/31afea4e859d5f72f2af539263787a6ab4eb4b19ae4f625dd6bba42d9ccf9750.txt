#### 36.2.9 Non-POSIX Extensions

In addition to implementing the POSIX API for threads, the GNU C Library provides additional functions and interfaces to provide functionality not specified in the standard.

- [Setting Process-wide defaults for thread attributes](https://sourceware.org/glibc/manual/latest/html_node/Default-Thread-Attributes.html)
- [Controlling the Initial Signal Mask of a New Thread](https://sourceware.org/glibc/manual/latest/html_node/Initial-Thread-Signal-Mask.html)
- [Thread CPU Affinity](https://sourceware.org/glibc/manual/latest/html_node/Thread-CPU-Affinity.html)
- [Wait for a thread to terminate](https://sourceware.org/glibc/manual/latest/html_node/Joining-Threads.html)
- [Thread Names](https://sourceware.org/glibc/manual/latest/html_node/Thread-Names.html)
- [Detecting Single-Threaded Execution](https://sourceware.org/glibc/manual/latest/html_node/Single_002dThreaded.html)
- [Restartable Sequences](https://sourceware.org/glibc/manual/latest/html_node/Restartable-Sequences.html)
