- **`optimise_level(self, level=2)`** - Set the optimisation level to @level from 0 to 2
- **`init_exec_engine(self)`**
- **`new_module(self, name='mod')`** - Create a module, with needed functions
- **`get_execengine(self)`** - Return the Execution Engine associated with this context
- **`get_passmanager(self)`** - Return the Pass Manager associated with this context
- **`get_module(self)`** - Return the module associated with this context
- **`add_shared_library(self, filename)`** - Load the shared library 'filename'
- **`add_fc(self, fc, readonly=False)`** - Add function into known_fc
- **`add_op(self)`** - Add operations functions
- **`memory_lookup(self, func, addr, size)`** - Perform a memory lookup at @addr of size @size (in bit)
- **`memory_write(self, func, addr, size, value)`** - Perform a memory write at @addr of size @size (in bit) with LLVM IR @value

### class `LLVMFunction_IRCompilation(LLVMFunction)`

LLVMFunction made for IR export, in conjunction with
LLVMContext_IRCompilation.

This class offers only the basics, and decision must be made by the class
user on how actual registers, ABI, etc. are reflected


Example of use:
>>> context = LLVMContext_IRCompilation()
>>> context.lifter = lifter
>>>
>>> func = LLVMFunction_IRCompilation(context, name="test")
>>> func.ret_type = llvm_ir.VoidType()
>>> func.init_fc()
>>>
>>> # Insert here function additional inits
>>> XX = func.builder.alloca(...)
>>> func.local_vars_pointers["EAX"] = XX
>>> #
>>>
>>> func.from_ircfg(ircfg)

- **`init_fc(self)`**
- **`gen_jump2dst(self, _attrib, _instr_offsets, dst)`**
- **`gen_irblock(self, irblock)`**
- **`from_ircfg(self, ircfg, append_ret=True)`**
