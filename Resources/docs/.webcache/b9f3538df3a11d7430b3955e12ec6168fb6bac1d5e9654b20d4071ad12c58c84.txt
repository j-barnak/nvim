# Function chroot Copy item path

1.56.0 · [Source](https://doc.rust-lang.org/src/std/os/unix/fs.rs.html#1186-1188)

``` rust
pub fn chroot<P: AsRef<Path>>(dir: P) -> Result<()>
```

Available on **Unix and non-Fuchsia** only.

Expand description

Change the root directory of the current process to the specified path.

This typically requires privileges, such as root or a specific capability.

This does not change the current working directory; you should call [`std::env::set_current_dir`](https://doc.rust-lang.org/std/env/fn.set_current_dir.html "fn std::env::set_current_dir") afterwards.

## Examples

``` rust
use std::os::unix::fs;

fn main() -> std::io::Result<()> {
    fs::chroot("/sandbox")?;
    std::env::set_current_dir("/")?;
    // continue working in sandbox
    Ok(())
}
```
