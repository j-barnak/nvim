#  Description

------------------------------------------------------------------------

This object is used to represent a bit vector. Mainly used by [Register](https://triton-library.github.io/documentation/doxygen/py_Register_page.html), [MemoryAccess](https://triton-library.github.io/documentation/doxygen/py_MemoryAccess_page.html) and [Immediate](https://triton-library.github.io/documentation/doxygen/py_Immediate_page.html).

\>\>\> ah = ctxt.registers.ah

\>\>\> bv = ah.getBitvector()

\>\>\> bv.getHigh()

15

\>\>\> bv.getLow()

8

\>\>\> bv.getVectorSize()

8

\>\>\> bv.getMaxValue()

255

#  Python API - Methods of the BitsVector class

------------------------------------------------------------------------

- **integer getHigh(void)**  
  Returns the highest bit position.
- **integer getLow(void)**  
  Returns the lowest bit position.
- **integer getMaxValue(void)**  
  Returns the max value of the vector.
- **integer getVectorSize(void)**  
  Returns the size of the vector.
