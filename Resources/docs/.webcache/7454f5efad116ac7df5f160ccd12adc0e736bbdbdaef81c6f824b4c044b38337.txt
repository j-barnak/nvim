# 9.4. Bochs GNU/Linux DiskTools

Bochs-Tools are a collection of scripts and programs to be used together with Bochs developed by Bernhard Bablok. Main goal was to provide a more Unix-like interface to the emulator and to enable access to Bochs disk-images from outside of Bochs. The latest version is available at [www.bablokb.de/bochs-tools](http://www.bablokb.de/bochs-tools).
