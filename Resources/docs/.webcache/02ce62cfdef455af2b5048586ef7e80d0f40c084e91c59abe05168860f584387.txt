Expand description

Equivalent to C’s `signed long` (`long`) type.

This type will always be [`i32`](https://doc.rust-lang.org/std/primitive.i32.html "primitive i32") or [`i64`](https://doc.rust-lang.org/std/primitive.i64.html "primitive i64"). Most notably, many Linux-based systems assume an `i64`, but Windows assumes `i32`. The C standard technically only requires that this type be a signed integer that is at least 32 bits and at least the size of an [`int`](https://doc.rust-lang.org/std/os/raw/type.c_int.html "type std::os::raw::c_int"), although in practice, no system would have a `long` that is neither an `i32` nor `i64`.
