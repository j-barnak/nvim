Expand description

This is the error type used by [`HandleOrInvalid`](https://doc.rust-lang.org/std/os/windows/io/struct.HandleOrInvalid.html "struct std::os::windows::io::HandleOrInvalid") when attempting to convert into a handle, to indicate that the value is `INVALID_HANDLE_VALUE`.
