# Struct Empty Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/core/io/util.rs.html#14)

``` rust
#[non_exhaustive]pub struct Empty;
```

Expand description

`Empty` ignores any data written via [`Write`](https://doc.rust-lang.org/std/io/trait.Write.html), and will always be empty (returning zero bytes) when read via [`Read`](https://doc.rust-lang.org/std/io/trait.Read.html).

This struct is generally created by calling [`empty()`](https://doc.rust-lang.org/std/io/fn.empty.html "fn std::io::empty"). Please see the documentation of [`empty()`](https://doc.rust-lang.org/std/io/fn.empty.html "fn std::io::empty") for more details.
