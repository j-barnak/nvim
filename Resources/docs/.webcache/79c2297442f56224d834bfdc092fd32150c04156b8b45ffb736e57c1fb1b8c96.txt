### class `BoundedDict(DictMixin)`

Limited in size dictionary.

To reduce combinatory cost, once an upper limit @max_size is reached,
@max_size - @min_size elements are suppressed.
The targeted elements are the less accessed.

One can define a callback called when an element is removed

- **`__init__(self, max_size, min_size=None, initialdata=None, delete_cb=None)`** - Create a BoundedDict
- **`__setitem__(self, asked_key, value)`**
- **`__contains__(self, key)`**
- **`has_key(self, key)`**
- **`keys(self)`** - Return the list of dict's keys
- **`data(self)`** - Return the current instance as a dictionary
- **`__getitem__(self, key)`**
- **`__delitem__(self, key)`**
- **`__del__(self)`** - Ensure the callback is called when last reference is lost
- **`__len__(self)`**
- **`__iter__(self)`**
