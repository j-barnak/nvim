Expand description

A `BarrierWaitResult` is returned by [`Barrier::wait()`](https://doc.rust-lang.org/std/sync/struct.Barrier.html#method.wait "method std::sync::Barrier::wait") when all threads in the [`Barrier`](https://doc.rust-lang.org/std/sync/struct.Barrier.html "struct std::sync::Barrier") have rendezvoused.

## Examples

``` rust
use std::sync::Barrier;

let barrier = Barrier::new(1);
let barrier_wait_result = barrier.wait();
```

Returns `true` if this thread is the “leader thread” for the call to [`Barrier::wait()`](https://doc.rust-lang.org/std/sync/struct.Barrier.html#method.wait "method std::sync::Barrier::wait").

Only one thread will have `true` returned from their result, all other threads will have `false` returned.

##### Examples

``` rust
use std::sync::Barrier;

let barrier = Barrier::new(1);
let barrier_wait_result = barrier.wait();
println!("{:?}", barrier_wait_result.is_leader());
```
