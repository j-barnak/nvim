Solar Assembler (aka Sol_Asm) is a multipass macro assembler written by Bogdan Ontanu. It supports HLL primitives, like procedures, structures/unions, .IF/.ENDIF, .WHILE/.ENDWHILE, .REPEAT/.UNTIL, etc. Sol_Asm can produce binary files, PE executables (32/64-bit), COFF object files (32/64-bit), ELF object files (32/64-bit) and Mach-O object files (32-bit only).

## Sol_Asm syntax

### Syntax comparison

The syntax of Sol_Asm is easy to learn and has similarities with the syntax of [TASM](https://wiki.osdev.org/TASM "TASM") or [MASM](https://wiki.osdev.org/MASM "MASM"). This table shows the differences between Sol_Asm and other HLL assemblers:

SOL_ASM [TASM](https://wiki.osdev.org/TASM) [MASM](https://wiki.osdev.org/MASM) / [JWASM](https://wiki.osdev.org/JWASM) [FASM](https://wiki.osdev.org/FASM) with HLL macros

Procedures [\[1\]](https://wiki.osdev.org/Solar_Assembler#endnote_1)

``` asm
PROC TestProc
     USES eax, ebx
     ARG Var1, Var2
     LOCAL Var3

     ...
ENDP
```

``` asm
TestProc PROC
     USES eax, ebx
     ARG Var1:DWORD, Var2:BYTE
     LOCAL Var3:WORD

     ...
ENDP
```

``` asm
TestProc PROC \
     USES eax, ebx \
     Var1:DWORD, Var2:BYTE
     LOCAL Var3:WORD

     ...
TestProc ENDP
```

``` asm
proc TestProc \
     USES eax ebx \
     Var1:DWORD, Var2:BYTE
     LOCAL Var3:WORD

     ...
endp
```

Structures

``` asm
STRUC StructTest
    Var1     db ?
    Var2     dw ?
    Var3     dd ?
ENDS
```

``` asm
StructTest STRUC
    Var1:    db ?
    Var2:    dw ?
    Var3:    dd ?
ENDS
```

``` asm
StructTest STRUC
    Var1:    db ?
    Var2:    dw ?
    Var3:    dd ?
StrucTTest ENDS
```

``` asm
struct StructTest
    Var1:    db ?
    Var2:    dw ?
    Var3:    dd ?
ends
```

## Original features

Sol_Asm also implements some original features.

### ENUMs

It is possible to define some constants like C language with the ENUM keyword. This little example will generate: TASK_ZOMBIE equ 0, TASK_READY equ 1, TASK_RUNNING equ 2, etc.

``` asm
ENUM TASK, 0, 4
    TASK_ZOMBIE
    TASK_READY
    TASK_RUNNING
    TASK_WAITING
    TASK_SLEEPING
ENDE
```

### Resource compiler

Sol_Asm includes a small resource compiler. This little example will define a dialog box:

``` asm
IDD_DIALOG1 equ 100
IDD_BUTTON1 equ 101

IDD_DIALOG1 DIALOGEX 10, 10, 320, 240
CAPTION "Hello!"
STYLE 0x10CF0000

BEGIN
    CONTROL "Hello", IDC_BUTTON1, "Button", 0x50010000, 10, 10, 50, 24, 0x00000000
END
```

- [↑](https://wiki.osdev.org/Solar_Assembler#ref_1)  by default, arguments and locals are always dwords.
