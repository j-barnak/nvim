# Trait FloatToInt Copy item path

[Source](https://doc.rust-lang.org/src/core/convert/num.rs.html#6)

``` rust
pub trait FloatToInt<Int>: Sized { }
```

ⓘ *This trait cannot be implemented outside `core`.*

🔬This is a nightly-only experimental API. (`convert_float_to_int` [\#67057](https://github.com/rust-lang/rust/issues/67057))

Expand description

Supporting trait for inherent methods of `f32` and `f64` such as `to_int_unchecked`. Typically doesn’t need to be used directly.

## Dyn Compatibility

This trait is **not** [dyn compatible](https://doc.rust-lang.org/1.98.1/reference/items/traits.html#dyn-compatibility).

*In older versions of Rust, dyn compatibility was called "object safety".*
