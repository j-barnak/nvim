# angr.rust.analyses.rust_symbol_recovery

class angr.rust.analyses.rust_symbol_recovery.RustSymbolRecovery  
Bases: [`Analysis`](https://docs.angr.io/en/latest/api/angr.analyses.analysis.html#angr.analyses.analysis.Analysis "angr.analyses.analysis.Analysis")

This analysis recovers Rust symbols by analyzing the binary’s symbol table and debug information. It identifies Rust-specific symbols, such as those related to traits, generics, and async functions, and annotates them for further analysis.
