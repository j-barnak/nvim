# angr.misc.picklable_lock

class angr.misc.picklable_lock.PicklableLock  
Bases: [`object`](https://docs.python.org/3/library/functions.html#object "(in Python v3.14)")

Normal thread-locks are not pickleable. This provides a pickleable lock by mandating that the lock is unlocked during serialization.

class angr.misc.picklable_lock.PicklableRLock  
Bases: [`PicklableLock`](#angr.misc.picklable_lock.PicklableLock "angr.misc.picklable_lock.PicklableLock")

Same as above, but uses RLock instead of Lock for locking. Note that RLock does not provide an interface to tell whether is it presently held by any thread, and thus this class will lie about whether it is locked.
