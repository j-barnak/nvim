save(*chunk_size: int \| None = 2097152*, *named: str \| bool = False*) → Iterator\[bytes\][\[source\]](https://podman-py.readthedocs.io/en/latest/_modules/podman/domain/images.html#Image.save)  
Returns Image as tarball.

Format is set to docker-archive, this allows load() to import this tarball.

Parameters:  
- **chunk_size** – If None, data will be streamed in received buffer size. If not None, data will be returned in sized buffers. Default: 2MB

- **named** (*str* *or* *bool*) – If `False` (default), the tarball will not retain repository and tag information for this image. If set to `True`, the first tag in the [`tags`](#podman.domain.images.Image.tags "podman.domain.images.Image.tags") list will be used to identify the image. Alternatively, any element of the [`tags`](#podman.domain.images.Image.tags "podman.domain.images.Image.tags") list can be used as an argument to use that specific tag as the saved identifier.

Raises:  
- **APIError** – When service returns an error

- **InvalidArgument** – When the provided Tag name is not valid for the image.
