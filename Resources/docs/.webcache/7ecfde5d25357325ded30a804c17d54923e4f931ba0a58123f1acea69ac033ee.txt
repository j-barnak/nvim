The type of raw OS error codes.

This is an [`i32`](https://doc.rust-lang.org/std/primitive.i32.html "primitive i32") on all currently supported platforms, but platforms added in the future (such as UEFI) may use a different primitive type like [`usize`](https://doc.rust-lang.org/std/primitive.usize.html "primitive usize"). Use `as` or [`into`](https://doc.rust-lang.org/std/convert/trait.Into.html#tymethod.into "method std::convert::Into::into") conversions where applicable to ensure maximum portability.
