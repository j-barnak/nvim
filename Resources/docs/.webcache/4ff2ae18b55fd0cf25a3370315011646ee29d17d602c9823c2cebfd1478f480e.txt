# Linux Kernel / Cgroup

The `drgn.helpers.linux.cgroup` module provides helpers for working with the cgroup interface in [`include/linux/cgroup.h`](https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/include/linux/cgroup.h). Only cgroup v2 is supported.
