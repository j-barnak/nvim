**Go** (also called **Golang**) is a language developed at Google. It was never designed to be a bare metal language, but with some tricks you can compile a kernel with it.

## Operating System Development

Go is a garbage-collected language with a comparable amount of runtime to C and C++, and the language needs some callbacks in order to work. Most notably Go lacks important features for kernel development such as converting an integer into a pointer (which is trivial in C; a small Assembly wrapper would be required for Go) and unions. Expect the need for creating wrappers just like that to workaround the language and make suitable for bare metal. Some of the projects below simply use [C](https://wiki.osdev.org/C "C") for the parts which cannot be written in Go natively (with the [Multiboot header](https://wiki.osdev.org/GRUB "GRUB") being one of them).

Details were discussed at GolangUK2017 talk "Bare Metal Gophers: Can you write a kernel in Go?", see [slides here](https://speakerdeck.com/achilleasa/bare-metal-gophers-can-you-write-an-os-kernel-in-go).

At the 36th Chaos Communication Congress in 2019 a full framework for bare metal Go development was released, see [talk](https://www.youtube.com/watch?v=4QircrJjEtQ) and [slides](https://github.com/abarisani/abarisani.github.io/tree/master/research/tamago), the TamaGo framework currently supports several ARM unikernels and also support AMD64 KVM bare metal execution.

## Compilers

Several compilers for Go exist:

- [Go](https://go.googlesource.com/go) ([GitHub mirror](https://github.com/golang/go)), the official main implementation. Architecture support: [AMD64](https://wiki.osdev.org/AMD64 "AMD64"), [x86](https://wiki.osdev.org/X86 "X86"), [ARM](https://wiki.osdev.org/ARM "ARM"), [ARM64](https://wiki.osdev.org/AArch64 "AArch64"), [ppc64](https://wiki.osdev.org/PowerPC "PowerPC"), [ppc64le](https://wiki.osdev.org/PowerPC "PowerPC"), [mips64](https://wiki.osdev.org/MIPS "MIPS"), [mips64le](https://wiki.osdev.org/MIPS "MIPS"), [MIPS](https://wiki.osdev.org/MIPS "MIPS"), [mipsle](https://wiki.osdev.org/MIPS "MIPS"), [riscv64](https://wiki.osdev.org/RISC-V "RISC-V"), [loong64](https://wiki.osdev.org/index.php?title=LoongArch&action=edit&redlink=1 "LoongArch (page does not exist)"), and [s390x](https://wiki.osdev.org/index.php?title=S390x&action=edit&redlink=1 "S390x (page does not exist)").

&nbsp;

- [gccgo](https://gcc.gnu.org/onlinedocs/gccgo/), a [GCC](https://wiki.osdev.org/GCC "GCC") frontend for Go
- [TinyGo](https://tinygo.org/), implementation targeted at embedded systems. Uses [LLVM](https://wiki.osdev.org/LLVM "LLVM") as the codegen backend.

## Projects

- [Bare Metal Gophers](https://github.com/achilleasa/bare-metal-gophers) - code repository for the talk (does not compile with latest Go compiler)
- [TamaGo](https://github.com/usbarmory/tamago) - a complete bare metal Go for AMD64/ARM/RISC-V processors
- [EggOS](https://github.com/icexin/eggos) - a fairly complete environment to run Go applications on bare metal (some parts written in C)
- [Goose](https://github.com/tgascoigne/goose) - the bare minimum environment and a protected mode "Hello World" kernel in Go
- [mykernel](https://gitlab.com/bztsrc/bootboot/tree/master/mykernel/go) a simplistic, long mode "Hello World" kernel in Go
