  

## VGA Resources

- [This wiki](https://wiki.osdev.org/Category:VGA "Category:VGA")
- [Google Search "VGA registers programming"](https://www.google.com/search?hl=en&ie=UTF-8&q=VGA+registers+programming&btnG=Google+Search),
- [OSD: Graphics](http://files.osdev.org/mirrors/geezer/osd/graphics/index.htm) From Chris Giese, containing many code snippets.
- [Tutorial on VGA graphics](http://web.archive.org/web/20140218012818/http://atschool.eduweb.co.uk/camdean/pupils/amac/vga.htm) including basis of font and line rendering, palette setting, unchained mode, etc.
- [FlingOS VGA Driver](https://github.com/FlingOS/FlingOS/tree/develop/Kernel/Libraries/Kernel.VGA) has a good (low-performance but easy to read, protected-mode) VGA driver supporting text and graphical modes

### [Free VGA](http://www.osdever.net/FreeVGA/vga/vga.htm)

- [Graphics Registers](http://www.osdever.net/FreeVGA/vga/graphreg.htm) -- control the way the CPU accesses video RAM.
- [Sequencer Registers](http://www.osdever.net/FreeVGA/vga/seqreg.htm) -- control how video data is sent to the DAC.
- [Attribute Controller Registers](http://www.osdever.net/FreeVGA/vga/attrreg.htm) -- selects the 16 color and 64 color palettes used for EGA/CGA compatibility.
- [CRT Controller Registers](http://www.osdever.net/FreeVGA/vga/crtcreg.htm) -- control how the video is output to the display.
- [Color Registers](http://www.osdever.net/FreeVGA/vga/colorreg.htm) -- selects the 256 color palette from the maximum possible colors.
- [External Registers](http://www.osdever.net/FreeVGA/vga/extreg.htm) -- miscellaneous registers used to control video operation.

## SVGA resources

- The VESA home page: [http://www.vesa.org](http://www.vesa.org)
- Emulating VESA calls from protected mode: [Virtual 8086 Mode](https://wiki.osdev.org/Virtual_8086_Mode "Virtual 8086 Mode"), or use a library like [libx86emu](https://github.com/wfeldt/libx86emu). Xfree86 used [this code](https://cgit.freedesktop.org/xorg/xserver/tree/hw/xfree86/x86emu) to access VESA functions on Linux.
