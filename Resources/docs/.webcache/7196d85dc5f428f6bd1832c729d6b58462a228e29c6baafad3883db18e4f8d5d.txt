# Struct OccupiedEntry Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/std/collections/hash/map.rs.html#1978-1985)

``` rust
pub struct OccupiedEntry<'a, K: 'a, V: 'a, A: Allocator = Global> { /* private fields */ }
```

Expand description

A view into an occupied entry in a `HashMap`. It is part of the [`Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html "enum std::collections::hash_map::Entry") enum.

1.10.0 · [Source](https://doc.rust-lang.org/src/std/collections/hash/map.rs.html#2762-2764)

Gets a reference to the key in the entry.

##### Examples

``` rust
use std::collections::HashMap;

let mut map: HashMap<&str, u32> = HashMap::new();
map.entry("poneyland").or_insert(12);
assert_eq!(map.entry("poneyland").key(), &"poneyland");
```

1.12.0 · [Source](https://doc.rust-lang.org/src/std/collections/hash/map.rs.html#2786-2788)

Take the ownership of the key and value from the map.

##### Examples

``` rust
use std::collections::HashMap;
use std::collections::hash_map::Entry;

let mut map: HashMap<&str, u32> = HashMap::new();
map.entry("poneyland").or_insert(12);

if let Entry::Occupied(o) = map.entry("poneyland") {
    // We delete the entry from the map.
    o.remove_entry();
}

assert_eq!(map.contains_key("poneyland"), false);
```

1.0.0 · [Source](https://doc.rust-lang.org/src/std/collections/hash/map.rs.html#2807-2809)

use std::collections::HashMap;
use std::collections::hash_map::Entry;

1.0.0 · [Source](https://doc.rust-lang.org/src/std/collections/hash/map.rs.html#2840-2842)

Gets a mutable reference to the value in the entry.

If you need a reference to the `OccupiedEntry` which may outlive the destruction of the `Entry` value, see [`into_mut`](https://doc.rust-lang.org/std/collections/hash_map/struct.OccupiedEntry.html#method.into_mut "method std::collections::hash_map::OccupiedEntry::into_mut").

##### Examples

``` rust
use std::collections::HashMap;
use std::collections::hash_map::Entry;

let mut map: HashMap<&str, u32> = HashMap::new();
map.entry("poneyland").or_insert(12);

assert_eq!(map["poneyland"], 12);
if let Entry::Occupied(mut o) = map.entry("poneyland") {
    *o.get_mut() += 10;
    assert_eq!(*o.get(), 22);

    // We can use the same Entry multiple times.
    *o.get_mut() += 2;
}

assert_eq!(map["poneyland"], 24);
```

1.0.0 · [Source](https://doc.rust-lang.org/src/std/collections/hash/map.rs.html#2869-2871)

Converts the `OccupiedEntry` into a mutable reference to the value in the entry with a lifetime bound to the map itself.

If you need multiple references to the `OccupiedEntry`, see [`get_mut`](https://doc.rust-lang.org/std/collections/hash_map/struct.OccupiedEntry.html#method.get_mut "method std::collections::hash_map::OccupiedEntry::get_mut").

##### Examples

``` rust
use std::collections::HashMap;
use std::collections::hash_map::Entry;

let mut map: HashMap<&str, u32> = HashMap::new();
map.entry("poneyland").or_insert(12);

assert_eq!(map["poneyland"], 12);
if let Entry::Occupied(o) = map.entry("poneyland") {
    *o.into_mut() += 10;
}

assert_eq!(map["poneyland"], 22);
```

1.0.0 · [Source](https://doc.rust-lang.org/src/std/collections/hash/map.rs.html#2892-2894)

Sets the value of the entry, and returns the entry’s old value.

##### Examples

``` rust
use std::collections::HashMap;
use std::collections::hash_map::Entry;

let mut map: HashMap<&str, u32> = HashMap::new();
map.entry("poneyland").or_insert(12);

if let Entry::Occupied(mut o) = map.entry("poneyland") {
    assert_eq!(o.insert(15), 12);
}

assert_eq!(map["poneyland"], 15);
```

1.0.0 · [Source](https://doc.rust-lang.org/src/std/collections/hash/map.rs.html#2915-2917)

Takes the value out of the entry, and returns it.

##### Examples

``` rust
use std::collections::HashMap;
use std::collections::hash_map::Entry;

let mut map: HashMap<&str, u32> = HashMap::new();
map.entry("poneyland").or_insert(12);

if let Entry::Occupied(o) = map.entry("poneyland") {
    assert_eq!(o.remove(), 12);
}

assert_eq!(map.contains_key("poneyland"), false);
```
