# angr.analyses.calling_convention.utils

angr.analyses.calling_convention.utils.is_sane_register_variable(*arch*, *reg_offset*, *reg_size*, *def_cc=None*)  
Filters all registers that are surly not members of function arguments. This can be seen as a workaround, since VariableRecoveryFast sometimes gives input variables of cc_ndep (which is a VEX-specific register) :-(

Parameters:  
- **reg_offset** ([`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")) – The register offset.

- **reg_size** ([`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")) – The register size.

- **arch** ([*Arch*](https://docs.angr.io/projects/archinfo/en/latest/api.html#archinfo.arch.Arch "(in archinfo)"))

- **def_cc** ([*SimCC*](https://docs.angr.io/en/latest/api/angr.calling_conventions.html#angr.calling_conventions.SimCC "angr.calling_conventions.SimCC") *\|* [*type*](https://docs.angr.io/en/latest/api/angr.analyses.data_dep.dep_nodes.html#angr.analyses.data_dep.dep_nodes.BaseDepNode.type "angr.analyses.data_dep.dep_nodes.BaseDepNode.type")*\[*[*SimCC*](https://docs.angr.io/en/latest/api/angr.calling_conventions.html#angr.calling_conventions.SimCC "angr.calling_conventions.SimCC")*\]* *\|* *None*)

Returns:  
True if it is an acceptable function argument, False otherwise.

angr.analyses.calling_convention.utils.merge_overlapping_register_spans(*arch*, *spans*)  
Merge register reads that belong to the same base register into one span per base register.

The merged span is the smallest named register starting at the base register that covers every read (e.g., reads of `ch` and `cx` become `cx`). When no register of the covering size exists, the widest read is kept. Floating-point and vector registers are left alone: their sub-registers hold separate arguments (e.g., `s0` and `s1` in `d0` on ARM hard-float).

Parameters:  
- **arch** ([`Arch`](https://docs.angr.io/projects/archinfo/en/latest/api.html#archinfo.arch.Arch "(in archinfo)")) – The architecture.

- **spans** ([`Iterable`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Iterable "(in Python v3.14)")\[[`tuple`](https://docs.python.org/3/library/stdtypes.html#tuple "(in Python v3.14)")\[[`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)"), [`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")\]\]) – Register reads as (offset, size) tuples.

Return type:  
[`list`](https://docs.python.org/3/library/stdtypes.html#list "(in Python v3.14)")\[[`tuple`](https://docs.python.org/3/library/stdtypes.html#tuple "(in Python v3.14)")\[[`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)"), [`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")\]\]

Returns:  
Merged (offset, size) tuples, sorted by offset.
