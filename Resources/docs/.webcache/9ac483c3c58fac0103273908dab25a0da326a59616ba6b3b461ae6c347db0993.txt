    type Usize;
    type Isize;
    type CastPtr<T>;

    // Required methods

    fn cast<T>(self) -> Self::CastPtr<T>;
    fn cast_const(self) -> Self::ConstPtr;
    fn addr(self) -> Self::Usize;

    fn with_addr(self, addr: Self::Usize) -> Self;
    fn expose_provenance(self) -> Self::Usize;
    fn with_exposed_provenance(addr: Self::Usize) -> Self;
    fn wrapping_offset(self, offset: Self::Isize) -> Self;
    fn wrapping_add(self, count: Self::Usize) -> Self;

}

Converts an address to a pointer without giving it any provenance.

Without provenance, this pointer is not associated with any actual allocation. Such a no-provenance pointer may be used for zero-sized memory accesses (if suitably aligned), but non-zero-sized memory accesses with a no-provenance pointer are UB. No-provenance pointers are little more than a usize address in disguise.

This is different from [`Self::with_exposed_provenance`](https://doc.rust-lang.org/std/simd/ptr/trait.SimdMutPtr.html#tymethod.with_exposed_provenance "associated function std::simd::ptr::SimdMutPtr::with_exposed_provenance"), which creates a pointer that picks up a previously exposed provenance.

Equivalent to calling [`core::ptr::without_provenance`](https://doc.rust-lang.org/std/ptr/fn.without_provenance.html "fn std::ptr::without_provenance") on each element.

[Source](https://doc.rust-lang.org/src/core/portable-simd/crates/core_simd/src/simd/ptr/mut_ptr.rs.html#61)

🔬This is a nightly-only experimental API. (`portable_simd` [\#86656](https://github.com/rust-lang/rust/issues/86656))

Creates a new pointer with the given address.

This performs the same operation as a cast, but copies the *address-space* and *provenance* of `self` to the new pointer.

Equivalent to calling [`pointer::with_addr`](https://doc.rust-lang.org/std/primitive.pointer.html#method.with_addr "method pointer::with_addr") on each element.
