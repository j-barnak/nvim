The Extensible Driver Interface (EDI) is a driver interface that is intended to be portable between OSes while standardizing as little functionality as possible.

## Introduction

In 2006, Eli Gottlieb made EDI after deciding that [UDI](https://wiki.osdev.org/UDI "UDI") standardized too much. It is designed to be small, extensible, and require very little from the system providing the implementation. This is done by using an object oriented model accessed using C functions, allowing drivers and operating systems in almost all languages to use it.
