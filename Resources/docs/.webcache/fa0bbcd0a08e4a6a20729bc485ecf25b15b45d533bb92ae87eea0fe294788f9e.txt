# Primitive Type bool Copy item path

1.0.0

Expand description

The boolean type.

The `bool` represents a value, which could only be either [`true`](https://doc.rust-lang.org/std/keyword.true.html) or [`false`](https://doc.rust-lang.org/std/keyword.false.html). If you cast a `bool` into an integer, [`true`](https://doc.rust-lang.org/std/keyword.true.html) will be 1 and [`false`](https://doc.rust-lang.org/std/keyword.false.html) will be 0.

## Basic usage

`bool` implements various traits, such as [`BitAnd`](https://doc.rust-lang.org/std/ops/trait.BitAnd.html "trait std::ops::BitAnd"), [`BitOr`](https://doc.rust-lang.org/std/ops/trait.BitOr.html "trait std::ops::BitOr"), [`Not`](https://doc.rust-lang.org/std/ops/trait.Not.html "trait std::ops::Not"), etc., which allow us to perform boolean operations using `&`, `|` and `!`.

[`if`](https://doc.rust-lang.org/std/keyword.if.html) requires a `bool` value as its conditional. [`assert!`](https://doc.rust-lang.org/std/macro.assert.html "macro std::assert"), which is an important macro in testing, checks whether an expression is [`true`](https://doc.rust-lang.org/std/keyword.true.html) and panics if it isn’t.

``` rust
let bool_val = true & false | false;
assert!(!bool_val);
```

## Examples

A trivial example of the usage of `bool`:

``` rust
let praise_the_borrow_checker = true;

// using the `if` conditional
if praise_the_borrow_checker {
    println!("oh, yeah!");
} else {
    println!("what?!!");
}

// ... or, a match pattern
match praise_the_borrow_checker {
    true => println!("keep praising!"),
    false => println!("you should praise!"),
}
```

Also, since `bool` implements the [`Copy`](https://doc.rust-lang.org/std/marker/trait.Copy.html "trait std::marker::Copy") trait, we don’t have to worry about the move semantics (just like the integer and float primitives).

Now an example of `bool` cast to integer type:

``` rust
assert_eq!(true as i32, 1);
assert_eq!(false as i32, 0);
```

Returns `Some(t)` if the `bool` is [`true`](https://doc.rust-lang.org/std/keyword.true.html), or `None` otherwise.

Arguments passed to `then_some` are eagerly evaluated; if you are passing the result of a function call, it is recommended to use [`then`](https://doc.rust-lang.org/std/primitive.bool.html#method.then "method bool::then"), which is lazily evaluated.

##### Examples

``` rust
assert_eq!(false.then_some(0), None);
assert_eq!(true.then_some(0), Some(0));
```

``` rust
let mut a = 0;
let mut function_with_side_effects = || { a += 1; };

true.then_some(function_with_side_effects());
false.then_some(function_with_side_effects());

// `a` is incremented twice because the value passed to `then_some` is
// evaluated eagerly.
assert_eq!(a, 2);
```

1.50.0 (const: [unstable](https://github.com/rust-lang/rust/issues/151531 "Tracking issue for const_bool")) · [Source](https://doc.rust-lang.org/src/core/bool.rs.html#65)

Returns `Some(f())` if the `bool` is [`true`](https://doc.rust-lang.org/std/keyword.true.html), or `None` otherwise.

##### Examples

``` rust
assert_eq!(false.then(|| 0), None);
assert_eq!(true.then(|| 0), Some(0));
```

``` rust
let mut a = 0;

true.then(|| { a += 1; });
false.then(|| { a += 1; });

// `a` is incremented once because the closure is evaluated lazily by
// `then`.
assert_eq!(a, 1);
```

1.98.0 (const: [unstable](https://github.com/rust-lang/rust/issues/151531 "Tracking issue for const_bool")) · [Source](https://doc.rust-lang.org/src/core/bool.rs.html#99)

Returns `Ok(())` if the `bool` is [`true`](https://doc.rust-lang.org/std/keyword.true.html), or `Err(err)` otherwise.

Arguments passed to `ok_or` are eagerly evaluated; if you are passing the result of a function call, it is recommended to use [`ok_or_else`](https://doc.rust-lang.org/std/primitive.bool.html#method.ok_or_else "method bool::ok_or_else"), which is lazily evaluated.

##### Examples

``` rust
assert_eq!(false.ok_or(0), Err(0));
assert_eq!(true.ok_or(0), Ok(()));
```

``` rust
let mut a = 0;
let mut function_with_side_effects = || { a += 1; };

assert!(true.ok_or(function_with_side_effects()).is_ok());
assert!(false.ok_or(function_with_side_effects()).is_err());

// `a` is incremented twice because the value passed to `ok_or` is
// evaluated eagerly.
assert_eq!(a, 2);
```
