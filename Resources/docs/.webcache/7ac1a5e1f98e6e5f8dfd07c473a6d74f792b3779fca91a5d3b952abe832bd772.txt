# Type Alias c_ushort Copy item path

pub type c_ushort = u16;

Expand description

Equivalent to C’s `unsigned short` type.

This type will almost always be [`u16`](https://doc.rust-lang.org/std/primitive.u16.html "primitive u16"), but may differ on some esoteric systems. The C standard technically only requires that this type be an unsigned integer with the same size as a [`short`](https://doc.rust-lang.org/std/ffi/type.c_short.html "type std::ffi::c_short").
