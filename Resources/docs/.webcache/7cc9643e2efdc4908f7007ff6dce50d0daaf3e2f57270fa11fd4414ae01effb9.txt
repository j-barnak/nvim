# Struct DebugSet Copy item path

pub struct DebugSet<'a, 'b>where

Expand description

A struct to help with [`fmt::Debug`](https://doc.rust-lang.org/std/fmt/trait.Debug.html "trait std::fmt::Debug") implementations.

This is useful when you wish to output a formatted set of items as a part of your [`Debug::fmt`](https://doc.rust-lang.org/std/fmt/trait.Debug.html#tymethod.fmt "method std::fmt::Debug::fmt") implementation.

This can be constructed by the [`Formatter::debug_set`](https://doc.rust-lang.org/std/fmt/struct.Formatter.html#method.debug_set "method std::fmt::Formatter::debug_set") method.

## Examples

``` rust
use std::fmt;

struct Foo(Vec<i32>);

impl fmt::Debug for Foo {
    fn fmt(&self, fmt: &mut fmt::Formatter<'_>) -> fmt::Result {
        fmt.debug_set().entries(self.0.iter()).finish()
    }
}

assert_eq!(
    format!("{:?}", Foo(vec![10, 11])),
    "{10, 11}",
);
```

Adds a new entry to the set output.

##### Examples

``` rust
use std::fmt;

struct Foo(Vec<i32>, Vec<u32>);

impl fmt::Debug for Foo {
    fn fmt(&self, fmt: &mut fmt::Formatter<'_>) -> fmt::Result {
        fmt.debug_set()
           .entry(&self.0) // Adds the first "entry".
           .entry(&self.1) // Adds the second "entry".
           .finish()
    }
}

assert_eq!(
    format!("{:?}", Foo(vec![10, 11], vec![12, 13])),
    "{[10, 11], [12, 13]}",
);
```

Adds a new entry to the set output.

This method is equivalent to [`DebugSet::entry`](https://doc.rust-lang.org/std/fmt/struct.DebugSet.html#method.entry "method std::fmt::DebugSet::entry"), but formats the entry using a provided closure rather than by calling [`Debug::fmt`](https://doc.rust-lang.org/std/fmt/trait.Debug.html#tymethod.fmt "method std::fmt::Debug::fmt").

Adds the contents of an iterator of entries to the set output.

##### Examples

``` rust
use std::fmt;

struct Foo(Vec<i32>, Vec<u32>);

impl fmt::Debug for Foo {
    fn fmt(&self, fmt: &mut fmt::Formatter<'_>) -> fmt::Result {
        fmt.debug_set()

           .finish()
    }
}

    format!("{:?}", Foo(vec![10, 11], vec![12, 13])),
    "{10, 11, 12, 13}",
);
```

1.83.0 · [Source](https://doc.rust-lang.org/src/core/fmt/builders.rs.html#630)

Marks the set as non-exhaustive, indicating to the reader that there are some other elements that are not shown in the debug representation.

##### Examples

``` rust
use std::fmt;

struct Foo(Vec<i32>);

impl fmt::Debug for Foo {
    fn fmt(&self, fmt: &mut fmt::Formatter<'_>) -> fmt::Result {
        // Print at most two elements, abbreviate the rest
        let mut f = fmt.debug_set();
        let mut f = f.entries(self.0.iter().take(2));
        if self.0.len() > 2 {
            f.finish_non_exhaustive()
        } else {
            f.finish()
        }
    }
}

assert_eq!(
    format!("{:?}", Foo(vec![1, 2, 3, 4])),
    "{1, 2, ..}",
);
```

1.2.0 · [Source](https://doc.rust-lang.org/src/core/fmt/builders.rs.html#672)
