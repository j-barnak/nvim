This mixin adds automatic allocation for a stack region based on the stack_end and stack_size parameters.

\_\_init\_\_(*stack_end=None*, *stack_size=None*, *stack_perms=None*, *\*\*kwargs*)  

allocate_stack_pages(*addr*, *size*, *\*\*kwargs*)  
Pre-allocates pages for the stack without triggering any logic related to reading from them.

Parameters:  
- **addr** ([`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")) – The highest address that should be mapped

- **size** ([`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")) – The number of bytes to be allocated. byte 1 is the one at addr, byte 2 is the one before that, and so on.

Returns:  
A list of the new page objects
