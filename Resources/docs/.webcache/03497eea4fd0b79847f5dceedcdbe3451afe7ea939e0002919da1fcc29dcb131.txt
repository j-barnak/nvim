# Function is_separator Copy item path

1.0.0 (const: [unstable](https://github.com/rust-lang/rust/issues/153106 "Tracking issue for const_path_separators")) · [Source](https://doc.rust-lang.org/src/std/path.rs.html#270-272)

``` rust
pub fn is_separator(c: char) -> bool
```

Expand description

Determines whether the character is one of the permitted path separators for the current platform.

## Examples

``` rust
use std::path;

assert!(path::is_separator('/')); // '/' works for both Unix and Windows
assert!(!path::is_separator('❤'));
```
