### 5.2. Maximizing Satisfying Assignments

Another use of models is to use them as a guide to a notion of optimal model. A *maximal satisfying solution*, in short *mss*, for a set of formulas `ps` is a subset of `ps` that is consistent with respect to the solver state `s` and cannot be extended to a bigger subset of `ps` without becoming inconsistent relative to `s`. We provide a procedure, from \[[48](#menciapm15 "Carlos Mencía, Alessandro Previti, and João Marques-Silva. 
Literal-based MCS extraction.")\], for finding a maximal satisfying subset in Figure [5](#fig-mss "An algorithm for computing maximal satisfying subsets"). It extends a set `mss` greedily by adding as many satisfied predicates from `ps` in each round as possible. If it finds some predicate `p` that it cannot add, it notes that it is a backbone with respect to the current `mss`. As a friendly hint, it includes the negation of `p` when querying the solver in future rounds.

```
def tt(s, f): 
    return is_true(s.model().eval(f))

def get_mss(s, ps):
    if sat != s.check():
       return []
    mss = { q for q in ps if tt(s, q) }
    return get_mss(s, mss, ps)

def get_mss(s, mss, ps):
    ps = ps - mss
    backbones = set([])
    while len(ps) > 0:
       p = ps.pop()
       if sat == s.check(mss | backbones | { p }):
          mss = mss | { p } | { q for q in ps if tt(s, q) }
          ps  = ps - mss
       else:
          backbones = backbones | { Not(p) }
    return mss          
```
