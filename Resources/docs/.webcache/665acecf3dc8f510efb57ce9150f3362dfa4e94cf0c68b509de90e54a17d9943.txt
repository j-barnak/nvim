# Type Alias c_double Copy item path

Expand description

Equivalent to C’s `double` type.

This type will almost always be [`f64`](https://doc.rust-lang.org/std/primitive.f64.html "primitive f64"), which is guaranteed to be an [IEEE 754 double-precision float](https://en.wikipedia.org/wiki/IEEE_754) in Rust. That said, the standard technically only guarantees that it be a floating-point number with at least the precision of a [`float`](https://doc.rust-lang.org/std/os/raw/type.c_float.html "type std::os::raw::c_float"); some 16-bit systems use [`f32`](https://doc.rust-lang.org/std/primitive.f32.html "primitive f32"), for example. Esoteric systems could use something entirely different from the IEEE-754 standard.
