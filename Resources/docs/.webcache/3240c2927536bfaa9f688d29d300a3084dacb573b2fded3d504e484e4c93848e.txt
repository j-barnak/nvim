# Linux Kernel / NUMA Node Masks

The `drgn.helpers.linux.nodemask` module provides helpers for working with NUMA node masks from [`include/linux/nodemask.h`](https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/include/linux/nodemask.h).

Get the upper bound on the number of NUMA node IDs.
