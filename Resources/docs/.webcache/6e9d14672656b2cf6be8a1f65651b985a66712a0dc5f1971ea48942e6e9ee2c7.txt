Expand description

An IPv4 socket address.

IPv4 socket addresses consist of an [`IPv4` address](https://doc.rust-lang.org/std/net/struct.Ipv4Addr.html "struct std::net::Ipv4Addr") and a 16-bit port number, as stated in [IETF RFC 793](https://tools.ietf.org/html/rfc793).

See [`SocketAddr`](https://doc.rust-lang.org/std/net/enum.SocketAddr.html "enum std::net::SocketAddr") for a type encompassing both IPv4 and IPv6 socket addresses.

## Portability

`SocketAddrV4` is intended to be a portable representation of socket addresses and is likely not the same as the internal socket address type used by the target operating system’s API. Like all `repr(Rust)` structs, however, its exact layout remains undefined and should not be relied upon between builds.

## Textual representation

`SocketAddrV4` provides a [`FromStr`](https://doc.rust-lang.org/std/str/trait.FromStr.html "trait std::str::FromStr") implementation. It accepts an IPv4 address in its [textual representation](https://doc.rust-lang.org/std/net/struct.Ipv4Addr.html#textual-representation "struct std::net::Ipv4Addr"), followed by a single `:`, followed by the port encoded as a decimal integer. Other formats are not accepted.

## Examples

``` rust
use std::net::{Ipv4Addr, SocketAddrV4};

let socket = SocketAddrV4::new(Ipv4Addr::new(127, 0, 0, 1), 8080);

assert_eq!("127.0.0.1:8080".parse(), Ok(socket));
assert_eq!(socket.ip(), &Ipv4Addr::new(127, 0, 0, 1));
assert_eq!(socket.port(), 8080);
```
