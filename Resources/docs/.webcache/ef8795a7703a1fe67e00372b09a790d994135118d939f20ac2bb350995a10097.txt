# NAME

podman-farm-remove - Delete one or more farms

# SYNOPSIS

**podman farm remove** \[*options*\] *name*

**podman farm rm** \[*options*\] *name*

# DESCRIPTION

Delete one or more farms.

# OPTIONS

## **--all**, **-a**

Remove all farms.

# EXAMPLE

Remove specified farm:

```
$ podman farm remove farm1
```

Remove all farms:

```
$ podman farm rm --all
```
