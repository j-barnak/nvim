# Trait FileExt Copy item path

Available on **Unix** only.

Expand description

Unix-specific extensions to [`fs::File`](https://doc.rust-lang.org/std/fs/struct.File.html "struct std::fs::File").

## Required Methods

1.15.0 · [Source](https://doc.rust-lang.org/src/std/os/unix/fs.rs.html#59)

Reads a number of bytes starting from a given offset.

Returns the number of bytes read.

The offset is relative to the start of the file and thus independent from the current cursor.

The current file cursor is not affected by this function.

Note that similar to [`File::read`](https://doc.rust-lang.org/std/fs/struct.File.html#method.read "method std::fs::File::read"), it is not an error to return with a short read.

##### Examples

``` rust
use std::io;
use std::fs::File;
use std::os::unix::prelude::FileExt;

fn main() -> io::Result<()> {
    let mut buf = [0u8; 8];
    let file = File::open("foo.txt")?;

    // We now read 8 bytes from the offset 10.
    let num_bytes_read = file.read_at(&mut buf, 10)?;
    println!("read {num_bytes_read} bytes: {buf:?}");
    Ok(())
}
```

1.15.0 · [Source](https://doc.rust-lang.org/src/std/os/unix/fs.rs.html#284)

Writes a number of bytes starting from a given offset.

Returns the number of bytes written.

The offset is relative to the start of the file and thus independent from the current cursor.

The current file cursor is not affected by this function.

When writing beyond the end of the file, the file is appropriately extended and the intermediate bytes are initialized with the value 0.

Note that similar to [`File::write`](https://doc.rust-lang.org/std/fs/struct.File.html#method.write "method std::fs::File::write"), it is not an error to return a short write.

##### Bug

On some systems, `write_at` utilises [`pwrite64`](https://man7.org/linux/man-pages/man2/pwrite.2.html) to write to files. However, this syscall has a [bug](https://man7.org/linux/man-pages/man2/pwrite.2.html#BUGS) where files opened with the `O_APPEND` flag fail to respect the offset parameter, always appending to the end of the file instead.

It is possible to inadvertently set this flag, like in the example below. Therefore, it is important to be vigilant while changing options to mitigate unexpected behavior.

``` rust
use std::fs::File;
use std::io;
use std::os::unix::prelude::FileExt;

fn main() -> io::Result<()> {
    // Open a file with the append option (sets the `O_APPEND` flag)
    let file = File::options().append(true).open("foo.txt")?;

    // We attempt to write at offset 10; instead appended to EOF
    file.write_at(b"sushi", 10)?;

    // foo.txt is 5 bytes long instead of 15
    Ok(())
}
```

##### Examples

``` rust
use std::fs::File;
use std::io;
use std::os::unix::prelude::FileExt;

fn main() -> io::Result<()> {
    let file = File::create("foo.txt")?;

    // We now write at the offset 10.
    file.write_at(b"sushi", 10)?;
    Ok(())
}
```

## Provided Methods

Like `read_at`, except that it reads into a slice of buffers.

Data is copied to fill each buffer in order, with the final buffer written to possibly being only partially filled. This method must behave equivalently to a single call to read with concatenated buffers.

1.33.0 · [Source](https://doc.rust-lang.org/src/std/os/unix/fs.rs.html#117-131)

Reads the exact number of bytes required to fill `buf` from the given offset.

The offset is relative to the start of the file and thus independent from the current cursor.

The current file cursor is not affected by this function.

Similar to [`io::Read::read_exact`](https://doc.rust-lang.org/std/io/trait.Read.html#method.read_exact "method std::io::Read::read_exact") but uses [`read_at`](https://doc.rust-lang.org/std/os/unix/fs/trait.FileExt.html#tymethod.read_at "method std::os::unix::fs::FileExt::read_at") instead of `read`.

##### Errors

If this function encounters an error of the kind [`io::ErrorKind::Interrupted`](https://doc.rust-lang.org/std/io/enum.ErrorKind.html#variant.Interrupted "variant std::io::ErrorKind::Interrupted") then the error is ignored and the operation will continue.

If this function encounters an “end of file” before completely filling the buffer, it returns an error of the kind [`io::ErrorKind::UnexpectedEof`](https://doc.rust-lang.org/std/io/enum.ErrorKind.html#variant.UnexpectedEof "variant std::io::ErrorKind::UnexpectedEof"). The contents of `buf` are unspecified in this case.

If any other read error is encountered then this function immediately returns. The contents of `buf` are unspecified in this case.

If this function returns an error, it is unspecified how many bytes it has read, but it will never read more than would be necessary to completely fill the buffer.

##### Examples

``` rust
use std::io;
use std::fs::File;
use std::os::unix::prelude::FileExt;

fn main() -> io::Result<()> {
    let mut buf = [0u8; 8];
    let file = File::open("foo.txt")?;

    // We now read exactly 8 bytes from the offset 10.
    file.read_exact_at(&mut buf, 10)?;
    println!("read {} bytes: {:?}", buf.len(), buf);
    Ok(())
}
```

[Source](https://doc.rust-lang.org/src/std/os/unix/fs.rs.html#165-167)

🔬This is a nightly-only experimental API. (`read_buf_at` [\#140771](https://github.com/rust-lang/rust/issues/140771))

Reads some bytes starting from a given offset into the buffer.

This equivalent to the [`read_at`](https://doc.rust-lang.org/std/os/unix/fs/trait.FileExt.html#tymethod.read_at "method std::os::unix::fs::FileExt::read_at") method, except that it is passed a [`BorrowedCursor`](https://doc.rust-lang.org/std/io/struct.BorrowedCursor.html "struct std::io::BorrowedCursor") rather than `&mut [u8]` to allow use with uninitialized buffers. The new data will be appended to any existing contents of `buf`.

##### Examples

``` rust
#![feature(core_io_borrowed_buf)]
#![feature(read_buf_at)]

use std::io;
use std::io::BorrowedBuf;
use std::fs::File;
use std::mem::MaybeUninit;
use std::os::unix::prelude::*;

fn main() -> io::Result<()> {
    let mut file = File::open("pi.txt")?;

    // Read some bytes starting from offset 2
    let mut buf: [MaybeUninit<u8>; 10] = [MaybeUninit::uninit(); 10];
    let mut buf = BorrowedBuf::from(buf.as_mut_slice());
    file.read_buf_at(buf.unfilled(), 2)?;

    assert!(buf.filled().starts_with(b"1"));

    Ok(())
}
```

Reads the exact number of bytes required to fill the buffer from a given offset.

This is equivalent to the [`read_exact_at`](https://doc.rust-lang.org/std/os/unix/fs/trait.FileExt.html#method.read_exact_at "method std::os::unix::fs::FileExt::read_exact_at") method, except that it is passed a [`BorrowedCursor`](https://doc.rust-lang.org/std/io/struct.BorrowedCursor.html "struct std::io::BorrowedCursor") rather than `&mut [u8]` to allow use with uninitialized buffers. The new data will be appended to any existing contents of `buf`.

##### Examples

``` rust
#![feature(core_io_borrowed_buf)]

use std::io;
use std::io::BorrowedBuf;
use std::fs::File;
use std::mem::MaybeUninit;

fn main() -> io::Result<()> {
    let mut file = File::open("pi.txt")?;

    // Read exactly 10 bytes starting from offset 2
    let mut buf: [MaybeUninit<u8>; 10] = [MaybeUninit::uninit(); 10];
    let mut buf = BorrowedBuf::from(buf.as_mut_slice());
```

1.33.0 · [Source](https://doc.rust-lang.org/src/std/os/unix/fs.rs.html#333-348)

Attempts to write an entire buffer starting from a given offset.

The offset is relative to the start of the file and thus independent from the current cursor.

The current file cursor is not affected by this function.

This method will continuously call [`write_at`](https://doc.rust-lang.org/std/os/unix/fs/trait.FileExt.html#tymethod.write_at "method std::os::unix::fs::FileExt::write_at") until there is no more data to be written or an error of non-[`io::ErrorKind::Interrupted`](https://doc.rust-lang.org/std/io/enum.ErrorKind.html#variant.Interrupted "variant std::io::ErrorKind::Interrupted") kind is returned. This method will not return until the entire buffer has been successfully written or such an error occurs. The first error that is not of [`io::ErrorKind::Interrupted`](https://doc.rust-lang.org/std/io/enum.ErrorKind.html#variant.Interrupted "variant std::io::ErrorKind::Interrupted") kind generated from this method will be returned.

##### Errors

This function will return the first error of non-[`io::ErrorKind::Interrupted`](https://doc.rust-lang.org/std/io/enum.ErrorKind.html#variant.Interrupted "variant std::io::ErrorKind::Interrupted") kind that [`write_at`](https://doc.rust-lang.org/std/os/unix/fs/trait.FileExt.html#tymethod.write_at "method std::os::unix::fs::FileExt::write_at") returns.

##### Examples

``` rust
use std::fs::File;
use std::io;
use std::os::unix::prelude::FileExt;

fn main() -> io::Result<()> {
    let file = File::open("foo.txt")?;

    // We now write at the offset 10.
    file.write_all_at(b"sushi", 10)?;
    Ok(())
}
```
