Expand description

The file descriptor for the standard input stream of the current process.

See [`io::stdin()`](https://doc.rust-lang.org/std/io/fn.stdin.html "fn std::io::stdin") for the higher level handle, which should be preferred whenever possible. See [`STDERR`](https://doc.rust-lang.org/std/os/fd/constant.STDERR.html "constant std::os::fd::STDERR") for why the file descriptor might be required and caveats.
