# Function channel Copy item path

[Source](https://doc.rust-lang.org/src/std/sync/mpmc/mod.rs.html#198-203)

``` rust
pub fn channel<T>() -> (Sender<T>, Receiver<T>)
```

🔬This is a nightly-only experimental API. (`mpmc_channel` [\#126840](https://github.com/rust-lang/rust/issues/126840))

Expand description

Creates a new asynchronous channel, returning the sender/receiver halves.

All data sent on the [`Sender`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html "struct std::sync::mpmc::Sender") will become available on the [`Receiver`](https://doc.rust-lang.org/std/sync/mpmc/struct.Receiver.html "struct std::sync::mpmc::Receiver") in the same order as it was sent, and no [`send`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html#method.send "method std::sync::mpmc::Sender::send") will block the calling thread (this channel has an “infinite buffer”, unlike [`sync_channel`](https://doc.rust-lang.org/std/sync/mpmc/fn.sync_channel.html "fn std::sync::mpmc::sync_channel"), which will block after its buffer limit is reached). [`recv`](https://doc.rust-lang.org/std/sync/mpmc/struct.Receiver.html#method.recv "method std::sync::mpmc::Receiver::recv") will block until a message is available while there is at least one [`Sender`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html "struct std::sync::mpmc::Sender") alive (including clones).

The [`Sender`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html "struct std::sync::mpmc::Sender") can be cloned to [`send`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html#method.send "method std::sync::mpmc::Sender::send") to the same channel multiple times. The [`Receiver`](https://doc.rust-lang.org/std/sync/mpmc/struct.Receiver.html "struct std::sync::mpmc::Receiver") also can be cloned to have multi receivers.

If the [`Receiver`](https://doc.rust-lang.org/std/sync/mpmc/struct.Receiver.html "struct std::sync::mpmc::Receiver") is disconnected while trying to [`send`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html#method.send "method std::sync::mpmc::Sender::send") with the [`Sender`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html "struct std::sync::mpmc::Sender"), the [`send`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html#method.send "method std::sync::mpmc::Sender::send") method will return a [`SendError`](https://doc.rust-lang.org/std/sync/mpsc/struct.SendError.html "struct std::sync::mpsc::SendError"). Similarly, if the [`Sender`](https://doc.rust-lang.org/std/sync/mpmc/struct.Sender.html "struct std::sync::mpmc::Sender") is disconnected while trying to [`recv`](https://doc.rust-lang.org/std/sync/mpmc/struct.Receiver.html#method.recv "method std::sync::mpmc::Receiver::recv"), the [`recv`](https://doc.rust-lang.org/std/sync/mpmc/struct.Receiver.html#method.recv "method std::sync::mpmc::Receiver::recv") method will return a [`RecvError`](https://doc.rust-lang.org/std/sync/mpsc/struct.RecvError.html "struct std::sync::mpsc::RecvError").

## Examples

``` rust
#![feature(mpmc_channel)]

use std::sync::mpmc::channel;
use std::thread;

let (sender, receiver) = channel();

// Spawn off an expensive computation
thread::spawn(move || {
    sender.send(expensive_computation()).unwrap();
});

// Do some useful work for a while

// Let's see what that answer was
println!("{:?}", receiver.recv().unwrap());
```
