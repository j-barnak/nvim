# Type Alias c_short Copy item path

pub type c_short = i16;

Expand description

Equivalent to C’s `signed short` (`short`) type.

This type will almost always be [`i16`](https://doc.rust-lang.org/std/primitive.i16.html "primitive i16"), but may differ on some esoteric systems. The C standard technically only requires that this type be a signed integer with at least 16 bits; some systems may define it as `i32`, for example.
