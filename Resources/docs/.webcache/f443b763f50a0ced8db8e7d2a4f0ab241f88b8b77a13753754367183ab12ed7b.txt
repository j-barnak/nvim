# networks_manager

PodmanResource manager subclassed for Network resources.

Classes and methods for manipulating network resources via Podman API service.

Example

with PodmanClient(base_url=”unix:///run/user/1000/podman/podman.sock”) as client:  
for net in client.networks.list():  
print(net.id, “

“)

list(*\*\*kwargs*) → [list](#podman.domain.networks_manager.NetworksManager.list "podman.domain.networks_manager.NetworksManager.list")\[[Network](https://podman-py.readthedocs.io/en/latest/podman.domain.networks.html#podman.domain.networks.Network "podman.domain.networks.Network")\][\[source\]](https://podman-py.readthedocs.io/en/latest/_modules/podman/domain/networks_manager.html#NetworksManager.list)  
Report on networks.

Keyword Arguments:  
- **names** ([*list*](#podman.domain.networks_manager.NetworksManager.list "podman.domain.networks_manager.NetworksManager.list")*\[str\]*) – List of names to filter by.

- **ids** ([*list*](#podman.domain.networks_manager.NetworksManager.list "podman.domain.networks_manager.NetworksManager.list")*\[str\]*) – List of identifiers to filter by.

- **filters** (*Mapping\[str,str\]*) –

  Criteria for listing networks. Available filters:

  - driver=”bridge”: Matches a network’s driver. Only “bridge” is supported.

  - label=(Union\[str, list\[str\]\]): format either “key”, “key=value” or a list of such.

  - type=(str): Filters networks by type, legal values are:

    > - ”custom”
    >
    > - ”builtin”

  - plugin=(list\[str\]\]): Matches CNI plugins included in a network, legal values are (Podman only):

    > - bridge
    >
    > - portmap
    >
    > - firewall
    >
    > - tuning
    >
    > - dnsname
    >
    > - macvlan

- **greedy** (*bool*) – Fetch more details for each network individually. You might want this to get the containers attached to them. Ignored.

Raises:  
**APIError** – when error returned by service
