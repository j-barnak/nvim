# Function cold_path Copy item path

[Source](https://doc.rust-lang.org/src/core/intrinsics/mod.rs.html#419)

``` rust
pub const fn cold_path()
```

🔬This is a nightly-only experimental API. (`core_intrinsics`)

Expand description

Hints to the compiler that current code path is cold.

Note that, unlike most intrinsics, this is safe to call; it does not require an `unsafe` block. Therefore, implementations must not require the user to uphold any safety invariants.

The stabilized version of this intrinsic is [`core::hint::cold_path`](https://doc.rust-lang.org/std/hint/fn.cold_path.html "fn std::hint::cold_path").
