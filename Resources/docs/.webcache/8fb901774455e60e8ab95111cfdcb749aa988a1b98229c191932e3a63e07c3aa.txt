# Working with Types, Structures, and Symbols

There are so many things to learn about working with Types in Binary Ninja that we've organized it into several sections!

- [Basic Type Editing](https://docs.binary.ninja/guide/types/basictypes.html): Brief overview of the basics
- [Working with Types](https://docs.binary.ninja/guide/types/type.html): Interacting with types in disassembly and decompilation
- [Importing/Exporting Types](https://docs.binary.ninja/guide/types/typeimportexport.html): How to import or export types from header files, archives, or other BNDBs
- [Attributes and Annotations](https://docs.binary.ninja/guide/types/attributes.html): Annotations you can apply to types to influence analysis and presentation
- [Type Fragments](https://docs.binary.ninja/guide/types/fragments.html): How analysis tracks bitwise slices of typed values while they move through integer storage

Additionally, several types of containers for type information are documented here:

- [Debug Info](https://docs.binary.ninja/guide/types/debuginfo.html): Debug Info can provide additional type information (examples include DWARF and PDB files)
- [Type Libraries](https://docs.binary.ninja/guide/types/typelibraries.html): Type Libraries contain types from commonly-used dynamic libraries
- [Platform Types](https://docs.binary.ninja/guide/types/platformtypes.html): Types that automatically apply to a platform
- [Type Archives](https://docs.binary.ninja/guide/types/typearchives.html): How you can use type archives to share types between analysis databases
- [Signature Libraries](https://docs.binary.ninja/dev/annotation.html#signature-libraries): Signature libraries are used to match names of functions with signatures for code that is statically compiled

Additionally, make sure to see the [applying annotations](https://docs.binary.ninja/dev/annotation.html) section of the developer guide for information about using the API with types and covering the creation of many of the items described below.
