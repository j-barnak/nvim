# Function set_current_dir Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/std/env.rs.html#80-82)

``` rust
pub fn set_current_dir<P: AsRef<Path>>(path: P) -> Result<()>
```

Expand description

Changes the current working directory to the specified path.

## Platform-specific behavior

This function [currently](https://doc.rust-lang.org/std/io/index.html#platform-specific-behavior "mod std::io") corresponds to the `chdir` function on Unix and the `SetCurrentDirectoryW` function on Windows.

Returns an [`Err`](https://doc.rust-lang.org/std/result/enum.Result.html#variant.Err "variant std::result::Result::Err") if the operation fails.

## Examples

``` rust
use std::env;
use std::path::Path;

let root = Path::new("/");
assert!(env::set_current_dir(&root).is_ok());
println!("Successfully changed working directory to {}!", root.display());
```
