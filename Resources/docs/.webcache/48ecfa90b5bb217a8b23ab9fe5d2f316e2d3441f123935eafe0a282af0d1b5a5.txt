angr.analyses.decompiler.block_similarity.longest_ail_subseq(*stmts_list*, *graph=None*)  
Given a list of List\[Statement\], it returns the longest List\[Statement\] that is a subsequence of all the lists. The common List\[Statement\] most all be in the same order and adjacent to each other. If no common subsequence is found, it returns None.

- **stmts_list** ([`list`](https://docs.python.org/3/library/stdtypes.html#list "(in Python v3.14)")\[[`list`](https://docs.python.org/3/library/stdtypes.html#list "(in Python v3.14)")\[[`Statement`](https://docs.angr.io/en/latest/api/angr.ailment.statement.html#angr.ailment.statement.Statement "angr.ailment.statement.Statement")\]\])

- **graph**

Return type:  
[`tuple`](https://docs.python.org/3/library/stdtypes.html#tuple "(in Python v3.14)")\[[`list`](https://docs.python.org/3/library/stdtypes.html#list "(in Python v3.14)")\[[`Statement`](https://docs.angr.io/en/latest/api/angr.ailment.statement.html#angr.ailment.statement.Statement "angr.ailment.statement.Statement")\] \| [`None`](https://docs.python.org/3/library/constants.html#None "(in Python v3.14)"), [`list`](https://docs.python.org/3/library/stdtypes.html#list "(in Python v3.14)")\[[`int`](https://docs.python.org/3/library/functions.html#int "(in Python v3.14)")\] \| [`None`](https://docs.python.org/3/library/constants.html#None "(in Python v3.14)")\]

`Tuple[List[Statement],`` ``List[int]]`, where the first element is the longest common subsequence, and the second element is a list of integers indicating the index of the longest common subsequence in each list of statements.
