# angr.exploration_techniques.driller_core

class angr.exploration_techniques.driller_core.DrillerCore  
Bases: [`ExplorationTechnique`](https://docs.angr.io/en/latest/api/angr.exploration_techniques.base.html#angr.exploration_techniques.base.ExplorationTechnique "angr.exploration_techniques.base.ExplorationTechnique")

An exploration technique that symbolically follows an input looking for new state transitions.

It has to be used with Tracer exploration technique. Results are put in ‘diverted’ stash.

\_\_init\_\_(*trace*, *fuzz_bitmap=None*)  
:param trace : The basic block trace. :type fuzz_bitmap: :param fuzz_bitmap: AFL’s bitmap of state transitions. Defaults to saying every transition is worth satisfying.
