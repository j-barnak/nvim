# Memory

How the kernel gives every process the illusion of a large, private address space — and manages the physical RAM and device access underneath.

- [Memory Management (mm/)](https://kernel-internals.org/mm/) — how the kernel allocates, maps, and reclaims physical and virtual memory
- [IOMMU (iommu/)](https://kernel-internals.org/iommu/) — address translation and isolation between devices and memory
