The tracer supports customization for special-purpose i/o via [drmemtrace_replace_file_ops()](https://dynamorio.org/namespacedynamorio_1_1drmemtrace.html#a5bbf91691acf379d4fb0c3800fa2bb13), allowing traces to be written to locations not supported by simple UNIX file operations. One option for using this function is to create a new client which links with the provided drmemtrace_static library, includes the [`drmemtrace/drmemtrace.h`](https://dynamorio.org/drmemtrace_8h.html "Header for customizing the DrMemtrace tracer.") header via:

use_DynamoRIO_drmemtrace_tracer(mytool)

And includes its own [dr_client_main()](https://dynamorio.org/dr__api_8h.html#a2b938c98dd186cc94eef6880f9e3c3e9) which calls [drmemtrace_client_main()](https://dynamorio.org/namespacedynamorio_1_1drmemtrace.html#a9e7c889c48426d00d708b6374c1fdcf7).

The tracer also supports storing custom data with each module (i.e., library or executable) such as a build identifier via [drmemtrace_custom_module_data()](https://dynamorio.org/namespacedynamorio_1_1drmemtrace.html#ae928b4aceb19475c965eb8de4d7ca07a). The custom data may be retrieved by creating a custom offline trace post-processor and using the [dynamorio::drmemtrace::module_mapper_t](https://dynamorio.org/classdynamorio_1_1drmemtrace_1_1module__mapper__t.html) class.
