# Struct AddrParseError Copy item path

1.0.0 · [Source](https://doc.rust-lang.org/src/core/net/parser.rs.html#487)

pub struct AddrParseError(/* private fields */);

Expand description

An error which can be returned when parsing an IP address or a socket address.

This error is used as the error type for the [`FromStr`](https://doc.rust-lang.org/std/str/trait.FromStr.html "trait std::str::FromStr") implementation for [`IpAddr`](https://doc.rust-lang.org/std/net/enum.IpAddr.html "enum std::net::IpAddr"), [`Ipv4Addr`](https://doc.rust-lang.org/std/net/struct.Ipv4Addr.html "struct std::net::Ipv4Addr"), [`Ipv6Addr`](https://doc.rust-lang.org/std/net/struct.Ipv6Addr.html "struct std::net::Ipv6Addr"), [`SocketAddr`](https://doc.rust-lang.org/std/net/enum.SocketAddr.html "enum std::net::SocketAddr"), [`SocketAddrV4`](https://doc.rust-lang.org/std/net/struct.SocketAddrV4.html "struct std::net::SocketAddrV4"), and [`SocketAddrV6`](https://doc.rust-lang.org/std/net/struct.SocketAddrV6.html "struct std::net::SocketAddrV6").

## Potential causes

`AddrParseError` may be thrown because the provided string does not parse as the given type, often because it includes information only handled by a different address type.

[ⓘ](# "This example panics")

``` rust
use std::net::IpAddr;
let _foo: IpAddr = "127.0.0.1:8080".parse().expect("Cannot handle the socket port");
```

[`IpAddr`](https://doc.rust-lang.org/std/net/enum.IpAddr.html "enum std::net::IpAddr") doesn’t handle the port. Use [`SocketAddr`](https://doc.rust-lang.org/std/net/enum.SocketAddr.html "enum std::net::SocketAddr") instead.

``` rust
use std::net::SocketAddr;

// No problem, the `panic!` message has disappeared.
let _foo: SocketAddr = "127.0.0.1:8080".parse().expect("unreachable panic");
```
