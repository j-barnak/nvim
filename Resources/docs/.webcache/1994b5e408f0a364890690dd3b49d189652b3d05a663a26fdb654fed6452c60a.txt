Those who just finished the [jsonic](https://beautifulracket.com/jsonic/) tutorial are ready to go. We’ll reuse the files that were already created.

Everyone else: [download the source files](https://beautifulracket.com/jsonic/source-listing.html) from the first jsonic tutorial and put the enclosing jsonic directory in a convenient location. Install this directory as a package with this terminal command:

    > raco pkg install /path/to/jsonic

### [Testing the setup](#testing-the-setup)

Once these source files are in place, we should be able to use jsonic as a language in DrRacket. For instance, if we run this source file:

jsonic-test.rkt

    #lang jsonic
    // a line comment
    [
      @$ 'null $@,
      @$ (* 6 7) $@,
      @$ (= 2 (+ 1 1)) $@,
      @$ (list "array" "of" "strings") $@,
      @$ (hash 'key-1 'null
               'key-2 (even? 3)
               'key-3 (hash 'subkey 21)) $@
    ]

We should get this result:

    [
      null,
      42,
      true,
      ["array","of","strings"],
      {"key-1":null,"key-3":{"subkey":21},"key-2":false}
    ]

If so, the language is set up correctly. We can continue.
