# Trait TrustedStep Copy item path

[Source](https://doc.rust-lang.org/src/core/iter/traits/marker.rs.html#118)

``` rust
pub unsafe trait TrustedStep: Step + Copy { }
```

🔬This is a nightly-only experimental API. (`trusted_step` [\#85731](https://github.com/rust-lang/rust/issues/85731))

Expand description

A type that upholds all invariants of [`Step`](https://doc.rust-lang.org/std/iter/trait.Step.html "trait std::iter::Step").

The invariants of [`Step::steps_between()`](https://doc.rust-lang.org/std/iter/trait.Step.html#tymethod.steps_between "associated function std::iter::Step::steps_between") are a superset of the invariants of [`TrustedLen`](https://doc.rust-lang.org/std/iter/trait.TrustedLen.html "trait std::iter::TrustedLen"). As such, [`TrustedLen`](https://doc.rust-lang.org/std/iter/trait.TrustedLen.html "trait std::iter::TrustedLen") is implemented for all range types with the same generic type argument.

## Safety

The implementation of [`Step`](https://doc.rust-lang.org/std/iter/trait.Step.html "trait std::iter::Step") for the given type must guarantee all invariants of all methods are upheld. See the [`Step`](https://doc.rust-lang.org/std/iter/trait.Step.html "trait std::iter::Step") trait’s documentation for details. Consumers are free to rely on the invariants in unsafe code.

## Dyn Compatibility

This trait is **not** [dyn compatible](https://doc.rust-lang.org/1.98.1/reference/items/traits.html#dyn-compatibility).

*In older versions of Rust, dyn compatibility was called "object safety".*
