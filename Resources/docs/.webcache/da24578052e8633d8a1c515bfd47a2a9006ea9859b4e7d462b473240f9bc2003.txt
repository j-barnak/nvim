# [Dioxus Guides](https://dioxuslabs.com/learn/0.7/guides/#dioxus-guides)

These guides build on topics covered in the [core concepts](https://dioxuslabs.com/learn/0.7/essentials/) chapter to provide more detailed explanations and examples. While we recommend everyone read either the entire [tutorial](https://dioxuslabs.com/learn/0.7/tutorial/) or [core concepts](https://dioxuslabs.com/learn/0.7/essentials/) chapters as you learn dioxus, these guides are intended for users who want to dive deeper into specific topics as needed.

## [Tools](https://dioxuslabs.com/learn/0.7/guides/#tools)

Dioxus provides a set of tools to make building cross platform applications easier. The [`dioxus-cli`](https://crates.io/crates/dioxus-cli) is the core tool for building, running, and managing dioxus applications. The [`tools`](https://dioxuslabs.com/learn/0.7/guides/tools/) guide provides more information on the various tools available in the dioxus ecosystem.

## [Platforms](https://dioxuslabs.com/learn/0.7/guides/#platforms)

When you build an app with dioxus, most of your application code can be platform agnostic. When you do need to interact with platform specific features, dioxus provides a variety of platform backends to help you do so. The [platforms](https://dioxuslabs.com/learn/0.7/guides/platforms/) guide provides more information on the various platforms supported by dioxus.

## [Publishing](https://dioxuslabs.com/learn/0.7/guides/#publishing)

Once you finish building your application, the [publishing guide](https://dioxuslabs.com/learn/0.7/guides/deploy/) provides an overview of how to package and distribute your application. It also includes information about what configuration options are available for bundling.

## [Custom Renderer](https://dioxuslabs.com/learn/0.7/guides/#custom-renderer)

If you are ready to dive into building your own renderer for dioxus, the [custom renderer guide](https://dioxuslabs.com/learn/0.7/guides/depth/custom_renderer) provides an overview of how to get started.

## [Migration](https://dioxuslabs.com/learn/0.7/guides/#migration)

If you are updating from an older version of dioxus, the [migration guides](https://dioxuslabs.com/learn/0.7/migration/) provide information about breaking changes and how to update your code to work with the latest version of dioxus.
