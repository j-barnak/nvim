🔬This is a nightly-only experimental API. (`field_projections` [\#145383](https://github.com/rust-lang/rust/issues/145383))

Expand description

The offset of a field queried by its field representing type.

Returns the offset of the field represented by `F`. This function essentially does the same as the [`offset_of`](https://doc.rust-lang.org/std/intrinsics/fn.offset_of.html "fn std::intrinsics::offset_of") intrinsic, but expects the field to be represented by a generic rather than the variant and field indices. This also is a safe intrinsic and can only be evaluated at compile-time, so it should only appear in constants or inline const blocks.

There should be no need to call this intrinsic manually, as its value is used to define [`Field::OFFSET`](https://doc.rust-lang.org/std/field/trait.Field.html#associatedconstant.OFFSET "associated constant std::field::Field::OFFSET"), which is publicly accessible.
