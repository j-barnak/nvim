The `drcallstack` DynamoRIO Callstack Walker provides clients with walking of the application callstack.

- [Setup](https://dynamorio.org/page_drcallstack.html#sec_drcallstack_setup)
- [Usage](https://dynamorio.org/page_drcallstack.html#sec_drcallstack_usage)
- [Limitations](https://dynamorio.org/page_drcallstack.html#sec_drcallstack_limits)

#  Setup

To use `drcallstack` with your client simply include this line in your client's `CMakeLists.txt` file:

use_DynamoRIO_extension(clientname drcallstack)

That will automatically set up the include path and library dependence.

The initialization routine [`drcallstack_init()`](https://dynamorio.org/group__drcallstack.html#ga31c32040f286785f9664f6c62ae08556) must be called prior to any of the other routines. Additional calls to [drcallstack_init()](https://dynamorio.org/group__drcallstack.html#ga31c32040f286785f9664f6c62ae08556) are allowed (so long as they are paired with corresponding calls to [drcallstack_exit()](https://dynamorio.org/group__drcallstack.html#ga038658586e669f77edcaa00e909ca4a2)).

#  Usage

To produce a callstack, first a [dr_mcontext_t](https://dynamorio.org/dr__defines_8h.html#ab55fe2529e760adfd88197d0246bc074) with the PC field and all general-purpose registers filled in with application values (i.e., [DR_MC_CONTROL](https://dynamorio.org/dr__defines_8h.html#af0434595b47158e7512c2bf5f0e43ae4ab7914092947d4a374f4a95e089870218) \| [DR_MC_INTEGER](https://dynamorio.org/dr__defines_8h.html#af0434595b47158e7512c2bf5f0e43ae4af2252e055eafe402a7bf12b9951410d8)) must be obtained. When using a custom clean call, the PC field must be explicitly set by the client (typically by passing the application address of the next instruction to the clean call) as it is not set in that case by [dr_get_mcontext()](https://dynamorio.org/dr__ir__utils_8h.html#a9e348b2596b8750ce3fad234ab022ced).

Next, call [drcallstack_init_walk()](https://dynamorio.org/group__drcallstack.html#ga715edbe49fe81870abee4c42301fccce) to set up for a walk. Then repeatedly call [drcallstack_next_frame()](https://dynamorio.org/group__drcallstack.html#gaa947f08b59a97893691302d9d0773fa3) to iterate over the frames of the callstack. When [DRCALLSTACK_NO_MORE_FRAMES](https://dynamorio.org/group__drcallstack.html#gga0c7dbd333e7a1cf017ca334da047f13aaefa373d98252e90ef9021139c2ff054c) or an error code is returned, clean up with [drcallstack_cleanup_walk()](https://dynamorio.org/group__drcallstack.html#ga4e2f81293edac4fac055e6f05049a8ef).

#  Limitations

Currently, `drcallstack` is only implemented for Linux.
