# angr.utils.strings

angr.utils.strings.decode_utf16_string(*data*)  
Decode a UTF-16 encoded string from a bytes object in a resilient manner.

Parameters:  
- **data** ([`bytes`](https://docs.python.org/3/library/stdtypes.html#bytes "(in Python v3.14)")) – The bytes object containing the UTF-16 encoded string.

- **errors** – The error handling scheme. Default is ‘strict’. Other options include ‘ignore’, ‘replace’, etc.

Return type:  
[`str`](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")

Returns:  
The decoded string.
