Dr. SymCache is a DynamoRIO Extension that provides caching of symbol lookup results. It is distributed as part of the Dr. Memory Framework, which is included with DynamoRIO versions 5.0.0 and higher. [Online documentation is available](http://drmemory.org/page_drsymcache.html). If this documentation is part of a DynamoRIO public release, [this link](https://dynamorio.org/drmemory/drmemory/docs/html/page_drsymcache.html) should point at the local documentation provided with the release package.
