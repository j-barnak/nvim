## Classes

### class `interval(object)`

Stands for intervals with integer bounds

Offers common methods to work with interval

- **`__init__(self, bounds=None)`** - Instance an interval object
- **`__iter__(self)`** - Iterate on intervals
- **`cannon_list(tmp)`** - Return a cannonizes list of intervals
- **`cannon(self)`** - Apply .cannon_list() on self contained intervals
- **`__repr__(self)`**
- **`__contains__(self, other)`**
- **`__eq__(self, i)`**
- **`__ne__(self, other)`**
- **`union(self, other)`** - Return the union of intervals
- **`difference(self, other)`** - Return the difference of intervals
- **`intersection(self, other)`** - Return the intersection of intervals
- **`__add__(self, other)`**
- **`__and__(self, other)`**
- **`__sub__(self, other)`**
- **`hull(self)`** - Return the first and the last bounds of intervals
- **`empty(self)`** - Return True iff the interval is empty
- **`show(self, img_x=1350, img_y=20, dry_run=False)`** - show image representing the interval
- **`length(self)`** - Return the cumulated length of intervals

## Functions

### `cmp_interval(inter1, inter2)`

Compare @inter1 and @inter2 and returns the associated INT_* case
@inter1, @inter2: interval instance
