[Mouse](sf-Mouse.md#mouse) move raw event subtype.

Raw mouse input data comes unprocessed from the operating system hence "raw". While the [MouseMoved](sf-Event-MouseMoved.md#mousemoved) position value is dependent on the screen resolution, raw data is not. If the physical mouse is moved too little to cause the screen cursor to move at least a single pixel, no [MouseMoved](sf-Event-MouseMoved.md#mousemoved) event will be generated. In contrast, any movement information generated by the mouse independent of its sensor resolution will always generate a `[MouseMovedRaw](#mousemovedraw)` event.

In addition to screen resolution independence, raw mouse data also does not have mouse acceleration or smoothing applied to it as [MouseMoved](sf-Event-MouseMoved.md#mousemoved) does.

Raw mouse movement data is intended for controlling non-cursor movement, e.g. controlling the camera orientation in a first person view, whereas [MouseMoved](sf-Event-MouseMoved.md#mousemoved) is intended primarily for controlling things related to the screen cursor hence the additional processing applied to it.

Currently, raw mouse input events will only be generated on Windows and Linux.
