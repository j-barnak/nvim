# Network module

Socket-based communication, utilities and higher-level network protocols (HTTP, FTP).

## Classes

| Name | Description |
|------|-------------|
| [`Ftp`](sf-Ftp.md#ftp) | A FTP client. |
| [`Http`](sf-Http.md#http) | A HTTP client. |
| [`IpAddress`](sf-IpAddress.md#ipaddress) | Encapsulate an IPv4 network address. |
| [`Packet`](sf-Packet.md#packet) | Utility class to build blocks of data to transfer over the network. |
| [`Sftp`](sf-Sftp.md#sftp) | An SSH File Transfer Protocol (SFTP) client. |
| [`Socket`](sf-Socket.md#socket) | Base class for all the socket types. |
| [`SocketSelector`](sf-SocketSelector.md#socketselector-1) | Multiplexer that allows to read from multiple sockets. |
| [`TcpListener`](sf-TcpListener.md#tcplistener) | [Socket](sf-Socket.md#socket) that listens to new TCP connections. |
| [`TcpSocket`](sf-TcpSocket.md#tcpsocket-1) | Specialized socket using the TCP protocol. |
| [`UdpSocket`](sf-UdpSocket.md#udpsocket-1) | Specialized socket using the UDP protocol. |
