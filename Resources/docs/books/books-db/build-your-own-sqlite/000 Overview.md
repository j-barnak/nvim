# Build your own SQLite

SQLite is a popular SQL database engine. In this challenge, you'll build your own version of SQLite
that is capable of reading a SQLite database file and answering basic SQL queries like SELECT and using indexes.

Along the way, you'll learn about the SQLite file format, SQL syntax and more.

## Stages

1. Print page size  (very_easy)
2. Print number of tables  (hard)
3. Print table names  (hard)
4. Count rows in a table  (medium)
5. Read data from a single column  (hard)
6. Read data from multiple columns  (hard)
7. Filter data with a WHERE clause  (hard)
8. Retrieve data using a full-table scan  (hard)
9. Retrieve data using an index  (hard)
