
Appendix A: Example Handler Code
This section introduces pseudo-code and assembly examples for handling interrupts in the presence of
ACLIC extensions. Examples are given at M-mode, and S-mode examples can be constructed analogously
by using the equivalent S-mode CSRs.

A.1. Smnip/Ssnip SW dispatcher
The first example modifies the example handler from AIA by adding support for nested preemption. When
mtvec.mode = Direct (0), all interrupts use the SW dispatcher as a common entry point. In vectored mode,
some interrupt may jump directly into a custom handler, if their nested interrupt preemption priority is
higher than any interrupt that uses the SW dispatcher. In this case, the entry in the interrupt table
corresponding to those interrupts, which should use the SW dispatcher, need to cause the execution to
jump to the common SW dispatcher.

  save processor registers
  i = read CSR mcause
  if (i >= 0) {
        handle synchronous exception i
        restore mstatus if necessary
  }
  if (mstatus.MPIE == 1) {
        save mistatus
        enable interrupts

        loop {
              call the interrupt handler for major interrupt id

              topsi_val = read/write CSR mtopsi with value of mistatus
              i = (int) topsi_val >> 16
        }

        disable interrupts
        restore mistatus
  }
  restore processor registers
  return from trap

(This example can be further optimized, but with an increase in complexity.)

A pending-and-enabled higher-priority interrupt can preempt a currently running interrupt handler.

The interrupt threshold is raised automatically on interrupt trap, and through the write portion of the
mtopsi access.

If no interrupt is pending-enabled when mtopsi is read, a special handler, located at vector table entry of
interrupt id 0, jumps to the epilogue of the handler.

Below is an example of the SW dispatcher written in assembly:

.if XLEN == 64
          .equ REGSZ, 8
          .equ P_ALIGN, 3         # pointer alignment
          .macro sr reg, off, base
              sd \reg, \off(\base)
          .endm
          .macro lr reg, off, base
              ld \reg, \off(\base)
          .endm
    .else
          .equ REGSZ, 4
          .equ P_ALIGN, 2         # pointer alignment
          .macro sr reg, off, base
              sw \reg, \off(\base)
          .endm
          .macro lr reg, off, base
              lw \reg, \off(\base)
          .endm
    .endif

    .equ MEI_ID,                     11
    .equ MAJOR_IRQ_COUNT,            64
    .equ HANDLER_SPLIT,              (MAJOR_IRQ_COUNT << P_ALIGN)

    .equ CSR_MISTATUS,               0x346
    .equ CSR_MTOPSI,                 0x348

interrupt_dispatcher:
    addi      sp, sp, -(4*REGSZ)                 # create stack frame
    sr        s0, 0*REGSZ, sp                    # save s0 to stack
    csrr      s0, mepc
    sr        s0, 1*REGSZ, sp                    # save mepc to stack
    sr        s1, 2*REGSZ, sp                    # save s1 to stack
    csrr      s1, mcause
    csrrs     s0, CSR_MISTATUS, 1                # enable interrupts

    call      __riscv_save                       # save ra, t0-t6, a0-a7

    slli      a0, s1, P_ALIGN                    # create vector table offset
    la        s1, i_handlers + HANDLER_SPLIT

call_handler:
    add       a0, a0, s1
    lr        a0, 0, a0
    jalr      a0

next_handler:
    csrrw   a0, CSR_MTOPSI, s0               # restores threshold from s0, claims interrupt
and raises threshold

        srai        a0, a0, (16 - P_ALIGN) # extract vector table index

        j           call_handler

  spurious_handler:

  dispatch_exit:
        call        __riscv_restore                 # restore ra, t0-t6, a0-a7

        lr          s1, 2*REGSZ, sp                 # restore s1 from stack

        csrw        CSR_MISTATUS, s0                # disables interrupts
        lr          s0, 1*REGSZ, sp                 # restore mepc from stack
        csrw        mepc, s0
        lr          s0, 0*REGSZ, sp                 # restore s0 from stack
        addi        sp, sp, (4*REGSZ)               # destroy stack frame

        mret

A.2. Smnip/Ssnip Preemptible Fast Interrupt Handler
A fast interrupt handler does not use a common SW dispatcher. It is directly jumped to after taking the
interrupt trap. An example of a preemptible fast interrupt handler is:

  fast_interrupt_handler:
      save mepc, mistatus
      enable interrupts

      /* interrupt handling */

      disable interrupts
      restore mepc, mistatus
      return from trap

In order to be able to resume and return after preemption, mepc and mistatus need to be saved prior to
enabling interrupts.

It is expected that GNU toolchains will support preemptible C-handlers like

  void fast_interrupt_handler() __attribute__((interrupt("preemptible")))
  {

      /* interrupt handling */

      return;
  }

Context needed to return after preemption is saved before enabling interrupts. Interrupts are enabled
before executing the first statement of the function. Before returning, interrupts are disabled, and context
is restored.

A possible assembly version of the handler is as follows:

  .if XLEN == 64
            .equ REGSZ, 8
            .macro sr reg, off, base
                  sd \reg, \off(\base)
            .endm
            .macro lr reg, off, base
                  ld \reg, \off(\base)
            .endm
       .else
            .equ REGSZ, 4
            .macro sr reg, off, base
                  sw \reg, \off(\base)
            .endm
            .macro lr reg, off, base
                  lw \reg, \off(\base)
            .endm
       .endif

       .equ STACKSZ, (4*REGSZ)

       .equ CSR_MISTATUS,                0x346

  fast_interrupt_entry:
       addi       sp, sp, -STACKSZ                # create stack frame
       sr         s0, 0*REGSZ, sp
       csrr       s0, mepc                        # save mepc
       sr         s1, 1*REGSZ, sp
       csrrsi     s1, CSR_MISTATUS, 2             # save mistatus, enable interrupts

  fast_interrupt_main:
       # handle interrupt

  fast_interrupt_exit:
       csrw       CSR_MISTATUS, s1                # restore mistatus, disables interrupts
       csrw       mepc, s0                        # restore mepc
       lr         s0, 0*REGSZ, sp
       lr         s1, 1*REGSZ, sp
       addi       sp, sp, STACKSZ                 # destroy stack frame

       mret

A.3. Smip/Ssip C interrupt handlers
When Smip/Ssip extensions are implemented, a GNU compiler may assume for any interrupt handler
defined with the interrupt attribute like

  void interrupt_handler() __attribute__((interrupt("push-pop")));

that the registers x10-x15 have been saved. Additionally, the compiler does not need to restore these
registers. Finally, it should generate an xipopret instruction at the end of the function instead of an xret.

The attribute can be combined with other attributes, e.g. like

  void interrupt_handler() __attribute__((interrupt("preemptible", "push-pop")));

To indicate that the nested preemption is used in addition. In that case, a possible assembly version of the
handler is as follows:

        .macro MIPOPRET
              .word 0x308000733
        .endm

        .equ CSR_MISTATUS,                  0x346

  fast_interrupt_entry:
        csrr         a0, mepc                       # save mepc
        csrrsi       a1, CSR_MISTATUS, 2            # save mistatus, enable interrupts

  fast_interrupt_main:
        # handle interrupt

  fast_interrupt_exit:
        csrw         CSR_MISTATUS, a1               # restore mistatus, disables interrupts
        csrw         mepc, a0                       # restore mepc

        MIPOPRET
