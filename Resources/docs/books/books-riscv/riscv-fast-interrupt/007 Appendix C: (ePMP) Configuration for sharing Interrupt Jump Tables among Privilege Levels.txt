Appendix C: (ePMP) Configuration for sharing Interrupt
Jump Tables among Privilege Levels
If xijt is configured such that multiple privilege levels share a single interrupt jump table, the memory
protection units (e.g., PMP, Smepmp) must grant read permission to the shared interrupt jump table for all
applicable lower privilege levels.

C.1. Example 1: Standard PMP
For a system with M-mode and S-mode, a PMP entry with L=1, R=1, W=0 and X=0 permits both privilege
levels to execute from the table while preventing modifications. If L=0, S-mode retains execute only
permission while M-mode maintains full permissions.

C.2. Example 2: Smepmp Extension
Under the Smepmp extension, the shared interrupt jump table can be secured as a "Shared data region".
Setting L=0, R=0, W=1 and X=0 grants both M-mode and S-mode read only permission to the interrupt
jump table. Additionally, M-mode has write permissions to the interrupt jump table. If S-mode requires
modifying the table, this requires either a system call or trap-and-emulate operation.
