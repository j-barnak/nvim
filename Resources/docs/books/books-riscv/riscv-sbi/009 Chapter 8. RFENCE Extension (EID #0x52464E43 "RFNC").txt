Chapter 8. RFENCE Extension (EID #0x52464E43 "RFNC")
This extension defines all remote fence related functions and replaces the legacy extensions (EIDs #0x05 -
#0x07). All the functions follow the hart_mask as defined in binary encoding section. Any function which
accepts a range of addresses (i.e. start_addr and size) must abide by the below constraints on range
parameters.

The remote fence operation applies to the entire address space if either:

 ⚫ start_addr and size are both 0, or
 ⚫ size is equal to 2^XLEN-1.

8.1. Function: Remote FENCE.I (FID #0)

  struct sbiret sbi_remote_fence_i(unsigned long hart_mask,
                                   unsigned long hart_mask_base)

Instructs remote harts to execute FENCE.I instruction.

The possible error codes returned in sbiret.error are shown in the Table 9 below.

                                   Table 9. RFENCE Remote FENCE.I Errors
      Error code                             Description
      SBI_SUCCESS                            IPI was sent to all the targeted harts successfully.
      SBI_ERR_INVALID_PARAM                  At least one hartid constructed from hart_mask_base and
                                             hart_mask, is not valid, i.e. either the hartid is not enabled by
                                             the platform or is not available to the supervisor.
      SBI_ERR_FAILED                         The request failed for unspecified or unknown other reasons.
