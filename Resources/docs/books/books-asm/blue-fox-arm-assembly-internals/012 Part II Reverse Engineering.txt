                                                                  II
                              Reverse Engineering

In the first part of this book, you learned about the fundamentals of ELF file
formats and the Arm architecture with its different instruction sets. With this
knowledge, you should now be able to disassemble real Arm binaries and
understand their underlying assembly language.
   The second part of this book provides you with the knowledge necessary
to reverse engineer Arm binaries and introduces you to the tools you can use
during your analysis. The first chapter of this second part provides a brief
overview of Arm environments. This is followed by chapters on static analysis
and dynamic analysis, as well as a bonus chapter on how to analyze malware
running on M1/M2 Macs.
