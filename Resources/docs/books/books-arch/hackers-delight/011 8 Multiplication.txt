In applying the grade-school scheme, we would like to treat each 32-bit word as

instruction, it is not readily accessible from most high-level languages. In fact, many
modern RISC machines do not have this instruction in part because it isn’t accessi-

For signed multiplication, it is not necessary to code the “correction steps” in
the lower half of Figure 8–1. These can be omitted if proper attention is paid to
whether the intermediate results are signed or unsigned (declaring them to be

The algorithm requires 16 basic RISC instructions in either the signed or

unsigned version, four of which are multiplications.

int mulhs(int u, int v) {
   unsigned u0, v0, w0;
   int u1, v1, w1, w2, t;

   u0 = u & 0xFFFF;  u1 = u >> 16;
   v0 = v & 0xFFFF;  v1 = v >> 16;
   w0 = u0*v0;
   t  = u1*v0 + (w0 >> 16);
   w1 = t & 0xFFFF;
   w2 = t >> 16;
   w1 = u0*v1 + w1;
   return u1*v1 + w2 + (w1 >> 16);
}
