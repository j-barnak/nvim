Chapter 24

Glossary (SAT)

 • clause — disjunction of one or more literals/terms. For example: var1 OR
   -var2 OR var3 ... - at least one literal must be satisfied in each clause.
 • CNF (conjunctive normal form) formula — conjunction of one or more
   clauses. Is a list of clauses, all of which must be satisfied.
 • literal/term — can be variable and -variable, these are different literals.
 • pure literal — present only as x or -x in instance. Can be eliminated at
   start.

 • unit clause — clause with only one literal.
 • DIMACS — file format, popular among SAT solvers, benchmarks, etc.
   Earliest description (1993): http://www.domagoj-babic.com/uploads/
   ResearchProjects/Spear/dimacs-cnf.pdf. ”DIMACS” acronym itself
   means ”The DIMACS Implementation Challenges”1 .

1 http://archive.dimacs.rutgers.edu/Challenges/
