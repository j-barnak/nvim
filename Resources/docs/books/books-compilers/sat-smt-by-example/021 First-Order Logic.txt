20.2       Exercise 9 from TAOCP “7.1.1 Boolean
           Basics”, solving it using Z3
Page 34 from fasc0b.ps or http://www.cs.utsa.edu/~wagner/knuth/fasc0b.
pdf.

Figure 20.2: Page 34

     For (a):
( assert
     ( forall ((x Bool) (y Bool) (z Bool))
          (=
              (or (xor x y) z)
              (xor (or x z) (or y z))
          )
     )
)
(check -sat)

     For (b):
( assert
     ( forall ((x Bool) (y Bool) (z Bool) (w Bool))
          (=
              (or (xor w x y) z)

                  (xor (or w z) (or x z) (or y z))
              )
    )
)
(check -sat)

   For (c):
( assert
     ( forall ((x Bool) (y Bool) (z Bool))
          (=
              (or (xor x y) (xor y z))
              (or (xor x z) (xor y z))
          )
     )
)
(check -sat)
