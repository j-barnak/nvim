             PYTHON DEBUGGER (PDB)
                  COMMANDS

   The Python DeBugger (pdb) tool has quite a few commands you can enter
at the (Pdb) prompt to control and monitor the execution of the code. In this
appendix, I outline the most important pdb commands in an easy-to-use
table.
  If you need even more information, you will find all pdb commands
exhaustively documented at https://docs.python.org/3/library/pdb.html.
Command(s)      Purpose
h command       Shows help for a command. If a command is omitted, this lists all
help command    available commands.
q               Quits the current pdb session.
quit

Moving around
w               Prints the stack trace for the current position.
where

u count         Moves the focus higher up the current stack trace, by count levels, or
up count        one level by default.
d count         Moves the focus further down the current stack trace, by count levels,
down count      or one level by default.
s               Executes and steps into the current line.
step

n               Executes and steps over the current line.
next

r               Executes the rest of the current function.
return
Command(s)          Purpose
c                   Continues execution until another breakpoint is hit.
cont
continue

unt lineno          Continues execution until lineno, or until any line number greater than
until lineno        the current one.
j lineno            After the current line, executes the line of code at lineno. You can only
jump lineno         do this on the bottommost frame, and you cannot do this in certain
                    situations. One use for this is if you want to temporarily skip some code
                    you think might be causing a problem.
run                 Restarts debugging from the beginning of the program, while retaining
restart             options, breakpoints, and history. This only works when you’ve invoked
                    pdb directly.

Inspecting things
p expression        Runs print(expression).
pp expression       Runs pprint(expression) (pretty-print with pprint module).
whatis              Prints type(expression).
expression

a                   Prints the argument list for the current function.
args

retval              Prints the last returned value for the current function.
display             Watches the value of expression, printing it each time the debugger
expression          stops in the current frame.
undisplay           Stops watching expression. If expression is omitted, this stops
expression          watching all expressions.
l lineno            Displays the 11 lines of source code around line lineno, or around the
list lineno         current line if lineno is omitted.
l from to           Displays the source code from line number from to line number to.
list from to

source name         Displays the source code for the given code object object, such as a
                    function, method, class, or module.
Interacting with things
! statement         Executes the given one-line statement in the current context, as if it
                    were the next line of code.
interact            Switches to an interactive Python shell at the current context, so you
                    can run additional code.
debug code          Starts another pdb session for debugging the statement code. When
                    you quit that session, you’ll return to the session you ran this command
                    in.
Managing breakpoints
Command(s)         Purpose
b                  Lists all breakpoints in the file, including how many times each one has
break              been hit.
b lineno           Sets a breakpoint at line number lineno in the current file or at line
break lineno       number lineno in the file with filename file.
b file:lineno
breakfile:lineno

b function         Sets a breakpoint at the top of the function function.
break function

tbreak where       Sets a temporary breakpoint at the location where (following the same
                   syntax as the break command). The first time the temporary breakpoint
                   is hit, it is removed.
cl                 Clears all breakpoints. Confirms before clearing everything.
clear

cl file:lineno     Clears the breakpoint on line lineno in the file with filename file.
clear
file:lineno

cl number          Clears the breakpoint number. You can specify multiple numbers,
clear number       separated by spaces, to clear multiple breakpoints.
