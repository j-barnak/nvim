                                    Let us recap what we have learned about async executors in general and the simple async executor in

                                          Learn More: Single Threaded Async Executor
                                    A single-threaded async executor manages the execution of tasks in an asynchronous context using only a
                                    single thread. It operates by multiplexing multiple tasks onto the same thread and switching between them
                                    whenever a task voluntarily suspends its execution—usually because it is waiting for an I/O operation or a
                                    timer.
                                    A single-threaded executor internally operates with an event loop and a task queue. It places a scheduled
                                    future for execution in the task queue. Entering the event loop, the executor repeatedly retrieves and polls
                                    futures from the queue. If a future is not ready—usually due to a pending I/O operation—it relinquishes
                                    control to the executor, allowing it to proceed to the next task. When a future becomes ready, the executor
                                    resolves it, enabling the caller of the async function to retrieve its result.

                                        target_pos: i32,
                                    }
                                    impl Future for UnitGotoFuture {
                                        type Output = ();
                                        fn poll(self: Pin<&mut Self>, _cx: &mut Context) -> Poll<Self::Output> {
                                            let unit_pos = self.unit.borrow().pos;
                                            if unit_pos == self.target_pos {
                                                Poll::Ready(())
                                            } else {
                                                self.unit.borrow_mut().pos
                                                            += (self.target_pos - unit_pos).signum();
                                                Poll::Pending
                                            }
                                        }
                                    }

                                        UnitGotoFuture {

                                    Async Executors: Scheduling and Task Management
                                    An async executor is responsible for running async tasks. It schedules the tasks and wakes them when they
                                    are ready to proceed.
                                    Let us look at a simple async executor. In the following code, the main function spawns async tasks and
                                    then starts executing the tasks. Typically, an async executor runs the tasks until they are complete. In our
                                    example, we simulate the executor by calling the Executor::step() method in a loop. We limit the
                                    number of steps to 30 to run the example in the Rust playground.

                                    fn main() {
                                        let executor = Executor::default();
                                        let units: [UnitRef; 2] = Default::default();
                                        executor.spawn(patrol(units[0].clone(), [-5, 5]));
                                        // executor.spawn(patrol(units[1].clone(), [-1,1]));
                                        for _ in 0..30 {
                                            executor.step();
                                        }
                                    }

                                          Key Takeaways
                                      •    Spawning an async task has nothing to do with the operating system. It is just a closure scheduled
                                           to be executed by the executor.

                                      •    A .await suspends the execution of an async task if the future is not ready. The executor will call
                                           the poll function again to check if the future is ready.

                                      •    The method returns Poll::Pending if the future is not ready. It returns Poll::Ready if the future
                                           is ready.

                                      •    If await is called inside an infinite loop, the function will never return Poll::Ready as it continues
                                           in the loop. Even a function with an infinite loop will return Poll::Pending if the future is not
                                           ready.

                                    Note: Unlike the real-world async executors, the simple async scheduler in this chapter calls the poll
                                    method of a future at every step. In a practical scenario, an executor will invoke the poll method only
                                    when the future is ready to progress.
