                                    Structure of This Book
                                    This book comprises seven parts, each centering on a different aspect of Rust’s inner workings. Here is a
                                    brief overview of the chapters in each part:

                                    Part A: Introduction to Assembly and Basic Constructs
                                          1.   Assembly Basics: Integers, Floats, and Tuples: We begin by examining simple functions, their
                                               assembly representations, and how they interact with immutable values, mutable references, and
                                               tuples.

                                          2.   Fundamentals of x86-64 Assembly: A brief introduction to x86-64 assembly, highlighting the
                                               most common instructions and their operands.

                                    Part B: Control Structures and Enums in Assembly
                                          3.   Deconstructing Match and If-Else Expressions: This chapter dives into the assembly output of
                                               match and if-else expressions, highlighting compiler optimizations.

                                          4.   Deep Dive into Enums: Layout and Patterns: An exploration of how enums reside in memory,
                                               paired with insights into the code generated for pattern matching.

                                    Part C: Data Structures and Memory Management
                                          5.   Arguments: Value, Reference, Box, Rc, and Arc: Investigating the performance nuances of
                                               passing self by various means, including value, reference, and smart pointers.

                                          6.   Structs: Alignment and Patterns: A dive into struct memory representation and the compiler’s
                                               approach to struct field pattern matching.

                                          7.   Arrays, Tuples, Option, and Box Internals: A consolidated view of how Rust manages these
                                               elements at the assembly level.

                                    Part D: Iteration and Optimization
                                          8.   Traditional vs. Functional Array Iteration: A comparison of assembly code outcomes between
                                               for-loop and functional-style array iterations, emphasizing array size’s influence.

                                          9.   Optimizing Array Iteration with SIMD: Enhancing our understanding of array iteration, focusing
                                               on the compiler’s capability to utilize SIMD (Single Instruction Multiple Data) instructions.

                                          10. In-Depth: Array Slices and Pattern Matching: A focused look at the assembly for array slices and
                                              pattern matching.

                                          11. Vector Iteration in Assembly: An under-the-hood look at vectors, their iteration, and the
                                              compiler’s selection of loop constructs based on vector length.

                                          12. Advanced Iterations: Mapping and Folding: We analyze complex two-tiered iteration structures
                                              and the assembly code they generate.

                                    Part E: Strings, Dispatch, and Recursion
                                          13. Strings and Slices: Under the Surface: Exploring Rust’s representation and manipulation of
                                              strings and string slices.

                                      14. Static vs. Dynamic Dispatch: We look at how the Rust compiler handles static and dynamic
                                          dispatch.

                                      15. Traits, Vtables, and Tail Calls: An advanced discussion on trait inheritance, memory management,
                                          and dynamic dispatch overhead optimization.

                                      16. Optimizing Recursive Functions: Understanding the compiler’s approach to optimizing tail call
                                          recursive functions.

                                    Part F: Closures and Async/Await
                                      17. Closures: From Environment to Execution: A deep dive into the mechanics of Rust closures,
                                          emphasizing variable storage and dynamic dispatch.

                                      18. Async/Await: Internal State Machine Dynamics: Introduction to Rust’s asynchronous function
                                          mechanics and its translation to assembly.

                                      19. Nested Async/Await: Desugaring to Loops: A continuation from the previous chapter, focusing
                                          on nested asynchronous constructs and their behavior.

                                      20. Async Executors: Task Scheduling Insights: We explore the scheduling of async tasks and delve
                                          into the workings of a simple async executor.

                                    Part G: Transformations and Takeaways
                                      21. Transforming into String Slice Vector: We go under the hood to understand the transformation
                                          of a bool vector into a vector of static string slices.

                                      22. Transforming into Owned String Vector: We focus on vectors of owned strings, their heap
                                          allocations, and memory management techniques.

                                      23. Key Insights: A summary of the key takeaways from our journey through Rust’s inner workings.

                                         Experiments and Exercises
                                    You can cement your understanding of Rust’s inner workings by exploring the examples and exercises at
                                    the end of most chapters. You can experiment with the code using the provided links to Compiler Explorer
                                    (https://godbolt.org/) or the Rust Playground (https://play.rust-lang.org/). The links are also accessible
                                    via the book's companion website, Rust Under the Hood Companion (https://eventhelix.com/ruth/).

                                    We hope you enjoy reading “Rust Under the Hood” and find it a valuable resource for understanding Rust’s
                                    inner workings.
