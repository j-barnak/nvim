
                                                        Chapter 9
                                           Optimizing Array Iteration with SIMD

                                    We have already gone under the hood to look at the code generated by the compiler for array iteration in
                                    the “Traditional vs. Functional Array Iteration” chapter. This chapter will examine how the Rust compiler
                                    generates AVX-512 SIMD (Single Instruction Multiple Data) instructions to speed up array iteration.

                                    Functional Style Loop
                                    We will work with the same example as in the “Traditional vs. Functional Array Iteration” chapter. The code
                                    sums up the squares of even numbers in an array.

                                    pub fn sum_of_even_squares<const N: usize>(arr: &[i64; N]) -> i64 {
                                        arr.iter()
                                            .filter(|&x| x % 2 == 0) // filter out odd numbers
                                            .map(|&x| x.pow(2)) // square remaining numbers
                                            .sum() // sum them up
                                    }

                                    pub fn sum_of_even_squares_specific_size(arr: &[i64; 1024]) -> i64 {
                                        sum_of_even_squares(arr)
                                    }

                                    AVX-512 SIMD Instructions
                                    In this chapter, we will be using the following compiler flags to enable AVX-512 SIMD:
                                    -C opt-level=3 -C target_cpu=skylake-avx512

                                        Learn More: AVX-512 SIMD
                                    AVX-512 SIMD instructions work with 512-bit registers. The processor supports dividing them into 16 32-
                                    bit elements, eight 64-bit elements, four 128-bit elements, or two 256-bit elements.
                                    Compilers must balance utilizing 512-bit zmm registers and 256-bit ymm registers. As of this writing, LLVM
                                    employs 256-bit ymm registers for AVX-512 SIMD instructions to circumvent AVX-512 downclocking on
                                    Intel Skylake processors.

                                    AVX-512: Vectorized Assembly Overview
                                    Before we dive into the assembly code, let us understand the high-level flow of the SIMD instructions in the
                                    generated assembly code.
                                    When AVX-512 is enabled, the Rust compiler uses 256-bit ymm registers. It unrolls the loop by 16. The AVX-
                                    512 SIMD instructions perform four operations per instruction. The compiler generates four sets of SIMD
                                    instructions to process 16 elements per iteration.
                                    The generated assembly has a lot to unpack (pun intended). We will start by looking at a flowchart of how
                                    the SIMD instructions perform the computation:
                                      1.    The code loads 16 array entries into four 256-bit ymm registers. It loads 16 array entries into 16 32-
                                            bit elements with four instructions.
                                      2.    The generated assembly then sets the status code registers based on the odd and even values in the
                                            16 array entries.
                                      3.    Four SIMD instructions to square the 16 array entries. Each SIMD instruction squares four array
                                            entries in parallel.
                                      4.    The code then conditionally accumulates the results in 4 SIMD registers. The processor employs the
                                            status code register to ascertain whether the entry is even and should be added to the sum.
                                      5.    The loop index increments by 16 because the loop processes 16 array entries.
                                      6.    The code compares the loop index to the array size to determine if the loop should continue.
                                      7.    When the loop is complete, the code adds the 16 accumulated SIMD registers.
                                      8.    The function returns the result.

                                    Annotated Assembly: SIMD in Array Iteration
                                    Now that we understand the SIMD flow and vectorized loop let us dive into the generated assembly code.

                                      •          Input: rdi = address of the array
                                      •          Output: rax = sum of even squares

                                          The function starts here.

                                    example::sum_of_even_squares_specific_size:

                                    Zero ymm0 by XORing it with itself. Although the instruction targets the lower 128 bits of the 256-bit
                                    register ymm0, it also zeroes the upper 128 bits (Learn more: https://bit.ly/vpxor).

                                    vpxor        xmm0, xmm0, xmm0                                           ;

                                          Initialize the loop index to 0. rax serves as the loop counter.

                                    xor          eax, eax

                                                     Broadcasts the 64-bit value at the memory location .LCPI0_0 to all the elements. ymm1 is a
                                    256-bit register that now stores four copies of a 64-bit value 1.

                                    vpbroadcastq            ymm1, qword ptr [rip + .LCPI0_0]

                                    Zero the 256-bit registers ymm2, ymm3, and ymm4, which, along with ymm0, will store the sum of the squares
                                    of the even elements. The instruction zeroes the lower and upper 128 bits of these 256-bit registers.

                                    vpxor        xmm2, xmm2, xmm2                                           ;
                                    vpxor        xmm3, xmm3, xmm3                                           ;
                                    vpxor        xmm4, xmm4, xmm4                                           ;

                                             Loop start

                                    .LBB0_1:

                                    Load 16 elements from the array into the 256-bit registers ymm5, ymm6, ymm7 and ymm8. The following four
                                    instructions load the loop index to loop index + 16. Each instruction loads four elements into the 256-bit
                                    register.

                                    vmovdqu ymm5, ymmword ptr [rdi + 8*rax]                                 ;
                                    vmovdqu ymm6, ymmword ptr [rdi + 8*rax + 32]                            ;
                                    vmovdqu ymm7, ymmword ptr [rdi + 8*rax + 64]                            ;
                                    vmovdqu ymm8, ymmword ptr [rdi + 8*rax + 96]                            ;

                                        Bitwise AND the 4 elements stored in ymm5, ymm6, ymm7 and ymm8 with the 4 copies of a 64-bit 1 stored
                                    in ymm1. The processor stores the status bits of the result in the mask registers k1, k2, k3, and k4. So, the
                                    following four instructions set 4*4 = 16 bits in the mask registers. The status bit is set to 1 if the AND
                                    operation results in a 0. It is set to 0 if the AND operation results in a 1. Thus, the k1, k2, k3, and k4 mask
                                    registers will have 1s in the status bits if the corresponding elements are even and 0s in the status bits if
                                    the corresponding elements are odd.

                                    vptestnmq               k1, ymm5, ymm1                                  ;
                                    vptestnmq               k2, ymm6, ymm1                                  ;
                                    vptestnmq               k3, ymm7, ymm1                                  ;
                                    vptestnmq               k4, ymm8, ymm1                                  ;

                                    Multiply the four elements stored in ymm5, ymm6, ymm7, and ymm8 with themselves. The following four
                                    instructions perform 4*4 = 16 multiplications.
                                    Note that the code performs multiplications for both even and odd values. Later, it will use the mask
                                    registers k1, k2, k3, and k4 to ignore the squares of odd values.

                                    vpmullq ymm5, ymm5, ymm5                                                ;
                                    vpmullq ymm6, ymm6, ymm6                                                ;

                                    vpmullq ymm7, ymm7, ymm7                                              ;
                                    vpmullq ymm8, ymm8, ymm8                                              ;

                                       Each of the four following instructions accumulates the result of its 4
                                    multiplications into a single 256-bit register (ymm0, ymm2, ymm3 or ymm4). The mask registers k1, k2, k3, and
                                    k4 mask out the results of odd value multiplications.

                                                 The code accumulates the 16 intermediate results into four registers in the loop body. It then
                                    adds these registers to obtain the result in the loop epilogue.

                                    vpaddq      ymm0 {k1}, ymm0, ymm5                                     ;
                                    vpaddq      ymm2 {k2}, ymm2, ymm6                                     ;
                                    vpaddq      ymm3 {k3}, ymm3, ymm7                                     ;
                                    vpaddq      ymm4 {k4}, ymm4, ymm8                                     ;

                                          Increment the loop index by 16. We are processing 16 elements in each iteration of the loop.

                                    add         rax, 16

                                          Check if the loop index has not reached the end of the array.

                                    cmp         rax, 1024

                                    ↩️ If the loop index has not reached the end of the array, jump to the beginning of the loop.

                                    jne         .LBB0_1

                                             Loop end

                                    Add the 16 intermediate results stored in ymm0, ymm2, ymm3, and ymm4 into four intermediate results stored
                                    in ymm0.

                                    vpaddq      ymm0, ymm2, ymm0                                          ;
                                    vpaddq      ymm0, ymm3, ymm0                                          ;
                                    vpaddq      ymm0, ymm4, ymm0                                          ;

                                       Extract the upper 128 bits of ymm0 into xmm1, storing the four intermediate results in the xmm0 and
                                    xmm1 registers, with two intermediate results in each register.

                                    vextracti128           xmm1, ymm0, 1

                                    Before the next instruction:
                                      •       xmm0 = [intermediate result 0, intermediate result 1]
                                      •       xmm1 = [intermediate result 2, intermediate result 3]

                                    After the next instruction:
                                      •       xmm0 = [intermediate result 0 + intermediate result 2, intermediate result 1 +
                                              intermediate result 3]
                                    vpaddq      xmm0, xmm0, xmm1                                          ;

                                       Swap the 64-bit halves of xmm0, placing the two intermediate results in the lower 64 bits of xmm0 and
                                    xmm1.

                                    vpshufd xmm1, xmm0, 238

                                          Perform 64-bit additions on the upper and lower 64 bits of xmm0 and xmm1. We only care about the
                                    lower 64 bits of the result.

                                    vpaddq      xmm0, xmm0, xmm1                                       ;

                                          Move the lower 64 bits of xmm0 into rax.

                                    vmovq       rax, xmm0                                              ;

                                          Ensure all ymm registers have their upper 128 bits cleared to prevent invalid results from ymm access.

                                    vzeroupper                                                         ;
                                    ret                                                                ;      Return result in rax

                                          Learn More: Conditional Addition with Masks - vpaddq
                                    We saw the following instruction in the assembly:

                                    vpaddq      ymm0 {k1}, ymm0, ymm5

                                    This instruction performs a conditional addition, executing the addition only if the corresponding bit in the
                                    mask register k1 is set. The setting of the mask register k1 depends on the result of the vptestnmq
                                    instruction.
                                    Let us look at the instruction in detail:
                                      •      vpaddq: This stands for Vector Packed ADD Quadword (64-bit). It adds packed quadword integers
                                             from the second operand (source operand) and the third operand and stores the packed integer
                                             results in the destination operand (first operand).

                                      •      ymm0 {k1}, ymm0, ymm5: This specifies the operands for the instruction. ymm0 and ymm5 are 256-
                                             bit ymm registers that can hold integers or floating-point numbers. The mask register {k1}
                                             determines which data lanes in the destination register are updated. The instruction adds ymm5 to
                                             ymm0 for the data lanes where k1 is set. In cases where k1 is not set, the data in ymm0 will remain
                                             unaltered.

                                            Key Takeaways
                                        •    AVX-512 processes 16 elements in each loop iteration by utilizing ymm registers, which handle four
                                             64-bit elements per instruction.
                                        •    The k registers mask the results of multiplications on odd numbers, serving to avoid branching.
                                        •    When the array size is not a multiple of 16, the compiler executes the loop until the last multiple of
                                             16 and runs the remaining iterations outside the loop.
                                        •    AVX-512 SIMD instructions can deliver a 4x speedup over the scalar code. However, memory
                                             bandwidth and thermal throttling can limit the speedup. AVX-512 instructions can increase power
                                             usage and may cause other cores on the CPU to downclock, potentially reducing overall system
                                             performance.
                                               –     You should perform benchmarks to confirm the performance benefits of using AVX-512
                                                     instructions.
