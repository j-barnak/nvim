                                    Example Code: Map a Vector of Bools to a Vector of String Slices
                                    The following code shows two functions:
                                      •    convert<A,B> function accepts a vector of type A and returns a vector of type B. The function
                                           accepts a closure that accepts an element of type A and returns an element of type B. Calling the map
                                           function on the vector iterator performs the conversion. Note that convert<A,B> is a generic
                                           function that generates no code.
                                      •    convert_bool_vec_to_static_str_vec function uses the convert<A,B> function to convert a
                                           vector of bools to a vector of string slices. The function accepts a vector of bools and returns a
                                           vector of string slices. The function calls the convert<A,B> function with a closure that converts a
                                           bool to a string slice.

                                    pub fn convert<A,B> (v: Vec<A>, f: impl Fn(A) -> B) -> Vec<B> {
                                        v.into_iter().map(f).collect()
                                    }

                                    pub fn convert_bool_vec_to_static_str_vec(v: Vec<bool>) -> Vec<& 'static str> {
                                        convert(v, |n| if n {"true"} else {"false"})
                                    }

                                    Overflow and Memory Allocation Failure Handling
                                    The compiler will generate a panic and drop the input vector if there is an overflow in the size computation
                                    or if the allocation fails.

                                    Part G Transformations and Takeaways
                                    Length-Based Optimization
                                    The generated code takes the following input vector length-based decisions:
                                         •      When the input vector length is 0, the output vector also has a length of 0, eliminating the need for
                                                heap allocation.
                                         •      If the input vector length is non-zero, the output vector matches this length and allocates its array
                                                on the heap.
                                                    –    If the input vector length is odd, the generated code handles one iteration and then falls
                                                         through to the code for even length handling.
                                                    –    The generated code handles two iterations per loop entry if the input vector length is even.
                                                         This loop unrolling reduces the branching penalty of the loops.

                                    Eliminating the Need for a Branch
                                    When examining the code, the initial expectation might be that it evaluates each bool in the input array.
                                    Based on this evaluation, the code should generate a pointer to the corresponding string slice (“true” or
                                    “false”) and subsequently update the slice’s length.
                                    However, closer inspection shows the code omits the direct bool condition check within its loop body.
                                    Instead, it adopts an alternative, more optimized approach as detailed below:
                                         1.     Conditional Movement: The process of copying the "true" or "false" string slice state to the
                                                output vector array leverages the cmove (conditional move) instruction.

                                         2.     Length Computation: An XOR operation between the number 5 (represented in binary as 0b101)
                                                and the value of the bool (0 or 1) determines the length of the string slice. This computation might
                                                seem a tad non-intuitive. The table below offers a breakdown:

                                     bool value              XOR with 0b101 (equals 5)                    Resulting String slice length
                                     0                       0b101 (5)                                    5 (corresponding to “false”)
                                     1                       0b100 (4)                                    4 (corresponding to “true”)

                                    Cleaning up the Input Vector on Exit from the Function
                                    The compiler generates a call to __rust_dealloc to free the input vector. Note that the function owns the
                                    input vector, so it is responsible for freeing up the memory allocated for the input vector array just before
                                    the function returns.

                                    Annotated Assembly: Bool Vector to a Vector of String Slices
                                    We are now ready to dive into the assembly code.

                                             Input:

                                         •      rdi points to the output vector. The caller is responsible for reserving space for the output vector
                                                struct. The called function allocates memory for the output vector’s data array.

                                         •      rsi points to the input vector v

                                             Output:

                                      •   rax: Address of the output vector
                                    example::convert_bool_vec_to_static_str_vec:
                                    push    rbp                             ; Save rbp

                                    push     r15                                   ; Save r15
                                    push     r14                                   ; Save r14
                                    push     r13                                   ; Save r13
                                    push     r12                                   ; Save r12
                                    push     rbx                                   ; Save rbx
                                    sub      rsp, 40                               ; Allocate 40 bytes for local variables

                                      Setting up registers based on the input vector v.

                                    mov      rbp, rdi                              ; rbp = address of the output vector

                                    mov      r12, qword ptr [rsi]                  ; Load the address of the input
                                                                                   ; vector v's data array into r12

                                    mov      r10, qword ptr [rsi + 8]              ; Load the capacity of the input vector v
                                                                                   ; into r10

                                    mov      r14, qword ptr [rsi + 16]             ; Load the length of the input vector v
                                                                                   ; into r14

                                    lea      r15, [r12 + r14]                      ; Load the address that points after the
                                                                                   ; last element.

                                      Save the input vector v’s data array address, capacity, and length into the stack.

                                    mov      qword ptr [rsp + 8], r12              ; Store the address of vector v's data
                                                                                   ; array into the stack

                                    mov      qword ptr [rsp + 16], r10             ; Store the capacity of vector v into the
                                                                                   ; stack frame

                                    mov      qword ptr [rsp + 24], r12             ; Store the address of vector v's data
                                                                                   ; array into the stack

                                    mov      qword ptr [rsp + 32], r15             ; Store the address of the end of vector
                                                                                   ; v's data array into the stack

                                      Check the length of vector v; if it is 0, set the output vector length to 0 and return from the function.

                                    test     r14, r14                              ; Test if the length of vector v is 0
                                    je       .LBB1_1                               ; Jump if the length of vector v is 0

                                      Check if this iteration will result in a capacity overflow.

                                    xor      ebx, ebx                              ; Set ebx to 0
                                    mov      rax, r14                              ; Set rax to the length of vector v

                                    shr      rax, 59                               ; The length of an array should not
                                                                                   ; exceed 2^59 bits
                                                                                   ; Move the uppermost nibble of the
                                                                                   ; length into lower bits

                                    sete     al                                    ; Set al to 1 if the uppermost nibble in
                                                                                   ; the address is 0

                                    jne          .LBB1_3                             ; Jump if the length of vector v is
                                                                                     ; greater than 2^59 bytes

                                          No capacity overflows. Now check if the length is 0.

                                    mov          qword ptr [rsp], r10          ; Store the capacity of vector v on the stack
                                    mov          r13, r14                      ; Set r13 to the length of vector v
                                    shl          r13, 4                        ; Convert the length of vector v to bytes

                                    mov          bl, al                        ; Set bl to a1 (which happens to be 1 if the
                                                                               ; length of vector v is less than 2^59 bytes)

                                    shl          rbx, 3                        ; Shift rbx to the left by 3 bits so that rbx
                                                                               ; is set to 8.

                                    test         r13, r13                      ; Check if the number of bytes needed for the
                                                                               ; output vector is 0

                                    je           .LBB1_6                       ; Jump to .LBB1_6 if no bytes are needed

                                          Vector is greater than 0 bytes. Allocate memory for the output vector.

                                    mov          rdi, r13        ; Set rdi = number of bytes needed for the output vector
                                    mov          rsi, rbx        ; Set rsi to 8 (the alignment of the output vector)

                                    call         qword ptr [rip + __rust_alloc@GOTPCREL]                ; Call __rust_alloc

                                    test         rax, rax        ; Test if the allocation failed
                                    je           .LBB1_9         ; Jump to .LBB1_9 if rax is 0 (allocation failed)

                                          Allocation succeeded. Now, set the address of the output vector’s data array to rax.

                                          Check if the length of vector v is odd. Handle one entry before entering the even loop.

                                    .LBB1_10:
                                    mov     qword ptr [rbp], rax                     ; Address of the output vector = rax

                                    mov          qword ptr [rbp + 8], r14            ; Set the capacity of the output vector to
                                                                                     ; the length of vector v

                                    mov          qword ptr [rbp + 16], 0             ; Set the length of the output vector to 0

                                    test         r14b, 1                             ; Test if the length of vector v is odd

                                    mov          r10, qword ptr [rsp]                ; Set r10 to the length of vector v

                                    jne          .LBB1_12                            ; Jump to .LBB1_12 if the length of
                                                                                     ; vector v is odd

                                          The capacity of vector v is even.

                                    mov          rdx, r12               ; Set rdx to the address of vector v's data array
                                    lea          r8, [rbp + 16]         ; Set r8 = address of the output vector's length

                                          Check if the vector length is 1.

                                    cmp          r14, 1              ; Compare the length of vector v to 1
                                    jne          .LBB1_14            ; Jump to .LBB1_14 if the length of vector v is not 1
                                    jmp          .LBB1_17            ; Jump to .LBB1_17 if the length of vector v is 1
                                                                     ; Length of vector v is 1, so the loop is not entered

                                          The length of vector v is 0.

                                    .LBB1_1:
                                    mov      qword ptr [rbp], 8                       ; Set the address of the output
                                                                                      ; vector to 8

                                    lea          r8, [rbp + 16]                       ; Set r8 to the address of the length
                                                                                      ; of the output vector

                                    xorps        xmm0, xmm0                           ; Set xmm0 to 0

                                    movups       xmmword ptr [rbp + 8], xmm0 ; Set the length and capacity of the
                                                                             ; output vector to 0

                                    jmp          .LBB1_17                             ; Jump to .LBB1_17

                                       The length of the output vector is odd, so one loop entry is performed before entering the loop that
                                    handles an even number of entries.

                                    .LBB1_12:
                                    movzx   ecx, byte ptr [r12]            ; Set ecx to the value of the first element of
                                                                           ; input vector v's bool data array

                                    and          ecx, 1                    ; Mask of the upper bits of ecx to ensure that
                                                                           ; the value is 0 or 1

                                        Initialize the length and pointer in the output vector entry. The compiler uses an XOR trick to determine
                                    the length of the slice.
                                      •       if true: 1 XOR 5 = 4 (length of "true").
                                      •       If false: 0 XOR 5 = 5 (length of "false").

                                    The compiler uses this trick to avoid a branch.

                                    mov          rsi, rcx                             ; Set rsi to ecx

                                    xor          rsi, 5                               ; Set rsi to 5 if rsi is 0, otherwise set
                                                                                      ; rsi to 4

                                    test         rcx, rcx                             ; Test if the first bit of vector v's
                                                                                      ; data array is 0

                                    lea          rcx, [rip + .L__unnamed_1]           ; Set rcx to the address of "false"
                                    lea          rdi, [rip + .L__unnamed_2]           ; Set rdi to the address of "true"

                                       The following conditional move makes rdi point to "true" if the bool value is 1. Otherwise, rdi
                                    points to "false".

                                    cmove        rdi, rcx                       ; rdi points to "false" if input
                                                                                ; element's entry is 0, otherwise,

                                                                                    ; it points to "true"

                                    lea         rdx, [r12 + 1]                      ; Set rcx = address of the next element
                                                                                    ; of input vector v

                                    mov         qword ptr [rax], rdi                ; Set the address of the mapped string in
                                                                                    ; the string slice

                                    mov         qword ptr [rax + 8], rsi            ; Set the length of the string slice

                                    add         rax, 16                             ; Point to the next slice in the output
                                                                                    ; data array

                                    lea         r8, [rbp + 16]                      ; Set r8 to the address of the output
                                                                                    ; vector's data array

                                    cmp         r14, 1                              ; Compare the length of vector v to 1

                                    je          .LBB1_17                            ; Jump to .LBB1_17 if the length of
                                                                                    ; the vector v is 1 (we are done)

                                             Begin the loop to process two entries per iteration, targeting an even number of entries.

                                    .LBB1_14:
                                    mov     r9, rbp                                    ; Set r9 to the address of output vector
                                    lea     rsi, [rip + .L__unnamed_1]                 ; Set rsi to the address of "false"
                                    lea     rbp, [rip + .L__unnamed_2]                 ; Set rbp to the address of "true"

                                          Processing of the first entry within the iteration.

                                    .LBB1_15:

                                    movzx       ebx, byte ptr [rdx]            ; Set ebx to the first byte of input
                                                                               ; vector v's data array

                                    and         ebx, 1                         ; Mask off the upper bits to get the bool value

                                        The code must initialize the length and pointer in the output vector entry. The compiler uses the XOR
                                    trick we saw earlier to determine the length of the output string slice.
                                      •       if true: 1 XOR 5 = 4 (length of "true").
                                      •       If false: 0 XOR 5 = 5 (length of "false").
                                    mov           rcx, rbx    ; Set rcx to the bool value mapped to 0 or 1

                                    xor         rcx, 5         ; Set rcx to 5 if rcx is 0. Otherwise, set rcx to 4

                                    test        rbx, rbx       ; Set the condition code bits based on the
                                                               ; content of bool value

                                    mov         rdi, rbp       ; Set rdi to point to "true".

                                       The following conditional move makes rdi point to "false" if the bool value is 0. Otherwise, rdi
                                    points to "true".

                                    cmove      rdi, rsi                 ; Set rdi to point to "false" if bool value
                                                                        ; is 0. Otherwise, set rdi to point to "true"
                                    mov        qword ptr [rax], rdi     ; Copy the address of "true" or "false"
                                                                        ; to the string slice
                                    mov        qword ptr [rax + 8], rcx ; Set the length of the string slice

                                      Processing of the second entry within the iteration

                                    movzx      ecx, byte ptr [rdx + 1]            ; Set ecx to the next element of the input
                                                                                  ; vector v's data array

                                    and        ecx, 1                             ; Mask off the upper bits to convert bool
                                                                                  ; into 0 or 1

                                    mov        rdi, rcx                           ; Move the bool's value to rdi
                                    xor        rdi, 5                             ; Convert the bool's value into the length
                                                                                  ; using the XOR trick

                                    test       rcx, rcx                           ; Set the condition codes based on the
                                                                                  ; bool's value

                                    mov        rcx, rbp                           ; rcx points to "true"

                                    cmove      rcx, rsi                           ; rcx points to "false" if the bool's
                                                                                  ; value is 0

                                    mov        qword ptr [rax + 16], rcx          ; Copy the address of "true" or "false"
                                                                                  ; to the string slice

                                    mov        qword ptr [rax + 24], rdi          ; Set the length of the string slice

                                      Moving to the next iteration.

                                    add        rdx, 2                             ; Move the input vector past the two
                                                                                  ; entries we have just processed.

                                    add        rax, 32                            ; Move the output vector pointer past the
                                                                                  ; two entries we have just processed.

                                    cmp        rdx, r15                           ; Check if we have processed all the
                                                                                  ; entries of the input vector

                                    jne        .LBB1_15                           ; Jump to .LBB1_15 if more entries need
                                                                                  ; to be processed

                                            End the loop for an even number of entries.

                                    mov        rbp, r9       ; Set rbp to the address of the output vector

                                      Returning when the length is 0 or 1.

                                    .LBB1_17:
                                    mov     qword ptr [r8], r14          ; Set the length of the output vector to the
                                                                         ; length of vector v

                                    test        r10, r10                     ; Test if the length of vector v is 0
                                    je          .LBB1_19                     ; Jump if the length of vector v is 0

                                        Aside: The compiler uses the following three instructions to set rdx to 1 as the call to __rust_dealloc
                                    expects the alignment of the vector to be in rdx. The alignment of the vector is 1 as the vector’s data array
                                    is a bool array. The compiler does this by setting rdx to the bitwise-not of the length of the vector and then
                                    shifting rdx to the right by 63 bits. This approach works as the most significant bit of the length in rdx is
                                    guaranteed to be 0 as the compiler has already checked for length overflow.

                                    mov         rdx, r10                     ; Set rdx to the length of vector v
                                    not         rdx                          ; Set rdx to the bitwise not of rdx
                                    shr         rdx, 63                      ; Set rdx to the uppermost bit of rdx

                                          Free the input vector v’s buffer, as this function owns the vector and v is going out of scope.

                                    mov         rdi, r12       ; Set rdi to the address of input vector v's data array
                                    mov         rsi, r10       ; Set rsi to the length of input vector v

                                    call        qword ptr [rip + __rust_dealloc@GOTPCREL]                   ; Call __rust_dealloc

                                          Return the output vector.

                                    .LBB1_19:
                                    mov     rax, rbp          ; Set rax to the address of the output vector
                                    add     rsp, 40           ; Set rsp to the address of the first byte of the output
                                                              ; vector's data array

                                    pop         rbx           ; Restore rbx
                                    pop         r12           ; Restore r12
                                    pop         r13           ; Restore r13
                                    pop         r14           ; Restore r14
                                    pop         r15           ; Restore r15
                                    pop         rbp           ; Restore rbp
                                    ret

                                          The following code handles the case when the vector v’s length is 0.

                                    .LBB1_6:
                                    mov      rax, rbx                                 ; Set rax to rbx

                                    test        rax, rax                              ; Test if rbx is 0
                                    jne         .LBB1_10                              ; Jump to .LBB1_10 if rbx is not 0

                                          Memory allocation for the output vector has failed, so signal an error.

                                    .LBB1_9:
                                    mov      rdi, r13                    ; Set rdi to r13
                                    mov      rsi, rbx                    ; Set rsi to rbx
                                    call     qword ptr [rip + alloc::alloc::handle_alloc_error@GOTPCREL]
                                    jmp      .LBB1_4                     ; Jump to .LBB1_4

                                          Capacity overflow has occurred, so signal an error.

                                    .LBB1_3:
                                    call     qword ptr [rip + alloc::raw_vec::capacity_overflow@GOTPCREL]

                                          Common logic for exception handling.

                                    .LBB1_4:
                                    ud2                                             ; Halt execution
                                    mov      rbx, rax                               ; Set rbx to rax
                                    lea      rdi, [rsp + 8]                         ; Set rdi to the address of the first
                                                                                    ; byte of the output vector's data array
                                    call        core::ptr::drop_in_place            ; Call core::ptr::drop_in_place
                                    mov         rdi, rbx                            ; Set rdi to rbx
                                    call        _Unwind_Resume@PLT                  ; Call _Unwind_Resume
                                    ud2                                             ; Halt execution

                                    .ascii "true"

                                    Convert a Vector of u64 to a Vector of bool
                                    The following code converts a vector of u64 to a vector of bool by checking whether the value is 0. Copy
                                    this code into Compiler Explorer and look at the generated assembly code.

                                    pub fn convert_u64_vec_to_bool_vec(v: Vec<u64>) -> Vec<bool> {
                                        convert(v, |n| n != 0)
                                    }

                                    Here are some observations about the generated assembly code:
                                      •      The compiler initializes many constants for efficient SIMD (Single Instruction Multiple Data)
                                             operations.
                                      •      Memory is allocated for the new boolean vector using the Rust allocator (__rust_alloc).
                                      •      A loop iterates over the u64 values in the input vector, checking each u64 value to determine if it is
                                             zero. Based on this check, it then writes the corresponding boolean value (true or false) to the
                                             new vector.
                                      •      The generated code employs different looping strategies depending on the input vector’s size, using
                                             SIMD instructions for large input vector lengths.
                                      •      The compiler optimizes the assembly to use SIMD instructions, allowing it to process multiple data
                                             points simultaneously. It simultaneously processes multiple u64 values, employing SIMD
                                             instructions like pcmpeqd, pshufd, and packuswb for comparing, shuffling, and packing values.
                                      •      After populating the output vector, the generated code deallocates the input vector’s heap memory
                                             (__rust_dealloc).

                                    Convert a Vector of (f32,f32) Tuple to a Vector of f32
                                    The following code converts a vector of (f32,f32) tuple to a vector of f32 by multiplying the two f32
                                    values. Copy this code into Compiler Explorer and look at the generated assembly code.

                                    pub fn convert_f32_f32_vec_to_f32_vec(v: Vec<(f32,f32)>) -> Vec<f32> {
                                        convert(v, |n| n.0*n.1)
                                    }

                                    Let us break down the assembly code:
                                      •     There is logic that checks the size of the vector to handle memory allocation (call
                                            __rust_alloc).
                                      •     As expected, the code goes over the input vector’s elements, takes each (f32, f32) tuple,
                                            multiplies the two f32 numbers, and then collects them in the output vector.
                                      •     The generated code adopts different looping strategies based on the input vector’s size, utilizing
                                            SIMD instructions for large input vector lengths.
                                      •     The compiler uses SIMD operations optimized for parallel floating-point operations (movss, mulss,
                                            etc.).
                                      •     After creating and populating the output vector, the code deallocates the input vector’s heap
                                            memory (invoking __rust_dealloc).

                                          Key Takeaways
                                      •     The functional style code in Rust is a zero-cost abstraction. The compiler can optimize the code to
                                            be as efficient as handwritten loops.
                                      •     An owned input vector will be deallocated when it goes out of scope. The compiler will generate
                                            code to deallocate the vector’s buffer.
                                      •     The compiler will also generate code to deallocate the vector’s buffer when an error occurs.
                                      •     The Rust compiler checks for address space overflow when allocating memory for a vector.
                                      •     If a function returns a vector, the compiler will generate the code to allocate memory for the
                                            vector’s data buffer. The caller passes a “hidden” pointer to the function with the address of the
                                            returned vector’s struct.
                                      •     The function will panic if it cannot allocate memory for a vector.
                                      •     The compiler uses different looping strategies based on the size of the input vector.
                                               –     When working with convert_bool_vec_to_static_str_vec, the compiler defined a
                                                     main loop for even entries and processed an additional entry when the input vector length
                                                     was odd.
                                               –     Our experiments with convert_u64_vec_to_bool_vec and
                                                     convert_f32_f32_vec_to_f32_vec showed that the compiler uses SIMD instructions to
                                                     process multiple data points simultaneously when the input vector length is large.
