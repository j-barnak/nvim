
                                                        Chapter 8
                                       Traditional vs. Functional Array Iteration

                                    This chapter delves into the assembly code generated from functional style array iteration. We will contrast
                                    this with the assembly produced from a traditional for-loop style iteration. Additionally, we will explore the
                                    effects of varying the array size on the resulting assembly.

                                    Iterator and Functional Style
                                    The following code sums up the squares of even numbers in an array. The code uses a functional style to
                                    iterate over the array. The code is generic over the array size. The array size is a const generic parameter.

                                    pub fn sum_of_even_squares<const N: usize>(arr: &[i64; N]) -> i64 {
                                        arr.iter()
                                            .filter(|&x| x % 2 == 0)   // Filter out odd numbers
                                            .map(|&x| x.pow(2))        // Square remaining numbers
                                            .sum()                     // Sum them up
                                    }

                                    pub fn sum_of_even_squares_specific_size(arr: &[i64; 1024]) -> i64 {
                                        sum_of_even_squares(arr)
                                    }

                                    Generated Assembly: Loop Unrolling, Inlining, and Conditional
                                    Moves
                                    We will analyze the code generated for the sum_of_even_squares_specific_size function. The
                                    compiler generates no code for the sum_of_even_squares function as it is generic. Code generation
                                    occurs for specialized instances of generic functions rather than for the generic functions themselves.
                                    We will see that in the sum_of_even_squares_specific_size function, the compiler inlines the
                                    sum_of_even_squares function. The compiler unrolls the loop by 2. So, the loop needs to go through 512
                                    iterations to process 1024 elements. The compiler also uses conditional move instructions (cmovne) to
                                    avoid branching. The compiler calculates the squares of even as well as odd numbers. It uses cmovne to add
                                    the results of squaring even numbers while discarding the square of odd numbers. We will experiment with

                                    changing the power of x to find the point where the compiler adds code to avoid odd number
                                    multiplication.

                                    ; Load the following two elements from the array.
                                    ;     The address of the first element in this iteration is rdi + 8*rdx.
                                    mov      rcx, qword ptr [rdi + 8*rdx]

                                    ;      The address of the second element in this iteration is rdi + 8*rdx + 8.
                                    mov       r9, qword ptr [rdi + 8*rdx + 8]

                                    ; Copy the first element to rsi.
                                    mov     rsi, rcx

                                    ;    Square the first element.
                                    imul    rsi, rcx

                                       Verify whether the initial element is even. The test instruction will set the zero flag to true when the
                                    result of performing a bitwise AND operation between the first element and 1 equals 0.

                                    test       cl, 1

                                        If the zero flag is not set, it indicates the first element is odd, and the code loads 0 into rsi (since r8 is
                                    0). Conversely, if the zero flag is set, the first element is even, and rsi already contains the square of the
                                    first element.

                                    cmovne     rsi, r8

                                        Add rax to rsi. Due to the conditional move instruction, rsi holds 0 for odd elements and the squared
                                    value for even ones. After this addition, rsi will have the cumulative sum of squares from even elements
                                    up to this point.

                                    add        rsi, rax

                                    ;      Move the loop counter forward by 2.
                                    add       rdx, 2

                                    ; Copy the second element to rax.
                                    mov     rax, r9

                                    ;    Square the second element.
                                    imul    rax, r9

                                    ;    Check if the second element is odd or even.
                                    test    r9b, 1

                                        If the second element is odd, the code loads 0 into rax (as r8 is 0). If the second element is even, then
                                    the square of the second element is already present in rax.

                                    cmovne         rax, r8

                                       Add rax to rsi. Due to the conditional move instruction, rax contains 0 for odd elements and the
                                    square of the element for even elements. After this addition, rax will contain the cumulative sum of even
                                    squares up to this iteration.

                                    add            rax, rsi

                                    ;           Check if the loop counter is 1024.
                                    cmp            rdx, 1024

                                    ;           If the loop counter is not 1024, jump to the loop start.
                                    jne            .LBB0_1

                                    Write the Code as a Loop
                                    Check in Compiler Explorer (https://godbolt.org/z/oj1oa4chn) that the compiler generates the same
                                    assembly code for a handwritten loop as the functional style. With Rust, writing the code in a functional
                                    style does not incur any performance penalty. It is a zero-cost abstraction.

                                    pub fn sum_of_even_squares_with_for<const N: usize>(arr: &[i64; N]) -> i64 {
                                        let mut sum = 0;
                                        for i in 0..N {
                                            let x = arr[i];
                                            if x % 2 == 0 {
                                                sum += x.pow(2);
                                            }
                                        }
                                        sum
                                    }

                                    pub fn sum_of_even_squares_specific_size_with_for(arr: &[i64; 1024]) -> i64 {
                                        sum_of_even_squares_with_for(arr)
                                    }

                                    Change the Power of x
                                    Alter the power of x from 2 and observe the effect on the generated code. As the parameter of x.pow
                                    increases, the compiler shifts its priority from avoiding branches to avoiding multiplications. This shift
                                    occurs when the parameter reaches 9. At x.pow(9), the compiler starts generating code with branching to
                                    minimize multiplications for odd numbers.

                                    pub fn sum_of_even_squares<const N: usize>(arr: &[i64; N]) -> i64 {
                                        arr.iter()
                                            .filter(|&x| x % 2 == 0) // filter out odd numbers
                                            .map(|&x| x.pow(2)) //    Change the power of x
                                            .sum() // sum them up
                                    }

                                          Key Takeaways
                                      •      Writing code in a functional style does not incur any performance penalty. It is a zero-cost
                                             abstraction. We saw this in our for-loop experiment.
                                      •      The array size has a significant impact on the generated code. We saw this in our array size
                                             experiment.
                                               –    For small array sizes, the Rust compiler completely unrolls the loop.
                                               –    The compiler optimizes iteration for odd array sizes by restructuring the code to avoid
                                                    unnecessary operations in the last iteration.

                                    Part D Iteration and Optimization
                                      •     The compiler goes out of its way to avoid branches. It prefers to calculate the power of x by a
                                            cascade of multiplications rather than using a branch to avoid the multiplications. We saw this in
                                            our power of x experiment.
                                      •     Code generation occurs for specialized instances of generic functions rather than for the generic
                                            functions themselves.
                                      •     The compiler may inline the code for a specialized instance of a generic function. For example, in
                                            the case of sum_of_even_squares, the compiler inlined it within
                                            sum_of_even_squares_specific_size. It generated no code for sum_of_even_squares.
