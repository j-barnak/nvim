                                    Field Ordering and Alignment
                                    Let us begin by exploring a basic structure containing various fields. We will then examine the code
                                    generated for the update_my_struct function.

                                    pub struct MyStruct {
                                        a: u8,
                                        b: u64,
                                        c: i8,
                                        d: i64,
                                        e: i32,
                                    }

                                    pub fn update_my_struct(my_struct: MyStruct) -> MyStruct {
                                        MyStruct {
                                            a: my_struct.a + 0xA,
                                            b: my_struct.b + 0xB,
                                            c: my_struct.c - 0xC,
                                            d: my_struct.d - 0xD,
                                            e: my_struct.e - 0xE,

                                    Rust Reorders Struct Fields
                                    Before we examine the generated code, let us explore the struct’s memory layout. In Rust, unlike C, the
                                    fields of a struct might not appear in memory in the same order they are declared. The generated code
                                    shows that Rust aligns these fields based on size, with larger fields facing stricter alignment requirements.
                                    The alignment of a field means the field’s address must be a multiple of a certain number of bytes. For
                                    example, a u64 requires an alignment of 8, meaning its address must be a multiple of 8. Conversely, a u8

                                         Learn More: C Compatibility
                                    You can turn off field reordering by adding the #[repr(C)] attribute to the struct, which is useful when

                                    Pattern Matching a Struct
                                    Rust is a highly expressive language. It allows us to pattern-match fields of a struct. Let us look at an
                                    example of pattern-matching with the OurStruct struct defined here. The are_we_compatible function
                                    returns true if the pattern-matching conditions are satisfied. Otherwise, it returns false.

                                    pub struct OurStruct {
                                        my_struct: MyStruct,
                                        your_struct: MyStruct,
                                    }

                                    pub fn are_we_compatible(our_struct: &OurStruct) -> bool {
                                        match *our_struct {
                                            OurStruct {
                                                my_struct: MyStruct { a: 10, .. },
                                                your_struct: MyStruct { a: 101, .. },
                                            } => true,
                                            OurStruct {
                                                my_struct: MyStruct { b: 11, .. },
                                                your_struct: MyStruct { c: 121, d: 42, .. },
                                            } => true,
                                            OurStruct { .. } => false,
                                        }
                                    }

                                    offsets for each field in OurStruct.

                                    maintaining the alignment of the MyStruct fields within OurStruct.

                                             Key Takeaways
                                         •    The Rust compiler will reorder struct fields to minimize padding.
                                         •    Reordering of fields reduces the size of the struct and increases the chances of vectorization.
                                         •    You can turn off the reordering of struct fields by using the #[repr(C)] attribute, which is
                                              particularly useful when interfacing with C code.
                                         •    The Rust compiler will add padding to the end of a struct to make the size of the struct a multiple of
                                              the alignment of the largest field.
