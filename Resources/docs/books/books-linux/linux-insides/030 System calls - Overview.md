# System calls

This chapter describes the `system call` concept in the Linux kernel.

* [Introduction to system call concept](031%20System%20calls%20-%20Introduction%20to%20system%20calls.md) - this part is introduction to the `system call` concept in the Linux kernel.
* [How the Linux kernel handles a system call](032%20System%20calls%20-%20How%20the%20Linux%20kernel%20handles%20a%20system%20call.md) - this part describes how the Linux kernel handles a system call from a userspace application.
* [vsyscall and vDSO](033%20System%20calls%20-%20vsyscall%20and%20vDSO.md) - third part describes `vsyscall` and `vDSO` concepts.
* [How the Linux kernel runs a program](034%20System%20calls%20-%20How%20the%20Linux%20kernel%20runs%20a%20program.md) - this part describes startup process of a program.
* [Implementation of the open system call](035%20System%20calls%20-%20Implementation%20of%20the%20open%20system%20call.md) - this part describes implementation of the [open](http://man7.org/linux/man-pages/man2/open.2.html) system call.
* [Limits on resources in Linux](036%20System%20calls%20-%20Limits%20on%20resources%20in%20Linux.md) - this part describes implementation of the [getrlimit/setrlimit](https://linux.die.net/man/2/getrlimit) system calls.
