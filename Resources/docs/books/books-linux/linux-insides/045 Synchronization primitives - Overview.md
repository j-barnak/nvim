# Synchronization primitives in the Linux kernel.

This chapter describes synchronization primitives in the Linux kernel.

* [Introduction to spinlocks](046%20Synchronization%20primitives%20-%20Introduction%20to%20spinlocks.md) - the first part of this chapter describes implementation of spinlock mechanism in the Linux kernel.
* [Queued spinlocks](047%20Synchronization%20primitives%20-%20Queued%20spinlocks.md) - the second part describes another type of spinlocks - queued spinlocks.
* [Semaphores](048%20Synchronization%20primitives%20-%20Semaphores.md) - this part describes implementation of `semaphore` synchronization primitive in the Linux kernel.
* [Mutual exclusion](049%20Synchronization%20primitives%20-%20Mutex.md) - this part describes - `mutex` in the Linux kernel.
* [Reader/Writer semaphores](050%20Synchronization%20primitives%20-%20Reader-Writer%20semaphores.md) - this part describes special type of semaphores - `reader/writer` semaphores.
* [Sequential locks](051%20Synchronization%20primitives%20-%20SeqLock.md) - this part describes sequential locks in the Linux kernel.
