    Appendix I: GPIO Alternate Functions
    (STM32L4)
    Software can program a GPIO pin to map this pin internally to the input or output of
    some on-chip peripheral. Thus, a GPIO pin usually can support more than one hardware
    functions, which are called alternate functions. The alternate function is selected by
    programming the AF S EL [3: 0) bits defined in the Alternate Function Low or High
    Register. Alternate functions allow embedded system designers to better tailor the
    processor chip to the application's need .
