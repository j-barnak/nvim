
Appendix C SVM Intercept Exit Codes
On a #VMEXIT, a reason for exit (an exit code) is stored in the EXITCODE field in the VMCB. The
exit codes are defined in Table C-1. Intercept exit codes are equal to the bit position of the corre-
sponding flag in the VMCB’s intercept vector.
