\doxysubsection{Detailed Description}
Class for loading and manipulating character fonts. 

Fonts can be opened from a file, from memory or from a custom stream, and supports the most common types of fonts. See the open\+From\+File function for the complete list of supported formats.

Once it is opened, a {\ttfamily \doxylink{classsf_1_1Font}{sf\+::\+Font}} instance provides three types of information about the font\+: \begin{DoxyItemize}
\item Global metrics, such as the line spacing \item Per-\/glyph metrics, such as bounding box or kerning \item Pixel representation of glyphs\end{DoxyItemize}
Fonts alone are not very useful\+: they hold the font data but cannot make anything useful of it. To do so you need to use the {\ttfamily \doxylink{classsf_1_1Text}{sf\+::\+Text}} class, which is able to properly output text with several options such as character size, style, color, position, rotation, etc. This separation allows more flexibility and better performances\+: indeed a {\ttfamily \doxylink{classsf_1_1Font}{sf\+::\+Font}} is a heavy resource, and any operation on it is slow (often too slow for real-\/time applications). On the other side, a {\ttfamily \doxylink{classsf_1_1Text}{sf\+::\+Text}} is a lightweight object which can combine the glyphs data and metrics of a {\ttfamily \doxylink{classsf_1_1Font}{sf\+::\+Font}} to display any text on a render target. Note that it is also possible to bind several {\ttfamily \doxylink{classsf_1_1Text}{sf\+::\+Text}} instances to the same {\ttfamily \doxylink{classsf_1_1Font}{sf\+::\+Font}}.

It is important to note that the {\ttfamily \doxylink{classsf_1_1Text}{sf\+::\+Text}} instance doesn\textquotesingle{}t copy the font that it uses, it only keeps a reference to it. Thus, a {\ttfamily \doxylink{classsf_1_1Font}{sf\+::\+Font}} must not be destructed while it is used by a {\ttfamily \doxylink{classsf_1_1Text}{sf\+::\+Text}} (i.\+e. never write a function that uses a local {\ttfamily \doxylink{classsf_1_1Font}{sf\+::\+Font}} instance for creating a text).

Usage example\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{comment}{//\ Open\ a\ new\ font}}
\DoxyCodeLine{\textcolor{keyword}{const}\ sf::Font\ font(\textcolor{stringliteral}{"{}arial.ttf"{}});}
\DoxyCodeLine{}
\DoxyCodeLine{\textcolor{comment}{//\ Create\ a\ text\ which\ uses\ our\ font}}
\DoxyCodeLine{sf::Text\ text1(font);}
\DoxyCodeLine{text1.setCharacterSize(30);}
\DoxyCodeLine{text1.setStyle(\mbox{\hyperlink{classsf_1_1Text_aa8add4aef484c6e6b20faff07452bd82a2af9ae5e1cda126570f744448e0caa32}{sf::Text::Regular}});}
\DoxyCodeLine{}
\DoxyCodeLine{\textcolor{comment}{//\ Create\ another\ text\ using\ the\ same\ font,\ but\ with\ different\ parameters}}
\DoxyCodeLine{sf::Text\ text2(font);}
\DoxyCodeLine{text2.setCharacterSize(50);}
\DoxyCodeLine{text2.setStyle(\mbox{\hyperlink{classsf_1_1Text_aa8add4aef484c6e6b20faff07452bd82aee249eb803848723c542c2062ebe69d8}{sf::Text::Italic}});}

\end{DoxyCode}


Apart from opening font files, and passing them to instances of {\ttfamily \doxylink{classsf_1_1Text}{sf\+::\+Text}}, you should normally not have to deal directly with this class. However, it may be useful to access the font metrics or rasterized glyphs for advanced usage.

Note that if the font is a bitmap font, it is not scalable, thus not all requested sizes will be available to use. This needs to be taken into consideration when using {\ttfamily \doxylink{classsf_1_1Text}{sf\+::\+Text}}. If you need to display text of a certain size, make sure the corresponding bitmap font that supports that size is used.

Be aware that there is no uniform definition of how the descent is calculated. It can vary from font to font.

The descent shares the same coordinate system as the ascent. This means that it will be negative for distances below the baseline.

Determine if this font has a glyph representing the requested code point. 

Most fonts only include a very limited selection of glyphs from specific Unicode subsets, like Latin, Cyrillic, or Asian characters.

While code points without representation will return a font specific default character, it might be useful to verify whether specific code points are included to determine whether a font is suited to display text in a specific language.
