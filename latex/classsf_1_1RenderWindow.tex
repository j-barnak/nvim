\doxysubsection{Detailed Description}
\doxylink{classsf_1_1Window}{Window} that can serve as a target for 2D drawing. 

{\ttfamily \doxylink{classsf_1_1RenderWindow}{sf\+::\+Render\+Window}} is the main class of the Graphics module. It defines an OS window that can be painted using the other classes of the graphics module.

{\ttfamily \doxylink{classsf_1_1RenderWindow}{sf\+::\+Render\+Window}} is derived from {\ttfamily \doxylink{classsf_1_1Window}{sf\+::\+Window}}, thus it inherits all its features\+: events, window management, Open\+GL rendering, etc. See the documentation of {\ttfamily \doxylink{classsf_1_1Window}{sf\+::\+Window}} for a more complete description of all these features, as well as code examples.

On top of that, {\ttfamily \doxylink{classsf_1_1RenderWindow}{sf\+::\+Render\+Window}} adds more features related to 2D drawing with the graphics module (see its base class {\ttfamily \doxylink{classsf_1_1RenderTarget}{sf\+::\+Render\+Target}} for more details). Here is a typical rendering and event loop with a {\ttfamily \doxylink{classsf_1_1RenderWindow}{sf\+::\+Render\+Window}}\+:
