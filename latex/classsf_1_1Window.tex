\doxysubsection{Detailed Description}
\doxylink{classsf_1_1Window}{Window} that serves as a target for Open\+GL rendering. 

{\ttfamily \doxylink{classsf_1_1Window}{sf\+::\+Window}} is the main class of the \doxylink{classsf_1_1Window}{Window} module. It defines an OS window that is able to receive an Open\+GL rendering.

A {\ttfamily \doxylink{classsf_1_1Window}{sf\+::\+Window}} can create its own new window, or be embedded into an already existing control using the {\ttfamily create(handle)} function. This can be useful for embedding an Open\+GL rendering area into a view which is part of a bigger GUI with existing windows, controls, etc. It can also serve as embedding an Open\+GL rendering area into a window created by another (probably richer) GUI library like Qt or wx\+Widgets.

The {\ttfamily \doxylink{classsf_1_1Window}{sf\+::\+Window}} class provides a simple interface for manipulating the window\+: move, resize, show/hide, control mouse cursor, etc. It also provides event handling through its {\ttfamily \doxylink{classsf_1_1WindowBase_a6090926b477e9d0a83854b94b9e1fd35}{poll\+Event()}} and {\ttfamily \doxylink{classsf_1_1WindowBase_ab5975f6f6a06ecd6c18fa0f62cd1edf7}{wait\+Event()}} functions.

Note that Open\+GL experts can pass their own parameters (anti-\/aliasing level, bits for the depth and stencil buffers, etc.) to the Open\+GL context attached to the window, with the {\ttfamily \doxylink{structsf_1_1ContextSettings}{sf\+::\+Context\+Settings}} structure which is passed as an optional argument when creating the window.

On dual-\/graphics systems consisting of a low-\/power integrated GPU and a powerful discrete GPU, the driver picks which GPU will run an SFML application. In order to inform the driver that an SFML application can benefit from being run on the more powerful discrete GPU, {\ttfamily \#SFML\+\_\+\+DEFINE\+\_\+\+DISCRETE\+\_\+\+GPU\+\_\+\+PREFERENCE} can be placed in a source file that is compiled and linked into the final application. The macro should be placed outside of any scopes in the global namespace.

void sf\+::\+Window\+::set\+Vertical\+Sync\+Enabled (\begin{DoxyParamCaption}\item[{bool}]{enabled}{}\end{DoxyParamCaption})}



Enable or disable vertical synchronization. 

Activating vertical synchronization will limit the number of frames displayed to the refresh rate of the monitor. This can avoid some visual artifacts, and limit the framerate to a good value (but not constant across different computers).

Vertical synchronization is disabled by default.
