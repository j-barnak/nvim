\doxysubsection{Detailed Description}
Utility class that measures the elapsed time. 

The clock starts automatically after being constructed.

{\ttfamily \doxylink{classsf_1_1Clock}{sf\+::\+Clock}} is a lightweight class for measuring time.

It provides the most precise time that the underlying OS can achieve (generally microseconds or nanoseconds). It also ensures monotonicity, which means that the returned time can never go backward, even if the system time is changed.

Usage example\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{sf::Clock\ clock;}
\DoxyCodeLine{...}
\DoxyCodeLine{Time\ time1\ =\ clock.\mbox{\hyperlink{classsf_1_1Clock_abe889b42a65bcd8eefc16419645d08a7}{getElapsedTime}}();}
\DoxyCodeLine{...}
\DoxyCodeLine{\mbox{\hyperlink{classsf_1_1Time_ac71085f83ee2bd74e005fc63d7a47a41}{Time}}\ time2\ =\ clock.\mbox{\hyperlink{classsf_1_1Clock_a123e2627f2943e5ecaa1db0c7df3231b}{restart}}();}
\DoxyCodeLine{...}
\DoxyCodeLine{\mbox{\hyperlink{classsf_1_1Time_ac71085f83ee2bd74e005fc63d7a47a41}{Time}}\ time3\ =\ clock.\mbox{\hyperlink{classsf_1_1Clock_a564522bc9caf98b412aa0c6f39a81d75}{reset}}();}

\end{DoxyCode}


The {\ttfamily \doxylink{classsf_1_1Time}{sf\+::\+Time}} value returned by the clock can then be converted to a number of seconds, milliseconds or even microseconds.
