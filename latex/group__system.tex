Base module of SFML, defining various utilities. It provides vector classes, Unicode strings and conversion functions, threads and mutexes, timing classes.

Standard stream used by SFML to output warnings and errors. 

By default, {\ttfamily \doxylink{group__system_gad3cbfe676d6ca096c4a943bbd2ff3b83}{sf\+::err()}} outputs to the same location as {\ttfamily std\+::cerr}, (-\/\texorpdfstring{$>$}{>} the stderr descriptor) which is the console if there\textquotesingle{}s one available.

It is a standard {\ttfamily std\+::ostream} instance, so it supports all the insertion operations defined by the STL ({\ttfamily operator\texorpdfstring{$<$}{<}\texorpdfstring{$<$}{<}}, manipulators, etc.).

{\ttfamily \doxylink{group__system_gad3cbfe676d6ca096c4a943bbd2ff3b83}{sf\+::err()}} can be redirected to write to another output, independently of {\ttfamily std\+::cerr}, by using the {\ttfamily rdbuf()} function provided by the {\ttfamily std\+::ostream} class.

Make the current thread sleep for a given duration. 

{\ttfamily \doxylink{group__system_gaf040a08fd33c3b7c10d6d25a1018c504}{sf\+::sleep}} is the best way to block a program or one of its threads, as it doesn\textquotesingle{}t consume any CPU power. Compared to the standard {\ttfamily std\+::this\+\_\+thread\+::sleep\+\_\+for} function, this one provides more accurate sleeping time thanks to some platform-\/specific tweaks.

{\ttfamily \doxylink{group__system_gaf040a08fd33c3b7c10d6d25a1018c504}{sf\+::sleep}} only guarantees millisecond precision. Sleeping for a duration less than 1 millisecond is prone to result in the actual sleep duration being less than what is requested.
