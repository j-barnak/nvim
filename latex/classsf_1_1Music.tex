\doxysubsection{Detailed Description}
Streamed music played from an audio file. 

Musics are sounds that are streamed rather than completely loaded in memory. This is especially useful for compressed musics that usually take hundreds of MB when they are uncompressed\+: by streaming it instead of loading it entirely, you avoid saturating the memory and have almost no loading delay. This implies that the underlying resource (file, stream or memory buffer) must remain valid for the lifetime of the {\ttfamily \doxylink{classsf_1_1Music}{sf\+::\+Music}} object.

Apart from that, a {\ttfamily \doxylink{classsf_1_1Music}{sf\+::\+Music}} has almost the same features as the {\ttfamily \doxylink{classsf_1_1SoundBuffer}{sf\+::\+Sound\+Buffer}} / {\ttfamily \doxylink{classsf_1_1Sound}{sf\+::\+Sound}} pair\+: you can play/pause/stop it, request its parameters (channels, sample rate), change the way it is played (pitch, volume, 3D position, ...), etc.

As a sound stream, a music is played in its own thread in order not to block the rest of the program. This means that you can leave the music alone after calling {\ttfamily \doxylink{classsf_1_1SoundStream_af05290eb2c6a316790fb18c5912a5dd6}{play()}}, it will manage itself very well.

Sets the beginning and duration of the sound\textquotesingle{}s looping sequence using {\ttfamily \doxylink{classsf_1_1Time}{sf\+::\+Time}} 

{\ttfamily \doxylink{classsf_1_1Music_ae7b339f0a957dfad045f3f28083a015e}{set\+Loop\+Points()}} allows for specifying the beginning offset and the duration of the loop such that, when the music is enabled for looping, it will seamlessly seek to the beginning whenever it encounters the end of the duration. Valid ranges for {\ttfamily time\+Points.\+offset} and {\ttfamily time\+Points.\+length} are \mbox{[}0, Dur) and (0, Dur-\/offset\mbox{]} respectively, where Dur is the value returned by {\ttfamily \doxylink{classsf_1_1Music_a288ef6f552a136b0e56952dcada3d672}{get\+Duration()}}. Note that the EOF "{}loop point"{} from the end to the beginning of the stream is still honored, in case the caller seeks to a point after the end of the loop range. This function can be safely called at any point after a stream is opened, and will be applied to a playing sound without affecting the current playing offset.

\begin{DoxyWarning}{Warning}
Setting the loop points while the stream\textquotesingle{}s status is Paused will set its status to Stopped. The playing offset will be unaffected.
\end{DoxyWarning}
