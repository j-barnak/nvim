\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class sf\+::\+Vector3$<$ T $>$}
Utility template class for manipulating 3-\/dimensional vectors. 

{\ttfamily \doxylink{classsf_1_1Vector3}{sf\+::\+Vector3}} is a simple class that defines a mathematical vector with three coordinates (x, y and z). It can be used to represent anything that has three dimensions\+: a size, a point, a velocity, etc.

The template parameter T is the type of the coordinates. It can be any type that supports arithmetic operations (+, -\/, /, \texorpdfstring{$\ast$}{*}) and comparisons (==, !=), for example int or float. Note that some operations are only meaningful for vectors where T is a floating point type (e.\+g. float or double), often because results cannot be represented accurately with integers. The method documentation mentions "{}(floating-\/point)"{} in those cases.

You generally don\textquotesingle{}t have to care about the templated form ({\ttfamily \doxylink{classsf_1_1Vector3}{sf\+::\+Vector3}\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}}), the most common specializations have special type aliases\+: \begin{DoxyItemize}
\item {\ttfamily \doxylink{classsf_1_1Vector3}{sf\+::\+Vector3}\texorpdfstring{$<$}{<}float\texorpdfstring{$>$}{>}} is {\ttfamily \doxylink{namespacesf_aabc495912efba35400b484ea842664d0}{sf\+::\+Vector3f}} \item {\ttfamily \doxylink{classsf_1_1Vector3}{sf\+::\+Vector3}\texorpdfstring{$<$}{<}int\texorpdfstring{$>$}{>}} is {\ttfamily \doxylink{namespacesf_ac128b1a250ca87839ef1dd0416b45961}{sf\+::\+Vector3i}}\end{DoxyItemize}
The {\ttfamily \doxylink{classsf_1_1Vector3}{sf\+::\+Vector3}} class has a small and simple interface, its x, y and z members can be accessed directly (there are no accessors like {\ttfamily set\+X()}, {\ttfamily get\+X()}).
