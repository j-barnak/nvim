\doxysubsection{Detailed Description}
Specialized shape representing a circle. 

This class inherits all the functions of {\ttfamily \doxylink{classsf_1_1Transformable}{sf\+::\+Transformable}} (position, rotation, scale, bounds, ...) as well as the functions of {\ttfamily \doxylink{classsf_1_1Shape}{sf\+::\+Shape}} (outline, color, texture, ...).

Usage example\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{sf::CircleShape\ circle;}
\DoxyCodeLine{circle.\mbox{\hyperlink{classsf_1_1CircleShape_a21cdf85fc2f201e10222a241af864be0}{setRadius}}(150);}
\DoxyCodeLine{circle.\mbox{\hyperlink{classsf_1_1Shape_a7dbbed35b7544a9e592acd3908713256}{setOutlineColor}}(\mbox{\hyperlink{classsf_1_1Color_a1d0a7892f248dc1a8e38e96e4d308109}{sf::Color::Red}});}
\DoxyCodeLine{circle.\mbox{\hyperlink{classsf_1_1Shape_a5ad336ad74fc1f567fce3b7e44cf87dc}{setOutlineThickness}}(5);}
\DoxyCodeLine{circle.\mbox{\hyperlink{classsf_1_1Transformable_a47c1375b57cbb0e513286e8d11f6dd4d}{setPosition}}(\{10,\ 20\});}
\DoxyCodeLine{...}
\DoxyCodeLine{window.draw(circle);}

\end{DoxyCode}


Since the graphics card can\textquotesingle{}t draw perfect circles, we have to fake them with multiple triangles connected to each other. The "{}points count"{} property of {\ttfamily \doxylink{classsf_1_1CircleShape}{sf\+::\+Circle\+Shape}} defines how many of these triangles to use, and therefore defines the quality of the circle.

The number of points can also be used for another purpose; with small numbers you can create any regular polygon shape\+: equilateral triangle, square, pentagon, hexagon, ...
