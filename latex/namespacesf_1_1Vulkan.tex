Tell whether or not the system supports \doxylink{namespacesf_1_1Vulkan}{Vulkan}. 

This function should always be called before using the \doxylink{namespacesf_1_1Vulkan}{Vulkan} features. If it returns {\ttfamily false}, then any attempt to use \doxylink{namespacesf_1_1Vulkan}{Vulkan} will fail.

If only compute is required, set {\ttfamily require\+Graphics} to {\ttfamily false} to skip checking for the extensions necessary for graphics rendering.
