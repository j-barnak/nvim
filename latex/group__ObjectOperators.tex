\doxysubsubsection{Detailed Description}
Object operators.

Various operators are defined on \doxylink{structdrgn__object}{drgn\+\_\+object}s. These operators obey the rules of the programming language of the given objects.

Operators which return a \doxylink{structdrgn__object}{drgn\+\_\+object} have the same calling convention\+: the result object is the first argument, which must be initialized and may be the same as one or more of the operands; the result is only modified if the operator succeeds.
