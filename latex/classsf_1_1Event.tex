\doxysubsection{Detailed Description}
Defines a system event and its parameters. 

{\ttfamily \doxylink{classsf_1_1Event}{sf\+::\+Event}} holds all the information about a system event that just happened. Events are retrieved using the {\ttfamily \doxylink{classsf_1_1WindowBase_a6090926b477e9d0a83854b94b9e1fd35}{sf\+::\+Window\+::poll\+Event}} and {\ttfamily \doxylink{classsf_1_1WindowBase_ab5975f6f6a06ecd6c18fa0f62cd1edf7}{sf\+::\+Window\+::wait\+Event}} functions.

A {\ttfamily \doxylink{classsf_1_1Event}{sf\+::\+Event}} instance contains the subtype of the event (mouse moved, key pressed, window closed, ...) as well as the details about this particular event. Each event corresponds to a different subtype struct which contains the data required to process that event.

\doxylink{classsf_1_1Event}{Event} subtypes are event types belonging to {\ttfamily \doxylink{classsf_1_1Event}{sf\+::\+Event}}, such as {\ttfamily \doxylink{structsf_1_1Event_1_1Closed}{sf\+::\+Event\+::\+Closed}} or {\ttfamily \doxylink{structsf_1_1Event_1_1MouseMoved}{sf\+::\+Event\+::\+Mouse\+Moved}}.

The way to access the current active event subtype is via {\ttfamily \doxylink{classsf_1_1Event_a9b697c801743a7891af6e1e84ab7e8c8}{sf\+::\+Event\+::get\+If}}. This member function returns the address of the event subtype struct if the event subtype matches the active event, otherwise it returns {\ttfamily nullptr}.

{\ttfamily \doxylink{classsf_1_1Event_a40df10cc639742089960c7dbe9144343}{sf\+::\+Event\+::is}} is used to check the active event subtype without actually reading any of the corresponding event data.
