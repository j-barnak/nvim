Callback for finding one or more symbols.

The callback should perform a symbol lookup based on the flags given in {\ttfamily flags}. When multiple flags are provided, the effect should be treated as a logical AND. Symbol results should be added to the result builder {\ttfamily builder}, via \doxylink{group__Programs_ga989ec61d4ea214979af8c7747b162c4a}{drgn\+\_\+symbol\+\_\+result\+\_\+builder\+\_\+add()}. When \doxylink{group__Programs_gga68a2d31672c92f6653ea1836a5de860dab362c2f2c3f86cb859eea1e70c78bc3c}{DRGN\+\_\+\+FIND\+\_\+\+SYMBOL\+\_\+\+ONE} is set, then the finding function should only return the single best symbol result, and short-\/circuit return.

When no symbol is found, simply do not add any result to the builder. No error should be returned in this case.
