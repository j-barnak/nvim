\doxysubsubsection{Detailed Description}
Object helpers.

Several helpers are provided for working with \doxylink{structdrgn__object}{drgn\+\_\+object}s.

Helpers which return a \doxylink{structdrgn__object}{drgn\+\_\+object} have the same calling convention\+: the result object is the first argument, which must be initialized and may be the same as the input object argument; the result is only modified if the helper succeeds.
