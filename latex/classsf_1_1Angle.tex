\doxysubsection{Detailed Description}
Represents an angle value. 

{\ttfamily \doxylink{classsf_1_1Angle}{sf\+::\+Angle}} encapsulates an angle value in a flexible way. It allows for defining an angle value either as a number of degrees or radians. It also works the other way around. You can read an angle value as either a number of degrees or radians.

By using such a flexible interface, the API doesn\textquotesingle{}t impose any fixed type or unit for angle values and lets the user choose their own preferred representation.

\doxylink{classsf_1_1Angle}{Angle} values support the usual mathematical operations. You can add or subtract two angles, multiply or divide an angle by a number, compare two angles, etc.
