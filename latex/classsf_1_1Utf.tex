{\ttfamily \doxylink{classsf_1_1Utf}{sf\+::\+Utf}} is a low-\/level, generic interface for counting, iterating, encoding and decoding Unicode characters and strings. It is able to handle ANSI, wide, latin-\/1, UTF-\/8, UTF-\/16 and UTF-\/32 encodings.
