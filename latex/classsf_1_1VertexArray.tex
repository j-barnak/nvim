\doxysubsection{Detailed Description}
Set of one or more 2D primitives. 

{\ttfamily \doxylink{classsf_1_1VertexArray}{sf\+::\+Vertex\+Array}} is a very simple wrapper around a dynamic array of vertices and a primitives type.

It inherits {\ttfamily \doxylink{classsf_1_1Drawable}{sf\+::\+Drawable}}, but unlike other drawables it is not transformable.
