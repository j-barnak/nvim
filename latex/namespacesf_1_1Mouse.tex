\doxysubsection{Detailed Description}
Give access to the real-\/time state of the mouse. 

{\ttfamily \doxylink{namespacesf_1_1Mouse}{sf\+::\+Mouse}} provides an interface to the state of the mouse. A single mouse is assumed.

This namespace allows users to query the mouse state at any time and directly, without having to deal with a window and its events. Compared to the {\ttfamily Mouse\+Moved}, {\ttfamily Mouse\+Button\+Pressed} and {\ttfamily Mouse\+Button\+Released} events, {\ttfamily \doxylink{namespacesf_1_1Mouse}{sf\+::\+Mouse}} can retrieve the state of the cursor and the buttons at any time (you don\textquotesingle{}t need to store and update a boolean on your side in order to know if a button is pressed or released), and you always get the real state of the mouse, even if it is moved, pressed or released when your window is out of focus and no event is triggered.

The {\ttfamily set\+Position} and {\ttfamily get\+Position} functions can be used to change or retrieve the current position of the mouse pointer. There are two versions\+: one that operates in global coordinates (relative to the desktop) and one that operates in window coordinates (relative to a specific window).
