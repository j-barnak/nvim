\doxysubsection{Detailed Description}
Objects in a program.

A \doxylink{structdrgn__object}{drgn\+\_\+object} represents an object (e.\+g., variable, constant, or function) in a program.

Various operators and helpers are defined on objects; see \doxylink{group__ObjectOperators}{Operators} and \doxylink{group__ObjectHelpers}{Helpers}.

Many operations are language-\/specific. C is currently the only supported language.

In drgn\textquotesingle{}s emulation of C\+:


\begin{DoxyItemize}
\item Signed and unsigned integer arithmetic is reduced modulo 2\texorpdfstring{$^\wedge$}{\string^}width.
\item Integer division truncates towards zero.
\item Modulo has the sign of the dividend.
\item Division or modulo by 0 returns an error.
\item Shifts are reduced modulo 2\texorpdfstring{$^\wedge$}{\string^}width. In particular, a shift by a value greater than the width returns 0.
\item Shifts by a negative number return an error.
\item Bitwise operators on signed integers act on the two\textquotesingle{}s complement representation.
\item Pointer arithmetic is supported.
\item Integer literal have the first type of {\ttfamily int}, {\ttfamily long}, {\ttfamily long long}, and {\ttfamily unsigned long long} which can represent the value.
\item Boolean literals have type {\ttfamily int} ({\bfseries{not}} {\ttfamily \+\_\+\+Bool}).
\item Floating-\/point literals have type {\ttfamily double}. 
\end{DoxyItemize}
