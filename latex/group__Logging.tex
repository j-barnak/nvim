\doxysubsection{Detailed Description}
Logging configuration.

drgn can log to a file (\doxylink{group__Logging_ga93f02e713d5735873c447625202e90b7}{drgn\+\_\+program\+\_\+set\+\_\+log\+\_\+file()}) or an arbitrary callback (\doxylink{group__Logging_gace9a34dd985adc45757157d95ef2e98b}{drgn\+\_\+program\+\_\+set\+\_\+log\+\_\+callback()}). Messages can be filtered based on the log level (\doxylink{group__Logging_ga0c7f0bbc02c4a8515efa90213dbe913b}{drgn\+\_\+program\+\_\+set\+\_\+log\+\_\+level()}).

By default, the log file is set to {\ttfamily stderr} and the log level is \doxylink{group__Logging_ga164347a257efe763454b7aa52b88c011}{DRGN\+\_\+\+LOG\+\_\+\+NONE}, so logging is disabled.

Additionally, drgn can display a progress bar for some operations, like downloading debugging information. By default, progress bars are displayed on standard error if standard error is a terminal, the log file is set to {\ttfamily stderr}, and the log level is less than or equal to \doxylink{group__Logging_ggac1399b9efea54691c398494738906c83a6ad988e5dc9e97a09fdcbf4bc720cca9}{DRGN\+\_\+\+LOG\+\_\+\+WARNING}, but this can be changed (\doxylink{group__Logging_ga68f736036cb478a4bbbfe9c01918f72b}{drgn\+\_\+program\+\_\+set\+\_\+progress\+\_\+file()}).
