\doxysubsection{Detailed Description}
Utility string class that automatically handles conversions between types and encodings. 

{\ttfamily \doxylink{classsf_1_1String}{sf\+::\+String}} is a utility string class defined mainly for convenience. It is a Unicode string (implemented using UTF-\/32), thus it can store any character in the world (European, Chinese, Arabic, Hebrew, etc.).

It automatically handles conversions from/to ANSI and wide strings, so that you can work with standard string classes and still be compatible with functions taking a {\ttfamily \doxylink{classsf_1_1String}{sf\+::\+String}}.

{\ttfamily \doxylink{classsf_1_1String}{sf\+::\+String}} defines the most important functions of the standard {\ttfamily std\+::string} class\+: removing, random access, iterating, appending, comparing, etc. However it is a simple class provided for convenience, and you may have to consider using a more optimized class if your program requires complex string handling. The automatic conversion functions will then take care of converting your string to {\ttfamily \doxylink{classsf_1_1String}{sf\+::\+String}} whenever SFML requires it.

Please note that SFML also defines a low-\/level, generic interface for Unicode handling, see the {\ttfamily \doxylink{classsf_1_1Utf}{sf\+::\+Utf}} classes.

Check if the position before a character is a grapheme boundary. 

When manipulating unicode strings, removing single codepoints does not always make sense since they might be a part of a grapheme composed of multiple codepoints. In the case of a text editor, it is more intuitive to the user if entire graphemes are removed when e.\+g. delete or backspace is pressed rather than single codepoints. For this reason, the visual caret that marks the insertion/deletion point should only be positioned at a grapheme boundaries.
