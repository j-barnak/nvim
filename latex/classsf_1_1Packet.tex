\doxysubsection{Detailed Description}
Utility class to build blocks of data to transfer over the network. 

Packets provide a safe and easy way to serialize data, in order to send it over the network using sockets ({\ttfamily \doxylink{classsf_1_1TcpSocket}{sf\+::\+Tcp\+Socket}}, {\ttfamily \doxylink{classsf_1_1UdpSocket}{sf\+::\+Udp\+Socket}}).

Packets solve 2 fundamental problems that arise when transferring data over the network\+: \begin{DoxyItemize}
\item data is interpreted correctly according to the endianness \item the bounds of the packet are preserved (one send == one receive)\end{DoxyItemize}
The {\ttfamily \doxylink{classsf_1_1Packet}{sf\+::\+Packet}} class provides both input and output modes. It is designed to follow the behavior of standard C++ streams, using operators \texorpdfstring{$>$}{>}\texorpdfstring{$>$}{>} and \texorpdfstring{$<$}{<}\texorpdfstring{$<$}{<} to extract and insert data.

It is recommended to use only fixed-\/size types (like {\ttfamily std\+::int32\+\_\+t}, etc.), to avoid possible differences between the sender and the receiver. Indeed, the native C++ types may have different sizes on two platforms and your data may be corrupted if that happens.

Packets have built-\/in {\ttfamily operator\texorpdfstring{$>$}{>}\texorpdfstring{$>$}{>}} and \texorpdfstring{$<$}{<}\texorpdfstring{$<$}{<} overloads for standard types\+: \begin{DoxyItemize}
\item {\ttfamily bool} \item fixed-\/size integer types ({\ttfamily int\mbox{[}8\texorpdfstring{$\vert$}{|}16\texorpdfstring{$\vert$}{|}32\mbox{]}\+\_\+t}, {\ttfamily uint\mbox{[}8\texorpdfstring{$\vert$}{|}16\texorpdfstring{$\vert$}{|}32\mbox{]}\+\_\+t}) \item floating point numbers ({\ttfamily float}, {\ttfamily double}) \item string types ({\ttfamily char\texorpdfstring{$\ast$}{*}}, {\ttfamily wchar\+\_\+t\texorpdfstring{$\ast$}{*}}, {\ttfamily std\+::string}, {\ttfamily std\+::wstring}, {\ttfamily \doxylink{classsf_1_1String}{sf\+::\+String}})\end{DoxyItemize}
Like standard streams, it is also possible to define your own overloads of operators \texorpdfstring{$>$}{>}\texorpdfstring{$>$}{>} and \texorpdfstring{$<$}{<}\texorpdfstring{$<$}{<} in order to handle your custom types.
