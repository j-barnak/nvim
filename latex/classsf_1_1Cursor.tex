\doxysubsection{Detailed Description}
\doxylink{classsf_1_1Cursor}{Cursor} defines the appearance of a system cursor. 

\begin{DoxyWarning}{Warning}
Features related to \doxylink{classsf_1_1Cursor}{Cursor} are not supported on i\+OS and Android.
\end{DoxyWarning}
This class abstracts the operating system resources associated with either a native system cursor or a custom cursor.

After loading the cursor graphical appearance with either {\ttfamily \doxylink{classsf_1_1Cursor_a93aa2dfcc8c4f27513c6632153521fa7}{create\+From\+Pixels()}} or {\ttfamily \doxylink{classsf_1_1Cursor_a3385d2f53bc5b3b296f0409f79a57116}{create\+From\+System()}}, the cursor can be changed with {\ttfamily \doxylink{classsf_1_1WindowBase_a07487a3c7e04472b19e96d3a602213ec}{sf\+::\+Window\+Base\+::set\+Mouse\+Cursor()}}.

The behavior is undefined if the cursor is destroyed while in use by the window.

Usage example\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{sf::Window\ window;}
\DoxyCodeLine{}
\DoxyCodeLine{\textcolor{comment}{//\ ...\ create\ window\ as\ usual\ ...}}
\DoxyCodeLine{}
\DoxyCodeLine{\textcolor{keyword}{const}\ \textcolor{keyword}{auto}\ cursor\ =\ \mbox{\hyperlink{classsf_1_1Cursor_a3385d2f53bc5b3b296f0409f79a57116}{sf::Cursor::createFromSystem}}(\mbox{\hyperlink{classsf_1_1Cursor_ab9ab152aec1f8a4955e34ccae08f930aaa78b1ac16c0cd02168097fc9a9bd7604}{sf::Cursor::Type::Hand}}).value();}
\DoxyCodeLine{window.\mbox{\hyperlink{classsf_1_1WindowBase_a07487a3c7e04472b19e96d3a602213ec}{setMouseCursor}}(cursor);}

\end{DoxyCode}

Construct a cursor with the provided image. 

{\ttfamily pixels} must be an array of {\ttfamily size} pixels in 32-\/bit RGBA format. If not, this will cause undefined behavior.

If {\ttfamily pixels} is {\ttfamily nullptr} or either of {\ttfamily size}\textquotesingle{}s properties are 0, the current cursor is left unchanged and the function will return {\ttfamily false}.

In addition to specifying the pixel data, you can also specify the location of the hotspot of the cursor. The hotspot is the pixel coordinate within the cursor image which will be located exactly where the mouse pointer position is. Any mouse actions that are performed will return the window/screen location of the hotspot.

\begin{DoxyWarning}{Warning}
On Unix platforms which do not support colored cursors, the pixels are mapped into a monochrome bitmap\+: pixels with an alpha channel to 0 are transparent, black if the RGB channel are close to zero, and white otherwise.
\end{DoxyWarning}
