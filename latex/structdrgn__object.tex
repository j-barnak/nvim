\doxysubsection{Detailed Description}
Object in a program.

A \doxylink{structdrgn__object}{drgn\+\_\+object} represents a symbol or value in a program. It can be in the memory of the program (a "{}reference"{}), a temporary computed value (a "{}value"{}), or "{}absent"{}.

A \doxylink{structdrgn__object}{drgn\+\_\+object} must be initialized with \doxylink{group__Objects_ga68599751fce0e5dc73afd058cba00562}{drgn\+\_\+object\+\_\+init()} before it is used. It can then be set and otherwise changed repeatedly. When the object is no longer needed, it must be deinitialized \doxylink{group__Objects_ga77f5752cb20419e957cccc541ef8e027}{drgn\+\_\+object\+\_\+deinit()}.

It is more effecient to initialize an object once and reuse it rather than creating a new one repeatedly (e.\+g., in a loop).

Members of a \doxylink{structdrgn__object}{drgn\+\_\+object} should not be modified except through the provided functions.
