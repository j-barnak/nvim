\doxysubsection{Detailed Description}
Android, chrono-\/compatible, suspend-\/aware clock. 

Linux steady clock is represented by {\ttfamily CLOCK\+\_\+\+MONOTONIC}. However, this implementation does not work properly for long-\/running clocks that work in the background when the system is suspended.

{\ttfamily \doxylink{structsf_1_1SuspendAwareClock}{Suspend\+Aware\+Clock}} uses {\ttfamily CLOCK\+\_\+\+BOOTTIME} which is identical to {\ttfamily CLOCK\+\_\+\+MONOTONIC}, except that it also includes any time that the system is suspended.

Note\+: In most cases, {\ttfamily CLOCK\+\_\+\+MONOTONIC} is a better choice. Make sure this implementation is required for your use case.
