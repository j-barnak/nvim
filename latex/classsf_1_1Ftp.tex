\doxysubsection{Detailed Description}
A FTP client. 

\begin{DoxyRefDesc}{Deprecated}
\item[\mbox{\hyperlink{deprecated__deprecated000003}{Deprecated}}]Use {\ttfamily \doxylink{classsf_1_1Sftp}{sf\+::\+Sftp}} if possible.\end{DoxyRefDesc}


{\ttfamily \doxylink{classsf_1_1Ftp}{sf\+::\+Ftp}} is a very simple FTP client that allows you to communicate with a FTP server. The FTP protocol allows you to manipulate a remote file system (list files, upload, download, create, remove, ...).

Using the FTP client consists of 4 parts\+: \begin{DoxyItemize}
\item Connecting to the FTP server \item Logging in (either as a registered user or anonymously) \item Sending commands to the server \item Disconnecting (this part can be done implicitly by the destructor)\end{DoxyItemize}
Every command returns a FTP response, which contains the status code as well as a message from the server. Some commands such as {\ttfamily \doxylink{classsf_1_1Ftp_a79c654fcdd0c81e68c4fa29af3b45e0c}{get\+Working\+Directory()}} and {\ttfamily \doxylink{classsf_1_1Ftp_a8f37258e461fcb9e2a0655e9df0be4a0}{get\+Directory\+Listing()}} return additional data, and use a class derived from {\ttfamily \doxylink{classsf_1_1Ftp_1_1Response}{sf\+::\+Ftp\+::\+Response}} to provide this data. The most often used commands are directly provided as member functions, but it is also possible to use specific commands with the {\ttfamily \doxylink{classsf_1_1Ftp_a44e095103ecbce175a33eaf0820440ff}{send\+Command()}} function.

Note that response statuses \texorpdfstring{$>$}{>}= 1000 are not part of the FTP standard, they are generated by SFML when an internal error occurs.

All commands, especially upload and download, may take some time to complete. This is important to know if you don\textquotesingle{}t want to block your application while the server is completing the task.

\mbox{\hyperlink{classsf_1_1Ftp_1_1Response}{Response}} sf\+::\+Ftp\+::connect (\begin{DoxyParamCaption}\item[{\mbox{\hyperlink{classsf_1_1IpAddress}{Ip\+Address}}}]{server}{, }\item[{unsigned short}]{port}{ = {\ttfamily 21}, }\item[{\mbox{\hyperlink{classsf_1_1Time}{Time}}}]{timeout}{ = {\ttfamily \mbox{\hyperlink{classsf_1_1Time_aef6391d0179a715bafec67d62ca3e32f}{Time\+::\+Zero}}}}\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [nodiscard]}}



Connect to the specified FTP server. 

The port has a default value of 21, which is the standard port used by the FTP protocol. You shouldn\textquotesingle{}t use a different value, unless you really know what you do. This function tries to connect to the server so it may take a while to complete, especially if the server is not reachable. To avoid blocking your application for too long, you can use a timeout. The default value, {\ttfamily \doxylink{classsf_1_1Time_aef6391d0179a715bafec67d62ca3e32f}{Time\+::\+Zero}}, means that the system timeout will be used (which is usually pretty long).
