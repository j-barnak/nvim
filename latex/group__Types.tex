\doxysubsection{Detailed Description}
Type descriptors.

Types in a program are represented by \doxylink{structdrgn__type}{drgn\+\_\+type}.

Type descriptors have various fields depending on the kind of type. For each field {\ttfamily foo}, there is a {\ttfamily drgn\+\_\+type\+\_\+kind\+\_\+has\+\_\+foo()} helper which returns whether the given kind of type has the field {\ttfamily foo}; a {\ttfamily drgn\+\_\+type\+\_\+has\+\_\+foo()} helper which does the same but takes a type; and a {\ttfamily drgn\+\_\+type\+\_\+foo()} helper which returns the field. For members, enumerators, parameters, and template parameters, there is also a {\ttfamily drgn\+\_\+type\+\_\+num\+\_\+foo()} helper.
